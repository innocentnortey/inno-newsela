# Newsela Lesson Studio

A hiring-partner project for Newsela, via Gauntlet AI. It bulk-generates standards-aligned ~50-minute ELA/ELD lessons
from an uploaded unit-outline sheet, stores them, and gives staff reviewers a collaborative editor with AI assists and
an approval workflow.

- Project entry and boundaries: [`CLAUDE.md`](CLAUDE.md)
- Where the project is: [`PROJECT-CHECKLIST.md`](PROJECT-CHECKLIST.md)
- Requirements: [`docs/prd/newsela-prd.md`](docs/prd/newsela-prd.md)
- How the run is operated on the VPS: [`ops/vps-run/README.md`](ops/vps-run/README.md)

All test, eval and demo data is synthetic.
