D2 · Night Desk · dark-first

A focused workbench for experts who live in it all day.

This is a static look; linked-screen prototypes come only for the directions you shortlist. Nothing here is clickable. Night Desk is dark-first: the four desktop mockups below are drawn on its dark palette (the primary theme), and M3 is repeated in the light twin. Same four screens and the same words as the other directions' sheets (LOOK_SHEET_COPY.md), so only the look changes. People's names and counts are synthetic.

Softnesshard: 6 px radius, hairlines, no shadow
Densitydense: 32 px rows, grouped lists
Shaperows, groups, tabs, mono IDs
Temperaturecool graphite + signal green
Typesystem grotesk + monospace IDs and numbers

Mockups, dark (the primary theme)

Desktop width, about 1200 × 760. Status is always a glyph shape plus a word: dashed ring = Draft, half-filled ring = In review, three-quarter ring = Submitted, filled check = Approved, filled cross = Failed or error, octagon = blocking, triangle = warning. Red appears only on what blocks; signal green only on the one primary action and on passed checks. On a narrow screen, scroll each frame sideways.

Palette (proposal; UX-3 makes it exact)

The six base tokens per mode (ground, panel, well, ink, ink2, primary) are the DESIGN-DIRECTIONS.md values, unchanged. The rest are added for this construction: rail and side for the navigation, selected, hair (decorative row dividers, not a control edge, so not checked), edge (control borders, checked at 3:1), status hues for glyphs, and the diff tints. Contrast is computed from these hex values with the WCAG formula; the build fails if any text pair is under 4.5:1 or any UI part under 3:1.
