The story so far

Newsela is entering California's core English classes. It needs about 180 lessons a grade, in its own lesson shape, good enough for state reviewers. Its staff write them from a unit outline, a spreadsheet with one row per day.

Stage 1 found that writing drafts is not the slow part. Proving each draft is right is. So our main number is reviewer minutes per approved lesson. Stage 2 worked five rows of the Grade 6 Unit 4 sheet by hand: four real ones and one cleaned copy. Stage 3 turned every hard spot into a card, and you approved the PRD at Stage 4.

This page is the first UX step. It answers one question: who does what, on which screen, and what does each screen need from the backend? Three people use the tool. An author turns the sheet into draft lessons. A reviewer fixes and submits each lesson. An approver signs off one frozen version at a time.

8 · Small choices the PRD left open

Planning hit ten spots the PRD does not settle. Each one takes the option closest to the PRD and the hard-problem cards. None changes a requirement. If you want any of them different, say so and UX-1 reopens.

UXP-1 Proposal

A lesson moves into review when a reviewer first opens it. The PRD names the move but not its trigger.

UXP-2 Proposal

A link to another lesson blocks in two steps. Empty slot: Lesson 4 can't be submitted. Filled slot: only its sign-off waits for Lesson 5. Both lessons get reviewed side by side.

UXP-3 Proposal

No regenerate or AI rewrite on a frozen or signed-off lesson. Withdraw or reopen first.

UXP-4 Proposal

Only an approver reopens a signed-off lesson. Reopening undoes a sign-off.

UXP-5 Proposal

A run that hits its cap stays stopped. Finish with a new run on the rows left.

UXP-6 Proposal

Send-back tags match the checklist items. One set of words for both.

UXP-7 Proposal

If the editor drops its connection, Submit waits. Submit freezes what the server holds.

UXP-8 Proposal

A run with every lesson ready is called complete. The PRD names the other endings only.

UXP-9 Proposal

A Units home screen, even with one unit. It lists outline versions and runs.

UXP-10 Proposal

Withdrawing needs no reason. It changes no content.
