Direction D3Soft Studio

A friendly team space that makes review feel shared.

A static look: four screens drawn in D3’s construction so you can judge its colour and feel in a minute. Nothing is clickable. Linked-screen prototypes come only for the directions you shortlist. Same four screens and the same words on every direction’s sheet (docs/ux/02-concepts/LOOK_SHEET_COPY.md); people’s names and the counts are synthetic. The one line added here is M2’s greeting.

Softness
Very soft: 16–20 px radius, soft shadows, full pills
Density
Airy: big cards, open spacing
Shape
Cards, pills, three panes
Temperature
Cool pastel periwinkle + indigo
Type
Rounded sans: the system rounded face in Safari; in Chrome, headings fall back to Arial Rounded and body to the system sans

Mockups, light (the primary theme)

Desktop frames at 1200 px wide; on a narrow screen each frame scrolls sideways inside its own box. Status always carries a word and a shape (dotted ring = draft, half-filled = in review, arrow = submitted, tick = approved, ! = blocking, triangle = advisory or warning, cross = failed), never colour alone. Red is kept for what blocks Generate, Submit or Approve.

Contrast is computed in the generator from these hex values with the WCAG formula; the build exits with an error if a text pair is under 4.5:1 or a UI part under 3:1.
