D1 · Clear Ledger

The lesson is a document on a desk; the tool is a quiet editor's frame around it.

A static look; linked-screen prototypes come only for the directions you shortlist. Nothing below is clickable. The four screens and every word on them are the same on all four direction sheets (docs/ux/02-concepts/LOOK_SHEET_COPY.md); only the look changes. Names and numbers marked synthetic there are made up.

Softnessmedium: 8 px radius, hairline borders, one soft page shadow
Densityairy: generous margins, reading width about 70 characters
Shapepage sheet, top stepper, right rail
Temperaturecool neutral white with ink blue
Typecrisp grotesk, large calm headings

Four screens in light mode (the primary theme)

Drawn at desktop width, 1200 × 760. On a narrow window each frame scrolls sideways inside its own box. Construction: a white page sheet on a cool grey desk, the five-step stepper with filled dots, tinted banners with an icon tile, light-ruled tables, the Issues · Standards rail, ink blue for the one primary action. Status always carries a word and a shape: hollow circle draft, half circle in review, arrow submitted, check approved, triangle failed, octagon blocking.

Palette (proposal; UX-3 makes it exact)

Ground, panel, well, ink, ink2 and primary are the D1 values in DESIGN-DIRECTIONS.md; the rest are added here. Contrast is computed from these hex values by the generator with the WCAG 2 formula, and the build stops if any text pair is under 4.5:1 or any meaningful UI part under 3:1. Lowest text pair: light ink3 on disabled 4.83:1; dark ink3 on disabled 5.20:1. Hairlines (hair) are decoration only; every control that needs an edge to be seen uses edge, and secondary buttons are identified by their label.
