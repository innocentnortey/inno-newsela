## 1. What to build
Page `/units/:unitKey/coverage`. `PageHeader` eyebrow "Unit", title (`h1`) "Coverage" (copy.ts `COPY.title`), meta = same `unitLabel(unitKey)` as export-screen ("Grade 6 · Unit 4"). Parts:
1. **Matrix** `Table` (caption "Coverage matrix", kit `Table` already gives the own-box horizontal scroll region, `role="region"`, `tabIndex=0`). `Thead`: first `Th` (scope col) "Standard", then one `Th scope="col"` per lesson, ordered by `number` ascending (null last, stable by `lesson_id`), text `Lesson {number}`; if `number` is null use `lessonLabel(lesson_id)` (id suffix). The header text is a `Link` to `/units/${unitKey}/lessons/${lessonKey}` when `lessonKeyFromId(lesson_id)` (`@/lib/keys`) returns a key (checked: `app/(app)/units/[unitKey]/lessons/[lessonKey]` exists); read-only navigation, not an edit control.
2. **Rows** = `standards` in returned order. Row header is `Th scope="row"` (sticky, see below) holding `CodeChip` with `code` and, beside it, `official_text` exactly as returned (GR-5: never the sheet's label, never truncated, trimmed or re-cased by us). For `never_assessed === true` (the server flag; never recompute from cells) add under the text a `<span className="text-warn inline-flex items-center gap-1"><Glyph shape="triangle-bang" className="text-warn shrink-0" /> Never assessed</span>`. The glyph is `aria-hidden` (kit); the words carry the meaning, so colour is never alone.
3. **Cell** (`Td`, one component `CoverageCell` in `cell.tsx`, props `{cell?: Cell; lessonLabel: string}`) for each standard × lesson. Look up by `${code}|${lesson_id}`; build the map once with `useMemo`. Never compute I/P/A, counts, or "never assessed" in the client.
   - With a cell: visible letters of `roles` in fixed order I, P, A joined by a thin space (`aria-hidden`), then a visible small text mark of who confirmed it (`aria-hidden`): `person` -> "Person", `judge_only` -> "Judge only", `generator_only` -> "Generator only". Then one `sr-only` span with the full words: `Introduced, Practised, Assessed` (only the roles present, joined by ", "), then ". Confirmed by a person." / ". Judge only, not confirmed by a person." / ". Generator only, not confirmed by a person.", then (CON-22 `source`) " From the approved version." / " From the working draft.". The cell's accessible name comes from this text content (role `cell`, name computed from content), so `getByRole("cell", {name: /Introduced.*Confirmed by a person/})` works.
   - No cell: visible "–" (`aria-hidden`) and sr-only "Not taught here.".
   - Choice recorded (ticket > DO-4 > DO-3): the visible mark is words, not a symbol set, so colour and shape are both unnecessary to read it; `source` is sr-only only (CON-22 says "marked per cell", SCR-18 does not show it).
4. **Sticky first column**: the `Th` of the header's first cell and each row `Th` get `sticky left-0 bg-panel` plus a right border `border-hair border-r` (tokens only); use `z-10` only if `tokens.css` `--z-sticky` is exposed as a utility (check `grep -rn "z-sticky\|z-10" src` first and copy whatever the kit uses; otherwise inline `style={{ zIndex: "var(--z-sticky)" }}`). The header's first `Th` needs the same sticky class and a higher index than body rows. Row `min-width` for the standard column: `min-w-[16rem]`; lesson columns `min-w-[7rem]`. Because `Table`'s `Th` forces classes via `cn`, pass the extra classes through its `className` prop.
5. `?standard=<code>` : the row whose `code` equals the param gets `aria-current="true"`, `bg-well` on its cells, and `scrollIntoView({block:"center"})` in a `useEffect` (guard `typeof el.scrollIntoView === "function"`). Unknown or absent value ignored silently. Needs `useSearchParams`, so `page.tsx` wraps in `Suspense` exactly as the export page.
6. **States** (read-only for every role; no `useSession` role branch, no `can()`):
   - loading: `<div aria-busy="true"><span className="sr-only">Loading coverage</span><div aria-hidden className="bg-well h-28 animate-pulse rounded-xl" /></div>` (same as export). A real skeleton of a few rows is allowed but keep it token-only.
   - empty: `lessons.length === 0` -> `<p>No lessons yet</p>` (`COPY.empty`, exact string "No lessons yet"). If lessons exist but `standards.length === 0` -> "No standards linked yet." (`COPY.noStandards`; choice, CON-22 has no wording).
   - error: any failure other than `NOT_FOUND` (incl. `NETWORK`, `ROLE_FORBIDDEN`, 503) -> shared `<CantLoad thing="coverage" onRetry={retry} />` ("Couldn't load coverage…" + **Retry**). `NOT_FOUND` -> shared `<NotFound what="unit" boardHref={`/units/${unitKey}/board`} where={unitLabel(unitKey)} />`.
   - Read once: one `GET` on mount and on `retry`; no `usePoll`, no refetch timer.
7. **Gate (cut #4)**: `CoverageGate({fired = FIRED_CUTS, children})`: `fired.includes(4)` -> `<NotFound what="page" />` else children; `CoverageScreen` wraps itself in it (copy of `export-gate.tsx` with 5 -> 4). The board's `links-row.tsx` already pushes `{label:"Coverage", href:/units/${unitKey}/coverage, cut: 4}` and filters on `FIRED_CUTS`, and `NAV_ENTRIES` (nav.ts) has no coverage entry, so "no nav entry when the flag is off" holds with no edit; do not edit either file.
8. **Must not**: compute coverage client-side, offer any edit/confirm/link control (confirming happens on SCR-9), use colour alone for I/P/A or confirmation, use raw colour literals, render HTML from data (React text only), or show the sheet's label for a standard.

## 7. Risks
1. Sticky + overflow: the kit `Table` wrapper is `overflow-x-auto`; `position: sticky` works against that box only if no ancestor between the `th` and the wrapper sets `overflow`. Keep `Th`/`Td` as direct children of `Tr`; do not wrap cells in a scroll div. Sticky cells need an opaque `bg-panel` or rows show through.
2. Accessible name of a `td`: it comes from content, so keep the visible letters `aria-hidden` and put the words in `sr-only` text (do not use `aria-label` on a `td`; axe `aria-allowed-attr`/names are unreliable there).
3. Dark theme: `text-warn` and `bg-well` are tokens with dark values; verify the warning row in the dark axe run (contrast).
4. `apiGlob` also matches page navigations, so keep `?view=1` on `COVERAGE_URL`.
5. Effects run twice in dev: the `alive` ref pattern from `use-exports.ts` prevents setting state after unmount; the matrix GET is idempotent so a double call is harmless.
6. `official_text` can be long: let it wrap (`whitespace-normal`), never `truncate` (GR-5 shows the text only as returned).
