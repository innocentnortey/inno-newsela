## 5. Behaviour (steps for the implementer)
1. **Load unit.** `LOAD_UNIT_ID = "G6.U9"`, lesson ids `G6.U9.L9<NN>` (`L901…`), title `"Synthetic load lesson"`, `state: "in_review"`. Seed exactly like `apps/web/e2e/integration/con-12/seed.ts` (insert `lesson` row with `insert_row` from `@ls/db/testing/insert-row`, then `PgLessonDocStore.seed_initial(lessonId, {...wp1, lesson_id}, SYSTEM_ACTOR, tx)`; fixture `packages/ydoc/tests/fixtures/stored-wp1.json`, read with `readFileSync` relative to `import.meta.url`). Idempotent: skip a lesson id that already exists. Guard `assert_load_lesson(id)`: throws `NotLoadLesson` (new class in `yjs-support.ts`) unless the id starts with `G6.U9.L9`; called before every socket open and every seed. If `G6.U9` collides with a real unit in the demo seed (`grep -n "G6.U9" ops/ docs/design` shows none expected) choose the next free `G6.U<n>` and say so in the devlog.
2. **Editors.** `opts.socket_editors` = number of simulated editors; lessons = `ceil(editors / editors_per_lesson)`; editor `i` goes to lesson `floor(i / editors_per_lesson)`. One synthetic reviewer per editor: `app_user` row (`role: "reviewer"`, `synthetic: true`, email `load-rev-<run_tag>-<i>@example.test`, name `Synthetic load reviewer <i>`) and a session: random 32-byte token, `PgSessionRepo.create_session(user_id, sha256hex(token), expires_at = now+2h, tx)` (`packages/db/src/repos/sessions.ts`, `app_session` table). The token is sent only as `Cookie: ls_session=<token>` (cookie name from `SESSION_COOKIE_NAME`, default `ls_session`) and is never logged. Afterwards delete the `app_session` rows it created (users stay, they are synthetic).
3. **Client.** One `HocuspocusProvider` per editor: `url: opts.collab_url`, `name: "lesson:<id>"`, `token: "cookie"`, `WebSocketPolyfill` = a `WebSocket` subclass that adds the cookie header and records each created socket (needed for forced drops), `onStateless` parses `stored` / `refused` / `mode`. Ramp: editor `i` connects at `i * ramp_s / editors` seconds; typing starts when `synced`; plateau lasts `plateau_s` after the last editor is synced.
4. **Typing.** `max(1, ceil(typing_share * editors_on_lesson))` typers per lesson, one update every `interval_ms`. An edit appends the token `make_token(editor_id, seq)` as a text node inside the first paragraph of section fragment `section:<first address>` (inspect `doc.getArray("section_order")`; fragment shape per `packages/ydoc/src/convert.ts`, `prosemirrorJSONToYXmlFragment`); use one `doc.transact`. Record `sent[token] = {t0: performance.now(), clock}` where `clock = Y.decodeStateVector(Y.encodeStateVector(doc)).get(doc.clientID)` after the transact.
5. **Remote-edit-visible.** Every other editor on that lesson runs `fragment.observeDeep` and on each event checks `fragment.toString().includes(token)` for tokens not yet seen by it; first sighting `t1 - t0` goes to `remote_samples`. Same process, same clock, so no skew.
6. **Stored.** On a `stored` stateless message (`{type, content_hash, state_vector(base64), stored_at}`), decode `state_vector` with `Y.decodeStateVector(Buffer.from(sv, "base64"))`; every unacknowledged token of that sender with `clock <= decoded.get(sender.doc.clientID)` becomes acknowledged, sample `now - t0` goes to `stored_samples`. A refused message (`LESSON_LOCKED`) counts as a socket error and its tokens are never "acknowledged".
7. **Forced drops (M-24).** Once, mid-plateau, close `max(1, ceil(drop_share * editors))` sockets (`ws.close(4000)` on the recorded instance; not `provider.destroy()`). The provider reconnects by itself; **keep typing while down** (edits are held and resent by Yjs). Reconnect time = drop → `onSynced` fires again and `provider.awareness.getStates().size >= editors_on_lesson` (presence restored); `reconnect_samples` in seconds. Timeout 30 s, counted as an error. These planned closes are NOT socket errors; only unplanned closes (`onClose` / `onDisconnect` with no pending planned drop for that socket) increment `socket_errors`. `sockets_opened` = initial opens + reconnect attempts.
8. **Finish.** Stop typing, wait up to `drain_ms` until every sent token is acknowledged (or the server is unreachable), then disconnect. **Lost updates:** read the latest `lesson_doc` row per load lesson over SQL (`select ydoc_bytes from lesson_doc where lesson_id=$1 order by seq desc limit 1`, `Y.applyUpdate` into a fresh doc, section text via `fragment.toString()` joined), then `count_lost(acknowledged_tokens_of_that_lesson, text)`. Also open one fresh provider per lesson and log (not count) whether the same tokens are visible after reload; a mismatch between the two logs `reload_mismatch=true`. **Duplicates:** `count_duplicates(all sent tokens, text)` goes to `YjsMixDetail.duplicates` and `p95_ms.duplicate_tokens` (AC-3: 0).
9. **Row.** `run_yjs_probe` builds the record and calls `deps.evidence.insert_probe_run(...)`:
   `kind: "yjs"`, `users: opts.users`, `duration_s: round(elapsed)`, `machine`, `provider_mode: "stub"`, `error_rate`, `lost_updates`, `event_loop_lag_p95_ms: 0`, `max_db_connections: 0` (the HTTP half owns these; documented in the devlog), `n: tokens sent`,
   `p95_ms: { remote_edit, stored, reconnect_p95_s, duplicate_tokens, unacknowledged, socket_errors, editors, lessons, incomplete, evidence: { git_sha, prompt_version: null, models: [], provider_mode: "stub" } }` (remote_edit and stored in ms, `reconnect_p95_s` in seconds, all numbers `percentile(.,95)`; `evidence` satisfies EV-R1 for a script that makes no model call). `lost_updates` is stored even when 0 (AC-6). `probe_run_id` comes from the returned id and is logged: `deps.log("wf=WF-30 probe_run_id=<id> kind=yjs users=… lost_updates=… incomplete=…")` (OBS-1, OBS-6). Mapping to DB column is the repo's job; do not touch `packages/db`.
10. **Incomplete / server down (AC-5).** If the collaboration server becomes unreachable (socket closes unplanned and does not return within the 30 s reconnect timeout, or the initial connect fails), stop typing, still write the row with `incomplete: true` and `error_rate > 0`, then return `exit_code: 1`. The row is written in a `finally` so a thrown error still leaves a row when any editor had connected. `exit_code` is also 1 when `lost_updates > 0` (a finding), 0 otherwise.
11. **Logging.** Only counts and ids. Never a cookie, token, lesson text or provider key. Lines go through `deps.log` (default `process.stdout.write`).
