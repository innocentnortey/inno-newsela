## 1. What to build
Page `/units/:unitKey/quality`. `PageHeader` eyebrow "Unit", title (`h1`) "Unit quality", meta = unit label (`unitLabel(unitKey)` pattern from run-summary `format.ts`; copy the tiny helper into `copy.ts`, do not import across features).
Order top to bottom, all from one `getUnitMetrics` response (no recomputation anywhere; every number is printed exactly as received):
1. **Reviewer context line** (`<p>`/`dl`, aria-label "Reviewer time context"): "Median {median_minutes} min · n = {north_star.n}" and `segment_label` verbatim when non-empty (this is the GR-15 label, e.g. "one reviewer, n = 3"). `median_minutes === 0` prints "0" (test `=== null`, never falsy); `null` prints nothing for the median. Aggregate only; no names.
2. **Tile groups** (`<section aria-labelledby>` each, headings "Draft quality (V)", "Operations and cost (O)", "Health (H)"): tiles grouped by the id prefix letter (`V-`, `O-`, `H-`), in response order within a group. A tile with an unknown prefix goes into a fourth group "Other" (never dropped). Tile = `label`, big value, unit, "n = {n}". Rules: `n === 0` or `value === null` -> no number at all, the text "No approved lessons yet" in the value slot, and still "n = 0"; `value === 0` with `n > 0` prints "0".
3. **Rating counts** (`Table`, caption "Draft-quality ratings"; rows "Usable as drafted", "Usable with edits", "Rewritten" with the three counts, then a footer line "n = {rating_counts.n}"). `rating_counts.n === 0` -> counts not shown, "No approved lessons yet".
4. **Seeded-error report** (`Table`, caption "Seeded-error report", sub-caption/visible label = `seeded_errors.label` verbatim, expected "our reviewers"): columns Planted, Caught (two numbers as received; no percentage, no rate). Row is keyed by a constant, never by a person.
5. **Empty state**: when `north_star.n === 0` (CON-10: no approved lesson yet) the whole body is replaced by "No approved lessons yet" (keep the h1).
6. **States**: loading (`aria-busy`, skeleton, sr-only "Loading unit quality"); `NOT_FOUND` -> shared `NotFound what="unit"`; any other failure incl. `NETWORK`/`SERVICE_BUSY` -> shared `CantLoad thing="unit quality"` with **Retry**; read-only (the screen has no controls other than Retry; no `can()` check because every role may read, UXQ-7); `quality === null` -> the server says cut #6 fired: render the same `NotFound what="page"` as the gate (decision below).
7. Must not: compute or derive any metric (no rates, sums, averages, sorting by value, ranking), show a name, claim a baseline (no "baseline", "target met", "improved", "vs"), or use raw HTML.

### Units for tiles (decision, ticket > DO-4 > DO-3)
The ticket says each tile shows value, unit and n, but CON-10 tile = `{id, value, n, label}` (no unit field). Use a static presentation table `TILE_UNITS` in `copy.ts` keyed by tile id from `docs/design/metrics-registry.md` (the registry's Unit column, wording only; it is a label, not a computation): `V-1` "%", `V-2` "%", `V-3` "%", `V-4` "(0–1)", `V-5` "%", `V-6` "%", `O-1` "USD per lesson", `O-2` "lessons per hour", `O-3` "days", `O-4` "%", `H-1` "%", `H-2` "minutes", `H-3` "% of cap", `H-4` "seconds", `H-5` "ms", `H-6` "seconds". An id not in the table shows no unit. Values print verbatim next to the unit; the screen never converts 0.6 to 60. If the real route (NL-104) returns fractions where the label says "%", that is a `CHG-N` on CON-10 raised by NL-104, not a fix here. Tile `label` is shown as received.
