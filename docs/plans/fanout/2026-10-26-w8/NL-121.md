## 5. Behaviour (steps)
1. Parse args; resolve `out_rel = "evals/local/held-out/" + clock.now().toISOString().slice(0, 10) + ".json"`.
2. **Refuse first**: `assert_output_ignored(repo_root, out_rel)`. On `RefusedPath`: `err("held-out report path is not ignored or is tracked; refusing to run")`, return 2. This happens before the restricted folder is touched (AC-3).
3. If the published dir does not exist: `err("published folder is missing")`, return 2 (AC-5). No path in the message.
4. `reader.lessons("G6.U4")`. For each generated lesson, `read_published(dir, number)`:
   - `ok` -> `compare_lesson`;
   - `missing` -> `lessons_no_published += 1` (case failure_category `no_published`);
   - `unreadable` -> `err(\`lesson ${number} unreadable\`)`, `lessons_unreadable += 1`, continue (AC-5). The message holds the integer and fixed words only.
5. Run the cases through `EvalRunner` (`evals/src/runner.ts`, unchanged) with `make_s11("stub", deps)` and `{ repeat: 1, provider_mode: "stub", git_sha, unit: "G6.U4" }`: this writes the `eval_run` row (counts only, git SHA), one `eval_case_result` per lesson, and the runner's own markdown report under `evals/local/reports/` (already ignored). Compute the comparison once (memoise) before the runner so each `score` just returns the stored result. Use `reports_dir: path.join(repo_root, "evals/local/reports")` explicitly.
6. `build_report(...)`; if `HeldoutEmpty` (nothing compared): `err("no lessons could be compared; nothing written")`, return 2. Else `HeldoutReport.parse(report)` (our own numbers, safe to parse), `mkdirSync(dirname, { recursive: true })`, `writeFileSync(out_abs, JSON.stringify(report, null, 2) + "\n", { mode: 0o600 })`. Same-day rerun overwrites.
7. `out(\`heldout compared=${n} type_match=${t} sequence_match=${s} eval_run_id=${id}\`)` (integers and the run id only). Return 0 regardless of the rates (measurement only).
8. Logging rule: the only things ever printed are integers, fixed words and the run id. No exception message from any file or JSON operation is printed: wrap, discard, replace with a fixed sentence. A top-level catch in `main` prints `"heldout failed (see exit code); no content printed"` and returns 2.
