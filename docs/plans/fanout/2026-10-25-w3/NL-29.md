# NL-29 plan: lesson/candidate job runner and nodes

Planner: Opus, 2026-10-25. Lane `lane::build-loop`, `risk::security` **no** (money and keys sit behind `PaidCaller` / `ModelCallRecorder`, NL-33/35; this ticket only asserts they are used). Ticket: `docs/plans/tickets/NL-29.md` (read it first; this plan resolves every judgement call in it).

## 1. Goal and sources

Deliver `LessonJobRunner` and its five nodes (`DraftNode`, `CompileCheckNode`, `RepairNode`, `StoreNode`, `FailNode`) in `apps/worker`: a claimed `lesson` or `candidate` job is drafted by one `PaidCaller` call (plus at most one truncation retry), compiled, checked, repaired at most once, then stored as numbered draft v1 (or a candidate) with full provenance, or failed with stated reasons. **Carry-in from NL-18:** `compile_draft` leaves `front_matter.standards = []`; `CompileCheckNode` fills it from the standards index (section 5, step 4) and recomputes `content_hash`.

Sources: DO-4 `docs/design/component-contracts.md` section 6 (lines 1813-1923), section 4 (1442-1560: `PaidCaller`, `ModelCallRecorder.checkpoint`, prompt inputs), section 3.4/3.5 ports; DO-3 section 2.4 and 7; CON-6, CON-16; PRD R-16, R-19; `docs/data/worked-pairs.md` WP-1, WP-2, WP-4; SP-1.

`LessonJobState.context` is `JobContext | null` (null until `DraftNode` builds it). Nodes mirror `draft_call` into `state.draft_call` too. `InvariantViolation` constructor: read `packages/core/src/errors.ts` line ~108 for its init shape before using it.

**Step 3. `nodes/draft-node.ts`.** `export class DraftNode { constructor(paid: PaidCallerPort, renderer: Pick<PromptRenderer,"render_lesson_draft">, outlines: OutlineRepo, runs: RunRepo, standards: StandardRepo, prompts: PromptRepo, settings: WorkerSettings, recorder: CheckpointPort); async run(state: JobState): Promise<JobState> }`. Steps:
1. `lesson_id = job.lesson_id`; null throws `InvariantViolation`.
2. `pinned = await runs.pinned_choices(job.run_id)`; `row_context = await outlines.row_context(job.outline_version_id, lesson_id, pinned)` (G-24: the run's pinned choices, not the version's).
3. codes = unique of `row.focus_codes, row.eld_codes, row.msls_codes`; `standards = await standards.texts(codes)`.
4. plan: `run = await runs.get(job.run_id)`; `plan_row = await runs.unit_plan(run?.parent_run_id ?? job.run_id)` (a candidate run reuses its parent's plan, R-8); `plan_entries` = entries whose `lesson_id` is the job's lesson or a neighbour's (`row_context.neighbours[].lesson_id`, non-null); `[]` when the plan is absent.
5. `prompt = await prompts.get(job.prompt_version_id)` (null throws `InvariantViolation`); `template = template_for(row.lesson_type)` (undefined throws `InvariantViolation`).
6. `rendered = renderer.render_lesson_draft({ prompt, context: row_context, plan_entries, standards, template, example_set_id: null, reviewer_note: job.reviewer_note })`. Never log `reviewer_note` or the rendered text.
7. Build state context `{ row_context, standards, calls: [], draft_call: null, draft_max_output_tokens: settings.draft_output_token_cap, raw_output: null, provider_error: null }`.
8. Draft call (a private `call(purpose, cap)` helper): `hit = await recorder.checkpoint(job.job_id, purpose, 1)`; if `hit` use it with **no call sent**; else `paid.call({ ctx: { run_id: job.run_id, lesson_id, job_id: job.job_id, attempt: 1, purpose, request_id: null, experiment_id: null, reservation_id: null }, req: { alias: "GENERATION", system_blocks: rendered.system_blocks, user_blocks: rendered.user_blocks, output_schema_name: "LessonDraft", output_json_schema: null, output_mode: "prompt_embedded", max_output_tokens: cap, timeout_ms: settings.model.model_call_timeout_ms, effort: settings.model.model_effort, temperature: null }, rendered, run_id: job.run_id, job_id: job.job_id, user_id: job.started_by })`. (`output_json_schema: null`: the schema is embedded in the rendered system block in `prompt_embedded` mode.) Wrap in `with_call`.
   - a. first call: purpose `"lesson_draft"`, cap `settings.draft_output_token_cap`.
   - b. `SpendRefused` -> `with_brake(state, brake_for(e))`, return with `raw_output null` (no repair, no row).
   - c. `ProviderError` -> `context.provider_error = e.kind`; if kind is `rate_limited` or `overloaded` also `with_brake("rate_limit_retries")`; return. Any other error (including `LeaseLost`) rethrows.
   - d. `stop_reason !== "max_tokens"` -> `raw_output = call.raw_output`, `draft_call = call`, done.
   - e. `stop_reason === "max_tokens"` -> second call purpose `"truncation_retry"`, ordinal 1, cap `settings.truncation_retry_token_cap`, same checks as b/c; `truncation_retries = 1` (this is **not** `repair_rounds`). If the retry is also `max_tokens` -> `with_brake("truncation_retry")`, `raw_output null`, return. Else `raw_output = retry.raw_output`, `draft_call = retry`, `draft_max_output_tokens = settings.truncation_retry_token_cap`.
   - On a requeue after a truncated stored draft, the checkpoint for `lesson_draft` returns the truncated call and the node continues to the `truncation_retry` checkpoint/call. No call is repeated.

**Step 4. `nodes/front-matter-standards.ts` (pure).** `export function build_front_matter_standards(row: NormalizedRow, rows: readonly StandardRow[]): Standard[]`. Order: `row.focus_codes` as role `"focus"`, then `row.msls_codes` as `"supporting"`, then `row.eld_codes` as `"eld"`; a code seen earlier is not repeated; each entry `{ code, role, origin: "outline", official_text: <matching StandardRow.text>, asserted_by: "outline", confirmation: null }`; a code with no `StandardRow` is skipped (intake and the `code_not_allowed`/`standard_*` checks own unknown codes). `row` here is the pinned-choices row from `row_context`. Test file: `front-matter-standards.test.ts` (order, de-duplication, missing code skipped, WP-1 row produces focus then eld).

**Step 5. `nodes/compile-check-node.ts`.** `export class CompileCheckNode { constructor(loader: CheckContextLoaderPort, rules: readonly CheckRule[], policy: CheckPolicy); async run(state: JobState): Promise<JobState> }`. Steps:
1. Reset `draft null, schema_issues [], compiled null, compile_error null, check_result null`. `raw = context.raw_output`; null throws `InvariantViolation` (the runner never calls this node on a fatal state).
2. `JSON.parse(raw)`; on throw `schema_issues = ["$"]`, return. Do not strip code fences or repair JSON (SP-1: prompt_embedded returns bare JSON; the repair is the retry).
3. `LessonDraft.safeParse`; on failure `schema_issues = issues.map(i => i.path.join(".") || "$")` (**paths only, never `message` or input text**), return with `draft null`. On success set `draft`.
4. `compiled = compile_draft(draft, { row: context.row_context.row, template: template_for(row.lesson_type)!, unit_id: job.unit_id, schema_version: job.schema_version })`. Catch either `CompileError` class -> `compile_error = e.message` (the message holds reason and address only); catch `RangeError` (ProseMirror `node.check()`) -> `compile_error = "COMPILE_ERROR: structure_invalid"`; return. Any other error rethrows. **Fill the carry-in:** `lesson = { ...compiled.lesson, front_matter: { ...compiled.lesson.front_matter, standards: build_front_matter_standards(row, context.standards) } }`; `compiled = { ...compiled, lesson, content_hash: content_hash(lesson) }` (the hash covers `front_matter`, so it MUST be recomputed; the stored `lesson_version.content_hash`, the `lesson_doc` and the checks all use this recomputed value).
5. `check_ctx = await loader.load(job.lesson_id, compiled.lesson, compiled.content_hash)`; `check_result = run_checks(check_ctx, this.rules, this.policy)`. The runner passes `CHECK_RULES` and `CHECK_POLICY`.

**Step 6. `nodes/repair-node.ts`.** `export class RepairNode { constructor(paid: PaidCallerPort, renderer: Pick<PromptRenderer,"render_repair">, prompts: PromptRepo, settings: WorkerSettings, recorder: CheckpointPort); async run(state: JobState): Promise<JobState> }`.
1. `hit = await recorder.checkpoint(job_id, "repair", 1)`; hit -> no call.
2. Else `prompt = await prompts.get(job.prompt_version_id)`; `failing` = `check_result.findings.filter(f => f.level === "blocking")` mapped to `{ kind, message, address }`, plus, when `compile_error !== null`, one `{ kind: "compile_error", message: compile_error, address: null }`; `schema_issues` = state's; `template = template_for(row.lesson_type)`; `rendered = renderer.render_repair({ prompt, draft_raw: context.raw_output, failing, schema_issues, template })` (the repair gets the draft and **only** what failed).
3. `paid.call` with `ctx.purpose "repair"`, `attempt 1`, `alias "REPAIR"`, `output_mode "prompt_embedded"`, `max_output_tokens settings.draft_output_token_cap`, `output_schema_name "LessonDraft"`, `output_json_schema null`, same timeout/effort/temperature null.
4. Result: `with_call`; `repair_rounds + 1`; `raw_output = call.raw_output`. `SpendRefused` / `ProviderError`: same handling as Step 3 b/c. A repair that returns `max_tokens` is **not** retried (R-19: one repair): its truncated text simply fails the next parse and the router sends it to fail.

Everything below in ONE `tx.with_tx(async (tx) => ...)` (G-25). Build `NewGeneratedVersion { lesson_id, unit_id: job.unit_id, kind, lesson: compiled.lesson, draft: state.draft, content_hash: compiled.content_hash, idempotency_key: job.idempotency_key, provenance }` with `provenance = { outline_row_hash: context.row_context.row_hash, prompt_version_id: job.prompt_version_id, model: context.draft_call.served_model, parameters, ... }` (see the parameters note below).

**Step 9. `lesson-job-runner.ts`.** `export class LessonJobRunner { constructor(draft: DraftNode, compile_check: CompileCheckNode, repair: RepairNode, store: StoreNode, fail: FailNode, queue: JobQueue, finalizer: RunFinalizerPort, clock: Clock, settings: WorkerSettings); async run(job: ClaimedJob): Promise<JobOutcome> }`. Algorithm:
1. `state = initial_state(job, clock.now().getTime())` typed as `JobState`.
2. Private `gate(state)` run **before every node except `fail`**: (a) `ok = await queue.renew_lease(job.job_id, settings.job_lease_ms)`; `false` -> `throw new LeaseLost({ job_id })` (the runner then calls neither `queue.finish` nor any store; the claim loop leaves the job to `requeue_expired`; invariant: no write after the lease is lost). (b) `await queue.is_cancelled(job.job_id)` true -> `with_brake("cancelled")`. (c) `wall_clock_exceeded(state, clock.now().getTime(), settings.job_wall_clock_ms)` -> `with_brake("job_wall_clock")`. If any brake was added the runner goes straight to `fail` with no further call. Before `fail` and `store` call only (a).
3. Flow: `gate`, `queue.set_tile_state(id,"drafting")`, `draft.run`; `is_fatal` -> fail. Then `gate`, `set_tile_state "checking"`, `compile_check.run`. Loop: `next = route_after_checks({ schema_valid: state.draft !== null, compiled: state.compiled !== null, check_passed: state.check_result !== null && state.check_result.blocking === 0, repair_rounds: state.repair_rounds, max_repair_rounds: 1 })`. `store` -> `gate`, `store.run`. `repair` -> `gate`, `set_tile_state "repairing"`, `repair.run`; `is_fatal` -> fail; `gate`, `set_tile_state "checking"`, `compile_check.run`, loop. `fail` -> if `state.repair_rounds >= 1` add brake `repair_round`; `fail.run`.
4. Lease check before `store.run` and `fail.run` (via `gate` for store; direct `renew_lease` for fail).
5. After store/fail: `outcome = outcome_of(state)`; `await queue.finish(outcome)`; `await finalizer.after_job(job.run_id, outcome)`; return `outcome`.
6. Only `LeaseLost` propagates; do not swallow other errors.
