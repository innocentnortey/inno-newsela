### 5.2 alignment/standards-view.ts (pure helpers, no I/O, <200 lines)
Exports (exact names):
- `FRONT = (ctx) => \`${ctx.lesson.lesson_id}.FrontMatter\``
- `recorded(ctx): Standard[]` = `ctx.lesson.front_matter.standards` where `confirmation !== "removed"`.
- `listed_codes(ctx): Set<string>` = `ctx.allowed_codes` + `ctx.row.focus_codes` + `eld_codes` + `msls_codes`.
- `focus_codes(ctx): string[]` = unique(`ctx.row.focus_codes` + recorded with `role === "focus"`), in that order.
- `cfu_tags(ctx): {code: string; address: string}[]`: for each section, each `find_cfu_items(section)` item, take `/^Pulse Check \((.+)\)$/` group 1 of `node_text(item.heading).trim()`, split on `,`, trim, drop empties. Address = the item's `address`.
- `covered(f: string, tags, recorded_codes: Set<string>): boolean` = some tag `t` with `t === f` or (`t.startsWith(f + ".")` and `recorded_codes.has(t)`). Reason: WP-1 lists parent `L.6.4` and the generator records leaf `L.6.4.b`; the Pulse Check tags the leaf and must check the parent. An UNRECORDED tag never covers a parent (an unlisted leaf must not satisfy a check silently; HP-3).
- `teaching_parts(lesson: StoredLesson): string[]` (addresses, document order, unique). Only sections named `Literacy Lab` or `Learning in Action`. Build `excluded = Set<PMNode>`: for every `find_cfu_items(section)` item add `heading` and every node (via `walk`) of each block; for every node of type `teacher_tip` or `collapsible` add all its descendants (ELD callouts are teacher support, not teaching). Then `visit_with_parts(section, ({node, address}) => ...)`: a `paragraph` not in `excluded` with non-blank `node_text` marks `address` as a teaching part (first hit per address). Launch is deliberately excluded (warm-up is not where a focus standard is taught).
  JUDGEMENT (Open item O1): compiled lessons carry no per-code teach tag (`compile-draft.ts` drops `DraftBlock.standard_codes`), so "taught" = the lesson has at least one teaching part. The function is the single seam to replace if a per-code tag lands (a `CHG-N`, not here).

### 5.3 alignment rule bodies
Each file keeps its existing export name and `kind`/`level`; replace only `run`.
1. `standard_not_taught`: for each `f` of `focus_codes(ctx)`: if `teaching_parts(ctx.lesson)` is empty, one finding, level `blocking`, address `FRONT`, `code: f`, message `` `Standard ${f} has no teaching part at ${address} (standard_not_taught)` ``.
2. `standard_not_checked`: for each `f`: if `!covered(f, cfu_tags(ctx), recorded codes)`: one finding, address = `teaching_parts(...)[0] ?? FRONT`, `code: f`, message `` `Standard ${f} has no Pulse Check item tagged with it at ${address} (standard_not_checked)` ``. Exactly one per code (AC-1).
3. (Both rules emit nothing when `focus_codes` is empty: this keeps the registry test green.)
4. `code_not_allowed` (scans RECORDED standards only, not Pulse Check tags: the registry test needs `[]` on a context whose Pulse Check tag `RL.6.1` is unlisted). For each `s` of `recorded(ctx)`: `std = ctx.standards.find(x => x.code === s.code)`.
   - flag if `std === undefined` (unknown code) or `!std.is_leaf` (any non-leaf code, even a listed one: parents are never recorded as chosen standards);
   - else allowed if `listed_codes(ctx).has(s.code)`, or (`std.parent_code !== null` and listed has `std.parent_code`), or (`s.origin === "added"` and the row's list for that set is empty: `CA_CCSS_ELA_6` -> `row.focus_codes`, `CA_ELD_6` -> `row.eld_codes`, `CA_MSLS...`/`MSLS_6` -> `row.msls_codes`);
   - otherwise flag. Flag = blocking, address `FRONT`, `code: s.code`, message `` `Code ${s.code} is not allowed for this lesson at ${address} (code_not_allowed)` ``.
5. `standard_confirmation` (level on the finding: `"confirmation"`): for each `s` of `recorded(ctx)` with `s.origin` in `narrowed|added` and no row in `ctx.confirmations` with `code === s.code && confirmed_by !== null` and `s.confirmation !== "confirmed"`: one finding, address `FRONT`, `code`, message `` `Standard ${code} (${origin}) needs a named reviewer to confirm or remove it at ${address} (standard_confirmation)` ``. The word "aligned" must not appear in any message.
6. `standard_add_suggestion` (level `advisory`): unique codes `t` from `cfu_tags(ctx)` where `t` is not recorded, not in `listed_codes`, and a `StandardRow` with `code === t`, `is_leaf`, `parent_code` in `listed_codes` exists. One finding per code, address = that tag's item address, `code: t`, message `` `Pulse Check names ${t}, an unlisted leaf of a listed parent; add it? at ${address} (standard_add_suggestion)` ``. Never produces an AlignmentLinkRow.
7. `eld_label_mismatch` (advisory). JUDGEMENT (O2): the rule has no sheet label or verdict table in `CheckContext` (NL-15 applies the verdict table at intake), so the lesson-side label is the recorded `Standard.official_text` of an `eld` standard. For each recorded `role === "eld"` standard `s` with `r = ctx.standards.find(code)`, `r?.eld_strand != null`: find `o = ctx.standards.find(x => x.code !== s.code && norm(x.text) === norm(s.official_text))` (`norm` = lower-case, collapse whitespace). Flag when `o !== undefined && o.eld_strand !== null && o.eld_strand !== r.eld_strand` (the label shown belongs to a code in another strand). Address `FRONT`, `code: s.code`, message `` `ELD code ${s.code} carries a label from another strand at ${address} (eld_label_mismatch)` ``. Empty `official_text` or no match -> nothing.
8. `derive.ts` `derive_alignment(ctx): AlignmentLinkRow[]`: codes = `focus_codes(ctx)` + recorded `role === "supporting"` codes (unique; never `eld`, never the add-suggestion codes). For each code `c`: `origin`/`asserted_by` come from the recorded standard (`outline-fixed` -> `"outline"`), else `origin: "outline"`, `asserted_by: "outline"`. `confirmed_by` = first `ctx.confirmations` row for `c` with non-null `confirmed_by`, else `null`. Teach rows: for each address `a` of `teaching_parts`, only when at least one exists: role `"I"` for the first, `"P"` for the others. Check rows: role `"A"` for each `cfu_tags` item with `covered`-style match for `c` (exact tag or recorded descendant), one row per (code, address). Dedupe on (code, address, role). `lesson_id: ctx.lesson_id`, `content_hash: ctx.content_hash`. `asserted_by` is never empty (GR-4). Returns `[]` when no codes.

### 5.4 safety
`safety/notes.ts` (exports):
- `tips_of(lesson): {address: string; note_id: string | null}[]`: for each section, count `teacher_tip` nodes in document order (use `walk` over each `section_nodes`), ordinal 1-based; `address = tip_address(section.address, ordinal)`, `note_id = node.attrs?.safety_note_id` if a string else `null`.
- `notes_of(ctx): {id: string; text: string; flag: SafetyFlagRow | null}[]`: first, each `ctx.row.segments` entry with `kind === "safety_note"` and `applies !== "ignore"`, ordinal i (1-based): `id = safety_note_id(ctx.lesson.lesson_id, i)`, `text = segment.text`, `flag = ctx.safety_flags.find(f => f.flag_id === id) ?? null`; then every flag in `ctx.safety_flags` not already attached: `id = flag.flag_id`, `text = flag.note ?? ""`, `flag`.
- `has_tip(note, tips)`: some tip with `note_id === note.id`, or (`note.flag?.teacher_tip_address != null` and a tip address equal to it).
`safety/words.ts`: `words(s): string[]` = lower-case matches of `/[\p{L}\p{N}][\p{L}\p{N}'’-]*/gu`.
`safety/student-blocks.ts`: `student_blocks(lesson): {address: string; text: string}[]` — the only student-facing text (everything else, including ELD callouts, `collapsible`, `callout`, `teacher_tip`, and CFU rationale paragraphs, is teacher-facing):
  1. each `find_cfu_items` item: `text` of its `paragraph` blocks whose text does not match `/^[A-Z]\.\s*(Correct|Incorrect)/`, and of its `ordered_list` blocks; address = item `address`; one entry per item;
  2. after each `routine_heading` with `attrs.icon === "writing"` (found through `visit_with_parts`, using its `siblings`/`index`): following sibling `paragraph`s until the next `heading` or `routine_heading`; address = the event address;
  3. section named `Homework`: every top-level node that is not `teacher_tip`, `collapsible` or `callout`; address = section address.
  JUDGEMENT (O3): the draft model has no "directions" role, so student-facing = Pulse Check stem/options, Quick Write prompts and Homework.
Rule bodies:
1. `safety_flag_open`: per flag in `ctx.safety_flags` with `status === "open"`: blocking, `address: flag.teacher_tip_address`, `related_lesson_id: null`, message `` `Safety note ${flag.flag_id} is open: a named reviewer must clear it (tip at ${flag.teacher_tip_address ?? "none"}) (safety_flag_open)` `` (id and address only, never `flag.note`).
2. `safety_note_without_tip`: per note of `notes_of(ctx)` with `!has_tip(note, tips_of(ctx.lesson))` (open or cleared flag, or a bare row safety_note): blocking, address `` `${lesson_id}.FrontMatter` ``, message `` `Safety note ${note.id} has no teacher tip carrying its id at ${address} (safety_note_without_tip)` ``. A flag with no tip therefore gives BOTH this and `safety_flag_open` (AC-6 case 2 asserts the first is present).
3. `safety_text_in_student_block`: `n = policy.safety_run_min_words` (never the literal 6). For each note with `text` having `words(text).length >= n`: `grams = Set` of every window of `n` consecutive words joined by a space; for each `student_blocks` entry, slide an `n`-window over `words(entry.text)`; a hit gives one finding per (note, block address): blocking, `address: entry.address`, message `` `Safety note ${note.id} text appears in a student-facing block at ${address} (safety_text_in_student_block)` `` — no note words. Invariant: shorter-than-`n` notes can never leak by construction; a 5-word run gives nothing.
4. `disclosure_prompt` (rule `level` stays `advisory`; each finding sets its own level): patterns, exact, case-insensitive: `/\ba time (?:when )?you\b/i`, `/\byour own experiences?\b/i`, `/\bhave you ever\b/i`, `/\bin your family\b/i`. `blocking = ctx.safety_flags.some(f => f.status === "open") || ctx.previous_lesson_flags.length > 0` (DO-4 §13 R-1: "the flagged lesson and the next"); else `advisory`. One finding per (student block, pattern) hit: address = block address, message `` `Disclosure-style prompt in a student block at ${address} (disclosure_prompt)` `` (do not echo the matched text).
