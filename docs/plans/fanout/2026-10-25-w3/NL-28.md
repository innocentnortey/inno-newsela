## 5. Steps
1. **Row mappers.** `to_job_row(r)`: `job_id=r.id`, parse numerics with `new Decimal(r.cost_usd)`, `failure_reasons=r.failure_reasons_json`, `brakes_fired=r.brakes_fired`. pg returns timestamptz as Date, numeric as string.
2. **create_run_jobs(jobs, tx).** Empty array -> 0. Take `SELECT pg_advisory_xact_lock(hashtext($1))` with key `'lesson_job_create:' + run_id` for each distinct run_id (sorted, to avoid deadlock) FIRST: invariant = two concurrent creates of the same keys cannot both insert, because the table has no unique index on idempotency_key (R2). One statement: `INSERT INTO lesson_job (id, run_id, kind, lesson_id, idempotency_key, status, tile_state, queued_at, reviewer_note) SELECT u.id, u.run_id, u.kind, u.lesson_id, u.key, 'queued', 'queued', $n::timestamptz, u.note FROM (SELECT DISTINCT ON (key) * FROM unnest($1::text[] ids, $2::text[] run_ids, $3::text[] kinds, $4::text[] lesson_ids, $5::text[] keys, $6::text[] notes) AS t(id,run_id,kind,lesson_id,key,note) ORDER BY key) u WHERE NOT EXISTS (SELECT 1 FROM lesson_job x WHERE x.idempotency_key = u.key)`; return `rowCount`. Use `ids.new_id("job")` per input job; null lesson_id/note pass as null in the arrays. (If an index on idempotency_key is later added, nothing here breaks.) 48 rows must be one statement.
3. **claim(worker_id, max_active_runs, lease_ms)** inside `db.with_tx`, ONE statement:
```sql
WITH active AS (
  SELECT id, created_at FROM run WHERE state IN ('planning','running') ORDER BY created_at, id LIMIT $1
), load AS (
  SELECT run_id, count(*) AS n FROM lesson_job WHERE status='running' AND run_id IN (SELECT id FROM active) GROUP BY run_id
), pick AS (
  SELECT j.id FROM lesson_job j
  JOIN active a ON a.id = j.run_id
  JOIN run r ON r.id = j.run_id
  LEFT JOIN load l ON l.run_id = j.run_id
  WHERE j.status = 'queued' AND (j.kind <> 'lesson' OR r.plan_stored_at IS NOT NULL)
  ORDER BY coalesce(l.n,0), a.created_at, a.id, j.queued_at, j.id
  LIMIT 1
  FOR UPDATE OF j SKIP LOCKED
)
UPDATE lesson_job j SET status='running', attempt=j.attempt+1, worker_id=$2,
  lease_until=$3::timestamptz + ($4::int * interval '1 millisecond'),
  started_at=coalesce(j.started_at,$3::timestamptz),
  tile_state = CASE WHEN j.kind='unit_plan' THEN 'planning' ELSE 'drafting' END
FROM pick, run r WHERE j.id = pick.id AND r.id = j.run_id
RETURNING j.id, j.run_id, j.kind, j.lesson_id, j.attempt, j.lease_until, j.idempotency_key, j.reviewer_note,
  r.unit_id, r.prompt_version_id, r.outline_version_id, r.started_by;
```
Params: `[max_active_runs, worker_id, now_iso, lease_ms]`. Zero rows -> null. `schema_version`: R3 (use constant). Invariants: paused/capped/cancelled runs excluded by the `active` CTE; cap applies to the active-run list (oldest first), not to runs that happen to have work; `reviewer_note` is copied for candidate jobs, null otherwise (column is null for others). Never log reviewer_note.
4. **renew_lease:** `UPDATE lesson_job SET lease_until=$now+lease WHERE id=$1 AND status='running' AND lease_until >= $now` ; return `rowCount===1`. **set_tile_state:** plain UPDATE by id (no status guard). **finish(outcome):** `UPDATE lesson_job SET status=$2, tile_state=$3, failure_reasons_json=$4::jsonb, brakes_fired=$5::jsonb, repairs, truncation_retries, retries, cost_usd=$..::numeric, finished_at=$now, calls_lost=(SELECT count(*)::int FROM model_call WHERE job_id=lesson_job.id AND status='lost'), lease_until=NULL WHERE id=$1 AND status='running'`. Ignore `outcome.calls_lost` and `version_id` (the DB count is the truth; version row belongs to NL-30). A second finish matches zero rows = silent no-op (do not throw). Cost param: `outcome.cost_usd.toFixed(6)`.
5. **requeue_expired(now):** `UPDATE lesson_job SET status='queued', worker_id=NULL, lease_until=NULL, tile_state='queued' WHERE status='running' AND lease_until < $1 RETURNING id`; report `{requeued: rows.length, job_ids: rows.map(r=>r.id)}`. Touch no other table. (attempt kept; claim increments it, giving attempt 2 in AC-11.)
6. **requeue_failed(run_id, tx):** `UPDATE ... SET status='queued', tile_state='queued', failure_reasons_json='[]', brakes_fired='[]', finished_at=NULL, worker_id=NULL, lease_until=NULL, queued_at=$now WHERE run_id=$1 AND status='generation_failed'`; return rowCount. Leave counters (repairs, retries, cost_usd, calls_lost, attempt) as they are. **cancel_run(run_id, reason, tx):** `UPDATE ... SET status='cancelled', tile_state='failed', failure_reasons_json=jsonb_build_array(jsonb_build_object('check',$2::text)), finished_at=$now WHERE run_id=$1 AND status='queued'`; return rowCount. **jobs_for_run:** SELECT all of the run's jobs ORDER BY queued_at, id. **is_cancelled:** `SELECT (j.status='cancelled' OR r.state='cancelled') AS c FROM lesson_job j JOIN run r ON r.id=j.run_id WHERE j.id=$1`; missing row -> false... throw InvariantViolation instead (unknown job id is a bug).
7. **create_candidate_job(job, tx):** insert one row (kind candidate, `reviewer_note`, `idempotency_key`, `queued_at=$now`), `RETURNING` -> JobRow. Catch `err.code==='23505' && err.constraint==='lesson_job_one_candidate'` -> `throw new DomainRefusal("INVALID_TRANSITION","candidate job already in flight",{reason:"candidate_in_flight", lesson_id})` (fixed text, no note). Caveat: a unique violation aborts the caller's transaction in Postgres; the test must run each create in its own `with_tx` and expect the rejection, then check row count in a fresh tx. Other errors rethrow.
8. **Class shell:** `export class PgJobQueue implements JobQueue { constructor(deps: PgRepoDeps) {...} }` (same private fields as PgAuditLog). No other exports besides optional `SCHEMA_VERSION_DEFAULT`.
9. **seed-run.ts** (test helper, exported from `packages/db/src/testing/seed-run.ts`): `export async function seed_run(q: Pick<DbTx,"query">, opts: {run_id?: string; state?: string; plan_stored_at?: Date|null; created_at?: Date; unit_id?: string}): Promise<string>` using `insert_row(q, "run", {...})` (fills the NOT NULL columns; give distinct `idempotency_key` and `started_by` per call so `(started_by, idempotency_key)` unique holds); and `seed_job(q, {run_id, kind?, status?, lesson_id?, idempotency_key?, lease_until?, queued_at?})` via `insert_row(q, "lesson_job", ...)` (id from caller or `x_`-prefixed? use `PrefixedIdGenerator().new_id("job")`). Also `seed_lost_calls(q, job_id, n)` inserting `model_call` rows `status 'lost'` via insert_row. Raw SQL only; imports no repo.
