### Step 3. `ModelCallRecorder` (`recorder.ts`)
```ts
export class ModelCallRecorder {
  constructor(client: ModelClient, log: ModelCallLog, clock: Clock, prices: PriceLookup, settings: ModelSettings, cost: CostMath, extras: RecorderExtras = {});
  model_id_for(alias: ModelAlias): string;   // GENERATION->settings.model_generation_id, REPAIR->model_repair_id, ASSIST->model_assist_id; JUDGE throws InvariantViolation("judge alias has no recorder model") (judge uses its own client)
  call(ctx: ModelCallContext, req: StructuredCallRequest, rendered: RenderedPromptLike): Promise<RecordedCall>;
  checkpoint(job_id: JobId, purpose: CallPurpose, attempt: number): Promise<RecordedCall | null>; // = this.log.completed_for(...)
}
```
(`extras` is an added optional 7th parameter, not in DO-4: DO-4 has no logger slot but the ticket requires the log line. Existing DO-4 callers are unaffected. Default `random` = `Math.random`; no logger = no line.)

`call` algorithm, in this order; each numbered step protects the stated invariant:
1. `const requested_model = this.model_id_for(req.alias)`.
2. `const id = await this.log.insert_sent({ run_id, lesson_id, job_id, attempt, purpose, alias: req.alias, requested_model, rendered_prompt: rendered.text, request_id, experiment_id, reservation_id } from ctx)`. Awaited, nothing is sent until it resolves. *Invariant: no send without a committed row (AC-1).* If it throws, propagate; the client is never called.
3. `let retries = 0; const started = clock.now()`. Loop: `try { resp = await this.client.complete(req); break; } catch (e)`:
   - not a `ProviderError`: `log.fail(id, {kind:"server_error", http_status:null, message:"unexpected client error", retry_after_s:null})`, log line status `failed`, rethrow the original error. No retry.
   - `ProviderError` with `e.retryable === true` and `retries < this.settings.provider_max_retries`: `delay_ms = e.retry_after_s !== null ? Math.min(e.retry_after_s, 120) * 1000 : 1000 * 2 ** retries * (1 + (random() * 0.4 - 0.2))` (the cap of 120 s on a provider-supplied value is a planner decision); `await this.clock.sleep(delay_ms)`; `retries += 1`; loop again. **Same row**, never a new insert. *Invariant: one row per call; a timeout (`retryable` false) is never retried because the provider may have billed it (R-22).*
   - anything else (non-retryable, or retries exhausted): `await this.log.fail(id, {kind: e.kind, http_status: e.http_status, message: e.kind, retry_after_s: e.retry_after_s})`. The message is the kind name only: no provider text. Emit the log line with status `failed`, then `throw e` (the same `ProviderError`). If `log.fail` itself throws, log `logger.error("model_call.fail_write_failed", …)` and still throw `e`.
   Retry counts: 1 initial send + at most `provider_max_retries` (3) retries (planner reading of "at most PROVIDER_MAX_RETRIES"): a call that is 429 four times fails with `retries 3`. The count of retries must reach the row: `log.fail`/`log.complete` have no `retries` field, so **the recorder passes it by extending `ModelCallCompletion` / `ProviderErrorRecord`?** No: ports are NL-12's and not editable. Decision: `PgModelCallLog` stores retries through a third method NOT on the port: `set_retries(id: ModelCallId, retries: number)`. The recorder cannot call a non-port method, so instead: the recorder calls `await this.log.complete(...)`, and `RecordedCall.retries` is returned from the recorder's own counter. `model_call.retries` is written by `PgModelCallLog` itself: see Open item 2 (the port lacks a retries input). **Chosen mechanism:** the recorder calls an optional method `record_retry?(id: ModelCallId): Promise<void>` on the log (declare `type RetryAwareLog = ModelCallLog & { record_retry?(id: ModelCallId): Promise<void> }` in `recorder.ts`), once per retry, before the sleep; `PgModelCallLog.record_retry` does `UPDATE model_call SET retries = retries + 1 WHERE id=$1`; the in-memory log implements it too. A log without it (`FakeModelCallLog`) simply does not persist retries; `RecordedCall.retries` is always correct.
4. On success (`resp`): **immediately**, before anything that can throw on content: `let cost_usd: Usd; try { cost_usd = this.cost.settle_cost(this.prices.price_for(resp.served_model), resp.usage); } catch { cost_usd = null }`. If pricing threw (unknown served model), call `log.complete` with `cost_usd = new Decimal(0)` so the raw output is saved anyway, `logger.error("model_call.unpriced", {...ids only})`, then throw `new InvariantViolation("no price for served model", {model_call_id: id})` (see Open item 3). Normal path: `await this.log.complete(id, { raw_output: resp.raw_text, stop_reason: resp.stop_reason, usage: resp.usage, cost_usd, served_model: resp.served_model, provider_request_id: resp.provider_request_id, latency_ms: resp.latency_ms })`. *Invariant: raw output is persisted before parse, validation or any caller code runs (AC-2). Price comes from the SERVED model and the response usage, never the request (AC-3).* `stop_reason` is stored as returned, including `max_tokens`; the recorder never retries it and never inspects the text.
5. Emit one log line, `this.extras.logger?.info("model_call", {request_id, run_id, lesson_id, job_id, duration_ms: resp.latency_ms, extra: {model_call_id: id, purpose, alias: req.alias, served_model, input_tokens, output_tokens, cache_read_tokens, cache_write_tokens, cost_usd: cost_usd.toFixed(6), latency_ms, retries, status: "completed"}})`. `service` and `build_id` come from the injected logger. For a failed call the same line with `status: "failed"`, `extra.error_kind`, `extra.http_status`, no tokens. Nothing else goes in `extra`: never `rendered.text`, `raw_text`, `req` blocks, a key, or an error message. A lost call is logged by `ClaimLoop` (NL-79), not here.
6. Return `RecordedCall{ model_call_id: id, purpose: ctx.purpose, attempt: ctx.attempt, raw_output: resp.raw_text, stop_reason: resp.stop_reason, usage: resp.usage, cost_usd, served_model: resp.served_model, retries }`.
No `setTimeout`/`AbortController` in the recorder: the hard 240 s limit is `req.timeout_ms`, which the client enforces and reports as `ProviderError{kind:"timeout"}` (decision: a recorder-side race would leak a 240 s timer per call under `SystemClock`). The recorder does assert `req.timeout_ms > 0` (else `InvariantViolation`).

### Step 4. `PaidCaller` (`paid-call.ts`)
```ts
export interface PaidCallRequest { ctx: ModelCallContext; req: StructuredCallRequest; rendered: RenderedPromptLike; run_id: RunId|null; job_id: JobId|null; user_id: UserId; }
export class PaidCaller {
  constructor(recorder: Pick<ModelCallRecorder, "call" | "model_id_for">, spend: SpendLedger, prices: PriceLookup, cost: CostMath);
  call(p: PaidCallRequest): Promise<RecordedCall>;
}
```
Algorithm:
1. `amount = this.cost.max_call_cost(this.prices.price_for(this.recorder.model_id_for(p.req.alias)), p.rendered.input_tokens_estimate, p.req.max_output_tokens)`. Every call reserves its own worst case (draft 32000, truncation retry 48000, repair 32000 are just different `max_output_tokens` on `req`).
2. `decision = await this.spend.reserve({ run_id: p.run_id, job_id: p.job_id, user_id: p.user_id, purpose: p.ctx.purpose, amount_usd: amount })`.
3. If `!decision.allowed || decision.reservation_id === null`: `throw new SpendRefused({ refused_by: decision.refused_by ?? "run_cap", scope: decision.scope, amount_usd: amount })`. No recorder call, no row, no client call. (An allowed decision with a null reservation id is a ledger bug: throw `InvariantViolation("allowed reservation has no id")` instead.)
4. `const reservation_id = decision.reservation_id; try { const recorded = await this.recorder.call({ ...p.ctx, reservation_id }, p.req, p.rendered); await this.spend.settle(reservation_id, recorded.cost_usd, recorded.model_call_id); return recorded; } finally { await this.spend.release(reservation_id); }`. `release` is a no-op after settle, so a throw or abort always frees the reservation. If `release` throws in `finally` while another error is in flight, the original error wins (wrap `release` in its own try/catch only when an error is already propagating; keep it simple: `let failed = true; … failed = false; … finally { try { await release } catch (r) { if (!failed) throw r; } }`).

### Step 5. `PgModelCallLog` (`packages/db/src/repos/model-calls.ts`)
`export class PgModelCallLog implements ModelCallLog` with `constructor(deps: PgRepoDeps)` (same field layout as `PgAuditLog`). Every method runs in its **own** `this.db.with_tx`, so the `sent` row is committed before the send and `complete` commits independently of any caller transaction. Ids from `deps.ids.new_id("mc")`; times from `deps.clock.now().toISOString()`. Numeric columns arrive as strings: convert with `new Decimal(row.cost_usd)`; write costs with `cost_usd.toFixed(6)` (`numeric(12,6)`).
- `insert_sent(s)`: `INSERT INTO model_call (id, run_id, lesson_id, job_id, attempt, reservation_id, purpose, alias, requested_model, rendered_prompt, status, retries, request_id, sent_at, experiment_id) VALUES (..., 'sent', 0, ..., $::timestamptz, ...)`; returns the id.
- `record_retry(id)`: `UPDATE model_call SET retries = retries + 1 WHERE id=$1 AND status='sent'` (not on the port; see step 3).
- `complete(id, d)`: `UPDATE model_call SET status='completed', raw_output, served_model, input_tokens, output_tokens, cache_read_tokens, cache_write_tokens, cost_usd, stop_reason, provider_request_id, completed_at WHERE id=$1 AND status='sent'`; if `rowCount !== 1` throw `InvariantViolation("model_call not in sent state", {model_call_id: id})`. `latency_ms` has no column: not stored (M-16 reads `completed_at - sent_at`).
- `fail(id, e)`: `UPDATE … SET status='failed', stop_reason=$2, completed_at=… WHERE id=$1 AND status='sent'` with `stop_reason = "error:" + e.kind + (e.http_status !== null ? ":" + e.http_status : "")`. `e.message` is ignored on purpose (no message text stored). Same rowCount check.
- `mark_lost(job_id)`: `UPDATE model_call SET status='lost', completed_at=… WHERE job_id=$1 AND status='sent'`; return `rowCount`.
- `completed_for(job_id, purpose, attempt)`: `SELECT … FROM model_call WHERE job_id=$1 AND purpose=$2 AND attempt=$3 AND status='completed' AND raw_output IS NOT NULL ORDER BY sent_at DESC LIMIT 1`; map to `RecordedCall` (`model_call_id: id`, tokens → `usage`, `cost_usd` → `Decimal`, `retries`); `null` when none.
- `totals_for_run(run_id)`: one `SELECT` with `count(*)`, `count(*) FILTER (WHERE status='completed')`, `'failed'`, `'lost'`, `coalesce(sum(retries),0)`, `count(*) FILTER (WHERE purpose='truncation_retry')`, `count(*) FILTER (WHERE purpose='repair')`, `coalesce(sum(cost_usd) FILTER (WHERE status='completed'),0)`, and `sum(input_tokens)` / `sum(output_tokens)` `FILTER (WHERE status='completed')` (completed rows only, per the ticket); cast counts `::int`. Return `RunCallTotals` with `cost_usd: new Decimal(string)`.
`attempt` here is the recorder's per-`(job, purpose)` ordinal from `ctx.attempt` (G-19), never `ClaimedJob.attempt`; the log stores whatever it is given.

### Step 7. Tests (named exactly as the ticket) and context
`packages/llm/src/recorder.test.ts` (vitest; `-t` names are the `it` titles, each containing the quoted token):
- `row_exists_before_send`: `on_enter` reads `MemoryModelCallLog.rows`, asserts exactly one row, `status sent`, full `rendered_prompt`, purpose, alias, requested_model, attempt, reservation_id; after the call the same row is `completed`, `raw_output` equals the scripted text, `served_model` is the response's.
- `raw_saved_before_parse`: caller does `JSON.parse` on a non-JSON `raw_output` right after `call` returns and throws; row already holds raw_output, usage, cost; `recorder.checkpoint(job, purpose, attempt)` returns it; an unknown ordinal returns null.
- `cost_from_usage`: 3 cases with exact `Decimal`s: no cache tokens; cache read; cache read + write (the latter two strictly greater, by table price); pricing uses `served_model` (script `served_model` different from requested and a price double that returns different prices by model).
