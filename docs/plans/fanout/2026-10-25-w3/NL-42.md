## 5. Steps
1. **Skeleton.** `export class PgLessonRepo implements LessonStateRepo, LessonVersionRepo, LessonGraphRepo { constructor(deps: PgRepoDeps) }`. Keep SQL in the class; add module-private helpers: `row_to_lesson`, `row_to_version`, `count_words`, `slot_is_filled`, `assert_tx`.
2. **Row mapping.** `row_to_version(r)`: `version_id=r.id`, `lesson=r.lesson_json`, `draft=r.draft_json`, `state_vector = r.state_vector ? r.state_vector.toString("base64") : null` (write with `Buffer.from(sv,"base64")`), `dependency_record=r.dependency_record_json`, `provenance = { ...r.provenance_json, cost_usd: new Decimal(r.provenance_json.cost_usd), run_id: r.run_id, model_call_ids: r.model_call_ids, derived_from_version_id: r.derived_from_version_id }` (columns win over JSON copy), `stored_at` Date as returned. On write, `provenance_json` = ProvenanceRecord with `cost_usd` as `cost_usd.toString()`, and the three mirrored columns filled from the same record. Pass objects to jsonb as `JSON.stringify(x)` with `$n::jsonb`.
3. **State port.** `get` → row or null. `lock_for_update`: `SELECT * FROM lesson WHERE id=$1 FOR UPDATE`; no row → `DomainRefusal("NOT_FOUND", "lesson not found", {lesson_id})`. `state_of`: select; missing → same NOT_FOUND; `editable = is_editable(state as LessonState, "reviewer")`, plus `reviewer_id`. `set_state`: `UPDATE lesson SET state=$2, reviewer_id=$3 WHERE id=$1 RETURNING *` (reviewer_id written as given, null clears it); no row → NOT_FOUND. `record_last_editor`: `UPDATE lesson SET last_editor_id=$2 WHERE id=$1`; rowCount 0 → NOT_FOUND. `append_review_event`: id `this.ids.new_id("ev")`, `at = this.clock.now()`, one INSERT of all 12 columns, return `{review_event_id, lesson_id, from_state, to_state, actor_id, at}`. No update/delete method.
4. **ensure_lessons.** Filter `rows` to `kind==="lesson" && lesson_id!==null`. For each: `INSERT INTO lesson (id, unit_id, number, type, title, state, schema_version) VALUES ($1,$2,$3,$4,$5,'draft',$6) ON CONFLICT (id) DO NOTHING RETURNING id` with `type=row.lesson_type`, `title=row.title`, `number=row.number`, `schema_version=SCHEMA_VERSION`. Sum RETURNING counts. Existing rows are never updated (invariant: a second call changes nothing).
5. **Numbering + lock (both writers).** First statement of `write_generated_version` and `write_snapshot` after `assert_tx`: `SELECT id FROM lesson WHERE id=$1 FOR UPDATE`; no row → `InvariantViolation("lesson missing", {lesson_id})` (before any INSERT). The row lock serializes numbering. `next_number = (SELECT COALESCE(MAX(number),0)+1 FROM lesson_version WHERE lesson_id=$1)`.
6. **write_generated_version.** Reject `kind` not in generated/candidate with `InvariantViolation`. After lock: INSERT as in table (`adopted=false`, `created_by=NULL`, `derived_from_version_id`/`run_id`/`model_call_ids` from provenance, `teacher_word_count=count_words_total(v.lesson)`, `draft_json=v.draft`, `state_vector=NULL`, `dependency_record_json='[]'`, `stored_at=clock.now()`, `idempotency_key`) `ON CONFLICT ON CONSTRAINT lesson_version_idempotency_key_key DO NOTHING RETURNING *`. If a row returns: `created:true`, and if `kind==="generated"` run `UPDATE lesson SET current_version_id=$id WHERE id=$lesson`; a `candidate` NEVER touches `lesson` (R-29). If none returns: `SELECT * FROM lesson_version WHERE idempotency_key=$1` → `created:false`, no other write. `count_words`: copy exactly this local function (it mirrors the private one in `core/src/compile/compile-draft.ts`; sum over `lesson.sections[].content`): `teacher_tip` → 0; if any child is `text`/`hard_break` → count `\S+` tokens of concatenated inline text (`hard_break` → " "); else sum over children.
7. **write_snapshot.** Order: (a) `if (!["submit","approve","reopen"].includes(s.kind)) throw new InvariantViolation("snapshot kind invalid", {kind})` before any SQL; (b) lock lesson (missing → InvariantViolation); (c) find source = newest row by `number DESC` where `lesson_id=$1 AND (kind='generated' OR (kind='candidate' AND adopted))`; none → `InvariantViolation("no generated version to descend from")`; (d) INSERT with number=next, `provenance = { outline_row_hash, prompt_version_id, schema_version, run_id }` copied from source, `model:null, parameters:{}, example_set_id:null, model_call_ids:[], cost_usd: new Decimal(0), ai_assisted_spans:0, derived_from_version_id: source.id`; `lesson_json=s.lesson`, `state_vector=Buffer.from(s.state_vector,"base64")`, `dependency_record_json=s.dependency_record`, `created_by=s.created_by`, `draft_json=NULL`, `idempotency_key=NULL`, `teacher_word_count` via `count_words`. Does not move `lesson.current_version_id`. Return mapped row.
8. **mark_adopted.** `UPDATE lesson_version SET adopted=true WHERE id=$1 AND kind='candidate' AND adopted=false RETURNING *`; rowCount 0 → `DomainRefusal("INVALID_TRANSITION", "candidate already adopted or not a candidate", {version_id})`.
9. **Reads + graph.**
   - `version(id)`, `latest_snapshot` (`kind IN ('submit','approve','reopen') ORDER BY number DESC LIMIT 1`), `candidate(lesson_id, id)` (`id=$2 AND lesson_id=$1 AND kind='candidate'`), `has_generated_version` (`EXISTS … kind='generated'`).
   - `approved_snapshots(unit_id)`: `SELECT v.* FROM lesson l JOIN LATERAL (SELECT * FROM lesson_version WHERE lesson_id=l.id AND kind='approve' ORDER BY number DESC LIMIT 1) v ON true WHERE l.unit_id=$1 AND l.state IN ('approved','exported') ORDER BY l.number NULLS LAST, l.id`.
   - Link set: rows of `lesson_link` where `outline_version_id = (SELECT id FROM outline_version WHERE unit_id = <lesson's unit_id> ORDER BY number DESC LIMIT 1)`.
   - `dependencies(L)`: for links with `from_lesson_id=L` → `{direction:"waits_on", lesson_id: to_lesson_id, slot_id}`; for `to_lesson_id=L` → `{direction:"depended_on_by", lesson_id: from_lesson_id, slot_id}`. In BOTH cases the "source" is the `to` lesson: `source_state` = its `lesson.state`; `source_approved_hash` = `content_hash` of its latest `approve` snapshot only when its state is `approved`/`exported`, else null; `slot_filled` = `slot_is_filled(latest lesson_doc.derived_json, slot_id)` (latest = `ORDER BY seq DESC LIMIT 1`, none → false). Order by `lesson_link.id`. Read-only: never write `lesson_doc`.
   - `slot_is_filled(derived, slot_id)`: recursive walk of `derived.sections[].content` nodes; true iff a node `type==="excerpt_slot"` has `attrs.slot_id===slot_id` and `typeof attrs.source_ref === "string"` (non-null).
   - `dependants(L)`: `SELECT DISTINCT from_lesson_id` for `to_lesson_id=L` in that link set, ordered.
10. **source_outline_version.** `SELECT r.outline_version_id FROM (SELECT run_id FROM lesson_version WHERE lesson_id=$1 AND (kind='generated' OR (kind='candidate' AND adopted)) ORDER BY number DESC LIMIT 1) v LEFT JOIN run r ON r.id = v.run_id` → null when no row or no run.
