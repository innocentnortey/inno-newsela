## 5. Steps (build order; each is checkable with `npx vitest run <file>`)

Style: TypeScript strict, `.ts` import suffixes, `snake_case` functions as in the surrounding code, no `any`, file < 200 lines each (split if needed), pure functions, no module-level mutable state, no throwing from `run` on odd input (return no finding).

**1. `finding.ts`.** `export function make_finding(kind: CheckKind, level: IssueLevelName, message: string, address: string | null): CheckFinding` returning `{kind, level, message, address, span_anchor: null, related_lesson_id: null, code: null}`. Invariant (AC-8): all 7 keys always present. Messages are fixed sentences and may carry numbers (word counts, range text) but **never** the matched/quoted/name text.

**2. `text.ts`.**
- `normalize_for_match(s)`: port SP-3 `normalizeForMatch` exactly (NFKC, strip `“”"‘’'` and backtick, en/em/non-breaking dash to `-`, collapse whitespace, lowercase, trim edge punctuation `.,;:!?…()[]` repeatedly).
- `count_words(s: string): number` = whitespace-split tokens that contain at least one `\p{L}` or `\p{N}` (ticket definition; use the `u` flag).
- `find_quote_spans(text): {inner:string; start:number; end:number}[]`: port SP-3 `findQuoteSpans` (the four regexes, overlap skip, sort by start).

**3. `fields.ts`.** Walk `ctx.lesson.sections` and return
```ts
export type TextField = { address: string; text: string; in_cfu_choice: boolean; };
export type SlotNode = { node: PMNode; address: string; };
export function collect(ctx: CheckContext): { fields: TextField[]; placeholders: SlotNode[]; excerpts: SlotNode[]; quotes: SlotNode[] }
```
Algorithm per section:
 a. `cfu_choice` = a `Set<PMNode>` (identity) of every node in `find_cfu_items(section)[*].blocks.slice(1)` and all their descendants (blocks[0] is the stem paragraph: advisory, not "option or rationale"; options = the ordered list, rationales = the following paragraphs).
 b. Use `visit_with_parts(section, cb)`. For each event whose `node.type` is `paragraph`, `heading` or `routine_heading`: skip it if any ancestor is a `quote` node (track by collecting all `quote` descendants into an "inside_quote" `Set<PMNode>` first with `walk`); otherwise push `{address: event.address, text: <joined inline text>, in_cfu_choice: cfu_choice.has(node)}`. Joined inline text = concatenate child `text` nodes, `hard_break` as one space, so a sentence split over several text nodes (marks) is one string (ticket requirement). Use a small local `inline_text(node)`; do not use `node_text` for paragraphs inside lists (it is fine, same result) but note `visit_with_parts` does not descend into paragraphs so list_item > paragraph is reached via the list_item container.
 c. Events whose type is `quote_placeholder` -> `placeholders`; `excerpt_slot` -> `excerpts`; `quote` -> `quotes`, each with `event.address`.
 d. Because `visit_with_parts` does not visit children of a `paragraph`, a paragraph that is a list item child is still visited as the container's child (it descends every non-paragraph node). Confirm with the WP-1 test that CFU option text is collected.
Address = the part-level address from the walker (this is the address WF-10 stores; AC-1 asserts it equals the address of the section/part holding the plant).

**4. `sources.ts`.** `build_sources(ctx): { texts: string[]; ranges: {page: Range[]; chapter: Range[]}; }` with `type Range = {from:number; to:number}`.
- `texts` (every string below that is non-null): `row.title`, `row.homework`, `row.pages`, `row.text_set`, `row.arc`, `ctx.arc_header`, `row.vocabulary[]`, `ctx.row.segments[].text` **only where `instruction_shaped === false`** (decision: injected or instruction-shaped row text is not a source of truth, GR-1; AC-7), each `ctx.text_cards` field (`title, author, edition, chapter, pages`), each `ctx.standards[].text`.
- `ranges`: run `extract_refs` (step 5) over `texts` and add every ref to `page`/`chapter` lists. (Page/chapter values from text cards come in through `texts`.)
- Do not add `ctx.lesson` text to sources (the draft is what is being checked).

**5. `page-refs.ts`.** Port SP-3 `page-scan.ts`: `extract_refs(text): {kind:"page"|"chapter"; from; to; match}[]` with the same two regexes and number-word table; `ref_in_range(ref, ranges)`: false when the list is empty (a reference when the row names none is flagged), otherwise every integer `from..min(to, from+2000)` must lie in some range.

**6. Rule bodies, one per file** (`run: (ctx, policy) => ...`; use `collect(ctx)` and `build_sources(ctx)`; level literals are fixed by each rule file's existing `level`):
- `quote_unmatched` (blocking): for each field, each `find_quote_spans` span with `count_words(inner) >= policy.quote_span_min_words` (never a literal 3), skipping spans containing `_{2,}` (fill-in blanks), where `normalize_for_match(inner)` is not a substring of `normalize_for_match(texts.join("\n"))`: finding at `field.address`, message `"Quoted passage of N words is not in this lesson's outline row, arc header, text cards or standards"`.
- `page_out_of_range` (blocking): for each field and each `extract_refs` hit not `ref_in_range`: finding, message `"Page or chapter reference is outside the range the outline row gives"` (no number echo needed).
- `proper_noun_unsourced`: `scan_names(field.text, name_index)` from step 7 for every field; one finding per distinct name per field; `level` = `"blocking"` if `policy.name_scan_scope === "blocking_everywhere" || field.in_cfu_choice`, else `"advisory"`. Message `"Proper name is not in this lesson's outline row, arc header, text cards or standards"`.
- `quote_without_source` (blocking): each `quotes` node where `typeof attrs.source_ref !== "string" || attrs.source_ref.trim() === ""`. Message `"Quote has no source"`.
- `quote_too_long` (blocking): each `quotes` node with `attrs.rights === "short-quote-commentary"` and `count_words(node_text(node)) > policy.reviewer_quote_max_words` (13 flagged, 12 not). Message `"Short quote is over the word limit"` (no digits of the policy hard-coded).
- `rights_to_clear` (blocking): each node in `quotes` **and** `excerpts` with `attrs.rights === "to-clear"`. Message `"Rights to clear before approval"`. Any other rights value gives nothing.
- `quote_placeholder_open` (blocking): one finding per `placeholders` node (the node still exists = still open). Message `"A quote is still needed here"`.
- `excerpt_slot_open` (blocking): one finding per `excerpts` node whose `attrs.rights === "unset"` **or** whose `attrs.source_ref` is null/blank. (Decision: a slot is filled only when it has both a source and a rights status.) Message `"An excerpt is still needed here"`.
All addresses are the node's/field's part-level address.

**7. `allow-list.ts` + `name-scan.ts`.** Port SP-3 verbatim: `ALLOW` and `STARTERS` (`name-lists.ts`), `tokenize`, `isSentenceInitial`, `nameCandidatesA`, `mergeAndDedupe` (option A) and `nameScanB` (option B, `compromise`) from `options/a/name-scan.ts` and `options/b/name-scan.ts`.
