Ports (verbatim): `LessonDocStore { store(req: StoreRequest): Promise<StoreAck>; seed_initial(lesson_id: LessonId, lesson: StoredLesson, actor: Actor, tx: Tx): Promise<SeedResult> }`; `LessonDocReader { latest(lesson_id): Promise<StoredDoc|null>; latest_derived(lesson_id): Promise<DerivedRow|null> }`; `CheckQueue.enqueue(lesson_id, content_hash, store_id, tx): Promise<void>`; `LessonStateRepo.record_last_editor(lesson_id, user_id, tx): Promise<void>`; `AuditLog.append(e: NewAuditEvent, tx): Promise<AuditEventId>`. `StoreAck { lesson_id, store_id, seq, content_hash, state_vector, stored_at: Date, stored_by: UserId|null, check_job_enqueued: boolean }`. `StoredDoc` has no `stored_by`/`derived`; `DerivedRow` has `lesson, stored_by`.

`ids.new_id("st")` makes the `store_id`. `db.with_tx(fn, advisory_lock)` runs `pg_advisory_xact_lock(hashtext($1))`; the callback gets `DbTx` (`tx.query(sql, values) -> {rows, rowCount}`), which is the `Tx` the ports expect (PgAuditLog rejects anything else).

Table `lesson_doc` (migration 0006): `lesson_id text, seq int, store_id text, ydoc_bytes bytea, derived_json jsonb, content_hash text, state_vector bytea, schema_version int, stored_by text, stored_at timestamptz default now(), request_id text, primary key (lesson_id, seq)`. **`state_vector` is bytea but the port type `StateVector` is base64 text**: write `Buffer.from(sv, "base64")`, read `row.state_vector.toString("base64")`. `ydoc_bytes`: write the `Uint8Array` as `Buffer.from(bytes)`, read back as `new Uint8Array(buf)`.

### 4.1 `store(req)` algorithm (`packages/db/src/repos/lesson-docs.ts`)
```ts
export interface PgLessonDocStore_ctor extends PgRepoDeps { checks: CheckQueue; states: LessonStateRepo; audit: AuditLog }
export class PgLessonDocStore implements LessonDocStore { constructor(deps: PgLessonDocStore_ctor) {...} }
```
1. `const store_id = this.ids.new_id("st"); const stored_at = this.clock.now();` (outside the tx; one clock read, reused for the row and the ack).
2. `return this.db.with_tx(async (tx) => {...}, "lesson_doc:" + req.lesson_id)`. Invariant: the lock serialises `max(seq)+1` per lesson so seq has no gap or duplicate (AC-3).
3. Inside: `INSERT INTO lesson_doc (lesson_id, seq, store_id, ydoc_bytes, derived_json, content_hash, state_vector, schema_version, stored_by, stored_at, request_id) VALUES ($1, (SELECT coalesce(max(seq),0)+1 FROM lesson_doc WHERE lesson_id=$1), $2,$3,$4::jsonb,$5,$6,$7,$8,$9::timestamptz,$10) RETURNING seq`. `$4 = JSON.stringify(req.derived)`, `schema_version = req.derived.schema_version`, `stored_at.toISOString()`.
4. `await this.checks.enqueue(req.lesson_id, req.content_hash, store_id, tx)`.
5. `if (req.stored_by !== null) await this.states.record_last_editor(req.lesson_id, req.stored_by, tx)`.
6. `await this.audit.append({ actor_id: req.stored_by, action: "lesson.store", target_kind: "lesson", target_id: req.lesson_id, version_hash: req.content_hash, reason: null, details: { seq, tag: req.tag }, request_id: req.request_id, store_id }, tx)`. (`tag` is `string|null`, both valid `JsonValue`; the audit guard rejects text over 120 chars or an email, which propagates and rolls everything back.)
7. Return `StoreAck { lesson_id, store_id, seq, content_hash: req.content_hash, state_vector: req.state_vector, stored_at, stored_by: req.stored_by, check_job_enqueued: true }`. Any throw in 3-6 rolls back the whole unit (the helper does ROLLBACK and rethrows the original error).
8. Do not recompute the hash or vector from the bytes (the collab server computes them; ticket says "the request's"). Do not touch `lesson`, `check_job` or `audit_event` in this file's SQL (Metz S2).

### 4.2 `seed_initial(lesson_id, lesson, actor, tx)`
1. `if (!(tx instanceof DbTx)) throw new InvariantViolation("seed needs a real transaction")`.
2. `await tx.query("SELECT pg_advisory_xact_lock(hashtext($1))", ["lesson_doc:" + lesson_id])`. Protects against a racing `store` on an empty lesson (same key as step 4.1.2 so both serialise).
3. `bytes = lesson_to_ydoc(lesson); hash = content_hash(lesson); sv = state_vector_of(bytes); store_id = ids.new_id("st")`.
4. `INSERT ... seq 1 ... stored_by = actor.user_id, request_id = null ... ON CONFLICT (lesson_id, seq) DO NOTHING RETURNING store_id` (same column list as 4.1.3 but literal `1`).
5. If `rowCount === 0`: return `{ lesson_id, seeded: false, store_id: null, content_hash: hash }`, enqueue nothing.
6. Else `await this.checks.enqueue(lesson_id, hash, store_id, tx)` and return `{ lesson_id, seeded: true, store_id, content_hash: hash }`. No audit row, no `record_last_editor`.
`lesson_id` must equal `lesson.lesson_id`; if not, throw `InvariantViolation("seed lesson id mismatch")` before any SQL.

### 4.5 `HttpCollabCommandClient` (`apps/web/src/server/adapters/collab-commands.ts`)
Imports: `CollabCommands, SubmitCommand, SnapshotResult, EditCommand, StoreAck, ModeCommand, ModeResult` from `@ls/core/ports/collab-commands`; `DomainRefusal, CollabUnavailable, InvariantViolation` from `@ls/core/errors`; `SecretStr` from `@ls/config/secret`; `Clock` from `@ls/core/ports/clock`; `Logger` from `@ls/obs/logger`; zod `z` and `LessonId, UserId, StoreId, VersionId, Sha256, StateVector, Timestamp` from `@ls/schema/ids`, `Error as ErrorEnvelope` from `@ls/schema/api/common`.
```ts
export interface HttpCollabCommandClient_ctor { base_url: string; token: SecretStr; timeout_ms: number /* default 5000 */ }
export interface CollabClientDeps { clock: Clock; logger: Logger; fetch_impl?: typeof fetch }
export type CollabCommandName = "lock_and_snapshot" | "apply_edit" | "set_mode";
export class HttpCollabCommandClient implements CollabCommands {
  constructor(cfg: HttpCollabCommandClient_ctor, deps: CollabClientDeps)
}
export function collab_refusal_from(status: number, body: unknown, command: CollabCommandName, lesson_id: string, request_id: string, logger?: Logger): DomainRefusal | CollabUnavailable
```
Route segment per command: `lock_and_snapshot` -> `lock-and-snapshot`, `apply_edit` -> `apply-edit`, `set_mode` -> `set-mode`.

Private `call(command, cmd)` steps:
1. `url = base_url.replace(/\/+$/, "") + "/lessons/" + seg(cmd.lesson_id) + "/" + route`. `seg(id)`: `encodeURIComponent(id)`, then if the result is `.` or `..` return `%2E` / `%2E%2E` (encodeURIComponent leaves dots, and `..` would walk the path). Invariant: the lesson id stays one path segment.
2. `fetch(url, { method: "POST", headers: { "content-type": "application/json", authorization: "Bearer " + token.reveal(), "x-request-id": cmd.request_id }, body: JSON.stringify(cmd), redirect: "error", signal })`. `token.reveal()` appears only here. Body: the whole command record (`Date` fields are none; ids are strings).
3. Timeout without real timers: `const ac = new AbortController(); const timer = clock.sleep(timeout_ms).then(() => "timeout" as const);` race `fetch(...)` against `timer`; on timeout call `ac.abort()` and treat as unavailable. (Tests use `FakeClock.advance(5000)`.)
4. Any thrown fetch error: log `logger.warn("collab.call_failed", { request_id, lesson_id, extra: { command, error: err instanceof Error ? err.name : "unknown" } })` and throw `new CollabUnavailable({ lesson_id, command })`. Never put `err.message`, the URL or the headers in the log or error.
5. Read `await res.text()`, `JSON.parse` in try/catch (parse failure -> `body = undefined`).
6. `res.status` 2xx: parse with the command's Zod mirror (below). Parse failure -> log `collab.bad_body`, throw `CollabUnavailable`. Success -> return the record. Exactly one request, no retry anywhere.
7. Non-2xx -> `throw collab_refusal_from(res.status, body, command, lesson_id, cmd.request_id, logger)`.

Zod mirrors (DO-4 §3.3 records; `stored_at` is revived):
- `SnapshotResult`: `{lesson_id: LessonId, version_id: VersionId, version_number: int, content_hash: Sha256, state_vector: StateVector, review_event_id: string, from_state: LessonStateName, to_state: LessonStateName}`.
- `StoreAck`: `{lesson_id, store_id: StoreId, seq: int, content_hash, state_vector, stored_at: Timestamp.transform(s => new Date(s)), stored_by: UserId.nullable(), check_job_enqueued: boolean}`.
- `ModeResult`: `{lesson_id, mode: z.enum(["editable","read_only"]), connections_notified: int}`.
- `LessonStateName` = `z.enum(["draft","generation_failed","in_review","submitted","changes_requested","approved","reopened","exported"])`.

### 4.6 `collab_refusal_from` (exported pure function, same file)
1. `status === 401` -> `logger?.error("collab.token_mismatch", { request_id, lesson_id, extra: new InvariantViolation("collab token rejected", { command }) })` (the logger prints the error name only) -> return `new CollabUnavailable({lesson_id, command})`. Check this before parsing the body.
2. Else `parsed = ErrorEnvelope.safeParse(body)`; failure (HTML, empty, wrong shape, unknown code) -> return `CollabUnavailable`.
3. Success: `details = {...(parsed.data.error.details ?? {})}`; `collab_request_id = typeof details.request_id === "string" ? details.request_id : null`; set `details.request_id = request_id` (the web id); `logger?.warn("collab.refusal", { request_id, lesson_id, extra: { command, code, collab_request_id } })`; return `new DomainRefusal(parsed.data.error.code, parsed.data.error.message, details as JsonValue)` (`JsonValue` from `@ls/core/ports/common`). Code, message and every other detail key are unchanged.
