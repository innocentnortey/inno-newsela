### Step 1. `packages/db/src/repos/outlines.ts`

Exports: `class NotBuiltYet extends Error { constructor(readonly owner: string) { super("NOT BUILT: " + owner); this.name = "NotBuiltYet"; } }`, `class PgOutlineRepo implements OutlineRepo`, `class PgStandardRepo implements StandardRepo`, and the types `UnitOverviewData`, `UnitOverviewVersion`. Constructors take `PgRepoDeps` (import from `./audit.ts`). Reads use `this.db.with_tx(async (tx) => (await tx.query(...)).rows)` like `audit.ts`; writes use the caller's tx after `if (!(tx instanceof DbTx)) throw new InvariantViolation("outline write needs a real transaction")`. Timestamps come from `this.clock.now()` (not `now()` in SQL) so tests with `FakeClock` are deterministic; return `created_at` as `toISOString()`.

**Storage mapping (the DDL is fixed and lossy; this is the decision, every method uses it):**

| Table | Mapping |
|---|---|
| `outline_version` | `id = ${unit_id}.ov${number}` (matches `OUTLINE_VERSION_ID_RE`), `unit_id`, `number`, `sha256`, `same_as_version`, `source_kind`, `source_name`, `uploaded_by`, `created_at`, `confirmed_at` null |
| `outline_row` (one per `NormalizedRow`) | `row_number`, `kind`, `lesson_id`; `segments_json = row.segments`; `codes_json = { focus_codes, eld_codes, msls_codes, vocabulary, meta: { number, title, lesson_type, arc, homework, pages, text_set } }`; `findings_json` = findings whose `row_number` equals this row's; `row_hash` |
| `outline_row` **meta row** (exactly one per version) | `row_number = 0`, `kind = 'meta'`, `lesson_id` null, `segments_json = []`, `codes_json = { unit_as_written, unit_from_filenames, unit_rules, counts }`, `findings_json` = findings whose `row_number` is null **or matches no stored row** (e.g. `missing_required_column` on the header line), `row_hash = sha256(canonical_json(codes_json))`. Real grid rows are 1-based, so 0 never collides. Every read of rows filters `kind <> 'meta'`; counts and changed-lesson maths ignore it. |
| `lesson_link` | `from_lesson_id`, `to_lesson_id`, `kind`, `slot_id = to_slot_id`. | `intake_choice` | read only here; the table has no `at` column, so `choices()` sets `at` to the version's `confirmed_at ?? created_at` (ISO) and `status` as stored. NL-77 will need a migration for a real `at` (Risks). |

**Row hash:** `row_hash_of(row) = sha256hex(canonical_json({ ...row, row_number: undefined }))`; implement by building a copy without `row_number` (delete the key) then `canonical_json`. `row_number` is excluded so a row that only moved down the sheet is not "changed" (invariant: `changed_lessons` counts content changes, keyed by `lesson_id`). Use `createHash("sha256")` from `node:crypto`; hex lowercase (must match `Sha256`).

**`insert_version(v, outline, links, tx)` (numbered, each step protects an invariant):**
1. Assert real tx (above).
2. `SELECT pg_advisory_xact_lock(hashtext('outline:' || $1))` with `$1 = v.unit_id` first. Invariant: two near-simultaneous uploads for one unit are serialized, so numbers never repeat (same hash function as `tx.ts`; re-taking a lock the session already holds is fine).
3. Validate `UNIT_ID_RE.test(v.unit_id)` else `InvariantViolation("bad unit id")`. Derive `grade` = digits after `G`, `unit_no` = digits after `.U`. `INSERT INTO unit (id, grade, title) VALUES ($1,$2,$3) ON CONFLICT (id) DO NOTHING` with `title = "Grade " + grade + " · Unit " + unit_no` (middle dot U+00B7).
4. `number = (SELECT coalesce(max(number),0)+1 FROM outline_version WHERE unit_id=$1)`.
5. `same_as_version = (SELECT min(number) FROM outline_version WHERE unit_id=$1 AND sha256=$2)` (null if none). Invariant: the lowest earlier version with the same bytes.
6. Insert the version row, the meta row, one row per `outline.rows` entry (loop; at most 200), then one `lesson_link` row per link, in the given order.
7. Return `{ outline_version_id, unit_id, number, sha256, same_as_version, source_kind, uploaded_by, created_at, confirmed_at: null }` (the `OutlineVersionRow` zod shape; it has no `source_name`).

**Other methods:**
- `list_units()`: `SELECT u.id, u.grade, u.title, (SELECT max(number) FROM outline_version v WHERE v.unit_id=u.id) AS n FROM unit u ORDER BY u.grade, (regexp_replace(u.id, '^.*\.U', ''))::int`; `latest_outline_version_id = n === null ? null : u.id + ".ov" + n`.
- `version(id)`: row or null (shape above, `created_at`/`confirmed_at` ISO).
- `rows(id)`: `SELECT row_number, kind, lesson_id, segments_json, codes_json, row_hash FROM outline_row WHERE outline_version_id=$1 AND kind <> 'meta' ORDER BY row_number`; rebuild each `NormalizedRow` from the mapping, run `NormalizedRow.parse(...)` (strict); a parse failure throws `InvariantViolation("stored outline row invalid", {outline_version_id, row_number})` (no cell text in the details).
- Public non-port method `outline(id): Promise<NormalizedOutline>` (NL-77 will use it for `generate_gate_inputs` and the report): rows via the same rebuild + meta row (`unit_as_written`, `unit_from_filenames`, `unit_rules`, `counts`) + all findings (per-row and meta) sorted by `finding_id` ascending (plain string compare, as the normalizer does). A version with no meta row throws `InvariantViolation`.
- `choices(id)`: see mapping.
- `links(id)`: see mapping.
- `row_context(id, lesson_id, choices)`: load `rows(id)` and the meta row; `row` = the row with that `lesson_id` (not found: `InvariantViolation("lesson not in outline version", {outline_version_id, lesson_id})`); `row_hash` = its stored hash; `arc_header` = `title` of the nearest `arc_header` row with a smaller `row_number` (fallback `row.arc`, else null); `neighbours` = the previous and the next row of kind `lesson` or `flex_day` in row order (up to one each side, in row order, never the row itself); `unit_rules` = meta `unit_rules` whose `scope_lesson_ids` includes `lesson_id`; `links` = `links(id)` filtered to `from_lesson_id === lesson_id || to_lesson_id === lesson_id`; `choices` = `choices ?? await this.choices(id)`, in both cases only entries whose `outline_version_id === id`. Row text is never rewritten: "applying" choices means the returned `choices` are the given set (the draft node interprets them).

**`PgStandardRepo`:**
- `index()`: `SELECT code, "set", text, parent_code, is_leaf, eld_strand FROM standard`; zero rows -> `throw new InvariantViolation("standard table is empty; seed it")` (an unseeded database would turn every code into a false error); else `StandardsIndex.from_rows(rows, load_eld_verdicts())`. ```ts

```ts
export function parse_sheet_url(sheet_url: string): { sheet_id: string; canonical_url: string; export_url: string }; // throws DomainRefusal INVALID_REQUEST
```

`parse_sheet_url` (runs before any I/O; invariant: the server never fetches an address the user chose):
1. `sheet_url.length > 2048` or not parseable by `new URL(...)` -> `INVALID_REQUEST` with details `{ fields: ["sheet_url"] }`, message `"The sheet link is not valid."`.
2. Require `protocol === "https:"`, `hostname === "docs.google.com"`, `port === ""`, `username === ""`, `password === ""`, and `pathname` matching `/^\/spreadsheets\/d\/([A-Za-z0-9_-]{1,128})(?:\/|$)/`. Anything else -> the same `INVALID_REQUEST`. (`https://docs.google.com.evil.example/...`, `https://user@docs.google.com/...`, `http://169.254.169.254/`, `file:///etc/passwd` all fail here.)
3. `canonical_url = https://docs.google.com/spreadsheets/d/<id>`; `export_url = https://docs.google.com/spreadsheets/d/<id>/export?format=xlsx` (built by us; the user's query and fragment are dropped).

`fetch_export` (one logical GET; no retry):
1. `parse_sheet_url`.
2. `const ac = new AbortController(); const deadline = this.clock.sleep(timeout_ms).then(() => { ac.abort(); throw new DomainRefusal("SHEET_UNREACHABLE", "Google Sheets did not answer in time. Try again or upload the file.", {}); })`; then `await Promise.race([this.get(export_url, ac.signal), deadline])`. Invariant: a stalled server cannot hold the request (AC-4 uses `FakeClock.advance(10_000)`). A `deadline` that loses the race must not become an unhandled rejection: attach `deadline.catch(() => {})` before racing. Any non-`DomainRefusal` error from the transport (network, abort) -> `DomainRefusal("SHEET_UNREACHABLE", same message, {})`.
3. `get`: loop at most 3 redirect hops. For the current URL (always https, host allowed): `transport(url, { signal, redirect: "manual", headers: { accept: "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet,*/*;q=0.1", "user-agent": "newsela-lesson-studio/1" } })`.
   - 3xx with a `location`: resolve with `new URL(location, current)`; if not `https:`, or the host is not `docs.google.com` and not matching `/^doc-[a-z0-9-]+\.googleusercontent\.com$/`, or host is `accounts.google.com`, or the path starts with `/accounts` or contains `ServiceLogin` -> `SHEET_NOT_PUBLIC`, **without requesting it**. Otherwise follow. More than 3 hops -> `SHEET_UNREACHABLE`. 3xx without `location` -> `SHEET_UNREACHABLE`.
   - 401, 403, 404 -> `SHEET_NOT_PUBLIC` (404: a wrong or deleted id looks the same as a private sheet; the message is the same).
   - any other non-2xx (5xx, 429, ...) -> `SHEET_UNREACHABLE`.
   - 2xx with `content-type` starting `text/html` -> `SHEET_NOT_PUBLIC` (a sign-in page served inline).
   - 2xx: if `content-length` > `max_bytes` -> `UNSUPPORTED_FILE` `{ reason: "too_large" }`. Read `body.getReader()`; keep a running total; as soon as total > `max_bytes` call `ac.abort()` and `reader.cancel()` and throw `UNSUPPORTED_FILE` `{ reason: "too_large" }` (message `"The sheet is larger than 5 MB."`). No body -> `SHEET_UNREACHABLE`.
4. Concatenate chunks into one `Uint8Array`; `sha256 = createHash("sha256").update(data).digest("hex")`; return `{ url: canonical_url, kind: "xlsx", data, sha256, fetched_at: this.clock.now() }`.

Fixed messages (no URLs, no stack traces, no response text): `SHEET_NOT_PUBLIC` -> `"This sheet is private; share it publicly or upload the file."` with details `{}`. Never put the user's URL in a message or details.
