## 5. Steps
1. **`arc-helpers.ts`** (pure, no I/O, each exported function tested through the rule tests):
   - `opening_routine(lesson: StoredLesson): string | null` = the `attrs.icon` of the FIRST `routine_heading` node (document order, via `walk`) in `lesson.sections[0]`; `null` when there is no section or no routine_heading in it. Decision: "primary activity type" = the opening routine icon (ticket AC-1 wording "open with the same routine"). Invariant: a lesson with no identifiable opening never repeats (quiet by default, GP-82).
   - `lesson_number(id: string): { prefix: string; n: number } | null` using `/^(.*\.L)(\d+)$/`; flex days (`...FLEX-1a`) return null so they neither fire nor count.
   - `parse_pages(s: string | null): Array<[number, number]> | null`: regex `/\b(?:pages?|pp?\.)\s*(\d+)(?:\s*[-–—]\s*(\d+))?/gi`; `"Ch. 1 pp. 9-15"` -> `[[9,15]]`, `"p. 4"` -> `[[4,4]]`; no match or `null` -> `null`; if end < start swap them.
   - `ranges_overlap(a, b): boolean` any pair with `a0 <= b1 && b0 <= a1`.
2. **`vocabulary_over_cap.ts`**: `run: (ctx, policy) => ctx.lesson.front_matter.vocabulary.length > policy.vocabulary_cap ? [one finding] : []`. Finding: `kind:"vocabulary_over_cap", level:"advisory", message:` `` `Vocabulary list has ${n} words; the cap is ${cap}` ``, `address: `${ctx.lesson.lesson_id}.FrontMatter``, `span_anchor:null, related_lesson_id:null, code:null`. Invariant: cap only from `policy`, never a literal (AC-3). Do not touch `row.vocabulary` and do not implement `vocabulary_word_missing`.
3. **`arc_repeat.ts` part 1, repeat window** (rule `kind:"arc_repeat", level:"advisory"`, export name unchanged):
   a. `me = lesson_number(ctx.lesson_id)`, `icon = opening_routine(ctx.lesson)`; if either is null skip this part.
   b. Build `by_n = Map<number, string|null>` from `ctx.linked_lessons` whose `lesson_number(d.lesson_id)` has the same `prefix` (ONLY lessons in the context are read; invariant: no loading).
   c. If `by_n.get(me.n-1) === icon` and `by_n.get(me.n-2) === icon` (both present and equal) emit exactly ONE finding: `address: ctx.lesson.sections[0]?.address ?? `${ctx.lesson_id}.Launch``, `related_lesson_id` = the lesson id of `n-1` (the nearest earlier lesson), `code:null`, message `` `Opens with the same routine (${icon}) as the two lessons before it` ``. Invariant: raised only on the later lesson, so for L6/L7/L8 only L8's context (which holds L6 and L7) fires; L7's context has n-2 = L5 (different or absent) so none.
4. **`arc_repeat.ts` part 2, homework link**:
   a. `hw = parse_pages(ctx.row.homework)`; null -> skip.
   b. Targets = distinct `to_lesson_id` of `ctx.links` where `from_lesson_id === ctx.lesson_id` and `kind` is `"homework_text"` or `"page_continuation"`, that also appear in `ctx.linked_lessons`.
   c. For each target: `reading = parse_pages` over every `text_cards[].pages` of `target.lesson` (concatenate ranges; none parsable -> skip, quiet). If NO range of `hw` overlaps any range of `reading`, emit a finding: `related_lesson_id: target.lesson_id`, `address:` the address of this lesson's section named `"Homework"` else `` `${ctx.lesson_id}.Homework` ``, `code:null`, message `` `Homework pages do not match the reading in ${target.lesson_id}` ``. Decision (ticket silent): "match" = page ranges overlap; the homework text is the preview of the next lesson's reading.
   d. No links, no neighbour in context, or unparsable pages -> `[]`.
5. **`arc_repeat.ts` part 3, unpractised skill**:
   - Local type in the rule file (do not edit `types.ts`): `type RoleCell = CoverageCell & { role?: "I" | "P" | "A" };` and read `(ctx.unit_coverage as RoleCell[])`.
   - `practised = new Set(cells.filter(c => c.role === "P").map(c => c.code))`.
   - For each distinct `code` among cells with `role === "A"` and `lesson_id === ctx.lesson_id` and `!practised.has(code)`: emit one finding `code: "skill_unpractised"` (literal, per ticket), `related_lesson_id:null`, `address: `${ctx.lesson_id}.FrontMatter``, message `` `Skill ${code} is assessed here but no lesson in the unit practises it` ``. Empty `unit_coverage` -> none.
   - Findings from parts 1, 2, 3 are concatenated in that order. Wrap nothing in try/catch; the code must not throw on missing/empty data (use optional access).
6. **Tests** (vitest, synthetic only): build `lesson_n(n, icon)` helpers in each test file via `reading_lesson({ lesson_id: `G6.U4.L${n}` , sections: [section("Launch", id, 5, [routine(icon,"x"), p("y")]), ...rest of reading_lesson sections] })`. Note `reading_lesson` addresses use `LESSON_ID`; rebuild sections with `section(name, id, ...)` for the lesson id used (copy `reading_lesson().sections.slice(1)` then re-address by building new ones; simplest: write a local `lesson_n` that calls `reading_lesson()` and replaces `lesson_id` plus Launch section only; other sections' addresses are irrelevant to arc rules). Cases per §3. AC-1: L6,L7,L8 all `reading`; ctx(L8) with linked [L6, L7] -> 1 finding on L8, level advisory, address ends `.Launch`; ctx(L6) linked [L7, L8] -> 0; ctx(L7) linked [L6, L8] -> 0; L7 `writing` -> ctx(L8) 0. AC-4: this lesson `row.homework = "Ch. 1 pp. 9-15"` (build via `{...ctx, row: {...ctx.row, homework: "..."}}`), link `{link_id:"k1", from_lesson_id: <this>, from_address:"a", to_lesson_id:<next>, to_slot_id:"s", kind:"homework_text", label:"l"}`, next lesson `text_cards:[{title:"T", author:null, edition:null, chapter:null, pages:"pp. 9-15", kind:"public-domain", content_available:true}]`; mismatch `pp. 20-25`. AC-5: for each of `row-wp1/3/4.json` (parse with `NormalizedRow.parse`, import from `@ls/schema/outline`) paired with the lesson `stored-wp1.json` / `wp3-clean.json` (parse with `StoredLesson.parse`), assert `findings.length <= 1`; JSON read with `readFileSync(new URL(..., import.meta.url))` as in `minutes-sections.test.ts`. The sheet's issued-grid fixtures need the full outline parser and are not used (D3).
7. **Context**: area-map edit, devlog file (§2). Run the checks (§7).
