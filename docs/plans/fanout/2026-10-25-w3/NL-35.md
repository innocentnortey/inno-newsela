## 5. Steps
**Step 1: `packages/core/src/spend/reservation.ts`** (pure, no I/O, imports only decimal.js, ports types, `InvariantViolation`). Exports (exact):
```ts
export function max_call_cost(price: ModelPrice, input_tokens_estimate: number, output_cap: number): Usd
export function settle_cost(price: ModelPrice, usage: TokenUsage): Usd
export function run_cap_for(cost_per_lesson: Usd, lessons: number, multiplier: Decimal, unit_plan_cost: Usd): Usd
export function user_day_cap_for(run_cap_default: Usd, multiplier: Decimal): Usd
export function decide_reservation(snapshot: SpendSnapshot, amount_usd: Usd): ReservationDecision
```
Use `Decimal.clone({ precision: 40 })` locally (`const D = Decimal.clone(...)`) so global config is untouched; results returned must still be `instanceof Decimal`? Tests may check `instanceof Decimal`: so compute with `new Decimal(x)` from the imported class (default precision 20 is enough for these magnitudes) and do NOT clone. Rounding: `max_call_cost` -> `.toDecimalPlaces(6, Decimal.ROUND_UP)`; `settle_cost` -> `.toDecimalPlaces(6, Decimal.ROUND_HALF_UP)`; `run_cap_for` -> `.toDecimalPlaces(0, Decimal.ROUND_UP)` (result prints `13`; test with `.equals(new Decimal("13.00"))`); `user_day_cap_for` = `run_cap_default * multiplier` (6 dp). max uses `Decimal.max(input_per_mtok, cache_write_per_mtok)`. Divide by `1_000_000` last (invariant: ceil applies to the exact quotient; check 5,701 tokens -> 0.334253).
`decide_reservation`: (1) `amount_usd.lte(0)` -> `throw new InvariantViolation("reservation amount must be positive", { amount_usd: amount_usd.toString() })`. (2) Build the list in order `run_cap` (only if `run_cap_usd !== null`: used = run_settled+run_reserved, cap = run_cap_usd, scope null), `day_cap` (user_day_*, scope "user"), `project_cap` (project_*, scope "project"). (3) First where `used.plus(amount).gt(cap)` -> return `{allowed:false, reservation_id:null, refused_by, scope, remaining_usd: Decimal.max(0, cap-used), snapshot}`. (4) Else `{allowed:true, reservation_id:null, refused_by:null, scope:null, remaining_usd:null, snapshot}`. Return the same `snapshot` object (unchanged, not copied). Invariant protected: inclusive caps, first-failing-cap naming, refusal carries headroom for the 429 details (CON-5).

**Step 2: ledger skeleton** `packages/db/src/repos/spend.ts`:
```ts
export interface PgSpendLedger_ctor extends PgRepoDeps { settings: SpendSettings; logger?: Logger }
export class PgSpendLedger implements SpendLedger { constructor(deps: PgSpendLedger_ctor) ... }
```
(`logger` optional so wiring can omit it; when absent use a no-op. See Risks.) `const LOCK = "spend"`. Private `today(): string` = `this.clock.now().toISOString().slice(0, 10)` (UTC). `day_cap = user_day_cap_for(settings.run_cap_default_usd, settings.user_day_cap_multiplier)`. Private row mapper `to_settled(row): SettledReservation` where `released_usd = Decimal.max(0, reserved - settled)`, `overshoot_usd` from the column.

**Step 3: `reserve(req)`**: `db.with_tx(async tx => {...}, LOCK)`:
1. `req.amount_usd.lte(0)` is caught by `decide_reservation` (throws before any insert).
2. Run sums (only if `req.run_id !== null`): `select cap_usd from run where id=$1` (no row -> `InvariantViolation("reserve for unknown run", {run_id})`); `select coalesce(sum(settled_usd),0) s, coalesce(sum(case when status='reserved' then reserved_usd else 0 end),0) r from spend_reservation where run_id=$1`. Cap = `run.cap_usd`.
3. Day sums: same aggregate `where user_id=$1 and day=$2` (day = today UTC).
4. Project sums: same aggregate over all rows, plus `select coalesce(sum(cost_usd),0) from model_call where reservation_id is null` added to `project_settled_usd` (imported spike calls, G-5).
5. Snapshot: `user_day_cap_usd` = day_cap, `project_ceiling_usd` = `settings.build_spend_ceiling_usd`.
6. `decide_reservation(snapshot, req.amount_usd)`; if `!allowed` return it (NO insert; nothing else written). If allowed: `id = this.ids.new_id("sr")`; `insert into spend_reservation (id,run_id,job_id,user_id,purpose,reserved_usd,status,day,created_at) values (...,'reserved',$day,$now)` with `created_at = clock.now()`; return decision with `reservation_id: id`.
Invariant: all reads and the insert happen under the one advisory lock in one tx, so 20 parallel reserves serialise (AC-7). Pool: the concurrent test needs `create_test_db({ pool_max: 4 })` or more; waiting callers queue on the lock, fine.

**Step 4: `settle` / `release`** (both under lock `"spend"`):
- `settle(id, actual, model_call_id)`: `select * from spend_reservation where id=$1 for update`; missing -> `InvariantViolation("settle unknown reservation", {reservation_id})`. If `status==='settled'`: if `row.model_call_id === model_call_id` return `to_settled(row)` (idempotent); else `InvariantViolation("reservation already settled by another model call", {...})`. If `actual.lt(0)` -> InvariantViolation. Else (status `reserved` or `released`): `overshoot = Decimal.max(0, actual - reserved_usd)`; `update ... set status='settled', settled_usd=$actual, overshoot_usd=$over, model_call_id=$mc, closed_at=$now`. If `overshoot.gt(0)` call `logger.warn("spend.overshoot", { run_id: row.run_id, job_id: row.job_id, extra: { reservation_id, reserved_usd: str, actual_usd: str, overshoot_usd: str } })` (strings, ids and numbers only). Return `to_settled`.
- `release(id)`: lock row; missing -> InvariantViolation; if `status==='reserved'`: `update set status='released', settled_usd=0, closed_at=$now`; return `to_settled` of the (possibly unchanged) row. No-op on settled/released returns stored result.
`SettledReservation.released_usd` for AC-9: settle 0.42 of 1.00 -> 0.58; release -> 1.00.

**Step 5: `release_for_jobs`, `run_totals`, `check_day_cap`**:
- `release_for_jobs(job_ids)`: empty array -> return 0 without SQL. Else under lock: `update spend_reservation set status='released', settled_usd=0, closed_at=$now where job_id = any($1::text[]) and status='reserved'`; return `rowCount`.
- `run_totals(run_id)`: join `run.cap_usd`; settled = sum(settled_usd) of the run's rows; reserved = sum of `reserved_usd` where status='reserved'. Missing run -> InvariantViolation.
- `check_day_cap(user_id, amount_usd)`: one tx (no lock needed, read-only); snapshot with `run_cap_usd:null`, run fields `new Decimal(0)`, day and project sums as in Step 3; `return decide_reservation(snapshot, amount_usd)` (reservation_id stays null; no insert). Factor the day/project sum queries into one private method `sums(tx, user_id): Promise<{day, project}>` shared with `reserve`.
