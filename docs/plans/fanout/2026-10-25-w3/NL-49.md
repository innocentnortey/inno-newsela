### Step 1. `packages/db/src/repos/evidence.ts` (PgEvidenceRepo)
`export class PgEvidenceRepo implements EvidenceRepo`, constructor `(deps: PgRepoDeps)` storing `db`, `ids`, `clock` (copy the field pattern of `PgAuditLog`).

JSON via `JSON.stringify`.
- `add_case_result(r)`: INSERT into `eval_case_result` with `$8::jsonb, $9::jsonb` for expected/actual. A duplicate (run, case_id) is a Postgres error: let it propagate.
- `finish_eval_run(id, passed, total, report_path)`: `UPDATE eval_run SET passed=$2, total=$3, report_path=$4, finished_at=$5 WHERE id=$1 RETURNING suite, started_at`. `rowCount === 0` → `throw new InvariantViolation("eval run not found", { eval_run_id: id })`. Return the `EvalRunRow` (read `suite`, `started_at` from RETURNING; `finished_at` = the clock value used). Invariant protected: a run is never "finished" without existing.
- `insert_probe_run(p)`: INSERT with `p95_json = $7::jsonb`; id = `p.probe_run_id`; returns it.
- `insert_experiment_run(e)`: INSERT `id = e.experiment_id`; returns it.
- `ops_event(e)`: `return record_ops_event(this.db, { kind: e.kind, service: e.service, build_id: e.build_id, details: e.details as Record<string, unknown> })`.

### Step 7. `evals/src/runner.ts`
```ts
export interface RunnerConfig { repo_root: string; reports_dir?: string /* default <repo_root>/evals/reports */; prompt_version_id: string | null; models: JsonValue; env?: Record<string, string | undefined> /* for the leak guard, default process.env */; }
export class EvalRunner {
  constructor(evidence: EvidenceRepo, suites: readonly EvalSuite[], clock: Clock, config: RunnerConfig)
  async run(suite: SuiteName, opts: EvalOptions): Promise<EvalRunSummary>
}
```
(The 4th constructor parameter extends DO-4's 3-arg form; it carries values `EvalOptions` has no field for. Declare it under Risks.) `run` steps, in order:
1. Find the suite in `suites` by `name`; none → `throw new InvariantViolation("suite not registered", { suite })`.
2. `cases = suite.cases()`; `cases.length === 0` → `throw new EmptySuiteError(suite)` BEFORE any evidence call (AC-3: no `eval_run` row, so nothing can read as passing).
3. `opts.repeat` must be an integer ≥ 1, else `InvariantViolation("repeat must be a positive integer")`.
4. `row = await evidence.start_eval_run({ suite, git_sha: opts.git_sha, prompt_version_id: config.prompt_version_id, models: config.models, provider_mode: opts.provider_mode, case_set: \`cases=${cases.length};repeat=${opts.repeat}\`, run_id: null })`.
5. For each case in order, for `rep` 1…repeat: `outcome = await suite.score(c, opts)`; `case_id = opts.repeat === 1 ? c.case_id : \`${c.case_id}#${rep}\``; run `guard(\`case:${case_id}\`, c.expected)` and `guard(..., outcome.actual)`; `await evidence.add_case_result({ eval_run_id: row.eval_run_id, case_id, provenance: c.provenance, source: c.source, guards: c.guards, passed: outcome.passed, failure_category: outcome.failure_category, expected: c.expected, actual: outcome.actual })`. Collect `{case_id, passed, source, failure_category}`; `cost = cost === null ? outcome.cost_usd : cost.plus(outcome.cost_usd)` (no `new Decimal` needed in prod code; at least one case exists). If `outcome.case_id !== c.case_id` throw `InvariantViolation("outcome case_id mismatch")`. A throw from `score` propagates; the run row stays unfinished (`finished_at` null), which is the honest record of an aborted run.
6. `passed = rows.filter(r => r.passed).length`, `total = rows.length`.
7. Build the section (Step 6 input; `prompt_version: config.prompt_version_id`, `n: total`), read the existing report file if present, `merge_section`, `guard("report", text)`, `mkdir -p` and write with `fs.writeFile`. `report_path = path.relative(repo_root, abs)` converted to forward slashes (never absolute outside tests).
8. `await evidence.finish_eval_run(row.eval_run_id, passed, total, report_path)`; return `{ eval_run_id, suite, passed, total, report_path, cost_usd: cost }`. Clock use: `clock` is held for the section's timestamp-free design; do not put wall-clock time into the report (reports must be reproducible); use `clock.now()` only for nothing else. (If the lint rule flags the unused field, prefix with `_`; do not drop the constructor parameter.)

### Step 11. `evals/src/cli.ts`

Unknown flags → exit 2.
Flow:
1. `suites = deps.suite_factory(provider_mode)`; with `--fixture`, replace the registered `S1` with `make_fixture_suite()` (both cases pass).
2. `runner = new EvalRunner(deps.evidence, suites, deps.clock, {repo_root, reports_dir, prompt_version_id, models, env})`.
3. For each selected suite in order: `summary = await runner.run(...)`; print `out(\`${suite} ${summary.passed}/${summary.total} report=${summary.report_path}\`)`; if `!floor_met(suite, passed, total)` record exit code 1 (keep running the remaining suites, final code = highest). Catch `EmptySuiteError` → `err("suite has no cases: S1")`, exit code 2 (continue is NOT done: stop at the first empty suite and return 2). Catch `NotImplemented` → `err(message)`, return 2. Catch `InvariantViolation` from the leak guard → `err(message)`, return 2. Anything else rethrows.
4. Exit codes: 0 all floors met; 1 a floor not met; 2 usage, empty suite, NotImplemented or guard.
