### Contract of `src/lib/api-client.ts` (exact exports)
```ts
import type { components, paths } from "./api-types";
export type ApiErrorCode = components["schemas"]["ErrorCode"] | "NETWORK";
export class ApiError extends Error {
  readonly status: number;            // 0 for NETWORK with no response
  readonly code: ApiErrorCode;
  readonly details: Record<string, unknown>;   // {} when absent
  readonly requestId: string | null;  // X-Request-Id response header
  constructor(init: { status: number; code: ApiErrorCode; message: string; details?: Record<string, unknown>; requestId?: string | null });
}
export function isApiError(e: unknown): e is ApiError;
export interface ApiClientOptions { baseUrl?: string; fetch?: typeof fetch }
export function createApiClient(opts?: ApiClientOptions): ReturnType<typeof createClient<paths>>;
export const api: ReturnType<typeof createApiClient>;          // default instance used by the app
export function setUnauthenticatedHandler(handler: (() => void) | null): void;
```
Rules: default `baseUrl` = `(process.env.NEXT_PUBLIC_API_BASE ?? "") + (process.env.NEXT_PUBLIC_API_PREFIX ?? "/api")` (`NEXT_PUBLIC_API_PREFIX` exists only so the Prism prefix can be fixed without editing code, Risks 3). `credentials: "same-origin"`.
Custom fetch wrapper `apiFetch(input, init)`: (1) `await fetch(...)` inside try/catch: a rejection throws `ApiError{status:0, code:"NETWORK", message:"Couldn't reach Lesson Studio. Try again."}`; (2) `res.ok` and (status 204 or content-type includes `application/json`) returns `res` untouched; (3) `res.ok` with any other body throws `NETWORK` (status = res.status); (4) not ok: `const text = await res.clone().text()`, `JSON.parse` in try; if it matches `{ error: { code: string, message: string } }` and `code` is a key of the catalog (use a local `const` array copied from `ErrorCode`, or check `typeof code === "string"`), throw `ApiError{status: res.status, code, message, details: error.details ?? {}, requestId}`; otherwise throw `NETWORK` with the HTTP status; (5) before throwing, if `code === "UNAUTHENTICATED"` call the installed handler (once per call). Nothing else throws raw. No hand-built URLs: every call is `api.GET("/session")`-style over `paths`.
