## 5. Steps (inside `load`, in this order)
1. `unit_id = lesson_id.slice(0, lesson_id.lastIndexOf("."))` as `UnitId` (lesson id minus last segment; ids look like `G6.U4.L4`).
2. Resolve version once: `const src = await this.graph.source_outline_version(lesson_id)`; if null, `const unit = (await this.outlines.list_units()).find(u => u.unit_id === unit_id)`, version = `unit?.latest_outline_version_id`. If still null/undefined throw `InvariantViolation(\`no_outline_version: ${lesson_id}\`, { lesson_id })`. (Invariant: a re-upload never changes the row a generated lesson is compared with; G-24, R-14.)
3. `const recs = await this.outlines.rows(version)`; sort by `row.row_number`; `const own = recs.find(r => r.row.lesson_id === lesson_id && (r.row.kind === "lesson" || r.row.kind === "flex_day"))`. If none throw `InvariantViolation(\`lesson_has_outline_row: ${lesson_id}\`, { lesson_id })` BEFORE any other port call (AC-6; message holds the id only, never lesson text).
4. `const rc = await this.outlines.row_context(version, lesson_id, null)`. `row = rc.row`, `arc_header = rc.arc_header`, `links = rc.links`.
5. `allowed_codes`: `idx = await this.standards.index()`; for each code in `[...row.focus_codes, ...row.eld_codes, ...row.msls_codes]` push `idx.leaves_of(code)`; flatten, dedupe preserving first-seen order.
6. `standards = await this.standards.texts([...new Set([...allowed_codes, ...lesson.front_matter.standards.map(s => s.code)])])` (set order = insertion order, deterministic). Use the result as returned; unknown codes simply have no row (AC-8). `text_cards = lesson.text_cards`.
7. `linked_lessons`: ids = `[...(await graph.dependencies(lesson_id)).map(d => d.lesson_id), ...(await graph.dependants(lesson_id))]`, deduped in order; skip `lesson_id` itself; for each `await this.reader.latest_derived(id)`, drop nulls. (Reads the other lesson's stored row only; never `latest_derived(lesson_id)`.)
8. `pending_suggestions = await suggestions.pending_for(lesson_id, this.clock.now())`; `safety_flags = await flags.open_for(lesson_id)`; `confirmations = (await alignment.for_lesson(lesson_id)).filter(a => a.origin === "narrowed" || a.origin === "added")`.
9. `previous_lesson_flags`: from sorted `recs`, keep those with `lesson_id !== null` and kind `lesson` or `flex_day` (arc headers/totals excluded); index of `own` in that list; if index 0, `[]`, else `flags.open_for(prev.lesson_id)`. `unit_coverage = await alignment.coverage_rows(unit_id)`.
10. Return object with exactly the `CheckContext` keys: `lesson_id, content_hash, outline_version_id: version, lesson, row, arc_header, allowed_codes, standards, text_cards, links, linked_lessons, pending_suggestions, safety_flags, confirmations, previous_lesson_flags, unit_coverage`. `lesson` and `content_hash` are the arguments, unmodified.

Run the port calls sequentially (no Promise.all) so the spy call order is deterministic.
