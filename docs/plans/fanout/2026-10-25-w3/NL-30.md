## 1. Goal and sources

Deliver two worker classes with no model call and no node logic:
- `ClaimLoop` (`apps/worker/src/queue/claim-loop.ts`): requeue expired leases once at start (mark lost calls, release orphaned reservations), then keep at most `GENERATION_CONCURRENCY` (6) jobs in flight, renew leases every 30 s, route `unit_plan` jobs, drain on SIGTERM.
- `RunFinalizer` (`apps/worker/src/generation/run-finalizer.ts`): after each job, move the run to `capped` / `paused` / `complete` / `partial` (once, in one tx) and expose the completeness query.

### Step 1: `run-finalizer.ts`
Exports: `RunStateChange`, `CompletenessReport`, `JobStatusView`, `RunStateInput`, `DeriveRunState`, class `RunFinalizer`.
```ts
export interface RunStateChange { run_id: RunId; from_state: RunStateName; to_state: RunStateName; paused_check: string | null }
export interface CompletenessReport { run_id: RunId; terminal_jobs_without_calls: JobId[]; summary_matches_calls: boolean }
type FinalizerSettings = Pick<WorkerSettings, "circuit_breaker_same_check">;
export class RunFinalizer {
  constructor(runs: RunRepo, queue: JobQueue, calls: ModelCallLog, tx: TxRunner, settings: FinalizerSettings,
              derive_run_state: DeriveRunState, logger: Logger) {}
  after_job(run_id: RunId, outcome: JobOutcome): Promise<RunStateChange | null>;
  completeness(run_id: RunId): Promise<CompletenessReport>;
}
```
(DO-4's constructor has 5 parameters; the last two are added so the class does not import NL-27 code and can log. NL-29 only types against `RunFinalizer` and calls `after_job`; NL-79 does the wiring.)

`after_job` algorithm (invariant in brackets):
1. `change = await tx.with_tx(async (t) => {...})`; all writes use `t` [capped mark and cancel are atomic, AC-8].
2. In the tx: `run = await runs.lock_for_update(run_id, t)` [serialises concurrent after_job calls for one run; the second sees the first's state, so no duplicate transition]. If `run.state` is `"cancelled"` or `"capped"` return `null` (nothing overwrites these).
3. Cap path: `cap = cap_of(outcome.brakes_fired)` with `spend_run_cap->run_cap`, `spend_day_cap->day_cap`, `spend_project_cap->project_cap`, first match in that order. If `cap`: `runs.mark_capped(run_id, cap, t)`, then `queue.cancel_run(run_id, "capped", t)`; return `{run_id, from_state: run.state, to_state: "capped", paused_check: null}`.
4. `jobs = await queue.jobs_for_run(run_id)`. Pause path, only when `run.state === "running"`: build `TerminalJobView[]` from jobs with `kind === "lesson"`, `lesson_id !== null`, `finished_at !== null`: `{lesson_id, status, first_failing_kind: fr.find(r => r.check === "check_failed")?.check_kind ?? null, finished_at: finished_at.getTime()}`. Call `should_pause_run(views, settings.circuit_breaker_same_check)`. If `pause` -> `runs.set_state(run_id, "paused", d.check, t)`, return change to `"paused"` with `paused_check: d.check`. Never write to job rows [AC-7: tripping job's `failure_reasons` unchanged].
5. Derive path: `views: JobStatusView[]` = every job `{status, tile_state, kind, failure_check: failure_reasons[0]?.check ?? null}`; `input = {current: run.state, plan_stored: run.plan_stored_at !== null, cancelled: false, capped: false, paused: run.state === "paused"}`; `next = derive_run_state(views, input)`. If `next === run.state` return `null`; else `runs.set_state(run_id, next, null, t)` and return a change.
6. After the tx: if `change === null` return null. If `change.to_state` is `complete|partial|capped`: `report = await this.completeness(run_id)` inside try/catch; any gap (`terminal_jobs_without_calls.length > 0 || !summary_matches_calls`) -> `logger.warn("run.incomplete", {run_id, extra: report})`; a thrown error -> `logger.error("run.completeness_failed", {run_id})` and continue (never fail the job). Then exactly once `logger.info("run.state_change", {run_id, extra: {from_state, to_state, paused_check}})`. Return `change`. [Log after commit so a rollback never logs.]

`completeness(run_id)` (DO-6 missing-instrumentation 1-2). Ports have no "calls for job" query (Risks 2), so interim rule using `calls.completed_for`:
1. `jobs = queue.jobs_for_run(run_id)`; consider jobs with status `ready` or `generation_failed`.
2. Exclude refused-before-first-call jobs: status `generation_failed`, `cost_usd` equals zero (`cost_usd.isZero()`), and every `failure_reasons[].check` in `{"capped","cancelled"}` (and at least one reason).
3. Exclude `generation_failed` jobs with zero cost and `calls_lost === 0` (cannot tell if a failed call row exists; documented limitation).
4. Remaining jobs must have a completed call: for `kind === "unit_plan"` check `completed_for(job_id, "unit_plan", 1)`; otherwise any non-null of `completed_for(job_id, "lesson_draft", 1)`, `completed_for(job_id, "truncation_retry", 1)`, `completed_for(job_id, "repair", 1)`. None -> push `job_id` to `terminal_jobs_without_calls` (keep jobs order).
5. `totals = await calls.totals_for_run(run_id)`; `summary = jobs.reduce((acc, j) => acc.plus(j.cost_usd), totals.cost_usd.times(0))` (no `decimal.js` import needed in prod code); `summary_matches_calls = summary.equals(totals.cost_usd)`. This compares the stored per-job spend with the call rows (the run's "summary"); adding 0.01 to one job's `cost_usd` flips it.

### Step 4: `claim-loop.ts`
Exports: `TickReport`, `LoopExit`, `StopSignal`, `LessonJobPort`, `UnitPlanJobPort`, `UnitPlanOutcomeView`, `LEASE_RENEW_MS = 30000`, class `ClaimLoop`.
```ts
export interface TickReport { claimed: number; in_flight: number; requeued_at_start: number; lost_calls_marked: number; reservations_released: number }
export interface LoopExit { reason: "sigterm" | "fatal"; drained_jobs: number; abandoned_jobs: number }
export interface StopSignal { is_set(): boolean }
type LoopSettings = Pick<WorkerSettings, "worker_id" | "generation_concurrency" | "max_active_runs" | "job_lease_ms" | "job_poll_ms">;
export class ClaimLoop {
  constructor(queue: JobQueue, calls: ModelCallLog, spend: SpendLedger, runner: LessonJobPort, unit_plans: UnitPlanJobPort,
              clock: Clock, logger: Logger, settings: LoopSettings, tx: TxRunner) {}
  start(): Promise<TickReport>;
  run_until(stop: StopSignal): Promise<LoopExit>;
}
```
`start()` [G-9: orphaned work is cleaned before any claim]:
1. `rep = await queue.requeue_expired(clock.now())`.
2. If `rep.job_ids.length > 0`: for each id in order `lost += await calls.mark_lost(id)`; then `released = await spend.release_for_jobs(rep.job_ids)`.
3. `logger.info("claim_loop.start", {extra: {requeued: rep.requeued, lost_calls_marked, reservations_released}})`; return `{claimed: 0, in_flight: 0, requeued_at_start: rep.requeued, lost_calls_marked, reservations_released}`. `start()` never claims; NL-79's `main.ts` calls `start()` then `run_until`.

`run_until(stop)` [never more than `generation_concurrency` real runners at once, even for a lease-lost job]:
1. State: `inflight = new Map<JobId, Promise<void>>()`, counters `drained = 0`, `abandoned = 0`, `fatal = false`. Every promise in `inflight` must never reject (wrap with try/catch inside `execute`).
2. Cycle: `while (!stop.is_set() && !fatal)`:
   a. If `inflight.size >= generation_concurrency`: `await Promise.race([...inflight.values(), clock.sleep(job_poll_ms)])`; `continue`.
   b. `job = await queue.claim(settings.worker_id, settings.max_active_runs, settings.job_lease_ms)` in try/catch (on throw: `logger.error("claim_loop.claim_failed", {extra: {name}})`, then `await clock.sleep(job_poll_ms)`, `continue`).
   c. `job === null` -> `await clock.sleep(job_poll_ms)`; `continue`. Otherwise start `execute(job)` (not awaited) and `continue` straight to the next cycle (no sleep).
3. `execute(job)`: `ctl = new AbortController()`; `lost = false`; `done = false`. Register `inflight.set(job.job_id, promise)` synchronously before the first await (so the cap check sees it). Body:
   - Start renew task (not awaited): `while (!done) { await Promise.race([clock.sleep(LEASE_RENEW_MS), done_promise]); if (done) break; let ok: boolean; try { ok = await queue.renew_lease(job.job_id, settings.job_lease_ms) } catch { logger.error("claim_loop.renew_failed", {job_id}); continue } if (!ok) { lost = true; ctl.abort(new LeaseLost({ job_id: job.job_id })); logger.warn("claim_loop.lease_lost", {run_id: job.run_id, job_id: job.job_id}); break } }`. `done_promise` resolves in `finally`.
   - `kind === "unit_plan"`: `out = await unit_plans.run(job, ctl.signal)`; if `lost` skip everything else. Else `queue.finish(plan_outcome(job, out))` then, if `out.failure?.check === "capped"`, `await tx.with_tx((t) => queue.cancel_run(job.run_id, "capped", t))`. (`finish` then `cancel_run`: `finish` takes no tx, so they cannot share one; a crash between leaves a capped run whose queued jobs are refused by the ledger, acceptable.)
   - `plan_outcome`: stored true -> `{status "ready", tile_state "ready", failure_reasons []}`; `failure` set -> `{status "generation_failed", tile_state "failed", failure_reasons [out.failure]}`; common fields `job_id, brakes_fired [], repairs 0, truncation_retries 0, retries 0, calls_lost 0, cost_usd: new Decimal(0), version_id null`. If neither stored nor failure: `throw new InvariantViolation("unit_plan outcome neither stored nor failed", {job_id})`.
   - `kind` `lesson` or `candidate`: `await runner.run(job, ctl.signal)`; the runner finishes its own job and calls the finalizer; the loop never calls `queue.finish` for these.
   - Error handling: `LeaseLost` (or any error while `lost`) -> `abandoned += 1`, no finish. `InvariantViolation` -> `logger.error("claim_loop.fatal", {job_id, extra: {invariant}})`, `fatal = true`. Any other error -> `logger.error("claim_loop.job_failed", {job_id, extra: {name: err.name}})` (never the message text of a prompt), `abandoned += 1`, job left for `requeue_expired`.
   - `finally`: `done = true`, resolve `done_promise`, `inflight.delete(job.job_id)`. After the stop signal fires, count successful normal finishes as `drained += 1` (track `stopping` flag set when the cycle exits).
4. After the cycle exits: `await Promise.allSettled([...inflight.values()])` (wait for in-flight; do not abort them); return `{reason: fatal ? "fatal" : "sigterm", drained_jobs: drained, abandoned_jobs: abandoned}` where `drained` counts only jobs that were in flight when the cycle exited and ended normally.
5. Budget: no growing structures; `inflight` is bounded by 6.
