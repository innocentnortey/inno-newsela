## 5. Steps
1. **`packages/schema/src/lesson-ref.ts`.** `export function parse_lesson_ref(raw: string): LessonId | null`. Algorithm: (a) if `LESSON_ID_RE.test(raw)` return `raw`; (b) match `/^g(\d{1,2})-u(\d{1,2}):(L\d{1,3}|FLEX-\d{1,2}[a-z]?)$/` (case-sensitive) and return `` `G${a}.U${b}.${c}` ``; (c) else `null`. Invariant: both forms give the same canonical `LessonId`. Test `lesson-ref.test.ts`: `G6.U4.L4`, `g6-u4:L4`, `g6-u4:FLEX-1a` resolve to `G6.U4.L4` / `G6.U4.FLEX-1a`; `g6-u4`, `G6.U4`, `g6-u4:L4 `, `g6-u4:l4`, `""` give null. Run: `npx vitest run packages/schema/src/lesson-ref.test.ts`.
2. **Service skeleton** `lesson-read-service.ts`: `export class LessonReadService implements LessonReadApi` with the DO-4 constructor, as `constructor(private readonly states: LessonStateRepo, private readonly versions: LessonVersionRepo & LessonVersionLister, private readonly reader: LessonDocReader, private readonly outlines: OutlineRepo, private readonly alignment: AlignmentRepo, private readonly suggestions: SuggestionRepo, private readonly audit: AuditLog, private readonly issues: IssueRepo, private readonly flags: SafetyFlagRepo, private readonly graph: LessonGraphRepo)`. Public: `get_lesson(user, lesson_id): Promise<Lesson>` = `(await this.get_lesson_traced(user, lesson_id)).lesson`; `get_lesson_traced`; `history`. Never import a concrete adapter; never call a method that takes a `tx`; hold no clock, no logger.
3. **Constants.** `FROZEN: ReadonlySet<LessonStateName> = new Set(["submitted","approved","exported"])`; `CHECKLIST_STATES = new Set(["submitted","changes_requested","approved","reopened","exported"])`; `NO_HASH = "0".repeat(64)`.
4. **Lookup.** `const row = await this.states.get(lesson_id)`; `null` → `throw new DomainRefusal("NOT_FOUND", "Lesson not found.", { lesson_id })`.
5. **Source choice (invariant: frozen states never read the derived row; nothing reads the live document).** If `FROZEN.has(row.state)`: `snap = await this.versions.latest_snapshot(lesson_id)`; `null` or `snap.state_vector === null` → `throw new InvariantViolation(...)` (data fault, fixed phrase + lesson id). Content = `snap.lesson`, hash = `snap.content_hash`, vector = `snap.state_vector`, `schema_version = snap.lesson.schema_version`, `version_number = snap.number`, `version_id = snap.version_id`, `snapshot = {version_id, content_hash, state_vector}`. Else: `d = await this.reader.latest_derived(lesson_id)`; `null` → `DomainRefusal("NOT_FOUND", "Lesson has no stored content.", { lesson_id })`. Content = `d.lesson`, hash/vector/`schema_version` from `d`; `version_number` = `row.current_version_id === null ? 0 : (await this.versions.version(row.current_version_id))?.number ?? 0`; `version_id = row.current_version_id`; `snapshot = null`.
6. **Schema check (invariant: unknown schema/node fails loudly, nothing returned).** Inside one `try`: `assert_known_nodes({ type: "doc" } as PMJson, schema_version)` (checks the version even for an empty lesson), then `assert_known_nodes(section.content as unknown as PMJson, schema_version)` for every section. `catch (e)`: if `e instanceof SchemaUnknownError` → `throw new DomainRefusal("SCHEMA_UNKNOWN", "The stored lesson uses a schema this version cannot open.", { lesson_id, schema_version: e.schema_version, unknown_nodes: [...e.unknown_nodes] })` (ids and node names only, no content); rethrow anything else. Run this BEFORE building the body.
7. **Standards.** Start from `content.front_matter.standards` (they already carry `official_text` from the standards table at compile time; never take text from alignment rows, GR-5). `links = (await this.alignment.for_lesson(lesson_id)).filter(l => l.content_hash === hash)`. For each stored standard with at least one link row for its `code`: `asserted_by` = that code's rows' value (first row; if any row has `asserted_by "reviewer"` use "reviewer"), `confirmation` = `"confirmed"` if any row has `confirmed_by !== null`, else keep the stored value unless it is null, then `"open"` when `asserted_by !== "outline"`. A stored `"removed"` stays `"removed"`. Standards with no link rows keep stored values untouched. `origin`, `role`, `official_text` always stay as stored (WP-1: `L.6.4.b` origin `narrowed`, `asserted_by generator`, `confirmation open`).
8. **Alignment map.** Group `links` by `code` (first-seen order): `teach_links` = addresses of rows with role `I` or `P`, `check_links` = addresses of rows with role `A` (assumption, R4), `link_role` = `"I"` if any I, else `"P"` if any P, else `"A"`, `asserted_by` as in step 7.
9. **Body.** `lesson_key` = last dot segment of `lesson_id`; `unit_id`/`number`/`title`/`type` from `row` (title/type of the stored lesson if they differ: use `row`); `state` = `row.state`; `last_editor = row.last_editor_id` and `reviewer = row.reviewer_id` (ids, not names; R3). `front_matter = { ...content.front_matter, standards }` (looseObject keeps `minutes_total`, `vocabulary`). `sections` = `content.sections` as stored (copy addresses, name, minutes, content). `text_cards` map from `TextCardRecord`: `title`, `author`, `edition_or_isbn = edition`, `chapter`, `pages`; `kind`: `off-platform-text`→`off-platform-text`, `newsela-article`→`newsela-reference`, `public-domain`→`excerpt`; `rights_status`: `public-domain`→`"public-domain"`, `newsela-article`→`"Newsela-owned"`, `off-platform-text` with `content_available === false`→`"to-clear"`, else `null`. `outline_row`: `ov = await this.graph.source_outline_version(lesson_id)`; `ov === null` → `{ row_number: 0, segments: [] }`; else `rec = (await this.outlines.rows(ov)).find(r => r.row.lesson_id === lesson_id)`; none → same empty object; else `{ row_number: rec.row.row_number, segments: rec.row.segments.map((s, i) => ({ segment_id: `${ov}.r${rec.row.row_number}.s${i}`, column: s.kind, kind: s.kind, text: s.text, action: s.applies, source: "default", by: null })) }` (text copied verbatim as a string; R5). `send_back`: only when `row.state === "changes_requested"`: newest (`at` max) `HistoryRow` from `await this.audit.history(lesson_id)` with `to_state === "changes_requested"` → `{ tag: "other", note: h.reason ?? "", by: h.actor_name ?? "system", at: h.at.toISOString() }` else `null` (R6). `dependencies`: `(await this.graph.dependencies(lesson_id)).map(d => ({ direction: d.direction, lesson_id: d.lesson_id, slot_id: d.slot_id, status }))` with `status` = `d.source_state === "reopened" ? "source_reopened" : (d.source_state === "approved" || d.source_state === "exported") ? "source_approved" : d.slot_filled ? "waiting_for_source_approval" : "slot_empty"`. No field named `html`; no review-time or person-level minutes (GR-15). The only `minutes` keys allowed are `sections[].minutes` and `front_matter.minutes_total` (lesson plan time, already in the stored lesson).
10. **Checklist** (`CHECKLIST_STATES.has(row.state)` else `[]`). `open_issues = (await this.issues.current(lesson_id)).issues.filter(i => i.resolved_at === null && i.cleared_by === null)`.
