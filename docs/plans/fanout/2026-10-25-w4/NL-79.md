**Step 1. `PaidCaller` abort seam** (`packages/llm/src/paid-call.ts`; small, keep every existing behaviour).
1. Add `signal?: AbortSignal;` to `PaidCallRequest` (doc comment: aborted when the job lease is lost).
2. Top of `call()`: `if (p.signal?.aborted) throw abort_reason(p.signal)` before pricing/reserving (no reservation, no row). `abort_reason(s)` returns `s.reason` if it is an `Error`, else `new Error("aborted")`.
3. After a reservation is allowed, build `const aborted = new Promise<never>((_, rej) => { p.signal?.addEventListener("abort", () => rej(abort_reason(p.signal!)), { once: true }); })` (no listener when `signal` is undefined: use a never-settling promise and do not leak listeners, remove it in `finally`). Run `Promise.race([this.recorder.call(...), aborted])`.
4. If the race rejects because of the abort (check `p.signal?.aborted`): `await this.spend.release(reservation_id).catch(() => undefined)`; attach `.catch(() => undefined)` to the orphaned recorder promise so it cannot raise an unhandled rejection; rethrow the abort reason. Never settle after an abort (the reservation is released; invariant: a lost lease must not leave money counted by a job another worker re-claims).
5. Non-abort errors keep the existing `UnpricedModelError` / release paths unchanged.
6. New test `packages/llm/src/paid-call-abort.test.ts` (copy the fakes style from `paid-call.test.ts`): (a) abort while the recorder call is pending -> rejects with the signal's reason, `spend.release` called once with the reservation id, `settle` never called; (b) already-aborted signal -> rejects, `reserve` not called; (c) no signal -> unchanged behaviour (one existing case re-asserted).
