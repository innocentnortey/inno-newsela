## 5. Steps
1. **copy.ts**: `COPY = { eyebrow: "Lesson history", title: (n) => \`History · Lesson ${n}\`, versionsHeading: "Versions", provenanceHeading: "Provenance", auditHeading: "Audit log", copyHash: "Copy hash", copied: "Copied", missing: "Missing", notApplicable: "Not applicable (made by a person)", noReason: "No reason recorded", noStateChange: "No state change", noAudit: "No audit rows for this version.", loading: "Loading history", cantLoadThing: "the history" }` and `KIND_LABEL`: generated "Generated", candidate "Candidate", submit "Submit snapshot", approval "Approval", reopen "Reopen". Candidate label adds " (adopted)" when `adopted===true`, " (not adopted)" otherwise.
2. **derive.ts** (pure, unit-tested):
   - `shortHash(h)` = `` `${h.slice(0,4)}…${h.slice(-4)}` `` (same as approval's).
   - `formatWhen(iso)` = `new Date(iso).toLocaleString("en-GB", { timeZone: "UTC", year:"numeric", month:"short", day:"2-digit", hour:"2-digit", minute:"2-digit", hour12:false }) + " UTC"`; `formatClock(iso)` = hh:mm UTC with `en-GB`, `hour12:false`. (UTC so the e2e is deterministic; specs set `timezoneId: "UTC"`.) These are timestamps of events, never durations.
   - `selectedVersion(versions, param)`: parse `param` as integer `version_number`; return the match, else the highest `version_number` (default and fallback for junk/unknown values). Invariant: never undefined while `versions` is non-empty (v1 always exists; if empty, return null and the screen shows the can't-load message).
   - `auditFor(audit, version)`: rows whose `version_hash === version.content_hash`, kept in server order (chronological).
   - `transitionFor(audit, version)`: for kind `submit`→ first row with action `submit`, `approval`→ `approve`, `reopen`→ `reopen`, among `auditFor` rows; `generated`/`candidate` → null. Returns `{from_state, to_state, reason}` or null.
   - `actionLabel(action)`: map `start_review` "Review started", `submit` "Submitted", `withdraw` "Withdrawn", `approve` "Approved", `request_changes` "Changes requested", `reopen` "Reopened", `clear_safety_flag` "Safety flag cleared"; anything else: replace `_` with space and capitalise the first letter.
   - `auditLine(row)` = `` `${actionLabel(row.action)} by ${row.user}${row.reason ? `: ${row.reason}` : ""} · ${formatClock(row.at)}` `` (exact shape from the spec: "Safety flag cleared by J. Rivera: <note> · 10:42").
   - `provenanceRows(v: VersionEntry): { key: string; label: string; value: string | null; state: "present"|"missing"|"na" }[]` in this fixed order and labels: `outline_row_hash` "Outline-row hash" (value = full hash), `prompt_version_id` "Prompt version", `model` "Model", `schema_version` "Schema version" (number→string), `example_set_id` "Example set", `run_id` "Run", `cost_usd` "Cost" (value `` `$${n.toFixed(2)}` ``). **Missing rule (decision; the spec says a missing field is a defect, but CON-19 says human-made versions legitimately carry empty `model`/`example_set_id`):** a field is `missing` when the key is absent/`undefined`, or is `null`/empty string for any field EXCEPT these two cases: `model` and `example_set_id` on kinds `submit`/`approval`/`reopen` (state `na`, rendered `COPY.notApplicable`), and `example_set_id` on kind `candidate` (also `na`). `cost_usd` of `0` is present. `schema_version` of `0` is present. `run_id` null on `generated`/`candidate` is missing. Do not render parameters or `derived_from_version_id` as a stat row; show `derived_from_version_id` as an extra line "Made from {id}" under the list only when non-null (not a required field).
