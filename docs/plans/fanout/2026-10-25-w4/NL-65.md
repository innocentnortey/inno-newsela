## 5. Steps

Each step ends green on `npx tsc --noEmit` before the next.

1. **`word-count.ts`**: `export const SHORT_QUOTE_LIMIT = 12; export function countWords(text: string): number` = number of whitespace-separated tokens that contain at least one `\p{L}` or `\p{N}` (regex `/[\p{L}\p{N}]/u`), mirroring the CON-15 rule. Test `word-count.test.ts`: "" gives 0; "a  b" gives 2; "- — ..." gives 0; "don't stop" gives 2; 9-word and 13-word samples give 9 and 13. Hint only; never gate on it.
2. **`rights.ts`**: `export const RIGHTS_OPTIONS: { value: "short-quote-commentary"|"public-domain"|"licensed"|"to-clear"; label: string; help: string }[]` in that order. `label` equals `value` (the spec names them by token). `help` one line each: short-quote-commentary "A short quote of 12 words or fewer, used with commentary."; public-domain "Out of copyright, so no permission is needed."; licensed "Newsela holds a licence to use this text."; to-clear "Permission is still to be requested. The lesson stays blocked until rights are recorded." Export `type OfferedRights = (typeof RIGHTS_OPTIONS)[number]["value"]`.
3. **`find-slot.ts`**: `export interface SlotInfo { kind: "quote" | "excerpt"; address: string; ask: string; rights: OfferedRights }` and `export function findSlot(sections: Lesson["sections"], slotId: string): SlotInfo | null`. Depth-first walk of each `section.content` (nodes may lack `content`/`attrs`; treat as `unknown` with a small type guard, no `any`). Match `attrs.slot_id === slotId` on type `quote_placeholder` (kind quote, ask = `attrs.reason` or "Reviewer to insert a quote here.", rights default `DEFAULT_QUOTE_RIGHTS`), `excerpt_slot` (kind excerpt, ask "Reviewer to insert the excerpt for this slot.", rights = `attrs.rights` if it is one of the four offered, else "public-domain"), `quote` (kind quote, ask "Replaces the quote now in this slot.", rights default as placeholder). `address` is the section's `address`. Return null when not found. Test `find-slot.test.ts`: the three node types, nested content, miss, using small inline docs (synthetic).
4. **`fill-errors.ts`**: `export type FillFailure = { target: "text" | "source"; message: string } | { target: "banner"; message: string }` and `export function mapFillError(e: unknown, wordCount: number): FillFailure`. If `!isApiError(e)` or `e.code === "NETWORK"` or `e.code === "COLLAB_UNAVAILABLE"` give banner "Couldn't insert. Your text is kept. Try again.". Then: `SOURCE_REQUIRED` gives source "A quote needs a source: add the book and page, or the URL."; `QUOTE_TOO_LONG` gives text `${n} of 12 words: a short-quote-commentary quote is 12 words or fewer. Shorten it or choose another rights status.` where n = `e.details.word_count` if it is a finite number, else `wordCount`; `ROLE_FORBIDDEN` gives banner "Only reviewers insert quotes."; `LESSON_LOCKED` gives banner "This lesson is locked. Withdraw it first to insert a quote."; `NOT_FOUND` gives banner "This slot is no longer in the lesson. Close this and reload."; anything else gives banner `e.message`. Mind the Unicode: the spec text uses a plain colon and straight sentences exactly as above.
5. **`insert-quote-form.tsx`** (`"use client"`; props `{ lessonId, slotId, onClose }`; mounted only while the dialog is open so every open starts fresh, as `StartRunDialog` does). Follow `start-run-form.tsx` for structure.
   - State: `const { load, retry } = useLesson(lessonId)`; `slot = load.kind==="ready" ? findSlot(load.lesson.sections, slotId) : null`; `frozen = ready && ["submitted","approved","exported"].includes(load.lesson.state)`.
   - Drafts: `useDraft(\`insert-quote:${slotId}:text\`)`, same for `:title`, `:chapter`, `:pages`, `:url`. Rights is plain `useState<OfferedRights>` initialised from `slot.rights` once the slot is known (a `useEffect` keyed on `slot?.rights` that sets it only while the user has not changed it; track with a ref). `finish()` calls the five `clear()` functions then `onClose()`; use it for Cancel, the header Close (`onOpenChange(false)`) and success. A sign-in hop unmounts the form without `finish`, so drafts survive (UXQ-1).
   - Title/eyebrow: `DialogShell open size="lg" busy={submitting} eyebrow={slot?.address} title={...}` with title "Insert quote" for kind quote, "Fill excerpt slot" for excerpt, and **"Insert quote or excerpt" while the slot is not known** (loading, error). That generic title keeps the unedited `shells.test.tsx` row green.
   - Body, in order: error Banner (when `failure.target==="banner"`, in a `tabIndex={-1}` div that takes focus when set); a `well` box (`<div className="bg-well rounded-lg p-3 text-body text-ink">` containing `slot.ask` as a text node; component-contracts name it `well`, use the class the other FW code uses for it: `bg-well`) ; **Textarea** label "Text", `rows={5}`, value from draft, `help` = counter string `${n} of 12 words` only while rights is `short-quote-commentary`, otherwise omitted; `error` = text failure; **fieldset "Source"** (`<fieldset><legend className="text-small font-semibold text-ink">Source</legend>`) holding TextInput "Book or title" (error = source failure, so `SOURCE_REQUIRED` shows on the Source field), TextInput "Chapter", TextInput "Page or pages", and, for kind excerpt only, TextInput "URL" (`type="url"`, help "Use this when the excerpt comes from a web page."); **Select** label "Rights status" with `options={RIGHTS_OPTIONS}` and `help` = the selected option's help. Footer: `Button variant="secondary"` Cancel (calls `finish`) and `Button type="submit" form="insert-quote-form" loading={submitting}` "Insert". Insert is `disabled` with `disabledReason` "Still loading the slot." while `load.kind==="loading"` (the width must not change, which `Button` already guarantees); not rendered at all when `frozen`, where the body shows `Banner level="blocking" title="This lesson is locked. Withdraw it first to insert a quote."`. Load `error` shows Banner "Couldn't load this slot. Try again." with `action` = Retry button calling `retry`; `not_found`, `schema_unknown` or a ready lesson without the slot show Banner "This slot is no longer in the lesson."
   - Focus: effect with `setTimeout(() => textRef.current?.focus(), 0)` that re-runs when the slot becomes ready (the Textarea is rendered only when ready). Return focus to the opener on unmount exactly like `start-run-form.tsx` (`opener` captured in `useState` initialiser, restore in an unmount effect).
   - Counter: `const words = countWords(text); const over = rights==="short-quote-commentary" && words > SHORT_QUOTE_LIMIT;` A `useRef(false)` holds the previous `over`; in an effect, when `over` becomes true and was false, call `announce(\`${words} of 12 words: over the limit for a short quote.\`)`. Never announce otherwise. The counter text itself is plain help text, not a live region.
   - Submit: `onSubmit(ev)`: `preventDefault`; return if `submitting`, no slot, or frozen. Clear failures. Build the body **without touching the text**: `{ text, source_ref: { title: titleDraft, chapter: chapter === "" ? null : chapter, pages: pages === "" ? null : pages, ...(url === "" ? {} : { url }) }, rights_status: rights }` (`text` is the raw state string: no `trim`, no normalisation). Excerpt-only `url` field is the only way `url` is set. Then `setSubmitting(true); try { const { data } = await api.POST(...)`; on success `toast.show({ message })` then `finish()`. Message: `data?.still_blocking` or rights `to-clear` gives "Inserted. Still blocking: rights to clear."; otherwise "Quote inserted. Issue 1 resolved." (literal per spec). `catch (e) { const f = mapFillError(e, words); setFailure(f); }` and focus the failing field (`textRef`, a ref to the title input, or the banner div). `finally { if (alive.current) setSubmitting(false) }` (`alive` ref as in StartRunForm). The idempotency of a retry is the server's; do not send an Idempotency-Key (the operation declares none).
   - Toast hook: `const toast = useWorkspaceToast();` inside the form. The exported dialog wraps the form in `<ToastHostBoundary>` so it never throws when mounted without a provider (the shells test).
   - **Do not**: count words as a gate (Insert is never disabled by the counter); `trim`, `normalize`, `slice` or otherwise alter `text`; call `localStorage`/`sessionStorage`; write to the document or open a collab connection; use `dangerouslySetInnerHTML` or render `text` anywhere except as a textarea value or a React text node; add raw colours (`#abc`, `rgb(`) or arbitrary-value colour classes, use tokens such as `bg-well`, `text-ink`, `text-ink2`, `text-danger`; edit a file you do not own.
