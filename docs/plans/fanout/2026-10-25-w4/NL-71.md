## 5. Steps
Dependency direction: `app page → run-summary-screen → {use-run-summary, stat-cards, failures-table, stat-list, format} → src/lib + components/ui`. Nothing outside the feature imports it. `format.ts` is pure (no React, no network). The network is only in `use-run-summary.ts`. No new abstraction is invented (one implementation, no known second).

1. **`format.ts`** (pure). Exact exports. Invariant: nothing here rounds, converts units or derives a number from other fields (R-57, "stored values, never recomputed").
   - `formatUsd(n: number): string`: `const s = String(n); const dec = s.includes("e") ? 6 : (s.split(".")[1]?.length ?? 0); return "$" + n.toFixed(Math.max(2, Math.min(dec, 6)));` (1.61 → `$1.61`; 0.4999 → `$0.4999`; 2 → `$2.00`; 0.5 → `$0.50`). It only pads, it never drops a digit up to 6 places.
   - `formatNumber(n: number): string` → `String(n)` (3.4 → `3.4`; 612 → `612`).
   - `nText(n: number): string` → `n = ${n} ${n === 1 ? "lesson" : "lessons"}` (`n = 3 lessons`, `n = 1 lesson`).
   - `unitLabel(unitKey: string): string`: `const id = unitIdFromKey(unitKey); const m = id && /^G(\d+)\.U(\d+)$/.exec(id); return m ? \`Grade ${m[1]} · Unit ${m[2]}\` : unitKey;` (a small local copy; do not import from `features/progress`).
   - `isGoing(state: RunState): boolean` → `state === "planning" || state === "running" || state === "paused"`.
2. **`use-run-summary.ts`** (`"use client"`): `export function useRunSummary(runId: string): UsePollResult<RunSummary> & { notFound: boolean }`.
   - `const [notFound, setNotFound] = useState(false);` Reset it with an effect keyed on `[runId]`.
   - Fetcher: `async () => { try { const { data } = await api.GET("/runs/{runId}/summary", { params: { path: { runId } } }); if (!data) throw new Error("empty"); return data; } catch (e) { if (isApiError(e) && e.code === "NOT_FOUND") setNotFound(true); throw e; } }`.
   - `const [going, setGoing] = useState(true)`: keep a ref/state of the latest `data`; `const finished = data !== undefined && !isGoing(data.state);` then `usePoll(fetcher, { enabled: !finished && !notFound })`. Because `usePoll` is called before `data` exists, hold `finished` in a `useState` that an effect on `[poll.data]` sets (`setFinished(poll.data ? !isGoing(poll.data.state) : false)`), and pass `enabled: !finished && !notFound`. (Same one-fetch-then-stop effect NL-59 gets from `terminal`; copy how `src/features/progress/use-run-progress.ts` does it if that reads simpler.) Invariant: a finished run causes no further requests; a running run polls every 2000 ms (the `usePoll` default; no backoff logic here, a single small GET).
   - Return `{ ...poll, notFound }`. No timers of your own.
3. **`stat-cards.tsx`**: `export function StatCards({ summary }: { summary: RunSummary })`. One `<dl aria-label="Run figures" className="grid grid-cols-1 gap-4 sm:grid-cols-2 xl:grid-cols-4">`; each card is a `<div className="bg-panel border-hair shadow-e1 rounded-xl border p-(--space-4) flex flex-col gap-1">` holding `<dt className="text-label text-ink2">`, `<dd>` figure and `<dd>` n-line (a `dl` may group dt/dd inside `div`). Figure style: `<dd className="text-display text-ink tabular-nums">…<span className="text-title-sm text-ink2"> unit</span></dd>`; n-line `<dd className="text-small text-ink3 tabular-nums">`. Exact content, in order:
   1. dt `Wall time`; figure `formatNumber(wall_time_seconds)` unit ` seconds`; n-line `nText(n)`.
   2. dt `Cost per lesson`; figure `cost_per_ready_lesson_usd === null ? null : formatUsd(...)`; null → `<dd className="text-title-sm text-ink2">No ready lessons yet</dd>` (no number); n-line `nText(lessons.ready)` followed by ` ready, cost ${formatUsd(cost_usd)} in total` (all stored values; wording: `n = 3 lessons · ready lessons only · total ${formatUsd(cost_usd)}`). Keep it one `dd`.
   3. dt `p95 minutes per lesson`; figure `formatNumber(p95)` unit ` min`; null → `No figure yet`; second line (always, a `dd text-small text-ink2`): `against the ${target_minutes_per_lesson}-minute target` (response value 5 → "against the 5-minute target"); n-line `nText(n)`.
   4. dt `Retries`; figure `formatNumber(retries)`; n-line `nText(n)`.
   Never compare p95 with the target in code (no "over/under", no colour by threshold): the sentence is the whole statement.
4. **`failures-table.tsx`**: `FailuresTable({ rows }: { rows: RunSummary["failures_by_reason"] })` using `Table caption="Failures by reason"`; `Thead` row `Reason` / `Count` (`numeric` on Count); `Tbody` one `Tr` per row (`key={reason}`), `Td` reason text (as given, no mapping) and `Td numeric` count. Empty → one `Tr` with `<Td colSpan={2}>No failures.</Td>`.
5. **`stat-list.tsx`**: `StatList({ summary })`: `<section aria-label="Other counts"><dl className="…">` rows (`div` with dt/dd, `tabular-nums` dd): `Placeholders left` → `formatNumber(placeholders_left)`; `Calls lost in flight` → `formatNumber(calls_lost_in_flight)`; `Brakes fired` → empty list: `None`; else `brakes_fired.map(b => \`${b.brake} × ${b.count}\`).join(", ")`; `Truncation retries` → `formatNumber(truncation_retries)`.
6. **`run-summary-screen.tsx`** (`"use client"`): props `{ unitKey: string; runId: string }`. Uses `useRunSummary(runId)`. No `useSession`: the screen is identical for every role.
   - `const board = \`/units/${unitKey}/board\`;`
   - `notFound` → `<NotFound what="run" boardHref={board} where={unitLabel(unitKey)} />`.
   - No data and no error → `<div aria-busy="true"><span className="sr-only">Loading run summary</span>` + four skeleton cards in the final grid shape (`<ul aria-hidden>`-free: `<div aria-hidden className="grid grid-cols-1 gap-4 sm:grid-cols-2 xl:grid-cols-4">` of four `<div className="bg-well rounded-xl h-28 animate-pulse" />`) `</div>`.
   - No data and error → `<CantLoad thing="run summary" onRetry={poll.retry} />`.
   - Data: `<PageHeader eyebrow="Run" title="Run summary" meta={<>{unitLabel(unitKey)} · {runId}</>} />` (Open items 1: the spec's "rows 8, 9 and 25" cannot come from CON-21).
   - Stack `flex flex-col gap-4`: `StaleBanner asOf={dataAt} thing="run summary"` when `poll.stale && dataAt`; when `isGoing(data.state)` → `<Banner level="info" title="This run is still going. Numbers so far:" />`; `StatCards`; `FailuresTable`; `StatList`; the report link; a `<nav aria-label="Run links">` with `<Link href={\`/units/${unitKey}/runs/${runId}\`}>Run progress</Link>` and `<Link href={board}>Back to the board</Link>`.
   - Report link: `data.report_path` non-null → `<Link href={data.report_path} external>Full-run report (file)</Link>`; null → `<p className="text-small text-ink2">Full-run report (file): not written yet</p>` (plain text, not a dead link).
   - Keep the stat cards visible while stale. `h1` lives only in `PageHeader`.
7. **Route `page.tsx`** (server component; Next 16 `params` is a Promise), same shape as `…/runs/[runId]/page.tsx`:
