Step 4. `auth.ts`:
```ts
export interface SocketAuthRequest { document_name: string; cookie_header: string | null; token_param: string | null; socket_id: string }  // socket_id added to DO-4's shape (SocketContext needs it)
export class CollabAuthenticator {
  constructor(sessions: SessionRepo, states: LessonStateRepo, guard: WriteGuard, frozen: FrozenDocs, clock: Clock, settings: CollabSettings)
  authenticate(req: SocketAuthRequest): Promise<SocketContext>
}
```
Algorithm (each step protects an invariant):
1. Parse `lesson_id` from `document_name` (`/^lesson:(.+)$/`); no match -> `DomainRefusal("NOT_FOUND", "Unknown document.")`. (No DB touched.)
2. Parse the cookie named `settings.session_cookie_name` from `cookie_header` (split on `;`, trim, split at first `=`; URL-decode not needed, the web sets a raw token). Missing or empty -> `DomainRefusal("UNAUTHENTICATED", "Sign in again.")` **before any database call** (AC-1: nothing loads). `token_param` is ignored for identity (cookie only).
3. `sessions.resolve(createHash("sha256").update(token).digest("hex"), clock.now())`; `null` -> UNAUTHENTICATED (the repo already treats expired and revoked as `null`; do not re-implement expiry).
4. `row = await states.get(lesson_id)`; `null` -> `DomainRefusal("NOT_FOUND", ...)`.
5. `frozen.seed(lesson_id, row.state)` (first connection only; seed is a no-op afterwards).
6. `decision = guard.can_write(ctx.user.role, row.state, lesson_id)`; return `{ socket_id, user, lesson_id, lesson_state: row.state, read_only: !decision.allowed }`.
Never log the cookie, token or hash. Messages are fixed phrases.

Step 5. `persistence.ts`:
```ts
export interface LoadedDoc { lesson_id: LessonId; ydoc_bytes: YDocBytes; seq: number; schema_version: number }
export class LessonPersistence {
  constructor(store: LessonDocStore, reader: LessonDocReader, frozen: FrozenDocs, acks: AckBroadcaster, logger: Logger, settings: CollabSettings)
  load(document_name: string): Promise<LoadedDoc>
  store(document_name: string, ydoc_bytes: YDocBytes, last_editor: UserId | null, request_id: RequestId | null): Promise<StoreAck | null>
  forget(lesson_id: LessonId): void
}
```
- `load`: parse the lesson id; `row = reader.latest(id)`; `null` -> `throw new Error("no lesson_doc for lesson " + id)`; `row.schema_version !== SCHEMA_VERSION` -> `throw new Error("unknown schema_version " + v + " for lesson " + id)` (message names the lesson id; no content); remember `last_sv.set(id, row.state_vector)`; return the bytes.
- `store`: (1) `sv = state_vector_of(bytes)`; if `sv === last_sv.get(id)` return `null` (nothing new since the last store or load; prevents duplicate rows from Hocuspocus's unload-time stores). (2) `derived = ydoc_to_lesson(bytes, SCHEMA_VERSION)` (throws on unknown nodes; propagate, no ack). (3) `hash = content_hash(derived)`. (4) `ack = await store.store({ lesson_id, ydoc_bytes: bytes, derived, content_hash: hash, state_vector: sv, stored_by: last_editor, request_id, tag: null })` (one transaction inside `PgLessonDocStore`; any failure rolls back everything and throws: do not catch). (5) only after success: `last_sv.set(id, sv)`; `acks.stored(id, ack)`; `logger.info("collab.stored", { lesson_id, store_id: ack.store_id, duration_ms, extra: { seq: ack.seq } })`. Return `ack`. Invariant: no `stored` message without a committed row; a refused edit never reaches here because it was never applied to the document.
- NL-106 will call `store` to store at once; a `null` return means "unchanged; read `LessonDocReader.latest`".
