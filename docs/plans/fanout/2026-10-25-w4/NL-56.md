```ts
const body = { file: file as unknown as string };
await api.POST("/outline-versions", {

  bodySerializer: () => { const fd = new FormData(); fd.append("file", file); return fd; },

## 5. Steps
Dependency direction: `app/.../page.tsx` imports the feature; the feature imports `components/*`, `lib/*`, `features/frame/*` (read only); nothing imports the feature except the page. No new abstraction is needed.

1. **`flags.ts`**: `export const LINK_IMPORT_ENABLED = true;` with one comment: "Trim (a), PRD 6.5: set false to cut the link import; the switch then disappears."
2. **`unit-label.ts`**: `export function unitLabel(unitKey: string): string` returns `Grade 6 · Unit 4` for `/^g(\d+)-u(\d+)$/i` (`g6-u4`), else the key unchanged.
3. **`messages.ts`** (pure, no React). Exact copy:
   - `export type UploadError = { code: ApiErrorCode | "NO_FILE" | "NO_LINK"; text: string; retry: boolean }` and `export function toUploadError(e: unknown): UploadError`. Any non-`ApiError` becomes the `NETWORK` row.
   - `SHEET_NOT_PUBLIC`: `This sheet is private. Share it publicly or upload the file.`
   - `UNSUPPORTED_FILE`: `This file type isn't supported. Upload a CSV or XLSX file.`; when `details.reason === "too_large"`: `This file is over 5 MB. Upload a smaller CSV or XLSX file.` (spec gap, see Open items).
   - `HEADER_NOT_FOUND`: `Couldn't find the header row. We looked for these columns: ${names.join(", ")}.` where `names` = `details.columns_looked_for` filtered to strings, at most 20, each cut to 60 chars; if the array is missing or empty: `Couldn't find the header row.`
   - `TOO_MANY_ROWS`: `Too many rows for one unit: this sheet has ${rows} rows; the limit is ${max}.` with `rows` and `max` read from `details.rows` and `details.max_rows` only when `typeof === "number"`; if `rows` is missing: `Too many rows for one unit: the limit is ${max ?? 200}.`
   - `SHEET_UNREACHABLE`: `Couldn't reach Google Sheets. Try again, or upload the file.` with `retry: true`.
   - `ROLE_FORBIDDEN`: `Only authors can upload an outline.`
   - `NETWORK`: `Couldn't reach Lesson Studio. Try again.` with `retry: true`.
   - anything else: `Couldn't upload this outline. Nothing was stored. Try again.` with `retry: true`.
   - `retry` is false for all other codes.
   - `export const MSG_EXT = "This file type isn't supported. Upload a CSV or XLSX file."` (same string as UNSUPPORTED_FILE/type; used by the extension check).
   - `export function successLine(v: OutlineVersion): string` returns `Grade ${g} · Unit ${u} · version ${v.version_number} · ${v.row_counts.lessons} lessons · ${v.row_counts.flex_days} flex days · ${v.row_counts.arc_headers} arc headers · ${v.row_counts.total_rows} total row` + `s` unless the count is 1. Take `g` and `u` from `v.unit_id` with `/^G(\d+)\.U(\d+)$/`; if it does not match use `v.unit_key`. Pluralise each noun by its own count (`1 lesson`, `1 flex day`, `1 arc header`, `1 total row`). Expected for the `firstUpload` example: `Grade 6 · Unit 4 · version 1 · 41 lessons · 6 flex days · 7 arc headers · 1 total row`.
   - `export function sameHashLine(v: OutlineVersion): string` returns `Version ${v.version_number} is the same as version ${v.same_as_version}; ${v.changed_lessons} lessons changed.` (`1 lesson changed` when 1). With the `sameAsV1` example: `Version 2 is the same as version 1; 0 lessons changed.`
   - `export const reportHref = (v: OutlineVersion) => `/units/${v.unit_key}/outlines/${v.version_number}``. A same-hash result is "same" when `v.same_as_version !== null`.
4. **`use-progress-stage.ts`**: `export function useProgressStage(active: boolean): 0 | 1 | 2`. When `active` turns true: `setTimeout` 1000 ms to stage 1, 10000 ms to stage 2; when false: clear both and reset to 0. Pure timers, nothing else.
5. **`drop-zone.tsx`** (`"use client"`): props `{ file: File | null; onFile(file: File): void; onReject(): void; error?: string; id?: string; disabled?: boolean }`; forwardRef to the button so the form can focus it.
   - Render a `<div>` with: `<button type="button" ref aria-describedby={hintId} onClick={() => inputRef.current?.click()}>` whose visible text is `Choose file` (the accessible name stays exactly "Choose file"), styled as a dashed `border-edge` zone using `bg-well rounded-lg` tokens, min height 36px; `<p id={hintId}>CSV or XLSX, up to 200 rows</p>` (outside the button, small `text-ink2`); `<input ref type="file" accept=".csv,.xlsx" hidden tabIndex={-1} onChange>`; when `file` is set `<p data-testid="chosen-file">Chosen: {file.name}</p>` (JSX text); when `error` is set the field-error style as `Field` does (`text-small text-danger`, `id={errorId}` and add to `aria-describedby`).

7. **`upload-form.tsx`** (`"use client"`), props `{ onDone?: never }` none needed. State: `source` ("file" default), `file`, `url`, `busy`, `error: UploadError | null`, `fieldError: string | null`, `result: OutlineVersion | null`. Hooks: `useRouter()` from `next/navigation`, `useAnnounce()`, `useProgressStage(busy)`.
   - Layout (inside the screen's PageSheet): `<SourceSwitch/>` only when `LINK_IMPORT_ENABLED`; panel for file: `<DropZone/>`; panel for link: `<TextInput label="Google Sheet link" type="url" inputMode="url" name="sheet_url" help="The sheet must be shared so anyone with the link can view it." value onChange autoComplete="off"/>` (do not paste-block); the progress line; the error block; a `<Button variant="primary" size="lg" loading={busy}>` labelled `Upload` (file) or `Import` (link).    - Switching source: set `source`, clear `error` and `fieldError`, keep the other source's file or url in state (so toggling back restores it). Disabled while `busy`.
   - `submit()`:
     1. `if (busy) return`. File mode with no file: `setFieldError("Choose a file first.")`, focus the drop-zone button, stop. Link mode with an empty trimmed url: `setFieldError("Paste the sheet's link first.")`, focus the input via a ref, stop. Neither calls the API.

     3. `try { const { data } = await (source === "file" ? uploadFile(file) : importLink(url)); setResult(data!) } catch (e) { const u = toUploadError(e); setError(u); announce(u.text); queueMicrotask-free: focus in an effect (below) } finally { setBusy(false) }`.      4. Success handling in an effect on `result`: set a `useRef` timer only for the first-version case. No: keep the form visible, but disable Upload/Import with `disabledReason` unset (use `loading`-less `disabled` only for the first-version dwell, 1.5 s). Keep it simple: after a result the Upload button is `disabled` (reason text `Version ${n} is saved`) so a double submit is impossible.

A `useEffect` keyed on `error` calls `errorRef.current?.focus()` (this makes focus land on the message; `Banner` supplies the single `role="alert"`). Do not add another `role="alert"`.
   - Extension reject: `onReject` sets `error = { code: "UNSUPPORTED_FILE", text: MSG_EXT, retry: false }`, does **not** store the file, announces, and focuses the message. It never calls `api`.
   - Progress line: when `busy`, `<p role="status" className="text-small text-ink2">` with stage 1 `Reading rows…`, stage 2 `Reading rows · Checking codes`; stage 0 renders an empty `<p role="status">` (keep the element mounted so screen readers hear changes).
