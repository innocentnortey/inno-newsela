## 4. Shared code to use (copied from main)

```ts
// ports (packages/core/src/ports/*.ts)
interface ClaimedCheck { lesson_id: LessonId; content_hash: Sha256; store_id: StoreId; lease_until: Date }
interface CheckQueue {
  enqueue(lesson_id, content_hash, store_id: StoreId, tx: Tx): Promise<void>;   // coalesces; needs a real DbTx
  claim(lease_ms: number): Promise<ClaimedCheck | null>;
  finish(check: ClaimedCheck): Promise<void>;
  pending_for(lesson_id): Promise<PendingCheckState>; // { lesson_id, pending, newest_queued_hash, latest_stored_hash, latest_stored_at }
}
interface LessonDocReader { latest(id); latest_derived(id): Promise<DerivedRow | null> }
// DerivedRow = { lesson_id; seq; store_id: string; lesson: StoredLesson; content_hash: Sha256 } (+ stored_at, stored_by at runtime)
interface IssueRepo {
  replace_for_hash(lesson_id, content_hash, findings: readonly CheckFinding[], tx: Tx): Promise<IssueSet>;
  current(lesson_id): Promise<IssueSet>; // { lesson_id, checked_hash: Sha256|null, checked_at: Date|null, issues }
}
interface AlignmentRepo { replace_for_hash(lesson_id, content_hash, links: readonly AlignmentLinkRow[], tx: Tx): Promise<number> }
interface LessonGraphRepo { dependants(lesson_id): Promise<LessonId[]> }   // dependants(L5) = lessons that link TO L5 = [L4]
interface TxRunner { with_tx<T>(fn: (tx: Tx) => Promise<T>, advisory_lock?: string | null): Promise<T> }
interface Clock { now(): Date; sleep(ms: number): Promise<void> }
interface Logger { info/warn/error(event: string, fields: LogFields) }  // LogFields: request_id, run_id, lesson_id, job_id, store_id, duration_ms, extra
// core checks
CheckContextLoader.load(lesson_id: LessonId, lesson: StoredLesson, content_hash: Sha256): Promise<CheckContext>   // @ls/core/checks/context-loader
run_checks(ctx: CheckContext, rules: CheckRuleList, policy: CheckPolicy): CheckResult  // @ls/core/checks/registry; no try/catch inside
// CheckResult = { content_hash; findings: CheckFinding[]; alignment: AlignmentLinkRow[]; blocking; confirmation; advisory; first_failing_kind }
CHECK_RULES (registry.ts), CHECK_POLICY (@ls/core/checks/policy)
type CheckRule = { readonly kind: CheckKind; readonly level: IssueLevelName; run(ctx, policy): CheckFinding[] }
// settings: WorkerSettings.check_poll_ms (CHECK_POLL_MS, default 500), no check lease setting
```

## 5. Steps

1. `checks/rule-failure.ts`: `export class RuleFailure extends Error { readonly kind: string; readonly cause_name: string; constructor(kind: string, cause: unknown) }`. Message is the fixed string `"rule_failed"` (never the cause's message: it may hold lesson text). `name = "RuleFailure"`, `cause_name = cause instanceof Error ? cause.name : "unknown"`.

2. `checks/check-job-runner.ts`:
   ```ts
   export const CHECK_LEASE_MS = 30000;  // no setting exists; claim() reclaims expired leases (AC-8)
   export interface CheckRunReport { lesson_id: LessonId; content_hash: Sha256; blocking: number; confirmation: number; advisory: number; dependants_requeued: number; duration_ms: number }
   export class CheckJobRunner {
     constructor(checks: CheckQueue, reader: LessonDocReader, issues: IssueRepo, alignment: AlignmentRepo,
       graph: LessonGraphRepo, loader: Pick<CheckContextLoader,"load">, rules: CheckRuleList, policy: CheckPolicy,
       tx: TxRunner, clock: Clock, logger: Logger)
     run_once(): Promise<CheckRunReport | null>
   }
   ```
   (DO-4 passes `settings: WorkerSettings`; the runner needs none, so it is dropped; the lane takes `check_poll_ms`. Choose this, do not add a field.) `run_once` algorithm, each step with its invariant:
   1. `const claim = await checks.claim(CHECK_LEASE_MS); if (!claim) return null;` (`null` = queue empty; the lane sleeps).
   2. `started = clock.now()`. `const derived = await reader.latest_derived(claim.lesson_id)` (the stored row, never a Y.Doc). If `derived === null`: `finish(claim)`, log `check.skipped` `{reason:"no_doc"}`, return `null`... **return null only after finish; the lane then sleeps one poll, acceptable**.
   3. Newer-hash rule: if `derived.content_hash !== claim.content_hash`: `const p = await checks.pending_for(lesson_id)`; if `p.newest_queued_hash !== null` (a newer store already queued its own job): `finish(claim)`, log `check.skipped` `{reason:"superseded"}`, return `null`. Otherwise (no queued job, e.g. enqueue lost) fall through and check `derived` (hash = `derived.content_hash`) so the lesson cannot stay unchecked. Use `const hash = derived.content_hash` below. Invariant: issues are only ever written for a hash that is the stored row's hash.
   4. `const prev = (await issues.current(lesson_id)).checked_hash` (used in step 8).
   5. `ctx = await loader.load(lesson_id, derived.lesson, hash)`; `result = run_checks(ctx, guarded(rules), policy)` where `guarded(rules)` maps each rule to `{ kind: r.kind, level: r.level, run: (c,p) => { try { return r.run(c,p) } catch (e) { throw new RuleFailure(r.kind, e) } } }`. This is only to name the failing rule in the log; do not change `CHECK_RULES` or modules.
   6. On any throw in steps 4-5 or 7: catch in `run_once`, log `logger.error("check.failed", { lesson_id, store_id: claim.store_id, extra: { content_hash: hash, rule: e instanceof RuleFailure ? e.kind : null, name: e instanceof Error ? e.name : "unknown" } })` (never `e.message`, never lesson text), **do not call `finish`** (no release method exists on `CheckQueue`; the lease expires after `CHECK_LEASE_MS` and `claim()` hands it out again; see Risks), and return `null` so the lane proceeds to the next lesson. Do not rethrow.
   7. One transaction: `await tx.with_tx(async (t) => { await issues.replace_for_hash(lesson_id, hash, result.findings, t); await alignment.replace_for_hash(lesson_id, hash, result.alignment, t); })`. Invariant: no partial `issue` set without its `alignment_link` rows.
   8. `await checks.finish(claim)`. If `claim.content_hash !== hash` the `finish` UPDATE matches nothing (it keys on hash); accept that (rowCount 0 is documented as fine) but in that fall-through case lease expiry will later re-run once and hit the same-hash path (idempotent). 
   9. Dependants (only if `prev !== hash`; this stops A to B to A ping-pong because a re-queued dependant checks an already-checked hash and enqueues nothing): `for (const dep of await graph.dependants(lesson_id))`: `const d = await reader.latest_derived(dep); if (d === null) continue; await tx.with_tx((t) => checks.enqueue(dep, d.content_hash, d.store_id, t)); n++`. Requeue every dependant (the rule reads the other lesson's stored row; no cheaper correct filter exists). `dependants_requeued = n`.
   10. Log `check.done` `{ lesson_id, store_id, duration_ms, extra: { content_hash, blocking, confirmation, advisory, dependants_requeued } }`. Return the report with `duration_ms = clock.now().getTime() - started.getTime()`.

3. `checks/check-lane.ts`:
   ```ts
   export interface LaneStop { is_set(): boolean }
   export interface CheckRunnerPort { run_once(): Promise<CheckRunReport | null> }
   export class CheckLane {
     constructor(runner: CheckRunnerPort, clock: Clock, logger: Logger, settings: { check_poll_ms: number })
     run_until(stop: LaneStop): Promise<{ checked: number }>
   }
   ```
   Loop: `while (!stop.is_set()) { let r; try { r = await runner.run_once() } catch (e) { logger.error("check_lane.failed", { extra: { name } }); await clock.sleep(check_poll_ms); continue } if (r === null) await clock.sleep(check_poll_ms) else checked++ }`. After `r !== null` loop at once (drain a backlog without sleeping). SIGTERM: when `stop.is_set()` it stops claiming; the `await run_once()` in hand finishes first. Do not import `ClaimLoop`, `StopSignal`, or `GENERATION_CONCURRENCY`/semaphore (own lane). No lease renewal (checks are well under 30 s; `CheckQueue` has no renew method).

## 8. Risks and requests

- **Release on rule failure.** AC-4 says "releases the claim". `CheckQueue` has no `release`/`fail` method, and `finish` would mark the hash `done` so `unchecked_stores` would never retry it. Chosen: do not finish; the lease expires after 30 s and `claim()` reclaims it (retry is bounded only by the lease). Request to the integrator (NL-37 owner): add `CheckQueue.release(check)` and a retry cap later; not added here.
- **Lane start-up.** `main.ts` (A0) is not owned by this ticket and still starts no loop (it does not start `ClaimLoop` either). `wire_checks` hands back `check_lane`; whoever wires `main.ts` (NL-79/NL-83 or the integrator) must call `check_lane.run_until(stop)` beside the claim loop and track it in the drain tracker. Request to the integrator.
- **`WorkerDeps.db` is a `TxRunner`**, repos need `PgDatabase`; the cast in `wire_checks` relies on NL-83 replacing the `unbuilt("NL-83")` proxy with a real `PgDatabase`.
- `shells.test.ts` one-line edit collides with NL-79/NL-110 (keep both sides).
- DO-4 `CheckJobRunner` ctor lists `settings: WorkerSettings`; this plan drops it (unused). Contract text left as is; the area map note records the real ctor.
- AC-9 depends on S2/S4 plants from NL-84/85, not merged; inline plants cover the AC and the suites can reuse the runner later.
- Timing (AC-1, 5000 ms) is asserted on `FakeClock` stamps, not wall time.
