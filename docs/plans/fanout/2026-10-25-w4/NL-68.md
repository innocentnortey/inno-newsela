Rules:
- `checklistRows`: start from `lesson.checklist` in server order. `state` is `"blocking"` when `status === "open"` OR an issue (from `issues` or `blockedIssues`) with `level === "blocking"` and `blocks.includes("approve")` maps to that row via `KIND_TO_KEY`; otherwise `"ok"`. Add a `dependencies` row state `"blocking"` with title `COPY.dependencyItem(n)` and `link` to `/units/${unitKey}/lessons/${lessonKey}/approve` for each `waitingOn(lesson)` entry (replace the server's `dependencies` row if one exists, otherwise append). Blocking issues that map to no row go in one extra row `key:"other"` titled "Other blocking issues" with the messages joined by "; ". `evidence` per key (Open item 2): `standards` => focus-role standards not `removed`: `${codes joined ", "} ${allConfirmed ? "confirmed" : "not all confirmed"}`; `quotes_and_rights` => text cards of kind `excerpt` or `off-platform-text`: `${title} · rights: ${rights_status ?? "not recorded"}` joined by "; "; any other key or empty result => `evidence_refs.join(", ")`, or `item.status === "ok" ? "No issues found" : "Needs attention"` when no refs. A blocked/open row's evidence is the issue message when there is one. `jump`: first `evidence_refs` entry that equals a `section.address` => `{ href: "#sec-" + address, label: "Jump to " + section.name }`, else `null`. `KIND_TO_KEY` map (write it as a `Record<Issue["kind"], Row["key"] | "other">`, exhaustive so the type checker flags new kinds): standards group = `standard_not_taught, standard_not_checked, code_not_allowed, standard_confirmation, standard_add_suggestion`; quotes group = `quote_placeholder_open, excerpt_slot_open, quote_unmatched, page_out_of_range, proper_noun_unsourced, quote_without_source, quote_too_long, rights_to_clear, linked_text_changed`; `eld_support` = `eld_label_mismatch`; `content_safety` = `safety_flag_open, safety_note_without_tip, safety_text_in_student_block, disclosure_prompt`; `ai_spans` = `suggestion_pending`; `dependencies` = `cross_lesson_link`; everything else (`minutes_out_of_range, section_missing, schema_invalid, vocabulary_over_cap, vocabulary_word_missing, arc_repeat, judge_no`) = `other`.
- `viewFromError`: `STALE_PIN`=>stale, `RATING_REQUIRED`=>rating, `FOUR_EYES`=>four_eyes, `NETWORK`=>network, `ROLE_FORBIDDEN`=>forbidden, `DEPENDENCY_UNAPPROVED`=>dependency with `details.source_lesson_ids` (array of strings, default `[]`), `BLOCKED`=>blocked with `details.issues` (array, default `[]`; cast each to `Issue`) and `message` = first issue's `message` (fallback `e.message`), anything else => other with `e.message`.
- `approveDisabledReason`: `view.kind==="stale"` => "Reload to continue"; `four_eyes` => the string "Someone else must approve"; `dependency` or `waitingOn(lesson).length>0` => `COPY.dependencyReason(first lesson number)`; otherwise `null`. **Rating-missing is NOT a disabled reason** (the click must produce the message). Compute nothing else about eligibility (GR-6, ticket "Must not").

**Step 5: `use-approve-action.ts`.**
```ts
export interface ApproveAction { rating: Rating | null; setRating: (r: Rating) => void; view: ApproveView | null; submitting: boolean;
  result: { name: string; short: string; ratingLabel: string; on: string; thanks: string[] } | null; approve: () => Promise<void>; clearView: () => void; firstRadioRef: RefObject<HTMLInputElement | null> }
export function useApproveAction(a: { client: ApiClient; lesson: Lesson; userName: string; onApproved: () => void }): ApproveAction
```
`approve()` steps (the order is the invariant list):
1. If `submitting` or `result` is set, return (invariant: one request per click, never a second approve).
2. If `lesson.snapshot === null`, return (never approve without the pin).
3. If `rating === null`: set `view = { kind: "rating" }`, move focus to `firstRadioRef.current`, return without a request.
4. Set `submitting`, `view = null`. `POST` with exactly `{ action: "approve", snapshot_hash: lesson.snapshot.content_hash, snapshot_state_vector: lesson.snapshot.state_vector, rating }`.
5. On success: set `result` with `name = userName`, `short = shortHash(snapshot.content_hash)`, `ratingLabel`, `on = new Date().toISOString().slice(0,10)`, `thanks = waitingOnThis(lesson).map(d => d.lessonId)`; call `onApproved()` (the screen announces `COPY.toast(...)`). Do not refetch.
6. On failure: `view = viewFromError(e)`; keep `rating`; clear `submitting`. For `view.kind==="rating"` (server) focus the first radio too.
`clearView()` sets `view=null`. Reset the whole action when the lesson's `snapshot.content_hash` changes (after Reload) except `rating`.
