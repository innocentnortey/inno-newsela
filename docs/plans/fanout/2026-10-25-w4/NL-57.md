## 5. Steps

1. **`report-model.ts` (pure, no React, no I/O).** Export:
   - `formatClock(iso: string): string` = `new Date(iso).toLocaleTimeString("en-GB", { hour: "2-digit", minute: "2-digit", hour12: false })` (same as `StaleBanner`; e2e pins `timezoneId: "UTC"`).
   - `plural(n, one, many)`; `rowsLabel(rows: number[])` -> `"8–23"` when contiguous else `"8, 9, 25"`.
   - `lessonNumber(lesson_id)` -> `"4"` from `G6.U4.L4`.
   - `errorItems(report): ErrorItem[]` where `ErrorItem = { row: Row; finding: Finding; where: string; name: string }`: every finding with `level === "error"`, ordered by `row_number`. `where`: `"Unit"` when `kind === "unit_conflict"`, else `Row ${n} · Lesson ${k} · Column ${finding.column}` (no lesson part for flex days). `name` (button naming): unit_conflict -> `the unit`; else `row ${n}`, plus `, column ${column}` only when that row has more than one error finding.
   - `warningItems(report)`: a discriminated union list ordered by row: `{type:"note", row, segment}` for segments of kind `editor_note` or `safety_note` (radio Apply / Show to reviewer only / Ignore; values `apply` `show_only` `ignore`); `{type:"writer_task", row, segment}` ("becomes an **excerpt slot**"); `{type:"finding", row, finding}` for findings with level `warning` or `info` EXCEPT kinds `eld_mismatch` and `eld_not_checked`; `{type:"unit_rule", rule}` for each `report.unit_rules` ("**unit rule** for rows 8–23").
   - `eldItems(report): EldItem[]`: dedupe `rows[].eld[]` by `code` (first occurrence wins for label/strand/verdict/choice), `EldItem = EldEntry & { rows: number[] }`; `flaggedEld = items.filter(i => i.verdict === "mismatch")`; export `eldSummary(report) => { total: number; flagged: number }` (total = distinct codes, flagged = distinct mismatches).
   - `okRows(report)`: rows with `level === "ok"`; `okRowLabel(row)` -> `Row 10 · Lesson 6 · OK · 0 warnings` (flex day: `Row 12 · Flex day · OK · 0 warnings`).
   - `headingCopy(counts)`: `errors_unconfirmed === 0 && errors > 0` -> `All ${errors} errors confirmed`; else `${u} ${plural(u,"error","errors")} to confirm`.
   - `gateBanner(report): { level: "advisory"|"success"; title: string; body?: string }`: `counts.errors === 0` -> success `No errors to confirm. ${w} ${plural(w,"warning","warnings")}.` (w = `counts.warnings`); `errors_unconfirmed === 0` -> success `All ${errors} errors confirmed. Generate is on.`; `errors_unconfirmed === errors` -> advisory title `${u} errors to confirm`, body `Generate stays off: ${u} errors to confirm`; otherwise advisory `${u} ${plural(u,"error","errors")} still to confirm` (singular: "1 error still to confirm"). This is display copy only; never derive `generate_allowed`.
   - `applyChoiceResult(report, result): Report`: replace the row with the same `row_number`, replace `counts` and `generate_allowed`; additionally, for every `eld` entry in `result.row`, copy its `choice` onto entries with the same `code` in other rows (an ELD choice is per code).
   - `refusalCopy(n)` -> `Generate refused: ${n} ${plural(n,"error","errors")} still to confirm.`
   - `choiceFailedCopy = "Couldn't save this choice. Try again."`
   Unit-test all of it in `report-model.test.ts` (step 11).
