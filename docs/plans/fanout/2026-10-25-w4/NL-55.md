## 5. Steps

1. **`format.ts`** (pure, no React):
   - `shortHash(sha: string): string` returns `sha.slice(0, 8)`.
   - `formatUploaded(iso: string): string` returns `new Date(iso).toLocaleDateString("en-US", { year: "numeric", month: "short", day: "numeric", timeZone: "UTC" })` (UTC so the server render, browser and tests agree: "Oct 25, 2026").
   - `progressText(counts: Record<string, number>): string` returns `` `${counts.ready ?? 0} of ${total} ready` `` where `total` = sum of all values.
   - `routes(unitKey)` helper object: `{ board, upload, report(n), run(id) }` with the strings above.
2. **`link-button.tsx`**: `LinkButton({ href, children })` renders a plain `<a>` styled as the primary button: `className="inline-flex h-9 items-center justify-center rounded-md px-(--space-4) text-body font-semibold bg-primary text-on-primary hover:bg-primary/90"` (only token classes; no hex/rgb). Reason: `Button` renders `<button>`; navigation must be a link.
3. **`use-units-home.ts`** (`"use client"`): `export type UnitsHomeState = { kind: "loading" } | { kind: "error" } | { kind: "ready"; units: Unit[]; progress: Record<string, RunProgress | "unavailable"> }`; `export function useUnitsHome(): { state: UnitsHomeState; retry: () => void }`. One `useEffect` keyed on an `attempt` number (pattern copied from `SessionGate`): set `alive` flag; `api.GET("/units")`; on throw set `{kind:"error"}` (any error); on success, for each unit with `latest_run`, `Promise.all` of `api.GET("/runs/{runId}/progress", ...)`, each caught individually to `"unavailable"` (the card then shows the pill from `latest_run.state` and the note "Progress counts couldn't load."; no Retry, the list stays usable). Key `progress` by `run_id`. `retry` sets state to `loading` and increments `attempt`. Never use `usePoll`, `setInterval` or a second fetch.
4. **`units-skeleton.tsx`**: `UnitsSkeleton()`: wrapper `<div data-testid="units-skeleton" aria-busy="true">`; one card-shaped block (`bg-panel border-hair rounded-xl border p-(--space-4)` containing three `bg-well rounded-sm h-4` bars with `motion-safe:animate-pulse`), then three rows `<div data-testid="units-skeleton-row" className="bg-well rounded-sm h-8 motion-safe:animate-pulse">`. Add `<span className="sr-only">Loading units</span>`. No spinner.
5. **`versions-table.tsx`**: `VersionsTable({ unitKey, versions })`. `<Table caption="Outline versions">`; columns (Th): Version, File, Uploaded by, Date, Hash, Report. Row per version (already newest first; do not re-sort): `v{version_number}`; File = `` `Outline sheet · ${row_counts.lessons} lessons` `` (the contract has no file name: Risks 3); `created_by`; `formatUploaded(created_at)`; Hash = `<code>{shortHash(sha256)}</code>` and, when `same_as_version !== null`, a second line `<span className="text-small text-ink2">same as v{same_as_version}</span>`; Report = `<Link href={report(n)}>Report v{n}</Link>` with `aria-label={`Validation report, version ${n}`}`. Under the table, for every version with `same_as_version !== null`, a `<ul className="text-small text-ink2">` item: `Version {n} is the same as version {m}; {changed_lessons} lessons changed.` (copy from the spec: "version 2 is the same as version 1; 0 lessons changed", capitalised, and singular "lesson" when 1).
6. **`unit-card.tsx`**: `UnitCard({ unit, progress })` where `progress: RunProgress | "unavailable" | undefined`. `<section aria-labelledby={id}>` with the Card visual classes `bg-panel border-hair shadow-e1 rounded-xl border p-(--space-4)` (do not use `Card`'s `title` prop: its title is a non-link `h3`; `Card` without title is fine and preferred, wrap children). Inside: `<h2 id={id} className="text-title">` containing exactly one `<Link href={routes.board}>{unit.title}</Link>` (the whole title is one anchor; decision: it goes to the board, the other destinations are separate labelled links below). Then:
   - if `unit.latest_run`: `<StatusPill status={`run.${state}` as StatusKey} />` plus `<span>` with `progressText(progress.counts_by_tile_state)` when `progress` is an object, or the text "Progress counts couldn't load." when `"unavailable"`; a `<Link href={routes.run(run_id)}>View run progress</Link>`.
   - else (versions exist, no run): `<Link href={routes.report(versions[0].version_number)}>No run yet. Confirm the report, then generate.</Link>` (the whole sentence is the link text).
   - always when `versions.length > 0`: `<Link href={routes.board}>Open the board</Link>` and `<Link href={routes.report(versions[0].version_number)}>Validation report</Link>`. (Two links named "Open the board"/"Validation report" besides the title link is intended; AC-5 asserts only that the title text sits in exactly one anchor.)
7. **`units-home-screen.tsx`** (`"use client"`): `useSession()` for `role`; `useSetBreadcrumb([{ label: "Units" }])`; `useUnitsHome()`. `const promptGuidance = can(role, "view_prompt_guidance") ? buildNav(role, "/units")[0].items.find((i) => i.id === "prompt-guidance") : undefined;` (this honours cut #7 through `FIRED_CUTS` without a second flag). `const canUpload = can(role, "upload_outline")`. Render `<PageHeader title="Units" actions={...}/>` where actions (rendered only when `state.kind === "ready"` and the role allows it): `canUpload ? <LinkButton href={upload}>Upload outline</LinkButton>` (upload href uses the first unit's key, or `MVP_UNIT_KEY` when empty) and `promptGuidance ? <Link href={promptGuidance.href}>Prompt guidance</Link>` styled ghost: `className="font-semibold"` on a `Link` is enough (text-primary token). Neither element is rendered at all for other roles (no `hidden`, no `aria-hidden`). Body by state: `loading` → `<UnitsSkeleton/>`; `error` → `<CantLoad thing="units" onRetry={retry}/>`; `ready` with `units.length === 0` → `<p>` the exact empty sentence from §3 (no Upload button inside the body; the header one is the single Upload outline, so that `getByRole("link",{name:"Upload outline"})` is unique); `ready` otherwise → for each unit `<UnitCard/>` then `<VersionsTable/>` (MVP has one unit; render per unit, each table with the same caption).
   Root element: `<div className="flex flex-col gap-(--space-4)">`. The app shell already provides `<main id="main-content">`; do not add another `<main>`.
