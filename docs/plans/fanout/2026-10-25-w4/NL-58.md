## 5. Steps
1. **Pure helpers (+ tests first).**
   - `parse-rows.ts`: `export type RowsParse = { ok: true; rows: number[] } | { ok: false; message: string }` and
     `export function parseRows(text: string, valid: ReadonlySet<number> | null): RowsParse`.
     Algorithm: (1) split on `/[\s,]+/`, drop empty tokens; (2) none -> `{ok:false, message:"Enter at least one row, like 8, 9, 25"}`; (3) any token not `/^\d+$/` -> `"Rows are numbers separated by commas, like 8, 9, 25"`; (4) dedupe keeping first-seen order; (5) if `valid` is non-null, collect rows not in it: one -> `Row 52 isn't a teaching day in this outline` (use the straight apostrophe exactly as written), several -> `Rows 52, 60 aren't teaching days in this outline`; (6) else `{ok:true, rows}`. `valid === null` (report not loaded) skips step 5; the server then enforces (invariant: never block on data we do not have).
   - `prompt-line.ts`: `export function formatPromptLine(p: PromptVersions): string` -> `` `v${n(p.locked_layer.version_id)} · locked rules + guidance v${g} · pinned to this run` `` where `n(id)` = trailing digits of `locked_layer.version_id` (`"locked-1"` -> `1`, none -> the raw id) and `g` = highest `number` in `guidance_versions` (none -> `0`). Example: Prism data -> `v1 · locked rules + guidance v1 · pinned to this run`.
