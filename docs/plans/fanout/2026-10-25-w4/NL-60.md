## 5. Steps
1. **`plan-copy.ts`** (pure, no React). Duplicate rather than import from `progress/` (no cross-screen imports; duplication beats a shared abstraction until a third user):
   - `planHeading(unitKey: string): string` → `Unit plan · Grade ${g} · Unit ${u}` using `unitIdFromKey` and `/^G(\d+)\.U(\d+)$/`; unknown key → `Unit plan · ${unitKey}`.
   - `unitLabel(unitKey)` → `Grade 6 · Unit 4` (same regex; fallback `unitKey`).
   - `sortByDay(entries: PlanEntry[]): PlanEntry[]` → `[...entries].sort((a, b) => a.day - b.day)` (stable; do not mutate input).
   - `lessonTitle(lessonId: string): string` → key from `lessonKeyFromId`: `L4` → `Lesson 4`; `F2` → `Flex 2`; null → the id as-is. (The contract's `PlanEntry` has no title field; see Open items 1.)
   - `lessonHref(unitKey, lessonId): string | null` → `` `/units/${unitKey}/lessons/${key}` `` or null. (Same href shape as `progress/tile-grid.tsx`.)
   - `splitLinkLabel(label: string): { from: string; to: string } | null` → split on `" → "` exactly once; null when it has no arrow.
   - Copy constants: `PLANNING_TEXT = "The plan is being written (one call). It appears here before any lesson is drafted."`, `EMPTY_TEXT = "No plan yet. A run writes the plan first."`, `FAILED_TEXT = "The plan couldn't be written, so the run is paused. Resume the run from its progress page to try again."`, `NO_LINKS_TEXT = "No links between lessons."`.
2. **`use-unit-plan.ts`** (`"use client"`): `useUnitPlan(runId: string): UsePollResult<UnitPlan> & { notFound: boolean }`.
   Follow `features/progress/use-run-progress.ts` for the per-run flags: `const [flags, setFlags] = useState({ runId, notFound: false, settled: false })`; `notFound`/`settled` count only when `flags.runId === runId` (a new run id starts clean with no reset effect). Fetcher: `api.GET("/runs/{runId}/plan", …)`; `if (!data) throw new Error("empty")`; `setFlags({runId, notFound:false, settled: data.state !== "planning"})`; return data. In `catch`: `if (isApiError(e) && e.code === "NOT_FOUND") set notFound true`; rethrow. `usePoll(fetcher, { enabled: !settled && !notFound })`. Invariant protected: once `stored`/`failed` is read the effect is torn down (usePoll clears its timer when `enabled` flips), so the request count freezes. No backoff (the poll is bounded to the short planning window; the stale banner covers outages). `retry` is `poll.retry` unchanged; after a can't-load error `enabled` is still true so Retry works.
3. **`plan-skeleton.tsx`**: `<div aria-busy="true"><span className="sr-only">Loading the unit plan</span>` + 6 `<div data-skeleton="entry" className="bg-well h-20 rounded-md" />` in a `flex flex-col gap-2`. Server render the same for the rail card (one `bg-well h-32 rounded-xl`).
4. **`plan-list.tsx`**: props `{ entries: PlanEntry[]; unitKey: string; focusDay: number | null }`. Render `<ol aria-label="Teaching days" className="flex flex-col gap-4">`; for each sorted entry an `<li id={`day-${e.day}`} tabIndex={-1} data-day={e.day} key={e.lesson_id} className="border-hair scroll-mt-(--layout-top-bar) rounded-lg border p-(--space-4) focus-visible:outline-2 focus-visible:outline-primary">` containing:
   - `<p className="text-caps text-ink3 uppercase">Day {e.day}</p>` (day as text, a11y requirement)
   - `<h2 className="text-title-sm text-ink">` with `Link` to `lessonHref` (plain text if null) reading `lessonTitle(e.lesson_id)`
   - `<p className="text-body text-ink">{e.purpose}</p>`
   - `<p className="text-small text-ink2">Hands forward: {e.hands_forward}</p>`
   - when `e.performance_task_thread` is non-empty: `<span className="bg-selected text-primary text-label inline-flex rounded-sm px-1.5 py-px">{e.performance_task_thread}</span>` (the `selected` tag; word on it is the thread text, so it is not colour-only).
   Do not render `routines` (the spec does not list them). Focus effect: `useEffect(() => { if (focusDay == null) return; const el = document.getElementById(`day-${focusDay}`); if (!el) return; el.scrollIntoView?.({ block: "start" }); el.focus(); }, [focusDay])` — `?.` because jsdom lacks `scrollIntoView`. Mount `PlanList` only after data exists, so the element is in the DOM when the effect runs. Heading levels: `h1` (sheet) → `h2` per entry; the rail card title is `h2` from `SideRail`. No `h3` skips.
5. **`links-rail.tsx`**: `<SideRail title="Links between lessons" narrow>`; if empty `<p className="text-small text-ink2">{NO_LINKS_TEXT}</p>`; else `<ul className="flex flex-col gap-3">` with one `<li key={l.link_id} className="text-small text-ink">` per link: `parts = splitLinkLabel(l.label)`; if parts: `<Link href={fromHref}>{parts.from}</Link>{" → "}<Link href={toHref}>{parts.to}</Link>` — so the `<li>` text reads exactly `Lesson 4 Homework → Lesson 5 excerpt slot`; the arrow is plain text. Hrefs: `lessonHref(unitKey, l.from_lesson_id)` and `lessonHref(unitKey, l.to_lesson_id)`; when a href is null render that part as plain text. If `parts` is null render two links named `lessonTitle(from)` and `lessonTitle(to)` with `" → "` between (never drop a link row). Do NOT add `?slot=` or other query strings (SCR-9 deep-linking belongs to NL-62; Open items 2).
