## 5. Steps

Dependency direction (rule `code-design-solid-modularity`): the driver depends on nothing but `fetch` (injectable) and the generated types; the report builder depends on narrow `Pick<>` port interfaces injected by parameter (ISP, DIP); suites depend on the builder; only `full-run-deps.ts` and `driver/main.ts`'s caller touch concrete classes.

1. **`driver/types.ts`**: `DriverConfig { base_url: string; email: string; password: string; unit: string; outline_path: string; provider_mode: "real"|"stub"; cap_usd: number; prompt_version_id: string|null; poll_ms: number /*2000*/; max_wall_ms: number /*7_200_000*/; fetch: typeof fetch; sleep: (ms:number)=>Promise<void>; log: (line: string)=>void }`; `DriverResult { run_id: string; final_state: string; summary: RunSummaryT; polls: number }`; `class DriverError extends Error { code: string }` (codes `HTTP_STATUS`, `SHAPE`, `TIMEOUT`, `CAP_REFUSED`, `NO_CREDENTIALS`).
2. **`driver/cap.ts`**: `resolve_cap(args: { provider_mode; cap_arg: string|null; env }): number`. Cap source = `--cap-usd` value, else env `DRIVER_CAP_USD`. Ceiling = `Number(env["BUILD_SPEND_CEILING_USD"] ?? "75")`. Rules: stub mode: cap defaults to `ceiling` if absent, no refusal. Real mode: absent -> throw `DriverError("CAP_REFUSED")`; not a finite number > 0 -> refuse; `> ceiling` -> refuse. Invariant: refusal happens before any I/O (PD-29, R-55).
3. **`driver/http.ts`**: `make_http(cfg)` returns `call(op: string, method, path, opts{json?,form?,headers?}) -> {status, body}`. Keeps a cookie jar: store the `name=value` of any `Set-Cookie` header for `ls_session` (use `res.headers.getSetCookie()`); send it as `Cookie`. Logs one line per call `op status ms` only (never headers, body, password or cookie). Non-2xx -> `DriverError("HTTP_STATUS")` with `{op,status,code}` taken from `body.error.code` if present (message text only, no body dump). Multipart for `uploadOutline`: `FormData` with `file` = `new Blob([bytes])` named by file basename.
4. **`driver/guards.ts`**: one pure function per consumed response (`as_session`, `as_outline_version`, `as_report`, `as_choice_result`, `as_prompt_versions`, `as_run`, `as_progress`, `as_summary`) that checks the required keys and primitive types listed in the OpenAPI `required:` arrays for the fields the driver reads plus every top-level required key, and throws `DriverError("SHAPE")` naming the operation and key. This is the runtime "validates against the OpenAPI types" check (no Ajv dependency).
5. **`driver/driver.ts`**: `class FullRunDriver { constructor(cfg: DriverConfig); run(): Promise<DriverResult> }`. Order, all through `http.call`: (a) refuse if `email`/`password` empty (`NO_CREDENTIALS`); (b) `signIn`; (c) `uploadOutline` (read `outline_path` bytes); (d) `getValidationReport(outline_version_id)`; (e) for every `rows[].findings[]` with `level === "error"` and no `choice` with `source === "confirmed"`: `recordIntakeChoice {target_id: finding_id, kind:"confirm_fix", value: proposed_fix}` (one POST per finding, sequential; do not re-fetch, do not gate on `generate_allowed`, the server refuses with `VALIDATION_INCOMPLETE` itself); (f) prompt version = `cfg.prompt_version_id ?? (await listPromptVersions).current_prompt_version_id`; (g) `startRun` with header `Idempotency-Key: full-run-<unit>-<first 16 hex of sha256(outline_version_id|prompt_version_id|cap_usd)>` (≤128 chars, deterministic so a retry returns the same run), body per section 4 with `cap_usd: cfg.cap_usd`; (h) poll `getRunProgress` every `cfg.poll_ms` (2000) via `cfg.sleep` until `state` is terminal; if `Date.now`-free elapsed (count `polls * poll_ms`) exceeds `max_wall_ms` throw `TIMEOUT` (use the injected sleep, never `setTimeout` directly, so tests run instantly); a `paused` state is not terminal but is logged once; (i) `getRunSummary` -> return. The driver never reads a database, never imports a service.
6. **`driver/main.ts`**: `export async function main(argv: string[], env: Record<string,string|undefined>, deps?: Partial<DriverConfig>): Promise<number>`; flags `--unit G6-U4` (required), `--outline <path>` (else env `DRIVER_OUTLINE_PATH`; required), `--provider stub|real` (default from env `MODEL_PROVIDER_MODE`, else stub), `--cap-usd <n>`, `--prompt-version <id>`, `--base-url <url>` (else env `DRIVER_BASE_URL`, default `http://127.0.0.1:3000/api`). Order: parse -> `resolve_cap` -> only then build config and call `FullRunDriver.run`. Any `DriverError` -> write the message (no secrets) to stderr, return 2; success prints `run_id=<id> state=<s>` and returns 0. Executable as `npx tsx evals/src/driver/main.ts ...` (add the same `import.meta.url` guard pattern as `cli.ts`). Credentials: `env["DRIVER_EMAIL"]`, `env["DRIVER_PASSWORD"]`.

8. **`full-run-report.ts`**. Exports:

   ```ts
   export interface FullRunReadPorts {
     runs: Pick<RunRepo, "summary_rows">; calls: Pick<ModelCallLog, "totals_for_run">; issues: Pick<IssueRepo, "current">;
     alignment: Pick<AlignmentRepo, "for_lesson">; versions: Pick<LessonVersionRepo, "version">; docs: Pick<LessonDocReader, "latest_derived">;
   }
   export interface FullRunContext { ports: FullRunReadPorts; evidence: EvidenceRepo; repo_root: string; reports_dir?: string; git_sha: string; prompt_version_id: string|null; models: JsonValue; provider_mode: ProviderMode; env?: Record<string,string|undefined> }

   export interface FullRunFacts { ...see below }
   export async function collect_full_run_facts(run_id: RunId, ports: FullRunReadPorts): Promise<FullRunFacts>
   export async function build_full_run_report(run_id: RunId, ctx: FullRunContext, api_summary?: ApiRunSummary): Promise<FullRunReport>
   export function evaluate_s9_thresholds(facts: FullRunFacts, api_summary: ApiRunSummary | null): ThresholdResult[]   // pure
   ```
   (`build_full_run_report` takes `ctx` because DO-4's one-argument form has no way to receive repositories; the return type is the DO-4 `FullRunReport`.) `collect_full_run_facts` algorithm, every number from a stored row, nothing invented:
   1. `rows = await ports.runs.summary_rows(run_id)`; `totals = await ports.calls.totals_for_run(run_id)`. `n = rows.jobs.filter(j => j.kind lesson job and j.lesson_id !== null).length` (jobs of kind `lesson`; if the `JobKind` literal differs check `packages/core/src/ports/common.ts` `JobKind`; exclude `unit_plan`/`candidate`/`check` kinds). `n` is not hard-coded 47; the 47 check is a threshold.
   2. `first_pass_schema_valid` = count of those jobs with `repairs === 0 && truncation_retries === 0` and no `failure_reasons` entry with `check === "schema_invalid"` (M-31: "parse and compile without repair"). Also keep the rate = value / n.
   3. `repairs = totals.repairs` (count of `purpose='repair'` calls). `failures_by_reason`: object `{ [check]: count }` over failed jobs' `failure_reasons[].check`, keys sorted. `placeholders = rows.placeholders_left`.
   4. Per lesson (jobs with `lesson_id`): `issues = (await ports.issues.current(lesson_id)).issues`; `grounding_flags_by_kind`: count of rows with `resolved_at === null && cleared_by === null` whose `kind` is in `GROUNDING_KINDS = ["quote_unmatched","page_out_of_range","proper_noun_unsourced","quote_without_source","quote_too_long","rights_to_clear"]`, as `{ [kind]: count }` sorted keys (this set is the "grounding kinds" of M-33; `quote_placeholder_open`/`excerpt_slot_open` are counted in `placeholders`, not here). `disclosure_prompts_l31_l32` = open `disclosure_prompt` issues on lesson ids ending `.L31` or `.L32` (S9 floor: must be 0).
   5. `confirmations` (M-41): per lesson, `links = await ports.alignment.for_lesson(lesson_id)`; keep links whose `content_hash` equals the version's `content_hash` (step 6) and `origin` is `narrowed` or `added` and `confirmed_by === null`; count per lesson; `confirmations` = median of those per-lesson counts over all lessons with a stored version, rounded up with `Math.ceil` when even n gives a .5 (conservative against the <= 4 limit). Keep the per-lesson array in facts.
   6. Round trip (HP-4): for each job with `tile_state === "ready"` and `version_id !== null`: `v = await ports.versions.version(version_id)`; `d = await ports.docs.latest_derived(lesson_id)`; match iff both non-null and `d.content_hash === v.content_hash`. `round_trip_ok`, `round_trip_total`. A lesson without a stored version counts as not matching.
   7. Cost: `cost_usd = totals.cost_usd` (Decimal, never float). `jobs_cost = sum(jobs.cost_usd)` (Decimal). `per_lesson_max = max(jobs.cost_usd)`.
