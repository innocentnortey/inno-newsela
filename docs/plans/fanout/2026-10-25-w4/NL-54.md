## 5. Steps

```ts
export interface SendBackRecord { lesson_id: LessonId; tag: string | null; note: string; by: string; at: Date; }
export interface UnitBoardExtras { send_backs: SendBackRecord[]; }
export interface BoardExtrasRead {
  unit_extras(unit_id: UnitId): Promise<UnitBoardExtras | null>; // null = no such unit

export type GraphLookup = Pick<LessonGraphRepo, "dependencies">;
export class BoardService {
  constructor(board: BoardReadRepo, issues: IssueRepo, metrics: MetricsRepo, extras: BoardExtrasRead, graph: GraphLookup, clock: Clock) {}
  board(user: RequestUser, unit_id: UnitId, state: LessonState | null): Promise<UnitBoard>
```

(The DO-4 signature has 3 constructor args and `state?`; the ticket needs the extra reads. `user` is unused by logic: every role reads, do not role-check. Prefix usage with `void user`.)

**Step 2: `PgBoardExtrasRepo` (`packages/db/src/repos/board-extras.ts`, header `// NL-54`, comment "No logging; read-only; selects no minutes").** `constructor(deps: PgRepoDeps)` (import type from "./audit.ts"), `private readonly db: PgDatabase` (from "../pool.ts"). Both methods use `this.db.with_tx(async (tx) => ...)` and `tx.query<Row>(sql, [unit_id])` exactly like `repos/metrics.ts`.
- `unit_exists`: `SELECT 1 FROM unit WHERE id=$1`.
- `unit_extras`: inside ONE `with_tx`: unit check as above (none -> return null); then
  `SELECT DISTINCT ON (e.lesson_id) e.lesson_id, e.reason_tag, e.note, e.at, u.name AS by_name FROM review_event e JOIN lesson l ON l.id = e.lesson_id LEFT JOIN app_user u ON u.id = e.actor_id WHERE l.unit_id = $1 AND l.state = 'changes_requested' AND e.to_state = 'changes_requested' ORDER BY e.lesson_id, e.at DESC, e.id DESC`.
  Map: `note: r.note ?? ""`, `by: r.by_name ?? ""`, `tag: r.reason_tag`. Decision: a send-back shows only while the lesson is currently `changes_requested` (a stale tag on an approved lesson would mislead).

**Step 3: `board()`** in this order, calls via `Promise.all` where independent:
1. `[rows, counts, extras] = await Promise.all([board.board_rows(unit_id, null), issues.counts_by_lesson(unit_id), extras.unit_extras(unit_id)])`. EXACTLY these 3 repo calls (AC-11). `extras === null` -> `throw new DomainRefusal("NOT_FOUND", "Not found.")`. Always fetch with `state = null`; filter in memory (so rollup covers the whole unit, AC-2).
2. `rollup`: object with all 8 `LessonState` values as keys, initial 0, `+1` per row (so values sum to `rows.length`).
3. Counts: `Map<lesson_id, LessonIssueCounts>`; missing -> 0/0/0.
4. Dependency flags (Step 4) for rows with `dependency_flag === true`.
5. Map each row to `BoardRow`: `lesson_key` (see section 4), `number`, `title`, `type`, `state`, `blocking_count`, `confirmation_count`, `advisory_count`, `reviewer: reviewer_name`, `last_change_at: last_change_at.toISOString()`, `dependency_flags`, `send_back` (`{tag: r.tag ?? "other", note, by, at: at.toISOString()}` or `null`), `judge_flag: null`. (Schema `judge_flag` is nullable and the ticket says omit until NL-110: send `null`.) If a tag is not in `SendBackTag` options, use `"other"` (parse with `SendBackTag.safeParse`).
6. Filter by `state` if given, then `sort_rows` (exported pure function, unit-tested). Lesson order = `number` ascending with null last, then `lesson_id` string compare. Groups: 0 = `generation_failed` (lesson order); 1 = active (`draft`, `in_review`, `submitted`, `changes_requested`, `reopened`): `blocking_count` desc, `advisory_count` desc, `confirmation_count` desc, lesson order; 2 = `approved`, `exported` (lesson order).
7. Return `{ unit_id, unit_key: unit_key(unit_id), generated_at: clock.now().toISOString(), rollup, rows }`. Never call `run_checks`.

**Step 4: dependency flags.** For each flagged row (concurrently, `Promise.all`), `graph.dependencies(lesson_id)`; keep entries with `direction === "waits_on"`; for each, `key = lesson_key(entry.lesson_id)`:
- `!entry.slot_filled` -> `{kind:"waits_on", status:"slot_empty", lesson_id: entry.lesson_id, label:"Waits on "+key}`
- else if `source_state` not in (`approved`,`exported`) -> `{kind:"waits_on", status:"waiting_for_source_approval", ...same label}`
- plus, if `source_state === "reopened"` -> an extra `{kind:"source_reopened", status:null, lesson_id, label: key+" was reopened"}`. Nothing changes the lesson state (read-only).
Cost note for AC-11: flagged rows add one `dependencies` call each; the budget test seeds 47 lessons with no flagged row and asserts exactly 3 calls, plus a second assertion that `dependencies` is called once per flagged row and never for unflagged rows. Known gap (Risks): a source that is approved while its slot is empty gets no flag because `PgBoardReadRepo.dependency_flag` is false then.

**Step 5: `metrics()`.**
1. `[exists, frozen, rows] = await Promise.all([extras.unit_exists(unit_id), metrics.unit_metrics_rows(unit_id), board.board_rows(unit_id, null)])`; not exists -> `NOT_FOUND`.
2. `human = frozen.filter(r => r.human_sessions > 0)` (NS counts human sessions only, CON-10). `n = human.length`.
3. `median_minutes`: sort `active_minutes` ascending (Decimal `.cmp`); odd n -> middle; even n -> mean of the two middle (`Decimal.add(...).div(2)`); return `Number(x.toFixed(2))`; `null` when `n === 0`.
4. `fast_approvals = { count: human.filter(r => r.active_minutes.lt(r.g2_threshold_minutes)).length, of: n }` (each row's own stored threshold).
5. `approved = { k: frozen.length, total: rows.length }` (k = lessons with a frozen first-approval row; total = lessons in the unit). Decision recorded in devlog.
6. `caption` constant exactly `No baseline yet (AQ-14). Measured with us as reviewers.`
7. `segment_label`: distinct reviewer count `d` = number of distinct non-null `reviewer_name` among `rows` whose `lesson_id` has a frozen row in `human`. The name is used only to count and is never emitted. `n === 0` -> `null`; `d >= 3` -> `null`; else `` `${d <= 1 ? "one reviewer" : d + " reviewers"}, n = ${n}` `` (so 0 distinct names with n>0 reads `one reviewer, n = ..`).
8. `quality: null`. Output object has exactly `north_star` and `quality`; no per-person or per-lesson minutes. Add no logging in this file (add a comment saying so).
