## 5. Steps

1. **`guidance-diff.ts`** (pure, no imports): `export function diff_lines(base: string, next: string): string`.
   Split both on `"\n"`. Strip the common prefix and common suffix of lines. On the middle parts run an LCS only if
   `a.length * b.length <= 4_000_000`; otherwise treat the whole middle as removed then added. Output one line per changed line,
   in order, `"-" + line` for removed and `"+" + line` for added (unchanged lines are omitted), joined by `"\n"`. Identical
   input gives `""`. Example: base `""` and next `"g"` gives `"+g"` (matches the NL-34 harness fixture `"+g"`); but note `"".split("\n")` is `[""]`,
   so treat an empty string as zero lines. Invariant protected: the diff is deterministic and computed against the named base only.
2. **Unit test `guidance-diff.test.ts`** (`// @vitest-environment node`): `("", "g") -> "+g"`; `("a\nb", "a\nc") -> "-b\n+c"`; identical -> `""`;
   insert in the middle; the large-input fallback (two 2,500-line unrelated texts) returns every old line as `-` then every new line as `+`.
3. **`save_guidance`** in `prompt-service.ts`. Keep `NotBuiltYet` exported (other files define their own, but leave this export; removing it is out of scope). Body, in this order:
   1. `if (user.role !== "author") throw new DomainRefusal("ROLE_FORBIDDEN", "Only authors can save guidance.")` (before anything is read or written; mirrors `RunService.control`).
   2. `await this.ready;` (a save must not race the boot-time v1 sync).
   3. Validate: `if (req.reason.trim() === "") throw new DomainRefusal("REASON_REQUIRED", "Say why you are changing the guidance.")`;
      `if (req.guidance_text.length > 8000) throw new DomainRefusal("INVALID_REQUEST", "The request is not valid.", { fields: ["guidance_text"] })`.
   4. `const row = await this.tx.with_tx(async (tx) => { ... })` containing, in order:
      - `const base = await this.prompts.get(req.base_version_id)`; if `base === null`, `const cur = await this.prompts.current()` and `throw new DomainRefusal("STALE_BASE", "The guidance changed since you opened it.", { latest_version_id: cur.prompt_version_id })`.
      - `const diff = diff_lines(base.guidance_text, req.guidance_text)`.
      - `const created = await this.prompts.insert_guidance({ base_version_id: req.base_version_id, guidance_text: req.guidance_text, reason: req.reason.trim(), author_id: user.user_id }, diff, tx)`. The repo takes the advisory lock, throws `STALE_BASE` unless the base is the latest, and inserts.
