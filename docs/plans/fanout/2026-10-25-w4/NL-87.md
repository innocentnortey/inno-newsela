2. **Table parser** (pure, no regex over whole file): split text into lines; a table is a run of lines starting with `|`; the second line of the run is the `|---|` separator; cells = `line.split("|")` trimmed, drop the first and last empty. Remember the nearest preceding `#`-heading or italic caption for diagnostics only. Number helpers: `parse_fraction(cell)` matches `^(\d+)/(\d+)` at the start of the cell (so `20/20, 0 ✓` gives pass 20 total 20); `parse_num(cell)` takes the first `-?\d[\d,]*(\.\d+)?` (strip commas); a cell with no number throws `SpikeReportError(file, "table <n> row <r> col <c>", "not_numeric")`. `<r>` is the 1-based data row, so the message names the row, never the value. Rows are looked up by the first-column label (strip `**`), not by position.
3. **SP-1 result** from the *Comparison table* (header `| Option | Item | Schema valid (first try / final) | Truncations | Wall time | Cost | Words | Required blocks | Within pass line? |`): for each data row make `{option, item, valid_first_try (cell starts "yes"), valid_final (text after "/" starts "yes"), truncations, wall_s, cost_usd, words, required_passed, required_total, within_pass_line (cell has ✓)}`; `result = { overall_pass: /OVERALL: PASS/ in text, rows: [...] }`, plus `rate_limit` from the last table (`header | Value`): keys `requests`, `input_tokens`, `output_tokens` numeric (strip " per minute"). `config = { spike: "SP-1", model: "claude-sonnet-5-5" (first match of that literal in the file; else throw bad_shape), source_record: basename(path) }`.
4. **SP-1 calls** from the sidecar `opts.calls_path ?? path.replace(/\.md$/, ".calls.json")`. If the file is absent: `SpikeReportError(path, "calls file", "missing")`. Validate the shape by hand (no new dependency): top-level `experiment_id` string starting `SP-1`, `ledger_total_usd` string, `calls` non-empty array; each call needs string `call_id`, `requested_model`, `served_model`, `stop_reason`, `kind`, `run`, `row`; integer `attempt`, `input_tokens`, `output_tokens`, `cache_read_tokens`, `cache_write_tokens`, `latency_ms`; decimal-string `cost_usd` (`/^\d+(\.\d+)?$/`). Any miss or non-numeric: `SpikeReportError(calls_path, "call <i> <field>", "missing"|"not_numeric")` (`<i>` 1-based). Ignore unknown fields (AC-7 never copies them). Duplicate `call_id` inside the file: `bad_shape`. Cross-check: the sum of `cost_usd` (Decimal) rounded to 6 dp must be within 0.00001 of `ledger_total_usd`, else `bad_shape` at `ledger_total_usd`. Never invent a call: only what the file lists.
5. **SP-2 result** from the table with header starting `| Measure | Pass line |`: columns are A, B and Control (header cells 3..5; match by `startsWith("A")`, `startsWith("B")`, `startsWith("Control")`). Assertion rows map by first-cell prefix: `No edits after a lock`→`no_edits_after_lock`, `No silent keystroke losses`→`no_silent_keystroke_losses`, `Round trip keeps the hash`→`round_trip_hash_stable`, `Stale approve`→`stale_approve_409_no_change`, `Approver client hash`→`approver_client_hash_matches`: each cell → `{pass,total}` via `parse_fraction`. The `Store transaction p50 / p95 (n)` row: cell `13.0 / 25.1 ms (130) ✓` → `{p50:13,p95:25.1,n:130}` (three numbers in order; Control cell is `—`, skip control). `Submit duration` row → `submit_ms {p50,p95}`; `Resurrected keystrokes` → number. Result: `{ options: { A: {assertions, store_ms, submit_ms, resurrected}, B: {...} }, control: { assertions }, verdict: { A: "PASS", B: "PASS" } }` (verdict = cell of the `Verdict` row, first word). Missing a required assertion row: `missing`. Control cells like `0/3 (150 edits after lock)` parse with `parse_fraction`. `config = { spike: "SP-2", trials: 20 (the denominator of the first A assertion), source_record }`. `experiment_id = "SP-2-20261025"` (see decision D1).
6. **SP-3 result** from the table with header starting `| Measure | Pass line |` (columns A, B): rows by prefix: `Code-detectable plants caught`→`plants_caught {caught,total}` (`11/11 ✓`, `parse_fraction`); `False flags per clean lesson, all fields`→`false_flags_per_lesson {row08,row09,row25,row39}` (cell `30 / 24 / 8 / 3 ✗`: four numbers in order); `False flags in check items`→`false_flags_cfu` (same shape; `**0 / 0 / 0 / 0 ✓**` strip `**`); `Quote and page scan false flags` → skip; `Name scan scope verdict` → `name_scan_scope` text cell (strip `**`). Result `{ options: { A: {...}, B: {...} }, recommended_option: "B", quote_threshold_words: 3 }`: take `recommended_option` from the text `option **B**` after "Recommendation:" and the threshold from `Quote span ≥ 3 words`/`quote span ≥ 3 words` (case-insensitive regex `/span\s*[≥>=]+\s*(\d+)\s*words/i`); either missing: `bad_shape`. `config = { spike: "SP-3", plants_total: 12, source_record }`, `experiment_id = "SP-3-20261025"`.
