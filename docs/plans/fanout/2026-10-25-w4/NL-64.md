Operations (path-param key is `lessonId`; `candidateId` for getCandidate):
- `api.POST("/lessons/{lessonId}/transitions", { params: { path: { lessonId } }, body })` with `body` = `{action:"start_review"}` | `{action:"submit", client_state_vector: string}` | `{action:"withdraw"}` → `TransitionResult { lesson_id, from_state, to_state, version, audit_id }`.
- `api.POST("/lessons/{lessonId}/standards/decision", { params:{path:{lessonId}}, body: { code, decision: "confirm"|"remove" } })` → `ResolveResult { item_id, status, by, at, audit_id, counts }`; undo body `{ code, decision: "undo", undo_of: <audit_id of the decision> }`.
- `api.POST("/lessons/{lessonId}/candidates", { params:{path:{lessonId}}, body: { note?: string|null } })` → 202 `Candidate { candidate_id, version_number, status: "queued"|"drafting"|"ready"|"failed", failure_reasons: string[], ... }`; omit `body` when no note.
- `api.GET("/lessons/{lessonId}/candidates/{candidateId}", { params:{ path:{ lessonId, candidateId } } })` → `{ data: Candidate }` (poll every 2 s).
- `api.POST("/lessons/{lessonId}/heartbeats", { params:{path:{lessonId}}, body })` → 204. Body = **exactly** `Heartbeat { tab_id, focused, visible, last_input_at, sent_at, version_id }`. Never add a minutes/active field.

Error codes used (all in `ErrorCode`): `BLOCKED` (422, `details.issues` = array of Issue-shaped objects), `CONFIRMATION_OPEN`, `SUGGESTION_PENDING`, `NOT_STORED` (409), `COLLAB_UNAVAILABLE` (503), `UNDO_EXPIRED` (409), `LESSON_LOCKED` (409), `DAY_CAP_REACHED` (422), `INVALID_TRANSITION` (409), `ROLE_FORBIDDEN`, `NOT_FOUND`.

Lesson fields used: `lesson_id, lesson_key, number, state` (`generation_failed|draft|in_review|submitted|changes_requested|approved|reopened|exported`), `state_vector`, `front_matter.standards[] {code, origin: outline|outline-fixed|narrowed|added, confirmation: open|confirmed|removed|null}`. Issue fields: `issue_id, level (blocking|confirmation|advisory), blocks[] ("submit"|"approve"), kind, message, resolution (null when open)`. Lesson has **no** version id: the heartbeat's `versionId` is a caller argument (NL-62 supplies it).
