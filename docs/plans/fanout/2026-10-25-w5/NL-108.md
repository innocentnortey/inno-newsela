## 5. Render

`render_kickoff(d)` returns a single string. Requirements: starts `<!doctype html>`, `<html lang="en">`, `<meta charset="utf-8">`, viewport meta, `<title>Experiment kickoff</title>`, inline `<style>` using `:root` custom properties and `@media (prefers-color-scheme: dark)` (light and dark readable), no `<script>` at all, no `src=`/`href=` of any kind pointing outside the file (anchors only `#id`). Everything user-sourced goes through an `esc()` (`& < > "`). Look and tokens: use the D1 look sheet `docs/artifacts/2026-10-25-d1-clear-ledger-look-sheet.html` as the reference for colours and type (read it once when writing the CSS; copy no text).
