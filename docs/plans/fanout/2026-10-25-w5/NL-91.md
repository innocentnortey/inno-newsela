## 3. Behaviour (service)
`class CoverageService { constructor(alignment: AlignmentRepo, lessons: BoardReadRepo, standards: StandardRepo, units: UnitExists); async coverage(user: RequestUser, unit_id: UnitId): Promise<CoverageMatrix> }`
1. `Promise.all` of `units.unit_exists`, `alignment.coverage_rows`, `lessons.board_rows(unit_id, null)`; if unit missing throw `NOT_FOUND`.
2. Group cells by `(code, lesson_id)`: `roles` = distinct roles sorted I,P,A; `confirmed_by` and `source` pass through (all rows for one pair share `source`, since it is per lesson; if `confirmation` differs across roles take the weakest-to-strongest order `person` > `judge_only` > `generator_only` is NOT allowed: take `person` only if every role row is person, else the first non-person value in the order judge_only, generator_only; document this in a comment and a test).
3. `lessons` = board rows mapped to `{lesson_id, number}` only. `standards` = codes appearing in cells, sorted by code, `official_text` from `standards.texts(codes)` (skip the call when no codes), `never_assessed` = no cell for that code has role `A`.
4. No model, no write, no clock. Sort everything so two reads are byte-identical.
