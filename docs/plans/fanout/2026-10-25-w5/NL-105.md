3. **Token guard, `routes.ts` `authorized(req, token: SecretStr): boolean`** (invariant: no early exit that depends on the supplied value). Read `req.headers.authorization` (string or undefined). Match `^Bearer (.+)$`; if no match use `""`. Compute `a = createHash("sha256").update(supplied).digest()` and `b = createHash("sha256").update(token.reveal()).digest()` (both 32 bytes) and `return timingSafeEqual(a, b) && matched`. Do the hash and compare even when the header is missing. Never log the header, the token or the supplied value. On failure respond 401 `{ error: { code: "UNAUTHENTICATED", message: "Not authorized", details: {} } }` and log `logger.warn("internal.unauthorized", { extra: { path_prefix: "/internal" } })`. The guard runs before the body is read, before path validation, and before any handler call, for every method (GET/PUT included; non-POST with a good token -> 405 envelope `INVALID_REQUEST`).

4. **Request flow, `handle_internal(req, res, logger)`**: keep the exported signature. Module state: `let installed: CollabCommandHandler | null = null; export function install_command_handler(h: CollabCommandHandler | null): void`. When `installed === null` keep today's behaviour exactly (503 `COLLAB_UNAVAILABLE`, `internal.not_built` log line, no Authorization read), so `main.ts` and its tests work with no wiring. Otherwise: (a) step 3 guard; (b) path must match `^/internal/lessons/([^/]+)/(lock-and-snapshot|apply-edit|set-mode)$` after `decodeURIComponent` (a bad escape or other path -> 404 `NOT_FOUND`); (c) read the body with a 1 MiB cap (over -> 400 `INVALID_REQUEST`), `JSON.parse` failure -> 400 `INVALID_REQUEST`; (d) validate with Zod (step 5); `cmd.lesson_id` must equal the path's lesson id, else 400 `INVALID_REQUEST`; (e) `request_id` = body `request_id`, falling back to header `x-request-id`, and if the header is present and differs, the **header wins is NOT allowed: the body's value is authoritative** (the web client sends both equal); (f) call the handler method; 200 with `JSON.stringify(result)`; (g) catch -> `envelope`. Responses are `Content-Type: application/json`. Log one `collab.command` info line per call with `request_id`, `lesson_id`, `extra: { command, outcome: "ok"|code }` (never bodies, text, cookies or tokens).

5. **Zod request schemas** in `routes.ts` (use `zod` as the web adapter does): `Actor = z.object({ user_id: z.string().nullable(), name: z.string(), role: z.enum(["author","reviewer","approver"]).nullable(), synthetic: z.boolean() }).strict()`. `EditCommand`: `lesson_id: LessonId`, `actor: Actor`, `request_id: z.string().min(1)`, `tag: z.enum(["standard-decision","slot-fill","candidate-adopt","ai-assist"])`, `edit` a `z.discriminatedUnion("kind", [...])` for `standard` (`code: string`, `decision: enum(confirm|remove|add|undo)`, `restore: Standard-schema|null`; refine: `restore` only meaningful for undo), `slot_fill` (`slot_id`, `text` min 1, `source_ref: SourceRef`, `rights_status: RightsStatus`), `adopt` (`candidate_version_id`, `scope: enum(whole|section)`, `section_address: string|null`; refine: scope `section` requires a non-null address), `suggestion_accept` (`suggestion_id`, `anchor: Anchor`, `expected_text: min(1)`, `replacement_text: string`), all `.strict()`. 6. **`apply-edit.ts` `apply_edit(deps, cmd): Promise<StoreAck>`** in this exact order (each step protects an invariant):
   a. `row = await deps.states.get(cmd.lesson_id)`; null -> `NOT_FOUND` (protects: no doc is created for an unknown lesson; `openDirectConnection` would otherwise try to load it).
   b. `deps.frozen.seed(cmd.lesson_id, row.state)` (protects: an unseeded lesson counts as frozen, so without seeding every HTTP edit on a lesson nobody has opened would be refused; `seed` is a no-op if already set, so a freeze that arrived first still wins).
   c. If `deps.frozen.is_frozen(id) || !is_editable(row.state, "reviewer")` -> `DomainRefusal("LESSON_LOCKED", "This lesson is locked", { state: row.state })`; nothing opened, nothing written. Editability is judged on the lesson state, not on the actor's role (the web service already authorised the person).
   d. `conn = await hocuspocus.openDirectConnection("lesson:" + id, { actor: cmd.actor, tag: cmd.tag, request_id: cmd.request_id })`. If `hocuspocus` fails the type guard -> `DomainRefusal("COLLAB_UNAVAILABLE", ...)`.
   e. `try { await conn.transact((doc) => edit_doc(doc, edit, deps_for_edit)) } finally`-style handling: `edit_doc` is **pure Yjs** (in `edit-doc.ts`) and throws a `DomainRefusal` BEFORE it mutates when it refuses (resolve and validate first, mutate last), so a refusal leaves the live document untouched. Candidate rows and standards text are fetched BEFORE `transact` (async) and passed in: for `adopt`: `deps.versions.candidate(id, edit.candidate_version_id)` null -> `NOT_FOUND`; for `standard` with `decision "add"`: `deps.standards.texts([code])` empty -> `NOT_FOUND`. The single `transact` call is the one Yjs transaction; the origin Yjs sees is `{ source: "local", context: { actor, tag, request_id } }` (the context object is what the ticket calls origin `{actor, tag}`; tests read `transaction.origin.context.tag`).
   f. Immediately `ack = await deps.persistence.store("lesson:" + id, Y.encodeStateAsUpdate(live_doc), cmd.actor.user_id, cmd.request_id)` where `live_doc` is the connection's document (get it from the same `transact` callback by capturing `doc`, or `conn.document`). `stored_by` = the acting person, so `PgLessonDocStore` records `last_editor_id` and `request_id` on the `lesson_doc` and audit rows. `persistence.store` also calls `acks.stored(...)` (the socket receives `stored`; do NOT broadcast a second time). If it returns `null` (the edit changed nothing, e.g. confirm on an already confirmed code), load the current row with `deps.reader.latest(id)` and return a `StoreAck` built from it only if `deps.store`... NO: do not invent. Rule: return the latest stored doc as ack with `check_job_enqueued: false`, `stored_by: null`, fields from `StoredDoc` (`store_id, seq, content_hash, state_vector, stored_at`).
   g. `await conn.disconnect()` in a `finally` (releases the direct connection; `disconnect` triggers the document's normal store hook, which is a no-op after step f). Never leave a direct connection open on a refusal.
   h. Return `ack`. Log `collab.edit_applied` with `request_id`, `lesson_id`, `store_id`, `extra: { tag }`.

   **`edit-doc.ts`** exports `edit_doc(doc: Y.Doc, edit: LessonEdit, pre: { candidate: StoredLesson|null; standard_text: { code: string; official_text: string } | null }): void`:
   - `standard`: `fm = doc.getMap("front_matter")`; `list = fm.get("standards") as Standard[]`. `confirm`/`remove`: entry by `code` else `NOT_FOUND`; write a **new array** `fm.set("standards", list.map(...))` with that entry's `confirmation` set to `"confirmed"`/`"removed"`. `add`: entry present -> `confirmation: "open"`; absent -> append `{ code, role: "supporting", origin: "added", official_text: pre.standard_text.official_text, asserted_by: "reviewer", confirmation: "open" }`. `undo`: `restore` non-null -> replace the entry with that code by `structuredClone(restore)` (if absent, append); `restore` null -> remove the entry with that code. Byte-for-byte: the restored object is the one sent, not re-derived (AC-15).
   - `slot_fill`: walk every `section:*` fragment named in `section_order` recursively (`Y.XmlElement` children) for the first element with `nodeName` in `{quote_placeholder, excerpt_slot, quote}` and attribute `slot_id === edit.slot_id`; none -> `NOT_FOUND` (resolve first, mutate after). Replace it (same parent, same index: `parent.delete(i,1); parent.insert(i,[el])`) with `el = new Y.XmlElement("quote")`, `el.setAttribute("slot_id", edit.slot_id)`, `el.setAttribute("source_ref", JSON.stringify(edit.source_ref))` (carry-in: an unsourced quote is `""`, never `"{}"`), `el.setAttribute("rights", edit.rights_status)`, `el.insert(0, [new Y.XmlText(edit.text)])`. Plain text only (R-58).
   - `adopt`: `scope "section"`: the fragment `section:<address>`; address not in `section_order` or not in `pre.candidate.sections` -> `NOT_FOUND`; clear it (`frag.delete(0, frag.length)`) and `prosemirrorJSONToYXmlFragment(EDITOR_SCHEMA, section.content, frag)`; also set `section_meta` for that address to `{ name, minutes }` of the candidate's section.
