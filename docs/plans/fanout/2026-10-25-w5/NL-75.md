## 1. What to build
Page `/units/:unitKey/export`. `h1` "Export (no live integration)". Parts, top to bottom:
1. Role note (non-approver only): "Only approvers can export." (`RoleNote`; no **Create export** in the DOM).
2. **Approved snapshots** table (`Table`, caption "Approved snapshots"): columns Lesson ("Lesson 31", number parsed from the id's trailing `L<n>`), Approved hash (first 8 chars in `CodeChip`, full hash in `title`). Rows = `included`. Empty `included` (and no held back) shows "No approved lessons to export yet." in place of the table.
3. **Held back** list (`<ul aria-label="Held back">`), one `<li>` per `held_back`: "Lesson 4 waits on Lesson 5" (+ `reason` as secondary text). Hidden when empty. A held-back lesson is never a table row.
4. **Create export** (`Button` primary), only if `can(role, "export")`. One in-flight call at a time (disabled while pending, text "Creating…").
5. Result line under the button (`role="status"`): 201 -> "Export v{n} written · {k} lessons" (k = `included.length`; "1 lesson" singular); 200 with `same_as_previous` -> "Same lesson payloads as the last export (v{n})." and no new row.
6. **Earlier export versions** (`Table`, caption "Export versions"), newest first: `Export v{n}`, date (`created_at`, `toLocaleDateString("en-GB",{timeZone:"UTC"})`), `lesson_count`, **Download** button per row. `created_by` is a user id, not a name (route known gap): do not show it. `?export=<export_id>` marks that row `aria-current="true"` and scrolls it into view; an unknown id is ignored silently.
7. Errors: `listExports` fails -> shared `CantLoad thing="export"` with **Retry**; `NOT_FOUND` -> shared `NotFound what="unit"`; `ROLE_FORBIDDEN` on list -> only the "Only approvers can export." line; create fails (any error incl. `NETWORK`) -> `Banner level="blocking"` "Nothing was written. Try again." with the page kept; create `ROLE_FORBIDDEN` -> "Only approvers can export.". Download failure -> `Banner` "Couldn't download export v{n}. Try again.".
8. Must not: build or alter the payload client-side, show a held-back lesson in the table, or imply a live integration (no "sync", "publish", "send to" words).
