### Parser library decision (made here)

**Use SheetJS Community Edition 0.20.3 from the SheetJS CDN, not exceljs, and keep the import name `xlsx`.**
- 0.18.5 is the last npm release (`npm view xlsx version` = 0.18.5, dist-tag latest). It has CVE-2023-30533 (prototype pollution, fixed 0.19.3) and CVE-2024-22363 (ReDoS, fixed 0.20.2). `npm audit` reports it high.
- 0.20.3 (SheetJS publishes only on its CDN) fixes both. Verified 2026-10-25: `https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz` returns HTTP 200, 2,409,319 bytes, package.json `"version": "0.20.3"`, `"license": "Apache-2.0"`, zero runtime dependencies. 4. Run `npm ci --dry-run` to prove the lock is consistent (CI fetches the tarball from cdn.sheetjs.com; see Risks).

**Step 2: `errors.ts`.** The class above; `Object.setPrototypeOf` not needed on Node 24 ES2023 target; `name = "IntakeError"`.

**Step 3: `parse-grid.ts` (security-critical).** `parse_workbook(data, kind, limits?)`; merged limits = `{...DEFAULT_PARSE_LIMITS, ...limits}`. Every refusal is `throw new IntakeError("UNSUPPORTED_FILE", { reason, ...numbers })` and never includes input text. Order matters (cheapest check first, each protects the next):
1. `kind` not exactly `"csv"` or `"xlsx"` → `not_csv_or_xlsx` (guards a caller passing user text).
2. `data.byteLength === 0` → `empty`.
3. `data.byteLength > max_bytes` → `too_large` **before any parser sees the bytes** (bounds memory and time for both parsers).
4. Magic sniff: `%PDF` (0x25 0x50 0x44 0x46) anywhere in the first 8 bytes → `not_csv_or_xlsx` for either kind. For `"xlsx"` the bytes must start `PK\x03\x04`; anything else (including legacy `.xls` `D0 CF 11 E0`) → `not_csv_or_xlsx` (legacy BIFF is a bigger attack surface and the product accepts only XLSX/CSV). For `"csv"`: starting `PK\x03\x04` or `D0 CF 11 E0`, or any NUL byte in the first 8192 bytes → `not_csv_or_xlsx`.
5. CSV path: decode with `new TextDecoder("utf-8", { fatal: true, ignoreBOM: false })`, strip one leading U+FEFF; invalid UTF-8 → `not_csv_or_xlsx`. If the text is empty or only whitespace/NBSP/newlines → `empty`. Hand-written RFC-4180 state machine (no library): comma delimiter, `"` quoting with `""` escape, quoted fields may contain `\r`/`\n`, record ends on `\r\n`, `\n` or lone `\r` outside quotes; an unterminated quote at EOF → `not_csv_or_xlsx`; a `"` that appears inside an unquoted field is kept literally. Keep U+00A0 and every other character untouched (no trim). While scanning, count cells and track the widest row: `cells > max_cells` or `cols > max_cols` or any field longer than `max_cell_chars` → `too_large` immediately (stop parsing; do not finish the file). Drop trailing records whose cells are all `""`; pad every row to the widest width with `""`. Return `{ rows, sheet_name: "" }`.
6. XLSX path: first `inspect_zip(data, limits)`: find the End-Of-Central-Directory record (signature `0x06054b50`, searching the last 65,557 bytes; none → `not_csv_or_xlsx`), read the entry count and central-directory offset (little-endian; bounds-check every offset against `data.byteLength`, out of range → `not_csv_or_xlsx`), walk central entries (signature `0x02014b50`; uncompressed size is the u32 at entry offset 24, name length u16 at 28, extra length u16 at 30, comment length u16 at 32). Refuse as `too_large` when entries > `max_zip_entries`, any uncompressed size is `0xFFFFFFFF` (zip64) or the running total of uncompressed sizes > `max_zip_uncompressed_bytes`; refuse as `not_csv_or_xlsx` when a name contains `..` or starts with `/` or `\`. This catches decompression bombs by declared size without inflating anything (invariant: no inflate happens before the budget is checked).
7. Then `read(data, {...options listed in §4, sheetRows: 2001})` inside try/catch; any thrown error → `not_csv_or_xlsx` (message discarded; never echo it).
8. Take `const name = wb.SheetNames[0]`; none → `empty`. If `name` (trimmed, lowercased) is `__proto__`, `constructor` or `prototype` → `not_csv_or_xlsx` (CVE-2023-30533 class). Get the sheet with `Object.hasOwn(wb.Sheets, name) ? wb.Sheets[name] : undefined` (never bracket-index with a user string without `Object.hasOwn`). Also reject if any other `SheetNames` entry is one of those three words.
9. Range cap from the **declared** range before materialising rows: `const ref = ws["!fullref"] ?? ws["!ref"]`; none → `empty`. `utils.decode_range(ref)`; `cols = e.c - s.c + 1`, `rows = e.r - s.r + 1`; if `cols > max_cols` or `rows * cols > max_cells` → `too_large`. (Experiment first in a scratch file: with `sheetRows` set, SheetJS may shrink `!ref` and keep the declared range in `!fullref`; the code above reads both. A sheet declaring `A1:XFD1048576` must be refused here in well under 2 s.)
10. `utils.sheet_to_json<string[]>(ws, { header: 1, raw: false, defval: "", blankrows: true })` → rows of formatted text. Coerce every value with `String(v)`; any cell longer than `max_cell_chars` → `too_large`. A formula cell arrives as its stored value text because `cellFormula` is false (the formula string is never read, never evaluated). Same trailing-empty-row drop and right-padding as CSV. All values zero rows → `empty`. Return `{ rows, sheet_name: name }`.
Never `console.*`, never a logger, never put cell text in an error.

**Step 5: `normalize-codes.ts`, `normalize-segments.ts`, `normalize.ts`.** Decisions (all made here):

*Header and columns.* Clean a cell for matching: replace U+00A0 with space, collapse whitespace, trim, lowercase. Column keys and the exact cleaned header text (startsWith where marked ~): `filename`="filename"; `arc`="lesson"; `lesson_number`="lesson #"; `lesson_type`="type of lesson"; `days`="days"; `tdq`~"text dependent question"; `description`="lesson description"; `text_set`="text set choice"; `homework`="homework"; `focus`~"focus standards"; `additional`~"additional supported"; `media`~"ca media literacy"; `performance`~"skill or content"; `foundational`="foundational skills focus"; `vocabulary`="vocabulary"; `eld`~"designated eld". The header row is the **first** row where at least 8 distinct keys match; none → `IntakeError("HEADER_NOT_FOUND", { reason: "no_header_row" })`. Required keys: `lesson_number, lesson_type, description, focus, eld`; a missing one → one `missing_required_column` error finding (row_number = header row, `original_text` = the missing key name, proposed_fix null, default_choice null) and the column is treated as empty. Duplicate header matches: the first column wins. Use `Map`/arrays for column lookup, **never an object keyed by cell text** (a header cell `__proto__` must be harmless: add a test).
*Row limit.* Data rows = rows after the header with at least one non-whitespace/NBSP cell; if `data_rows > max_rows` → `IntakeError("TOO_MANY_ROWS", { max_rows, rows: data_rows })`.
*Unit.* Search rows above the header, cell by cell, for `/G(\d{1,2})\s*,?\s*U(\d{1,2})/i`; first hit gives grade G and `unit_as_written = "U"+n` (e.g. `U4`), `unit_id = "G6.U4"`. `unit_from_filenames`: most frequent `/_G(\d{1,2})_U(\d{1,2})_/` match over the filename column as `"U"+n`, else null. No unit anywhere → `unit_as_written = ""`, lesson ids null, one `missing_required_column` finding `original_text: "unit"`. Unit differs from filenames → ONE `unit_conflict` error: `row_number: null`, `original_text` = the title cell verbatim, `proposed_fix: unit_as_written`, `default_choice: null`.
*Row kinds* (by the cleaned cells; rows with every cell blank are skipped, not rows): `flex_day` if arc cell lower-cased is `flex` or type matches `/flex day/i`; else `arc_header` if type and filename cells are blank and the arc cell is non-blank; else `total` if arc, filename, type and lesson-number cells are all blank but another cell is not; else `lesson`. A `lesson` whose `lesson #` does not match `/^\s*lesson\s*(\d{1,3})\b/i` gets `lesson_id: null`, `number: null` and one `missing_required_column`-free path: emit a `malformed_code`? **No**: emit nothing extra; (not present in the issued data) record it under the dev log if seen.
*Ids.* Lesson: `${unit_id}.L${n}`. Flex: a flex "group" is a run of consecutive flex rows after an arc header; group index g = 1,2,3 in order of appearance; letters `a`, `b`, ... within the group: `${unit_id}.FLEX-${g}${letter}` (first flex after Investigation 1 = `G6.U4.FLEX-1a`). Duplicate lesson id on a later row → `duplicate_id` error (`original_text` = that row's `lesson #` cell, `proposed_fix` null), row kept.
*Row fields.* `title`: first non-blank line of the description cell trimmed (arc_header: the arc cell; total: `""`). `lesson_type`: for lessons strip a leading `Core `, a trailing `\s*\(.*\)`, and trailing ` \d+`; flex: `Flex Day`; others `""`. `arc`: lessons = arc cell; arc_header = arc cell; flex = text of the preceding arc_header's arc cell; total = null. `pages`: first `/\bpp?\.\s*(\d+)\s*[–-]\s*(\d+)/` in the description → `"${a}–${b}"` (en dash) else null. `text_set`: text-set cell verbatim or null. `homework`: homework cell lines that are not `safety_note` lines, joined with `"\n"`, or null if none/blank. `vocabulary`: vocabulary-cell lines matching `/^\W*([A-Za-z][A-Za-z' -]*?)\s*\((\d+(?:[–,-]\d+)*)\)\s*$/` kept **as written** with bullet characters stripped from the front only (`"envy (1)"`). `focus_codes`/`eld_codes`/`msls_codes`: see codes below.
*Codes (`normalize-codes.ts`).* Tokenise a standards cell with `/(?:(RL|RI|RF|W|SL|L)\.)?(\d{1,2})\.(\d{1,2})(?:\.([a-z])(?:\s?[–-]\s?([a-z]))?)?/g`; MSLS tokens `/MSLS\s*\d+\.\d+[a-z]?/g` (media column; leave text as written); ELD lines `/^\W*(ELD\.P(?:I|II)\.\d+\.?\d*[a-z]?)\s*[–-]\s*(.+?)\s*$/` give `(code, label)`. Chunks = the cell split on `,` and newlines; a chunk may hold several tokens (`6.2 L.6.4`). A token with **no strand prefix** is malformed: its prefix is the prefix of the nearest preceding prefixed token in the same cell (`6.2` after `RL.6.1` → `RL.6.2`); none preceding → no fix, error still raised with `proposed_fix: null`. **`malformed_code` finding:** one per chunk containing a bare token, `original_text` = the whole cell verbatim, `proposed_fix` = the chunk's tokens (repaired, ranges left unexpanded) joined with `", "` (`"RL.6.2, L.6.4"` for `6.2 L.6.4`), `default_choice: null`.
