## 4. Shared code to use

No new dependencies; nothing goes in the lockfile. Use only `node:fs`, `node:path`, `node:url` (not forbidden for `core` in `eslint.config.js`; forbidden there are `pg`, SDKs, yjs, next, http(s)). Do not import `@ls/db`, `@ls/schema` or anything else.

Contract shapes to mirror (TypeScript spellings; names are snake_case on purpose, matching DO-4 and the ticket):

```ts
export type StandardSet = "CA_CCSS_ELA_6" | "CA_ELD_6" | "MSLS_6";
export interface StandardRow {            // DO-4 3.5 / the `standard` table columns
  code: string; set: StandardSet; text: string;
  parent_code: string | null; is_leaf: boolean; eld_strand: string | null;
}
export type StandardStatus = "ok" | "malformed" | "unknown" | "parent";
export interface StandardResolution {     // DO-4 8
  input_code: string; status: StandardStatus; resolved: string[];
  suggestion: string | null; eld_label_mismatch: boolean;
}
export type Verdict = "fits" | "partial" | "mismatch";
export interface EldVerdictEntry {
  code: string;                    // sheet code, e.g. "ELD.PI.6.2"
  strand_part: string;             // e.g. "I.A.2"
  strand: string;                  // official strand name
  verdict: Verdict;
  suggested_remap: string | null;
  descriptions: { label: string; verdict: Verdict }[];   // sheet labels seen
}
export type EldVerdictTable = Record<string, EldVerdictEntry>;  // keyed by code
```

Public API to export from `standards-index.ts`:
- `class StandardsIndex` with `static from_rows(rows: readonly StandardRow[], verdicts?: EldVerdictTable): StandardsIndex`, `resolve(code: string, sheet_label?: string | null): StandardResolution`, `leaves_of(code: string): string[]`, `text_of(code: string): string | null`, plus one extra read method `strand_of(code: string): string | null` (needed by AC-4; not in DO-4, see Risks).
- `load_standard_rows(dir?: string): StandardRow[]`, `load_eld_verdicts(dir?: string): EldVerdictTable`, `load_standards_index(dir?: string): StandardsIndex`.
- `export const DEFAULT_STANDARDS_DIR: string` = `fileURLToPath(new URL("../../data/standards/", import.meta.url))`.
- `compilerOptions` come from `tsconfig.base.json` (strict, `noUncheckedIndexedAccess` was restored in NL-06): guard every indexed access.

Seed file shape (all of ccss/eld/msls; `JSON.parse` + hand validation in the loader, throw `Error` with the file name on a bad shape; no `resolveJsonModule`):

```json
{ "header": { "source": "docs/source/05-standards-referenced.md (quotes the CDE tables)",
              "official_documents": ["<url>"], "derived": "2026-10-25",
              "rule": "official text only, never the sheet's labels (GR-5)",
              "set": "CA_CCSS_ELA_6" },
  "standards": [ { "code": "RL.6.1", "text": "...", "parent_code": null, "is_leaf": true,
                   "eld_strand": null, "ca": false } ] }
```
`eld-6.json` adds `"sheet_codes": [ ...12 codes ]` to the top level. `eld-verdicts.json` is `{ "header": {...}, "verdicts": EldVerdictEntry[] }`. Loader maps `standards[i]` to `StandardRow` (set from `header.set`; drop `ca`).

3. **Loader.** `load_standard_rows(dir = DEFAULT_STANDARDS_DIR)` reads the three seed files (order: ccss, eld, msls) with `readFileSync(path.join(dir, name), "utf8")`, validates shape, returns `StandardRow[]`. `load_eld_verdicts` returns the table keyed by `code`. `load_standards_index(dir)` = `StandardsIndex.from_rows(load_standard_rows(dir), load_eld_verdicts(dir))`. This is the only place `node:fs` is used.

4. **Index algorithm** (`from_rows` builds `Map<code,StandardRow>`, a `Map<parent_code, string[]>` of leaves sorted by code, ignoring tier rows). A tier row is a `CA_ELD_6` row whose code matches `/\.(Em|Ex|Br)$/`; tier rows are stored in the code map but never counted as leaves. `leaves_of(code)`: strip a tier suffix, return a copy of the sorted leaf list for a parent, else `[]`. `text_of(code)`: the row's `text` or `null` (tier code returns the tier row's text). `strand_of`: row `eld_strand` or `null`. `resolve(code, sheet_label = null)`, `input_code` is the argument as given:
   1. `t = code.trim()`. If `t` matches `/^(ELD\..+)\.(Em|Ex|Br)$/`, `base = $1`, else `base = t`.
   2. If `base` is a known non-tier row: parent row (has leaves) -> `status "parent"`, `resolved = leaves_of(base)`, `suggestion null`; otherwise `status "ok"`, `resolved [base]`, `suggestion null`.
   3. Otherwise (invariant: a code the index cannot find never gets text):
      a. `/^(\d)\.(\d)\.?([a-z])$/` with candidate `MSLS d.da` (e.g. `2.1.a` -> `MSLS 2.1a`) that exists: `malformed`, `suggestion` = candidate, `resolved []`.
      b. `/^\d+\.\d+(\.[a-z])?$/` (no strand prefix, e.g. `6.2`): `malformed`, `suggestion null` (the number alone fits several strands; NL-16 proposes the prefix from the neighbouring code).
      c. else `unknown`, `resolved []`; `suggestion` = `t` with a trailing sub-part letter removed (`/^(.+\d)\.?[a-z]$/` -> group 1, so `RL.6.9.a` -> `RL.6.9`, `ELD.PI.6.3b` -> `ELD.PI.6.3`) only if that stripped code exists, else `null`.
   4. Label verdict: only when `sheet_label` is a non-empty string and `base` (status ok or parent) starts with `ELD.`: `key` = `base` with a trailing sub-part letter removed (`ELD.PI.6.6b` -> `ELD.PI.6.6`). If `verdicts[key]` exists and one of its `descriptions` has `normalize(label) === normalize(sheet_label)` and verdict `mismatch`, set `eld_label_mismatch true` and, if the entry has one, `suggestion = suggested_remap`. `normalize` = trim, lowercase, collapse whitespace, strip leading/trailing quotes and trailing period. Labels not in the table are not a mismatch (we only report what the verdict table lists).
   5. `eld_label_mismatch` is `false` in every other case.
   6. Ranges (`W.6.2.a–f`) and multi-code cells are not handled: anything else falls to `unknown`, suggestion null.
