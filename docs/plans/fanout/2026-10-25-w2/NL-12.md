### Step 4. `clock.ts` and `ids.ts` (DO-4 §3.6)
`clock.ts`:
```ts
export class SystemClock implements Clock { now(): Date { return new Date(); } sleep(ms: number): Promise<void> { return new Promise((r) => setTimeout(r, ms)); } }
export class FakeClock implements Clock {
  constructor(start: Date = new Date("2026-01-01T00:00:00.000Z"));
  now(): Date;                    // a new Date copy of the current time
  advance(ms: number): void;      // moves time forward, then resolves every sleeper whose wake time <= now, in wake order
  sleep(ms: number): Promise<void>; // ms <= 0 resolves immediately; otherwise pending until advance() reaches now+ms
}
```
Invariant: `sleep(500)` never resolves before 500 ms of `advance` calls in total; resolution happens inside `advance`, never on a timer.
`ids.ts` `class PrefixedIdGenerator implements IdGenerator`, `constructor(opts?: { now?: () => number; random?: (bytes: number) => Uint8Array })` (defaults `Date.now` and `crypto.randomBytes` from `node:crypto`). `new_id(prefix)` returns `` `${prefix}_${ulid}` ``. ULID algorithm (own implementation, no dependency):
1. Crockford alphabet `"0123456789ABCDEFGHJKMNPQRSTVWXYZ"`.
2. Keep `last_ms` and `last_rand` (BigInt, 80 bits). Let `ms = max(now(), last_ms)` (a clock that steps back must not reorder ids).
3. If `ms === last_ms`: `rand = last_rand + 1n`; if that exceeds `2n**80n - 1n`, set `ms = last_ms + 1` and draw fresh randomness. Else draw 10 random bytes into a BigInt.
4. `value = (BigInt(ms) << 80n) | rand`; encode as exactly 26 characters, most significant 5-bit group first (130 bits, top group is 0-7). Fixed length + big-endian makes string order equal numeric order, so ids minted in one millisecond are strictly increasing.
5. Store `last_ms`, `last_rand`.

### Step 6. Scripted fakes (`packages/core/src/testing/`)
`scripted.ts`:
```ts
export class UnscriptedCall extends Error { readonly method: string; constructor(method: string) } // message: `unscripted call: ${method}`
export interface RecordedCallEntry { readonly method: string; readonly args: readonly unknown[] }
export class Script<P> {
  readonly calls: RecordedCallEntry[];                       // every call, in order, scripted or not
  returns<K extends keyof P & string>(method: K, ...values: ScriptValue<P, K>[]): this;   // queue results
  throws<K extends keyof P & string>(method: K, ...errors: Error[]): this;                // queue errors
```
