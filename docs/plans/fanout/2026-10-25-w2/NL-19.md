## 4. Shared code to use (verified on main)

```ts
import * as Y from "yjs";                        // 13.6.33
import { prosemirrorJSONToYXmlFragment, yXmlFragmentToProsemirrorJSON } from "y-prosemirror"; // 1.3.7; both import fine under node (checked)
//   prosemirrorJSONToYXmlFragment(schema, docJson, xmlFragment): void
//   yXmlFragmentToProsemirrorJSON(xmlFragment): { type: "doc", content?: ... }

```
- `StoredLesson` = `{ lesson_id, schema_version (int>=1), title, type, front_matter: { standards: Standard[], minutes_total: int, vocabulary: string[] }, sections: Section[], text_cards: TextCardRecord[] }`.
- `assert_known_nodes(doc: ProseMirrorDoc, schema_version: number): NodeCheck` throws `SchemaUnknownError({lesson_id:null, schema_version, unknown_nodes})`; `err.with_lesson_id(id)` returns a new error.
- schema `PMNode` and editor-schema `ProseMirrorDoc` differ structurally: cast with `as unknown as ProseMirrorDoc` when calling editor-schema, and `as unknown as Section["content"]` back.
- Export type aliases from `convert.ts`: `export type YDocBytes = Uint8Array;`. `StateVector` type comes from `@ls/schema/ids`.

## 5. Steps
1. **convert.ts `lesson_to_ydoc(lesson: StoredLesson): YDocBytes`.**
   a. For each section, `assert_known_nodes(section.content as unknown as ProseMirrorDoc, lesson.schema_version)`; on `SchemaUnknownError` rethrow `e.with_lesson_id(lesson.lesson_id)` (refuse early, invariant: nothing dropped).
   b. `const doc = new Y.Doc(); doc.clientID = 1;` (set before any change; fixed id gives byte-identical output; never random).
   c. Do everything inside ONE `doc.transact(() => {...})` in this fixed order: `front_matter` map sets, then `section_order`, then `section_meta`, then fragments in `lesson.sections` order.
   d. `front_matter = doc.getMap("front_matter")`; set keys in this order: `lesson_id`, `title`, `type`, `standards`, `vocabulary`, `minutes_total`, `text_cards`, `schema_version`. Values are plain JSON (arrays/objects/null/number/string; never `undefined`). `lesson_id` is added beyond the ticket's key list because `StoredLesson` (and so the hash) contains it and `ydoc_to_lesson` has no other source for it (see Open items).
   e. `section_order = doc.getArray<string>("section_order")`; `push(addresses)`. `section_meta = doc.getMap("section_meta")`; `set(address, { name, minutes })`.
   f. For each section: `prosemirrorJSONToYXmlFragment(EDITOR_SCHEMA, section.content, doc.getXmlFragment("section:" + address))`.
   g. Return `Y.encodeStateAsUpdate(doc)`; `doc.destroy()`.
2. **convert.ts `ydoc_to_lesson(data: YDocBytes, schema_version: number): StoredLesson`.**
   a. `new Y.Doc()`, `Y.applyUpdate(doc, data)`.
   b. Read `front_matter`, `section_order`, `section_meta`. If `front_matter.get("schema_version") !== schema_version` or `schema_version !== SCHEMA_VERSION` throw `new SchemaUnknownError({lesson_id, schema_version, unknown_nodes: []})` (assert_known_nodes also throws for version != 1; call it first on each section anyway).
   c. For each address in `section_order`: `json = yXmlFragmentToProsemirrorJSON(doc.getXmlFragment("section:"+address))`; run `assert_known_nodes(json, schema_version)` FIRST (collect/propagate its error, `.with_lesson_id(lesson_id)`); only then normalise: `EDITOR_SCHEMA.nodeFromJSON(json).toJSON()` (makes null/default attrs explicit). An empty fragment yields `{type:"doc"}` or `{type:"doc",content:[]}`; whatever nodeFromJSON+toJSON returns is what is stored (the AC-1 fixtures have no empty sections; add no special case).
   d. Section = `{ address, name: meta.name, minutes: meta.minutes, content }`.
   e. Return `{ lesson_id, schema_version: SCHEMA_VERSION, title, type, front_matter: { standards, minutes_total, vocabulary }, sections, text_cards }`. Throwing leaves nothing returned.

6. **covers.** Private `decode(sv: string): Map<number, number>`: reject (throw `StateVectorError`) when the string is empty, fails `/^[A-Za-z0-9+/]+={0,2}$/` or its length % 4 != 0; `bytes = Buffer.from(sv, "base64")`; `try { map = Y.decodeStateVector(bytes) } catch { throw StateVectorError }`; then require `Buffer.from(Y.encodeStateVector(map)).toString("base64") === sv` (Y.encodeStateVector accepts a Map; this rejects trailing garbage; verify empirically that valid vectors from real docs pass, including `"AA=="`). Then: for each `[id, clock]` of client: `(stored.get(id) ?? 0) >= clock`, else return false; all pass -> true. Empty client map -> true. Decode BOTH vectors before comparing so a malformed `stored` also throws. Invariant: NOT_STORED (CON-18) is decided only on valid vectors.
