## 5. Steps (check each before the next)

1. **Generator `apps/web/scripts/gen-error-status.ts`.** `export function render_error_status(catalog_yaml: string): string` : parse with `import { parse } from "yaml"` (already a root devDependency), read `doc["x-error-catalog"].codes`, require 36 entries each with an integer `status`, and return text exactly:

   ```
   export const ERROR_STATUS = {
     "INVALID_REQUEST": 400,
     ...                       // catalog order, 2-space indent, double quotes, trailing comma, one per line
   } as const;
   export const RETRY_AFTER_CODES = ["SERVICE_BUSY"] as const;   // codes whose catalog entry has retry_after: true, catalog order
   ```
   File ends with one newline. Main part (guarded by `if (import.meta.url === pathToFileURL(process.argv[1] ?? "").href)`): read the YAML via `node:fs` relative to `import.meta.url` (`../../../docs/contracts/interface.openapi.yaml`), write `../src/server/http/error-status.generated.ts`. Run `npm run gen:error-status` once and commit the output. Add the root script line.
2. **`refusal.ts`.** Exports `to_error_response(refusal: DomainRefusalLike, request_id: string): ErrorResponse`, `is_domain_refusal(e: unknown): e is DomainRefusalLike`, `status_for(code: ErrorCode): number`.
   - `status_for` reads `ERROR_STATUS[code]` (import `ERROR_STATUS` from `./error-status.generated.ts`); a type-level guard `const _all: Record<ErrorCode, number> = ERROR_STATUS;` makes a missing code a compile error.
   - `to_error_response` returns `{ status, body: { error: { code, message, details: { ...(plain-object details or {}), request_id } } } }` (`request_id` always wins over a same-named key).
   - `is_domain_refusal`: `e instanceof Error` AND (`e.name === "DomainRefusal"` OR `e.constructor.name === "DomainRefusal"`) AND `ErrorCode.safeParse((e as {code?:unknown}).code).success` AND `typeof message === "string"`. A `PoolExhausted` or a plain `Error` is never a refusal (invariant: no unnamed error code ever reaches a client).
3. **`with-route.ts` helpers (private, same file; keep the file under the repo size cap, split a `request-id.ts` only if it passes ~250 lines, and then add it to owned files in the report).**
   - `mint_request_id()`: `"req_" + ulid()` where `ulid()` = 10 Crockford chars of `Date.now()` (alphabet `0123456789ABCDEFGHJKMNPQRSTVWXYZ`, big-endian base32) + 16 Crockford chars from `node:crypto` `randomBytes(10)` (5 bits each; use 80 random bits). Must match `/^req_[0-9A-HJKMNP-TV-Z]{26}$/`.
   - `resolve_request_id(headers)`: take `headers["x-request-id"]`; use it iff `RequestId.safeParse(v).success` (so 66 chars or a space fails and a fresh id is minted).
   - `check_origin(method, headers, app_origin): boolean`: for GET/HEAD/OPTIONS return true; for POST/PUT/PATCH/DELETE (case-insensitive) require an `origin` header that parses with `new URL` and whose `.origin` equals `new URL(app_origin).origin`; absent, `"null"`, unparseable or different -> false.
   - `parse_cookie(headers)` is not needed: `request.cookies` is already a record; token = `request.cookies[settings.session_cookie_name] ?? null`.
   - `SCHEMAS`: `Record<string, z.ZodType>` built by `import * as` of `@ls/schema/api/{board,collab,common,exports,lessons,metrics,outlines,prompts,review,runs,session,transition}`, collecting every export whose value is an object with `safeParse` (same method as `packages/schema/tests/contract/oracle.ts`). `request_schema` names are looked up here; an unknown name throws at **`with_route` construction time** (`Error("unknown request_schema: ...")`), never per request.
   - `zod_fields(error: z.ZodError, prefix: string): string[]`: for each issue, path joined with "."; for `unrecognized_keys` issues emit `path.key` for each key in `issue.keys`; empty path -> `"body"`; add the prefix `query.` / `path.` for those parts (body has no prefix). De-duplicate, keep order. Never put `issue.message`, `received` or input values in the response.
4. **`make_with_route(deps)`** returns `with_route`. `WithRouteDeps`:
   ```ts
   export interface WithRouteDeps {
     sessions: () => SessionResolver;                 // lazy: called per request, only for non-public routes
     logger: Logger;
     settings: Pick<WebSettings, "app_origin" | "busy_retry_after_s" | "session_cookie_name">;
     now_ms?: () => number;                           // default performance.now()
     new_request_id?: () => string;                   // default mint_request_id
   }
   ```
   Pipeline inside the returned `RouteHandler` (each numbered step = INTERFACE guarantee 11; a thrown refusal skips the rest):
   1. `request_id` = valid client id, else `new_request_id()`. Start timer. `role = null`, `status = 500`.
   2. `try {`
      a. **Origin** (mutations only; also for `public` routes) : false -> refusal `UNAUTHENTICATED`, message "Sign in again."
      b. **Session** (skip when `spec.public`): `user = await deps.sessions().require(token, request_id)`; set `role = user.role`. Resolver refusals pass through. The resolver is given the token; the wrapper never logs it, never puts it in a header or body.
      c. **Parse** : if `request_schema !== null`, parse `request.body` (a missing body is `undefined` for zod, so required fields fail); then `params_schema` against `path_params`, `query_schema` against `query`. Collect all failures; on any, refusal `INVALID_REQUEST` message "The request is not valid.", `details: { fields }`. The handler receives a request copy whose `body`/`path_params`/`query` are the parsed outputs.
      d. **Role** : `spec.roles !== null && spec.roles !== undefined && !spec.roles.includes(user.role)` -> `ROLE_FORBIDDEN` "Your role cannot do this." (public routes have no role check).
      e. **Service call** : `await handler(user, parsed_request)` (public: `user = null`). `DomainRefusal`s pass through unchanged.
      f. Response `{ status: spec.success_status, headers: {"X-Request-Id": request_id, "Content-Type": "application/json"}, body }`.
   3. `catch (e)`: `is_domain_refusal(e)` -> `to_error_response`, log `deps.logger.warn("route.refused", { request_id, extra: { operation_id, code } })`. `e instanceof PoolExhausted` -> same as a `SERVICE_BUSY` refusal (message "The service is busy. Try again shortly.") plus header `Retry-After: String(settings.busy_retry_after_s)`; log `route.refused` with code `SERVICE_BUSY`. Anything else -> status 500, body `{ request_id }` **only** (not an envelope), header `X-Request-Id`; log `deps.logger.error("route.unhandled", { request_id, extra: { operation_id, error_class: e instanceof Error ? e.name : "NonError" } })` (class only: never message, stack, cause).
   4. `finally`-equivalent (after building the response, before returning, exactly once): `deps.logger.info("route.done", { request_id, duration_ms: Math.round(now_ms() - start), extra: { operation_id, status, role } })`. `extra` has exactly those three keys. Never log name, email, body, cookies, headers or paths.
   5. Every response (success, refusal, 500) has `X-Request-Id`. The wrapper has **no audit dependency** (refusal writes no audit row, guarantee 2).
   - Overloads: `with_route(handler: PublicServiceCall, spec: PublicRouteSpec): RouteHandler; with_route(handler: ServiceCall, spec: ProtectedRouteSpec): RouteHandler`.
   - Construction-time check in the implementation for JS callers: non-public spec with `roles === undefined` throws (the type already forbids it).
5. **Default export `with_route`** = `make_with_route(lazy_default_deps())` where default deps read lazily per request: `sessions: () => getServices().sessions as unknown as SessionResolver`, `logger` = a getter-backed proxy that calls `getServices().logger`, `settings` = `load_web_settings(process.env)` computed on first request and cached in a module variable. Importing `with-route.ts` must **not** call `getServices()` or load settings at import time (test: import module with no env set, no throw). `import "server-only"` is not needed in this file.
6. **Tests** (see §7). Write with the code; the test-writer's frozen AC-1..4 tests are authoritative if they exist: make them pass, never edit them.
7. **Context.** Area-map row, dev-log file, then run `check_context.py`.
