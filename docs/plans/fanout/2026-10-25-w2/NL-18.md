Real shapes:
- `DraftBlock {role, section: string, part: string|null, text: string, standard_codes: string[], code_origins: ("outline"|"narrowed"|"added")[], cfu: CfuItemDraft|null, minutes: number|null}`; `CfuItemDraft {stem, options: string[] (>=2), key_index, rationales: string[] (same length), standard_code}`; `LessonDraft {lesson_id, title, blocks, text_cards}`. Roles (`DRAFT_ROLES`): routine_heading, teacher_talk, sample_response, callout_purpose, callout_say, callout_watch, support_table, cfu_item, quick_write, text_evidence_needed, excerpt_slot, teacher_tip, homework, paragraph, list.

- Editor schema nodes/attrs (exact): `paragraph{align:null|"center"}`, `heading{level 1-5}`, `bullet_list`, `ordered_list{order:int>=1, type:null|"A"}`, `list_item` (content `paragraph (block|teacher_block)*`), `table > table_row > table_cell|table_header` (cell attrs colspan 1, rowspan 1, colwidth null; content `block+`), `routine_heading{icon: cfu|notes_section|writing|graphic_organizer|academic_discussion|personal_dictionary|reading}`, `callout{variant: purpose|say|watch}` (content `(block|teacher_block)+`), `collapsible{label: string}`, `teacher_tip{safety_note_id: string|null}` (group teacher_block, content `block+`), `quote_placeholder{slot_id, reason}` (atom), `excerpt_slot{slot_id, rights default "unset", source_ref null}` (atom), `hard_break`, text. - Contract types to define (DO-4 §8): `SectionSlot{name, minutes, required_roles}`, `SectionTemplate{lesson_type, sections: SectionSlot[]}`, `CompileContext{row: NormalizedRow; template: SectionTemplate; unit_id: UnitId; schema_version: number}`, `CompiledLesson{lesson: StoredLesson; content_hash: Sha256; teacher_word_count: number; placeholders: number; safety_tips: string[]}`, `class CompileError extends Error {lesson_id: LessonId; reason: "section_not_in_template"|"role_not_allowed"|"unknown_node"; address: string|null}`.

## 5. Steps (dependency order; each step ends with the named test green)
Imports allowed in `compile/**`: `@ls/schema/*`, `@ls/editor-schema/*`, relative files. Nothing else (eslint boundaries enforces). Relative imports use the `.ts` extension. Use `import type` for types (`verbatimModuleSyntax`).

1. **`labels.ts`**: export a frozen table, the *only* source of compiler-added text: `ELD_LABEL = "Integrated ELD Instructions"`, `SUPPORT_LABEL = "Additional Student Support"`, `SUPPORT_HEADERS = ["Situation", "Try this"]`, `PULSE_CHECK = "Pulse Check"`, `QUICK_WRITE = "Quick Write"`, `CORRECT = "Correct:"`, `INCORRECT = "Incorrect:"`, `TEACHER_LABELS = ["Say these Directions:", "Say:", "Ask:"]` (longest first) and `routine_icon(text: string): IconName` (lowercase, trim, first `startsWith` match, in this order: "quick write"->writing; "pulse check"|"check for understanding"->cfu; "think-pair-share"|"turn and talk"->academic_discussion; "language study"->notes_section; else notes_section). `export const ALL_LABELS: readonly string[]` lists every string above (AC-7 uses it).
2. **`templates.ts`**: export the three types, `SECTION_TEMPLATES: { templates: readonly SectionTemplate[] }` and `template_for(lesson_type: string): SectionTemplate | undefined` (exact match). Templates (name, minutes, required_roles) **[D]**:
   - Five-section types `Reading`, `Writing`, `Academic Discussion`, `Research`, `Presentation`: Launch 5 `[routine_heading, teacher_talk, sample_response]`; Literacy Lab 10 `[routine_heading, cfu_item, callout_purpose, callout_say, callout_watch, support_table]`; Learning in Action 30 `[teacher_talk, cfu_item, callout_purpose, callout_say, callout_watch, support_table]`; Look Back 5 `[quick_write, sample_response]`; Homework 0 `[homework]`.
   - `Spark`: Launch 15 `[routine_heading, teacher_talk, sample_response]`; Learning in Action 30 `[teacher_talk, cfu_item]`; Look Back 5 `[quick_write]`; Homework 0 `[homework]`.
   - `Flex Day`: Launch 5 `[routine_heading, teacher_talk]`; Learning in Action 40 `[teacher_talk, cfu_item]`; Look Back 5 `[quick_write]` (no Homework: WP-3 gives none).
   - `Assessment`: same slots as Flex Day.
   `required_roles` are data for NL-29's repair step and NL-20; **the compiler never enforces them**. Test `templates.test.ts`: minutes per type sum to 50 (Homework 0), Spark/Flex/Assessment have no Literacy Lab, `template_for("Nope")` is undefined, every `required_roles` entry is in `DRAFT_ROLES`.
3. **`roles.ts`**: `check_role(role: DraftRole, section_name: string): "ok" | "role_not_allowed"`: `homework` allowed only in `Homework`; `callout_purpose|callout_say|callout_watch|support_table` not allowed in `Launch`, `Look Back`, `Homework`; everything else allowed everywhere.
4. **`addresses.ts`**: 
   ```ts
   export function section_slug(name: string): string            // name.replace(/[^A-Za-z0-9]+/g, "")
   export function normalise_part_label(label: string): string   // trim; if /^part\s+/i matches, "Part " + rest; else "Part " + label
   export function part_address(section_address: string, part_label: string): string // `${section_address}.${section_slug(normalise_part_label(part_label))}` -> ...LearningInAction.PartA
   export function tip_address(section_address: string, ordinal: number): string      // `${section_address}.Tip${ordinal}` [D]
   export function safety_note_id(lesson_id: string, ordinal: number): string         // `${lesson_id}.sn${ordinal}` (1-based among the row's safety_note segments) [D]
   export function assign_addresses(lesson: StoredLesson, unit_id: UnitId): StoredLesson
   ```
   `assign_addresses` returns a new object (no mutation), each section `address = lesson.lesson_id + "." + section_slug(name)`; throws `RangeError` if `!lesson.lesson_id.startsWith(unit_id + ".")`; idempotent. Test `addresses.test.ts`: slug, part address, idempotence, no mutation, RangeError.
5. **`nodes.ts`**: pure builders returning `PMJson` (types from editor-schema). Helpers: `text(s, marks?)` (never create an empty text node), `para(s, marks?)`, `paras(s, marks?)` (split on `/\n+/`, trim, drop blanks; if none return one `paragraph` with no content), `bullets(s)`. Marks written in schema order (strong, em, teacher_talk, sample_response). Builders (one per role, signature `(block: DraftBlock, ...) => PMJson[]`):
   - `routine_heading` -> `{type:"routine_heading", attrs:{icon: routine_icon(text)}, content:[text]}`.
   - `teacher_talk` -> `paras`, mark `teacher_talk`; if the first paragraph starts with a `TEACHER_LABELS` entry, split it: label text node marks `[strong, teacher_talk]`, remainder (leading space kept) marks `[teacher_talk]`.
   - `sample_response` -> `paras` with mark `sample_response`. `paragraph` -> `paras`. `homework` -> `paras`. `list` -> `bullet_list` of `list_item > paragraph`, one per non-blank line, stripping a leading `- `, `* ` or `• `.
   - ELD group (`eld_group(blocks: DraftBlock[]): PMJson`): `collapsible{label: ELD_LABEL}` holding `callout{variant}` per block, stably sorted purpose, say, watch, each holding `paras(text)`. No other text.
   - `support_table(block)` -> `collapsible{label: SUPPORT_LABEL}` > `table` : header row (`table_header` cells "Situation", "Try this", each wrapping a paragraph) then one `table_row` of `table_cell`s per non-blank line, split at the first `|`, both trimmed (no `|` -> second cell an empty paragraph). Cell attrs `{colspan:1,rowspan:1,colwidth:null}`.
   - `cfu_item(block)` (uses `block.cfu`, ignores `block.text`) -> [`routine_heading{icon:"cfu"}` text `Pulse Check (${standard_code})`; paragraph stem; `ordered_list{order:1,type:"A"}` with one `list_item>paragraph` per option; then per option one paragraph: strong text `${letter}. Correct:` or `${letter}. Incorrect:` (letter `String.fromCharCode(65+i)`, correct when `i === key_index`) followed by text ` ${rationale}`]. The label is built from `CORRECT`/`INCORRECT` plus the letter; add `"A. "`-style letter prefixes to `ALL_LABELS` handling by having the AC-7 test strip `/^[A-Z]\. /` from added strings (see step 8).
   - `quick_write` -> `routine_heading{icon:"writing"}` text `QUICK_WRITE` + `paras(text)`.
   - `text_evidence_needed` -> `quote_placeholder{slot_id, reason: block.text}`; `excerpt_slot` -> a `paragraph` with the block's text (the reviewer instruction; no attr can hold it) **[D]** followed by `excerpt_slot{slot_id, rights:"unset", source_ref:null}`. `slot_id` is passed in: `${lesson_id}.slot${n}`, n = 1-based counter over placeholder and slot blocks in compiled order **[D]**.
   - `teacher_tip(block, safety_note_id: string|null)` -> `teacher_tip{safety_note_id}` > `paras(text)`.
   - `part_heading(label)` -> `heading{level:2}` with `normalise_part_label(label)`.
6. **`compile-draft.ts`**: define `CompileError`, `CompileContext`, `CompiledLesson`; message format `COMPILE_ERROR: ${reason} at ${address ?? lesson_id}` (never include model text). Algorithm of `compile_draft(draft, ctx)`:
   1. **Validate every block first, in draft order** (invariant: no partial lesson). If `ctx.template.sections` lacks `block.section` (exact name) -> `CompileError{lesson_id: draft.lesson_id, reason:"section_not_in_template", address: `${draft.lesson_id}.${section_slug(block.section)}`}`. Else if `check_role(...)==="role_not_allowed"` -> same with `role_not_allowed`.
   2. **Safety plan.** `notes = ctx.row.segments.filter(kind==="safety_note")`, ordinal = index+1, `id = safety_note_id(draft.lesson_id, ordinal)`. Every note counts, whatever its `applies` **[D]**. Target section for tips: `Homework` if the template has it, else the last template section **[D]**.
   3. **Per template section, in template order**, take its blocks (draft order). Walk them: emit `part_heading` when `block.part` is non-null and differs from the previous block's part in this section; group each maximal run of consecutive `callout_*` blocks with the same part into one `eld_group`; otherwise call the role's builder. In the target section, the i-th draft `teacher_tip` block pairs with note i (gets `safety_note_id`); extra tips get `null`. After the walk, for each note with no paired draft tip append a fallback `teacher_tip` whose paragraph is the note's `text` (original text, never lost).
   4. **Omit a section that produced no nodes** (the doc node needs `block+`); the target section is created if it has only fallback tips.
   5. Section `minutes` = sum of `block.minutes ?? 0` over its blocks. **Never** adjust. `front_matter = {standards: [], minutes_total: sum of section minutes, vocabulary: [...ctx.row.vocabulary]}` **[D]** (official standard text is not available to a pure compiler; NL-29 fills `standards`).
   6. **Normalise** each content doc: `assert_known_nodes(doc, ctx.schema_version)` inside try/catch; a `SchemaUnknownError` becomes `CompileError{reason:"unknown_node", address: section address}`; then `const node = EDITOR_SCHEMA.nodeFromJSON(doc); node.check(); content = node.toJSON()`. Any other thrown error is a compiler bug: let it propagate (do not wrap).
   7. Build `StoredLesson {lesson_id, schema_version: ctx.schema_version, title: draft.title, type: ctx.template.lesson_type, front_matter, sections (address "" placeholder), text_cards: draft.text_cards}`, then `assign_addresses(lesson, ctx.unit_id)`.
   8. `safety_tips` = `tip_address(section.address, ordinal)` per note, in ordinal order, computed after addresses.
   9. `teacher_word_count`: walk each section's content; for every node whose children are inline, concatenate its inline text (hard_break as a space) and add `(s.match(/\S+/g) ?? []).length`; skip the whole subtree of any `teacher_tip`. `placeholders` = count of `quote_placeholder` + `excerpt_slot` nodes. `content_hash = content_hash(lesson)` (name the import `content_hash as hash_lesson` to avoid shadowing).
   No clock, no randomness, no I/O, no module-level mutable state.
