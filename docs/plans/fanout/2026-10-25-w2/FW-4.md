## 4. Shared code to use (exact, from main)
Imports use alias `@/*` -> `apps/web/src/*` (tsconfig paths).
- `@/components/layout`: `AppShell({navSections: NavSection[], topBar?, children, productName?})`; `NavSection {id; label?; items: NavItem[]}`; `NavItem {id; label; href; count?: number; current?: boolean; icon?}`; `PageHeader({eyebrow?, title: ReactNode, meta?, breadcrumb?: Crumb[], actions?})`; `Breadcrumb({items: Crumb[]})`, `Crumb {label; href?}`; `TwoPane({children, rail, railWidth?: "rail"|"rail-narrow", className?})`; `SideRail({title, children, narrow?, className?})`; `PageSheet({children, toolbar?, className?})`. AppShell renders the single `nav` (aria-label "Primary") and `main#main-content`, so the gallery page is wrapped in ONE AppShell and never renders a second `main`/`nav`.
- `@/components/ui/*` (import each from its file): `button` (`Button`: `variant?: "primary"|"secondary"|"ghost"|"danger"`, `size?: "sm"|"md"|"lg"`, `loading?`, `disabled?`, `disabledReason?`); `link` (`Link` href, `external?`, `inText?`); `text-input` (`TextInput`, `Textarea`: `label`, `help?`, `error?`); `select` (`Select`: `label`, `help?`, `error?`, `options?: {value,label}[]`); `choice` (`Checkbox`, `Radio`, `RadioCard` take `label`; `RadioGroup({legend, required?, children})`); `status-pill` (`StatusPill({status: StatusKey, by?, detail?})`); `status` (`STATUS_SPECS`, `StatusKey`, `STEPS`); `badge` (`CapsTag`, `CountBadge({count})`, `Marker({n})`, `VersionChip({version})`, `CodeChip`); `banner` (`Banner({level: "blocking"|"advisory"|"info"|"success", title, children?, action?})`); `card` (`Card({title?, children})`, `MetricTile({title, value: string|null, unit?, caption?, note?})`); `table` (`Table({caption, captionHidden?})`, `Thead`, `Tbody`, `Tr`, `Th({numeric?, sort?})`, `Td({numeric?})`); `tabs` (`Tabs` (Radix Root, use `defaultValue`), `TabsList`, `TabsTrigger({count?})`, `TabsContent`); `stepper` (`Stepper({current: 1|2|3|4|5, offPath?})`); `dialog-shell` (`DialogShell({open?, onOpenChange?, trigger?, title, description?, eyebrow?, size?, footer?, children?, busy?})`); `toast` (`Toast({message, action?: {label,onAction}, onDismiss?, durationMs?})`, `ToastRegion`).
- Status coverage: iterate `Object.keys(STATUS_SPECS) as StatusKey[]` so every `design.md` §2 row renders and new rows appear automatically.
- Radix Dialog is modal: an open modal makes the rest of the page `aria-hidden`. Never render it open in the main gallery; use `trigger` only.
