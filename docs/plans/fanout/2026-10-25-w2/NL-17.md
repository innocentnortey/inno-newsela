## 5. Steps (module design: pure core, no seams needed; internal helpers stay unexported and under ~300 lines total; if the file passes 400 lines, move helpers to `report-overlay.ts` in the same folder and list it in the devlog)
1. **Fixtures first** (`tests/fixtures/report/builders.ts`, `import type` only, synthetic, no real or restricted data, seed = none, fully literal/deterministic). Exports: `version_row()` (`outline_version_id "G6.U4.ov1"`, `unit_id "G6.U4"`, `number 1`, `sha256` 64 x `"a"`, `same_as_version null`, `source_kind "xlsx"`, `uploaded_by "usr_" + "0".repeat(25)+"1"` (26 Crockford chars), `created_at "2026-10-25T00:00:00Z"`, `confirmed_at null`), `choice(finding_id, status, value, at, by)`, `clean_outline()`, `issued_shape_outline()`.
   `issued_shape_outline()`: 41 lesson rows (row_number 3..43, lesson_id `G6.U4.L{n}`), 6 flex rows (`G6.U4.FLEX-1a`..`FLEX-6a`), 7 arc_header rows (lesson_id null), 1 total row (lesson_id null); unique ascending `row_number`s. Findings with ids `f01`..: `unit_conflict` (error, row_number null, original "U3"), `malformed_code` (error, row L4), 3 x `nonexistent_code` (error, three different rows), 2 x `bad_filename` (warning), 7 x `eld_mismatch` (warning, rows: use two findings on one row to prove counts are findings not rows). Fill `counts` field of the outline to match. `clean_outline()` has `unit_as_written "U4"`, `unit_from_filenames "U4"`.
2. **Write `report.test.ts`** with the named tests (`describe` names exactly `wp5_clean`, `issued_sheet_counts`, `gate_refuses`, `choices_overlay`, `unit_and_latest_wins`, `deterministic_and_parses`, `text_verbatim`; `-t` filters match the describe/it names, so name each `it("wp5_clean", ...)` etc.).
3. **Choice overlay helper** `latest_choice_by_target(choices): Map<string, IntakeChoiceRow>`. Invariant: latest wins. Order by `Date.parse(at)` (parsing a string, not reading a clock); ties go to the row later in the array. Ignore rows whose `outline_version_id` differs from `version.outline_version_id` (in `generate_gate`, which has no version, skip this filter).
4. **Per-finding resolution**: a finding is *confirmed* only when its latest choice has `status === "confirmed"`. A `default`-status latest row (a revert) means unconfirmed. Resolved `choice` field: confirmed -> `{value: row.choice, source:"confirmed", by: row.confirmed_by, at: row.at}`; otherwise -> `{value: finding.default_choice, source:"default", by:null, at:null}`.
5. **Findings -> report findings**: drop `level === "ok"` findings. Map `kind` through a `Set` of the 17 CON-3 kinds; an unknown kind throws `Error("UNKNOWN_FINDING_KIND:" + kind)` (fail loud). `level` passes through. `column` comes from a constant `KIND_COLUMN: Record<kind,string>`: malformed_code/nonexistent_code/parent_code "Focus"; unit_conflict "Unit"; bad_filename "Filename"; duplicate_id "Lesson #"; missing_required_column "Header"; eld_mismatch/eld_not_checked "ELD"; vocabulary_over_cap/vocabulary_word_missing "Vocabulary"; homework_links_later_row/safety_note_proposed "Homework"; non_breaking_space/duplicate_text/instruction_shaped/writer_task "Description" (presentation only; see Open items). `original_text` and `proposed_fix` pass through unchanged (R-58). Sort by `finding_id` with plain `<` comparison on strings (not `localeCompare`, which depends on locale).
6. **Rows**: sort outline rows by `row_number`. Row `findings` = findings whose `row_number` equals the row's. Row `level` = `error` if any error, else `warning` if any warning, else `ok` (no `info` stored). `segments`: `segment_id = "S" + row_number + "." + index`; `column`: content/writer_task/editor_note "Description", unit_rule "Description", safety_note "Homework"; `action`: `null` for kind `content`, else the record's `applies`; `source`/`by` from the latest choice on that segment_id (confirmed -> `"confirmed"`, `by`; and if the choice value is one of apply/show_only/ignore, `action` = that value), else `"default"`, `null`. `eld`: one entry per `eld_codes` item: `sheet_label ""`, `official_strand ""` (not stored; see Open items), `verdict` "mismatch" if the row has an `eld_mismatch` finding whose `original_text` contains the code, else "not_checked" if the row has an `eld_not_checked` finding, else "fits"; `suggested_remap null`; `choice` "remap" only when the mismatch finding is confirmed with `choice === "remap"`, else "keep". `flags`: `["instruction_shaped"]` when any segment has `instruction_shaped`, else `[]`.
7. **Counts** (from rows and findings, never from `outline.counts`, which the stored value might drift from): `lessons`/`flex_days`/`arc_headers` = row kind counts; `total_rows` = rows of kind `total`; `teaching_days = lessons + flex_days`; `errors` = error-level findings (including those with `row_number null`); `errors_unconfirmed` = those not confirmed; `warnings` = warning-level; `unit_conflicts` = findings of kind `unit_conflict`; `malformed_codes` = kind `malformed_code`; `rows_with_nonexistent_code` = distinct non-null `row_number` among `nonexistent_code` findings; `bad_filenames` = kind `bad_filename`; `eld_mismatches` = kind `eld_mismatch`.
8. **unit block**: `as_written = outline.unit_as_written`, `filenames_say = unit_from_filenames`. `confirmed` = at least one `unit_conflict` finding exists AND every one has a confirmed latest choice (literal reading of the ticket: false until a `confirm_unit` choice exists, so a sheet with no conflict stays false); `confirmed_by` = `confirmed_by` of the confirmed unit_conflict choice with the latest `at`, else `null`.
9. **unit_rules**: one per outline rule in stored order; `scope_rows` = sorted, de-duplicated `row_number`s of rows whose `lesson_id` is in `scope_lesson_ids`; `source` "confirmed" if the latest choice on target `"unit_rule:" + index` is confirmed, else "default".
10. **Assemble in this literal key order** (determinism): `outline_version_id, version_number (= version.number), sha256, same_as_version, unit, counts, rows, unit_rules, runs_from_this_version: [], generate_allowed (= errors_unconfirmed === 0)`. Inside `unit`: `as_written, filenames_say, confirmed, confirmed_by`. `counts` key order as in `ReportCounts`. Build every object literal in the schema's key order; never spread input objects.
11. **`generate_gate`**: collect error-level findings not confirmed (step 3-4); `unconfirmed_finding_ids` sorted with `<`. Empty -> `{allowed:true, refusals:[], details:{unconfirmed_finding_ids:[]}}`; else `{allowed:false, refusals:["VALIDATION_INCOMPLETE"], details}`. It never returns another code; warnings never count. Use the same internal helper as the report so the two cannot disagree (assert in `choices_overlay`: `generate_gate(...).allowed === report.generate_allowed` at each step).
12. Area map + devlog (AC-8). Do not edit the ticket file.

Must not: read a DB, clock, model or env; compute `runs_from_this_version`; let a warning block; escape, trim or normalise cell text; use `localeCompare`; mutate inputs (copy before sort).
