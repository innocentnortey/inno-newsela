## 1. What this does (concrete first)

A reviewer selects a passage in the live editor, opens More > "AI assist", types a note and clicks Ask. The web server calls the stub model (`AssistRewrite` -> `{suggested_text}`), stores a `pending` suggestion outside the document and shows it. Accept makes the web server tell the collaboration server (`apply_edit`, `suggestion_accept`) to replace the STORED selected text at the anchor, in one Yjs transaction tagged `ai-assist` attributed to the acceptor. Reject discards and logs. Today `wire_assist` returns `suggestions: undefined` (container throws "NOT BUILT: NL-116" on first use), `AssistPanel` is not mounted, and nothing produces a real anchor.

Input -> process -> output: selection "Connection to Today's Learning" in WP-1 Lesson 4 + note -> `POST /api/lessons/{id}/suggestions` -> `model_call` row written before the call, `suggestion` row `pending`, `content_hash` unchanged -> Accept -> `POST .../decision` -> collab `apply-edit` -> new `lesson_doc` row, provenance tag `ai-assist`, audit event `suggestion.accept`.
