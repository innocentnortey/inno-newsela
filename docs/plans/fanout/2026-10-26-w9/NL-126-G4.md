## 1. F-9 (#156): sideways scroll
Hypotheses, in order of likelihood:
- **H1, workspace (SCR-9/10/11 at 390, 58 px):** `workspace-screen.tsx` line 198 and `skeleton.tsx` use `grid gap-6 lg:grid-cols-[var(--layout-outline)_minmax(0,1fr)]`. Below `lg` there is no explicit column, so the implicit track is `auto` and grows to the min-content of the PageSheet / editor. Fix: `grid-cols-1` is not enough (it is `minmax(0,1fr)` in Tailwind 4, so yes it is enough): add `grid-cols-1` plus `min-w-0` on both grid children. Same defect class in `approval-skeleton.tsx`, `history-skeleton.tsx`, `validation-report-screen.tsx` ReportSkeleton (all `grid gap-6 lg:grid-cols-...`).
- **H2, SCR-4/5 (1350 px at 1280, 1953 px at 390):** a non-wrapping element inside `PageSheet`'s reading column (the issued sheet's long Focus cells, "RL.6.1, RL.6.2, ...") widens an ancestor that has no `min-w-0`/clip. `Table` wraps in `overflow-x-auto`, which clips a table, so the likely culprit is a non-table node (CodeChip rows, `okRowLabel` li, `fix-editor`, or `errors-section` cells) in a flex/grid child without `min-w-0`. Fix: `min-w-0` on `TwoPane` `content` (already present) and `PageSheet` (`min-w-0 max-w-full`), `overflow-wrap:anywhere` on the offending cell; if the culprit is a table nested in a table cell, give the inner `Table` wrapper `max-w-full`. The spec says tables scroll in their own box (SCREEN_SPECS), so tables keep `overflow-x-auto` and never widen the page.
- **H3, SCR-18 coverage (367 px at 1280, 1021 px at 390):** `Table` wrapper has `overflow-x-auto` but its parent (`coverage-screen.tsx` wrapper or `AppShell` `main`) can still grow: `main` is `w-full` with no `min-w-0`, and below `md` it is a block so should clip; check `StandardRowHeader` `min-w-[16rem] whitespace-normal` and the `sticky left-0` header. Fix: `min-w-0 max-w-full` on `main` (`app-shell.tsx`), and `overflow-x-clip` on the shell root as a belt (not a replacement: the probe must show the real widener is gone).
- **H4, SCR-3 (26 px at 390):** `upload-outline-screen.tsx` `PageSheet mx-auto w-full max-w-(--layout-dialog-md)` plus `drop-zone.tsx` / `upload-form.tsx` content. Fix whatever the probe names (likely a fixed-width or `whitespace-nowrap` child).
Do not add `overflow-x: hidden` to `html`/`body` as the fix (hides the loss, fails WCAG 1.4.10 for content that is then cut off).
