## 1. Goal and sources
When the lock lands, the server sends a stateless `mode` message `read_only`; `CollabSession` sets `mode_read_only`, `LessonEditor` passes `editable={false}` to every `SectionEditor`, and ProseMirror turns `contenteditable` off. Keys typed after that go to a non-editable element and the browser drops them with no trace. Keys typed just before it reach the server, are refused (`refused` message) and show in `RefusedNotice` (`Removed text: “…”`) through `CollabSession.refusal.text`. Evidence: `evals/reports/integrity-0e573c14a27e.md` (14/20 trials lose one token, e.g. `n01` in snapshot, `b` in notice, `06` nowhere, trial detail `lost_at_boundary: 1`); `docs/devlog/2026-10-26-w8-nl125.md` ("Review fixes" section); oracle `apps/web/e2e/integrity/scenarios.ts` `no_silent_loss` (lines ~193-283; a straddling token counts as accounted for when its head is in the submit snapshot and the notice text, after the `Removed text: “` prefix, **starts with** the tail; so late keys must come right after the refused text, in typing order).
Fix: capture printable keys that arrive after the editable-to-read-only flip and append them to the refusal text, so the notice reads `b06 …`. Nothing is sent to the server (the lock stays honoured; these keys never enter a Y.Doc).

## 5. Steps
1. **`apps/web/src/editor/late-keys.ts`** (new, about 80 lines, no React, no collab imports). Exact exports:
```ts
export const ENGAGED_MS = 1500;   // a flip counts only if a printable key went into the editor this recently
export const LATE_KEY_IDLE_MS = 1000; // capture ends after this gap between captured keys
export interface KeyLike { key: string; ctrlKey: boolean; metaKey: boolean; altKey: boolean; isComposing?: boolean }
/** The character a key press types, or null (Enter, Backspace, arrows, shortcuts, IME composition). */
export function printable_key(e: KeyLike): string | null   // e.key.length === 1 && !ctrl && !meta && !alt && !isComposing, else null
export interface LateKeyCaptureOptions {
  root: HTMLElement;                 // the lesson editor root div
  doc: Document;
  is_editable: () => boolean;        // true while the editor accepts input
  on_text: (s: string) => void;
  now?: () => number;                // default Date.now; tests inject a clock
}
export interface LateKeyCapture { arm(): void; dispose(): void }
export function create_late_key_capture(o: LateKeyCaptureOptions): LateKeyCapture
```
   Behaviour of `create_late_key_capture` (state: `last_at = -Infinity`, `armed = false`):
   a. One `keydown` listener on `o.doc`, **capture phase** (`addEventListener("keydown", fn, true)`); `dispose()` removes it.
   b. `ch = printable_key(e)`; if null return. Target filter: `const t = e.target as Node | null; const inside = !!t && o.root.contains(t); const bare = t === o.doc.body || t === o.doc.documentElement;` if `!inside && !bare` return (typing into any other input is never captured; invariant: we never swallow text meant for another field). Never call `preventDefault`.
   c. If `armed`: if `now - last_at > LATE_KEY_IDLE_MS` set `armed = false` and fall through to (d); else `last_at = now; o.on_text(ch); return`.
   d. If `inside && o.is_editable()` set `last_at = now` (engagement is only recorded while the editor is editable, so a read-only viewer is never "engaged").
   e. `arm()`: `armed = (now() - last_at) <= ENGAGED_MS`; (keep `last_at` as is; the idle window therefore runs from the last key).
2. **`collab-session.ts`**: replace the single `refusal` assignment by two private fields and a rebuild:
   - add `private refused_text: string[] = [];`, `private refused_dropped = 0;`, `private late_text = "";`
   - `handle_refused`: after `apply_refusal(...)` set `this.refused_text = outcome.refused_text; this.refused_dropped = outcome.dropped_updates; this.rebuild_refusal();` (delete the old direct `this.refusal = {...}`).
   - new `private rebuild_refusal(): void { if (this.refused_text.length === 0 && this.late_text === "" && this.refusal === null) return; this.refusal = { message: "Your last edits were not saved.", text: this.late_text === "" ? this.refused_text : [...this.refused_text, this.late_text], dropped: this.refused_dropped }; }` (new object each call so the snapshot reference changes).
   - new public `add_late_text(s: string): void { if (this.destroyed || s === "") return; this.late_text += s; this.rebuild_refusal(); this.emit(); }`. Doc comment: "Keys typed after the editor turned read-only. They never enter the doc and are never sent; they only make the notice honest."
   - Do **not** touch `refused`, `discard_local_state`, `compute`, or `on_update`.
3. **`lesson-editor.tsx`**:
   - `import { create_late_key_capture, type LateKeyCapture } from "./late-keys";`
   - `const root_ref = useRef<HTMLDivElement>(null);` and put `ref={root_ref}` on the root `div`.
   - `const read_only_ref = useRef(false); const capture = useRef<LateKeyCapture | null>(null);` Place after `read_only` is computed (line ~187): `useEffect(() => { read_only_ref.current = read_only; });` (no deps, like the file's other ref-sync effects).
   - effect creating the capture: `useEffect(() => { if (!session || !root_ref.current) return; const c = create_late_key_capture({ root: root_ref.current, doc: document, is_editable: () => !read_only_ref.current, on_text: (s) => session.add_late_text(s) }); capture.current = c; return () => { c.dispose(); capture.current = null; }; }, [session]);`
   - flip effect: `const was_read_only = useRef(read_only); useEffect(() => { if (!was_read_only.current && read_only) capture.current?.arm(); was_read_only.current = read_only; }, [read_only]);` Order the effects so `read_only_ref` sync is declared before the flip effect. The `session` effect (create) must be declared before the flip effect so `capture.current` exists on first flip.
   - Invariant protected: `arm()` runs in the same commit flush as `SectionEditor`'s `setProps({ editable })` effect (children first), so a key goes either to ProseMirror (editable, ends up in the doc, is refused, shows via the refused text) or to the capture, never both and never neither. Keep the `read_only` flip logic (`prop_read_only || snap.read_only`) unchanged.
