## 4. Decisions made (tile values: single number per tile, `value` null with `n` 0 and label "Not measured yet" when no source rows)

All numbers come from stored rows; never a model call. Percentages are 0-100 rounded to 2 decimals (the oracle compares with `toBeCloseTo(x, 2)`). `n` = the denominator rows. Unit scope = lessons of the unit; runs/jobs of those lessons.

| Tile | Value | n | Source tables |
|---|---|---|---|
| V-1 (M-5) | % of lessons whose FIRST `lesson_version` (min `number`) has 0 `issue` rows of blocking severity for its `content_hash` | lessons with a first version | `lesson_version`, `issue` |
| V-2 (M-6) | % of focus-standard claims with a reviewer-confirmed teach+check link on approved lessons | claims | `alignment_link` |
| V-3 (M-7) | % of quote spans sourced or placeholder | quote spans | `issue` kind `quote_match`, `lesson_version.lesson_json` |
| V-4 (M-8) | median normalized edit distance (Levenshtein / max length, 0-1) between first generated and first approved version text | approved lessons | `lesson_version` |
| V-5 (M-9) | % of submitted lessons with at least one in_review -> changes_requested event | submitted lessons | `review_event` |
| V-6 (M-10) | accept rate % = accepted / offered | offered suggestions | `suggestion` |
| O-1 (M-11) | USD per first-approved lesson = (sum `model_call.cost_usd` on the lesson + `active_minutes/60*40`) / lessons (model cost and review cost may be summed; the tile `label` names both parts) | approved lessons | `model_call`, `lesson_metrics` |
| O-2 (M-12) | first-approved lessons per active human hour | human lessons | `lesson_metrics` |
| O-3 (M-13) | days from outline `confirmed_at` to the last first approval | approved lessons | `outline_version`, `lesson_metrics` |
| O-4 (M-14) | % of outline focus standards with an assessed lesson | focus standards | `alignment_link` |
| H-1 (M-15) | % of `lesson_job` rows ending `ready` | jobs | `lesson_job` |
| H-2 (M-16) | p95 minutes of (`finished_at - started_at`) per job (nearest-rank p95) | finished jobs | `lesson_job` |
| H-3 (M-17) | the largest run of the unit: sum of its `model_call.cost_usd` / `run.cap_usd` * 100 | runs | `model_call`, `run` |
| H-4 (M-18) | `p95_ms->>'lesson_open'` of the latest `probe_run kind='http'`, in seconds | probe `n` | `probe_run` |
| H-5 (M-19) | `p95_ms->>'remote_edit'` of the latest `probe_run kind='yjs'`, in ms | probe `n` | `probe_run` |
| H-6 (M-20) | `p95_ms->>'board'` of the latest `probe_run kind='http'`, in seconds | probe `n` | `probe_run` |
