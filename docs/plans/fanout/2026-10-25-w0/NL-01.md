### 4.2 Config API (`packages/config/src/`)

`secret.ts`:
```ts
export class SecretStr {
  constructor(value: string);
  reveal(): string;                       // the only way to read the value
  toString(): string;                     // "[redacted]"
  toJSON(): string;                       // "[redacted]"
  [Symbol.toPrimitive](): string;         // "[redacted]" (template literals)
  [Symbol.for("nodejs.util.inspect.custom")](): string; // "[redacted]"
}
```
Store the value in a `#value` private field (not an own enumerable property).

`errors.ts`:
```ts
export class ConfigError extends Error {
  readonly variable: string;   // the NAME, never the value
  readonly problem: string;    // one of: "missing" | "malformed" | "out of range" | "required when MODEL_PROVIDER_MODE=real"
  constructor(variable: string, problem: string);   // message = `${variable}: ${problem}`; name = "ConfigError"
}
```
`problem` is always one of those four fixed strings. Never interpolate the offending value, never copy a zod message
(zod messages can echo input).

`env.ts` (internal readers; each takes `(env, name, opts)`, treats `undefined` and `""` as unset, builds a **zod** schema, uses
`safeParse`, and on failure throws `ConfigError(name, problem)` where problem is `"missing"` for unset-without-default,
`"out of range"` for zod issue codes `too_small`/`too_big`, else `"malformed"`):
- `read_string(env, name, {default?})`, `read_int(env, name, {default?, min, max?})`
  (schema: `z.string().regex(/^\d+$/).transform(Number).pipe(z.number().int().min(min).max(max ?? Number.MAX_SAFE_INTEGER))`),
- `read_decimal(env, name, {default})` (`/^\d+(\.\d+)?$/` then `new Decimal(raw)`),
- `read_bool(env, name, {default})` (`"true"`/`"false"` only, case-insensitive),
- `read_enum(env, name, values, {default?})`, `read_url(env, name, protocols, {default?})` (`new URL()` in try/catch; check protocol),
- `read_secret(env, name)` and `read_optional_secret(env, name)` -> `SecretStr` / `SecretStr | null`.

`settings.ts` (types exactly as DO-4 section 9, plus loaders):
