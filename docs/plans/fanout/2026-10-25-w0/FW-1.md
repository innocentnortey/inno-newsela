## 5. Steps

1. **Install.** `mkdir -p apps/web && cd apps/web`; write `package.json` (fields above, no deps), `npm install --save-exact <deps>`, `npm install --save-exact -D <devDeps>` (lists in §4). Commit nothing in `node_modules`. Check: `npm ls --depth=0` shows the exact pins.

2. **Generator `scripts/build-tokens.mjs`** (ESM, Node built-ins only, JSDoc types, `allowJs` makes it typed). Exports:
   - `DESIGN_PATH` = `path.resolve(here, "../../../docs/design/design.md")`, `OUT_PATH` = `path.resolve(here, "../src/styles/tokens.css")` (`here` = dirname of `import.meta.url`).
   - `extractTokens(markdown: string): TokensJson` — match fenced block with ```` /```json tokens\n([\s\S]*?)\n```/g ````; throw `Error("design.md: expected exactly one json tokens block")` unless exactly one; `JSON.parse` it.
   - `buildTokensCss(tokens): string` — deterministic, key order = JSON order, ends with a single `\n`, 2-space indent, no trailing spaces. Layout below.
   - `main()` — reads DESIGN_PATH, writes OUT_PATH (mkdir -p), prints `wrote <path>`; runs only when `import.meta.url === pathToFileURL(process.argv[1]).href`.

   Variable names (kebab keys kept; `.` in a key becomes `_`):
   | JSON | CSS variable = value |
   |---|---|
   | `colors.<theme>.<k>` | `--color-<k>: <string as-is>` |
   | `type.family.sans/mono` | `--font-sans`, `--font-mono` = string as-is |
   | `type.weight.<k>` | `--font-weight-<k>: <n>` |
   | `type.scale.<k>` | `--text-<k>: <size>px`, `--text-<k>--line-height: <lh>`, `--text-<k>--font-weight: <w>`, `--text-<k>--letter-spacing: <tracking>` (Tailwind v4 text-utility convention) |
   | `type.measure.reading` | `--measure-reading: 68ch` |
   | `space.<k>` | `--space-<k with . → _>: <n>px` (`0` → `0px`) |
   | `spaceSemantic.<k>` | `--sem-<k>: <n>px` |
   | `control.height.<k>` | `--control-<k>: <n>px` |
   | `radius.<k>` | `--radius-<k>: <n>px` |
   | `border.width.<k>` | `--border-width-<k>: <n>px`; `border.focusOffset` → `--focus-offset: 2px` |
   | `elevation.<theme>.<k>` | `--shadow-<k>: <string as-is>` |
   | `motion.duration.<k>` | `--duration-<kebab(k)>: <n>ms` (`indicatorDelay` → `--duration-indicator-delay`) |
   | `motion.easing.<k>` | `--ease-<k>: <string>` |
   | `motion.reducedMotion.opacityFadeMax` | `--duration-fade-reduced: 120ms` |
   | `z.<k>` | `--z-<k>: <n>` |
   | `breakpoints.<k>` | `--breakpoint-<k>: <n>px` |
   | `layout.<k>` | `--layout-<k>: <n>px` |
   Skip `name/version/status/source` except the header comment. Ignore `border.role`.

3. **CSS layout produced** (this is the contract the tests parse):
   ```
   /* GENERATED by scripts/build-tokens.mjs from docs/design/design.md (tokens clear-ledger 0.1.0). Do not edit; run `npm run tokens`. */

   @theme static {
     --color-*: initial;
     <all light colours> <fonts> <weights> <text scale> <measure> <space> <sem> <control> <radius> <border widths + focus offset> <light shadows> <durations> <fade-reduced> <easing> <z> <breakpoints> <layout>
   }

   :root {
     color-scheme: light dark;
   }

   [data-theme="light"] {
     color-scheme: light;
   }

   [data-theme="dark"] {
     color-scheme: dark;
     <all dark colours> <dark shadows>
   }

   @media (prefers-color-scheme: dark) {
     :root:not([data-theme]) {
       <all dark colours> <dark shadows>
     }
   }

   @media (prefers-reduced-motion: reduce) {
     :root {
       --duration-fast: 0ms; --duration-base: 0ms; --duration-slow: 0ms;   (one per line)
     }
   }
   ```
   Invariants: `@theme static` makes Tailwind emit every variable on `:root` in the final CSS even if unused, and the dark blocks override the same variable names so utilities (`bg-ground`, `text-ink`, `rounded-md`, `shadow-e2`) switch theme with no `dark:` variants. `--color-*: initial` removes Tailwind's default palette, so only token colours exist. `indicator-delay` and `instant` are NOT zeroed in the reduce block.

4. **Run** `npm run tokens`; commit the output. `grep -c '^  --color-' src/styles/tokens.css` should be 33×... just check both themes have the same key count (33 each: 28 listed names + presence-1…4 + focus etc.; the test in step 6 asserts light keys == dark keys).

5. **`app/globals.css`** (no hex colours, no rgba literals):
   ```css
   @import "tailwindcss";
   @import "@fontsource-variable/inter";
   @import "../src/styles/tokens.css";
   ```
   (If Next/Tailwind cannot resolve the bare Inter import, use `@import "@fontsource-variable/inter/index.css";` — both are in the package's `exports`.) Then:
   - `@layer base { html { -webkit-text-size-adjust: 100%; scroll-padding-top: var(--layout-top-bar); } body { margin: 0; background: var(--color-ground); color: var(--color-ink); font-family: var(--font-sans); font-size: var(--text-body); line-height: var(--text-body--line-height); font-weight: var(--text-body--font-weight); -webkit-font-smoothing: antialiased; } h1,h2,h3,h4 { text-wrap: balance; } p { text-wrap: pretty; } code, kbd, pre, samp { font-family: var(--font-mono); font-size: var(--text-code); } :focus-visible { outline: var(--border-width-focus) solid var(--color-focus); outline-offset: var(--focus-offset); } }`
   - `@utility num { font-variant-numeric: tabular-nums; }`, `@utility caps { text-transform: uppercase; }`, `@utility font-code { font-family: var(--font-mono); font-size: var(--text-code); line-height: var(--text-code--line-height); }`.
   - Tabular numerals on the numeric scales: `@utility text-stat-num`? **No**: keep scope small; `stat` and `display` users add `num`.
   - Reduced motion (UI-12): `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { transition-duration: 0ms !important; animation-duration: 0ms !important; animation-iteration-count: 1 !important; scroll-behavior: auto !important; } }`
   - Default-transition durations read tokens: `:root { --default-transition-duration: var(--duration-fast); --default-transition-timing-function: var(--ease-standard); }` placed inside `@layer base`.
   Tailwind's `text-page` etc. utilities come from `--text-*`. The heading in `page.tsx` uses `text-page`; if the build shows the class generates nothing (check `.next/static/css/*.css` contains `--text-page`), report it under Open items rather than adding a hex or px literal.
