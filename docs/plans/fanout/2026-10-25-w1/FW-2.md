## Files to create (`apps/web/src/components/ui/`)
All client-safe, `forwardRef` where an element is wrapped, props spread last, `cn()` for classes, no data/network/editor.
1. `button.tsx`: `export type ButtonVariant = "primary"|"secondary"|"ghost"|"danger"; export type ButtonSize = "md"|"lg";` (md = 36px, lg = 44px; ticket says 36/44; design `sm` 28 omitted). Props: `variant?, size?, loading?: boolean, disabled?: boolean, disabledReason?: string` + `ButtonHTMLAttributes` (omit native `disabled`). Rules: disabled renders `aria-disabled="true"` (never the `disabled` attribute), stays focusable, onClick suppressed; if `disabledReason` it renders a visible `<span id={useId()}>` with a lock glyph and the text and sets `aria-describedby`. `loading`: `aria-busy="true"`, width kept (render label always; spinner slot reserved in an element with fixed `size-4`, spinner shown only after a `useEffect` timer of 250 ms (`INDICATOR_DELAY_MS = 250`, exported) , clicks ignored). Primary: `bg-primary text-on-primary`. danger = danger-ghost per design (`text-danger`, no fill). Default `type="button"`.
2. `link.tsx`: `Link` = `<a href>`; props `AnchorHTMLAttributes` + `external?: boolean` (adds out-arrow svg `aria-hidden` and `rel="noopener noreferrer"`, `target="_blank"`) + `inText?: boolean` (always underlined; else underline on hover, 600 weight). href required in type.
3. `field.tsx`: shared `Field` wrapper used by TextInput/Textarea/Select: label `<label htmlFor>`, help `<p id>`, error `<p id>` with octagon glyph; computes `aria-describedby` = help id + error id; `aria-invalid` when `error`. Exports `useFieldIds`.
4. `text-input.tsx`: `TextInput` and `Textarea` (label, help?, error?, props of input/textarea; `required` shows nothing red). Height 36, `border-edge`... use `border-hair`/`border-edge` (edge is the visible control border), invalid `border-danger`.
5. `select.tsx`: `Select` native `<select>` in `Field`, chevron svg; `options: {value:string; label:string}[]` or children.
6. `choice.tsx`: `Checkbox` (native `input type=checkbox`, label), `Radio` (native radio), `RadioGroup` (`<fieldset><legend>`, `required` appends "(required)" text in legend), `RadioCard` (label wraps radio, whole card clickable, min-height 36, selected style via `has-[:checked]:bg-selected`).
7. `status.ts`: data only. `export type GlyphShape = "circle-open"|"circle-dashed"|"circle-half"|"circle-back"|"circle-up"|"circle-check"|"circle-turn"|"square-out"|"square"|"triangle-bang"|"circle-half-wrench"|"circle-bang"|"circle-pause"|"octagon-bar"|"circle-i"|"diamond"|"none"; export type Tone = "neutral-ink2"|"neutral-ink3"|"info"|"warn"|"success"|"danger"|"plain";` and `export const STATUS_SPECS: Record<StatusKey, {label: string; glyph: GlyphShape; tone: Tone}>` where `StatusKey` is namespaced `"lesson.draft"`, etc. Exactly the §2 table, 33 keys: lesson: draft, in_review, changes_requested, submitted, approved, reopened, exported, generation_failed (8); tile: queued, planning, drafting, checking, repairing, ready, failed (7); run: planning, running, complete, partial, capped, paused, cancelled (7); issue: blocking, confirmation, advisory, resolved (4); origin: outline, outline-fixed, narrowed, added (4); validation: error, warning, ok (3). Labels and glyph/tone per §2 (tile planning/drafting/checking labels Planning/Drafting/Checking; issue.confirmation label "Confirm"; issue.resolved "Resolved"; origin.outline "from the outline" (glyph none, tone plain); origin.outline-fixed "outline, fixed"; narrowed "AI-proposed"; added "confirm"; validation labels Error/Warning/OK). Also `STEPS = ["Draft","In review","Submitted","Approved","Exported"] as const`.
8. `glyph.tsx`: `Glyph({shape})` returns inline 12px svg with `aria-hidden="true"`, `focusable="false"`, `data-glyph={shape}`, distinct path per shape (simple primitives are fine); `none` returns null.
9. `status-pill.tsx`: `StatusPill({status: StatusKey; by?: string; detail?: string})`: height 22, `rounded-sm text-label`; renders `<span data-status={status}>` glyph + text label (`label`, plus ` by {by}` for resolved, plus ` ({detail})` e.g. "Repairing (1 repair)"). Accessible name = label text only (glyph aria-hidden). Also exports `Badge` family: `CapsTag({children})`, `CountBadge({count})` (22x22, tabular), `Marker({n})`, `VersionChip({version})`, `CodeChip({children})` (`whitespace-nowrap`), all in this file or `badge.tsx` (prefer `badge.tsx`; ticket says StatusPill and Badge).
10. `banner.tsx`: `Banner({level: "blocking"|"advisory"|"info"|"success"; title: string; children?; action?: ReactNode})`. Level word is rendered visible text ("Blocking","Advisory","Info","Success") next to the title, plus a 32px icon tile (svg aria-hidden). `role="alert"` for blocking only, `role="status"` otherwise. Map: blocking=danger, advisory=warn, info=selected/primary, success.
11. `card.tsx`: `Card({title?, children})` (`<section>` with `aria-labelledby` when titled), `MetricTile({title, value: string|null, unit?, caption?, note?})`: when `value === null` render "No approved lessons yet" and NO number; tabular figures.
12. `table.tsx`: `Table` (`<table>` with required `caption: string` prop, `captionHidden?: boolean` -> sr-only), `Th({scope = "col", numeric?, sort?: "ascending"|"descending"|"none"})` default `scope="col"`, sets `aria-sort` when `sort`; `Td({numeric?})` numeric -> `tabular-nums text-center`; thin wrappers `Thead/Tbody/Tr`. Wrapper div `overflow-x-auto`.
13. `tabs.tsx`: wrap `@radix-ui/react-tabs`: `Tabs, TabsList, TabsTrigger({count?}), TabsContent`; underline selected via `data-[state=active]`.
14. `stepper.tsx`: `Stepper({current: 1|2|3|4|5, offPath?: ReactNode, "aria-label"?})`: `<ol aria-label="Lesson progress">` of 5 `<li>`; current `<li aria-current="step">`; each li has visible `aria-hidden` "Step n/5" and for the current one an `sr-only` `Step {n} of 5, {label}` (so textContent contains "Step 2 of 5, In review"); done steps show check; not interactive. Also a compact `<p>` "Step 2 of 5 · In review" shown `md:hidden` is OPTIONAL (omit if it duplicates text in tests; if added, mark `aria-hidden`).
15. `dialog-shell.tsx`: wrap `@radix-ui/react-dialog`: `DialogShell({open?, onOpenChange?, trigger?: ReactNode, title: string, description?: string, eyebrow?, size?: "sm"|"md"|"lg", footer?: ReactNode, children, busy?: boolean})`. Title uses `Dialog.Title`, description `Dialog.Description` (Radix wires `aria-labelledby`/`aria-describedby`), icon close button `aria-label="Close"`, footer slot right-aligned, `busy` blocks Escape/outside close via `onEscapeKeyDown`/`onPointerDownOutside` `preventDefault`. Radix provides focus trap and return-to-trigger; use `Dialog.Trigger asChild` for the trigger. If no description, pass `aria-describedby={undefined}` on Content to avoid Radix warning.
16. `toast.tsx`: `Toast({message, action?: {label: string; onAction: () => void}, onDismiss?, durationMs = 6000})` presentational: `<div role="status" aria-live="polite">` glyph + sentence + optional action button (Undo slot); auto-dismiss timer calls `onDismiss`, paused on `mouseenter`/`focusin`, resumed on leave/blur. `ToastRegion` fixed bottom-right container (`z-toast`).
17. `index.ts` is NOT created (no barrel; DO-3). Consumers import by file.

## Notes / pitfalls

- Dark-mode contrast for AC-1 reads token files; do not hardcode hexes in the test.
