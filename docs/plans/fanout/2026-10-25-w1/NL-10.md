## Schema design (exact)
Nodes (18 types, this order; `doc` first, `text` present):
- `doc` content `block+`.
- Groups: `block` = paragraph, heading, bullet_list, ordered_list, table, routine_heading, callout, collapsible, quote_placeholder, excerpt_slot. `teacher_block` = teacher_tip only (NOT in `block`).
- `paragraph` group block, content `inline*`, attrs `align: {default: null}` (null | "center"; `validate: (v) => v === null || v === "center"`), parseDOM/toDOM `<p>`.
- `heading` content `inline*`, attrs `level: {default: 1, validate: "number"}` plus a range check 1-5 (use `validate` function; `Node.check()` / `nodeFromJSON` then throws `RangeError`).
- `bullet_list` content `list_item+`; `ordered_list` content `list_item+`, attrs `order: {default: 1}`, `type: {default: null}` (null | "A" | "a" | "1"; validate allows null or "A" per ticket plus "1"; keep to null, "A", "1").
- `list_item` content `(paragraph | heading | bullet_list | ordered_list | callout | quote_placeholder | excerpt_slot | teacher_block)+` written as `paragraph (block | teacher_block)*`. Simplest: `paragraph (block | teacher_block)*`.
- `table` content `table_row+`; `table_row` content `(table_cell | table_header)+`; `table_cell`/`table_header` content `block+` (so teacher_tip is rejected inside a cell), attrs `colspan {default:1}`, `rowspan {default:1}`, `colwidth {default:null}` (null | number[]).
- `routine_heading` content `inline*`, attr `icon` (default `"cfu"`, validate in the 7-value list: cfu notes_section writing graphic_organizer academic_discussion personal_dictionary reading).
- `callout` content `(block | teacher_block)+`, attr `variant` (default `"purpose"`, validate in purpose|say|watch).
- `collapsible` content `(block | teacher_block)+`, attr `label` (default `""`, string).
- `teacher_tip` group `teacher_block`, content `block+`, attr `safety_note_id` default null (string|null). Allowed in doc, callout, collapsible, list_item; so `doc` content is `(block | teacher_block)+`.
- `quote_placeholder` group block, atom, attrs `slot_id` (required string, no default), `reason` (default `""`, string).
- `excerpt_slot` group block, atom, attrs `slot_id` (required), `rights` (default `"unset"`, validate in unset|public-domain|Newsela-owned|licensed|to-clear|short-quote-commentary), `source_ref` default null.
- `text` group inline; `hard_break` inline, group inline, selectable false.
Marks (exactly four): `strong`, `em`, `teacher_talk`, `sample_response`; no attrs; no colour mark. Roles only (render step maps colour elsewhere).
Give every node a `toDOM` (`["div", {"data-node": name}, 0]` style) so the schema can be used by the editor later; `parseDOM` optional.
Attr order: declare attrs in the order the fixture lists them; `toJSON` emits attrs in declaration order, and AC-2 compares with `toEqual` (key order is not asserted by toEqual, so ALSO assert `JSON.stringify(roundtrip) === JSON.stringify(input)` for the fixture, which pins order). Fixture JSON must therefore list attrs in spec order, and include all attrs explicitly (ProseMirror `toJSON` omits `attrs` for nodes with no attrs, and writes defaults for others).

## assert_known_nodes behaviour
1. If `schema_version !== SCHEMA_VERSION` throw `SchemaUnknownError({lesson_id:null, schema_version, unknown_nodes: []})` (message names the version).
2. Recursive walk of the JSON (no mutation, no `fromJSON`): count every node; collect each `type` not in `NODE_NAMES` and each mark `type` not in `MARK_NAMES`, deduped, in first-seen order; if any, throw with `unknown_nodes` = that list and the given `schema_version`.
3. Else return `{ok: true, node_count, schema_version: 1}`. `node_count` counts every node object including `doc` and `text` nodes.
Never `Object.freeze`, delete or rewrite input. Test deep-equal against a `structuredClone` taken before the call.
