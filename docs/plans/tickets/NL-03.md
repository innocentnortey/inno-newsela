### Story
Delivery (no US): the demo video (NL-138) is a required deliverable; the `demo-video` skill voices the narration with ElevenLabs, so the key and voice must exist before recording. It enables NL-138 only.

### What to build
**What Innocent does (`gate::human`).** About 5 minutes.
1. elevenlabs.io → sign in → *Profile → API Keys* → *Create API key* (Text to Speech permission is enough).
2. Pick a voice: *Voices → Library* → copy the voice ID; or, for your own voice, record 1–3 minutes of clean speech and tell Claude the file path (Claude runs `demo.py clone`).
3. On `claude-vultr`: `mkdir -p /home/linuxuser/workspaces/inno-newsela/.demo && nano /home/linuxuser/workspaces/inno-newsela/.demo/.env` with `ELEVENLABS_API_KEY=<key>` and `ELEVENLABS_VOICE_ID=<id>`; then `chmod 600 .demo/.env`.
4. Reply on the issue with the voice's **name** (never the key).

**What Claude records afterwards.** `git check-ignore -v .demo/.env` (ignored); `python3 .claude/skills/demo-video/scripts/demo.py setup` (installs packages, creates `.demo/.gitignore`, reports the key present without printing it); if no voice was chosen, `demo.py voices` output for Innocent to pick from; one dev-log line. The ElevenLabs key stays in `.demo/.env` only; it never goes in the workspace shared file (shared-credentials rule, *Out of scope*).
