### Story
US-15 / US-30 — As the person judging whether the tool cut reviewer time, I need review time measured honestly: active minutes only, one person in two tabs counted once, synthetic accounts excluded, and one frozen row per lesson at its first approval, never shown by name. This is the north-star data (M-1) and its guard (M-3, G-2).

### What to build
Four pieces, all in area A13:
**1. Pure core** — `packages/core/src/metrics/sessions.ts` `merge_heartbeats(beats, gap_s) → ActiveInterval[]` (per user, across tabs: consecutive active beats within `gap_s` join; beats closer than 10 s from one tab add no time; synthetic beats carry `synthetic` through) and `packages/core/src/metrics/frozen-row.ts` `compute_lesson_metrics(sessions, version, rating, approved_at) → LessonMetricsRecord` (human sessions only; `active_minutes` = Σ `active_seconds`/60; `human_sessions`; `teacher_word_count` from the version; `g2_threshold_minutes = 0.5 × (teacher_word_count ÷ 250)`, M-3).
**2. Repository** — `PgMetricsRepo` in `packages/db/src/repos/metrics.ts` (`insert_heartbeat`, `extend_session(hb, gap_s)` — one `review_session` per user, lesson and version: an active beat within `gap_s` of `last_at` adds `min(at − last_at, gap_s)` seconds, a second tab inside the same span adds only what extends it, an inactive beat adds 0; `sessions_for`, `first_approval_exists(lesson_id, tx)`, `write_lesson_metrics(row, tx)` as `INSERT … ON CONFLICT DO NOTHING` returning whether it wrote, `unit_metrics_rows`). `BoardReadRepo` is **not** in this file (NL-42).
**3. Services** — `apps/web/src/server/services/heartbeat-service.ts` `HeartbeatService.record(user, lesson_id, hb)` (authors → `ROLE_FORBIDDEN`; unknown lesson → `NOT_FOUND`; active = focused ∧ visible ∧ `sent_at − last_input_at ≤ HEARTBEAT_MERGE_GAP_S` (60, allowed 60–90); a beat under `HEARTBEAT_MIN_SPACING_S` (10) from the same tab is stored but adds no time — INTERFACE CON-20 wins over DO-4 §5's word "dropped"; `synthetic` copied from the account) and `metrics-writer.ts` `MetricsWriter.write_first_approval(lesson_id, version, rating, tx) → MetricsWriteResult` (`written: false` and no change when a row exists: rework never edits the first row).
**4. Route** — `apps/web/app/api/lessons/[lessonId]/heartbeats/route.ts` (`sendHeartbeat`, roles reviewer and approver, 204 empty body). `wiring/metrics.ts` is filled by NL-54, not here.
Must not: return minutes with a person's name from any route (CON-G8, GR-15), count author or synthetic sessions, edit a stored `lesson_metrics` row, or fill `wiring/metrics.ts`.
