### Story
US-3 — As an author I need to see every problem in the outline before any money is spent, with Generate kept off until every error is confirmed, so that a bad code never reaches 47 paid model calls. US-4 and US-5 — I confirm what each cell really is and keep or re-map an ELD label, so that the lesson cites the state's standard.

### What to build
Add the two read/write halves of intake to the `OutlineService` that NL-26 created (same file, **methods only**; the constructor and `wiring/outlines.ts` do not change, slice plan *Composition-root wiring owners*):

- `OutlineService.report(user, outline_version_id) -> ValidationReport` (CON-3, `getValidationReport`): reads the stored rows and findings through `OutlineRepo.version / rows / choices` and returns `build_validation_report(version, outline, choices)` (DO-4 §8, NL-17). **Reads never write** (shared guarantee 5) and never call a model (HP-6). Also fills `runs_from_this_version` (run id, started_at, `choices_hash`, newest first, empty before the first run) and `generate_allowed` (true when `errors_unconfirmed == 0`, `generate_gate`).
- `OutlineService.record_choice(user, outline_version_id, req) -> IntakeChoiceResult` (CON-4, `recordIntakeChoice`): one tx via `TxRunner.with_tx`: role `author` only, target lookup, kind-vs-value validation, `OutlineRepo.upsert_choice` (status `default` or `confirmed`, `confirmed_by`), `OutlineRepo.mark_confirmed` the first time `generate_gate` allows, one `AuditLog.append`. `revert` restores the stored default. Returns the updated row, new counts and `generate_allowed`.
- Routes: `apps/web/app/api/outline-versions/[outlineVersionId]/report/route.ts` (GET) and `.../choices/route.ts` (POST), both through `with_route` (NL-13 / NL-25: session, Origin check, Zod parse, role, then the service). The choices methods of `packages/db/src/repos/outlines.ts` (`upsert_choice`, `mark_confirmed`) are NL-26's file; add only those two methods if NL-26 left them as shells, otherwise do not touch it.

**Refusals (CON-3/CON-4):** `NOT_FOUND` (version or target), `ROLE_FORBIDDEN` (non-author on choices), `INVALID_CHOICE` 422 with `details.reason` (e.g. `edit_fix` to a code not in the standards list, a unit-rule scope naming a row outside the sheet), `INVALID_TRANSITION` 409 (`confirm_unit` with a different unit after a run started from this version). Error precedence per shared guarantee 11. A refusal writes no row of any kind, only one application-log line (shared guarantee 2).

**Must not:** call a model; recompute findings on read (they are stored at upload, NL-26); return cell text as markup (R-58); edit NL-26's upload/import code, `wiring/outlines.ts` or the standards data.
