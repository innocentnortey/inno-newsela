### Story
US-3 — As an outline author (P-2) I need every row marked OK, warning or error, with the original cell and a proposed fix, and Generate kept off until I have confirmed every error, so that a bad code never reaches 47 paid model calls. This ticket is the pure function that decides, from the stored findings and choices, what the report shows and whether Generate is allowed.

### What to build
`packages/core/src/intake/report.ts` (A4a; pure).
**`build_validation_report(version: OutlineVersionRow, outline: NormalizedOutline, choices: Sequence[IntakeChoiceRow]): ValidationReport`** (the OpenAPI component of `@ls/schema/api/outlines`, CON-3): `outline_version_id`, `version_number`, `sha256`, `same_as_version`, `unit{as_written, filenames_say, confirmed, confirmed_by}` (confirmed only after a `confirm_unit` choice), `counts` (`teaching_days`, `lessons`, `flex_days`, `arc_headers`, `total_rows`, `errors`, `errors_unconfirmed`, `warnings`, `unit_conflicts`, `malformed_codes`, `rows_with_nonexistent_code`, `bad_filenames`, `eld_mismatches`), `rows` (each with `findings` carrying `choice{value, source default|confirmed, by, at}`, `segments`, `eld`, `flags`), `unit_rules`, `runs_from_this_version` (always `[]` here: the service fills it from `RunRepo`), `generate_allowed` (true exactly when `errors_unconfirmed` is 0). The latest choice per target wins; a choice with `status default` counts as unconfirmed; warnings never block (R-5 as amended). Output is byte-deterministic: fixed field order, rows by `row_number`, findings by `finding_id`.
**`generate_gate(outline, choices): GateDecision`** (`{allowed, refusals, details}`): allowed when no error finding is unconfirmed; otherwise `refusals: ["VALIDATION_INCOMPLETE"]` and `details.unconfirmed_finding_ids` sorted (CON-5). It returns no other code: the day cap and the idempotency window are `RunService`'s.
Must not: read the database, a clock or a model, compute `runs_from_this_version`, or let a warning block.
