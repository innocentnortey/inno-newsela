### Story
US-15 — As a reviewer (P-1) I need to edit the lesson together with colleagues and know my edits are stored, so nothing I type is lost and my time is counted fairly; when the lesson freezes under me, the editor must say plainly which of my edits were not kept (SP-2).

### What to build
- `apps/web/src/editor/**` (replaces NL-24's `LessonEditor({ lessonId, lesson, readOnly, onClientState })` shell, same props) and `src/features/workspace/live/**`: a ProseMirror editor with the Newsela node schema (allow-listed nodes only, R-58), `y-prosemirror` bound to a Yjs doc, and a Hocuspocus provider to `x-collaboration-channel` (CON-12; URL from the client config, session cookie). Toolbar strip (Paragraph, B, I, U, list, link, undo, redo), labelled textbox "Lesson 4 text", per-role marks from CON-11's compiled shape.
- Presence: remote carets with a name flag in the user's presence colour (name in text, not colour alone), initials on the outline item, and the top-bar sentence "M. Okafor is editing Part B" (real text, polite). Save state slot: `connecting` ("Connecting to the editor…" after 1 s; read-only CON-11 text meanwhile) → `synced` → `saving` ("Saving…") → `stored` ("Saved · 10:42", on the `stored {content_hash, state_vector, stored_at}` ack) → `DISCONNECTED`. `onClientState` reports `{ state, state_vector, stored }` for NL-64's Submit reasons ("Saving", `NOT_STORED`).
- `DISCONNECTED` (UXP-7): `warn` banner "Reconnecting: your last edits are not saved yet. Submit is off until they are.", save state "Not saved", typing continues locally, the provider reconnects with backoff and resyncs; on reconnect the held edits go up.
- Freeze (SP-2, CON-12 `refused`): on `mode {read_only, state}` the editor turns read-only (no toolbar, no caret). When the server answers a local update with `refused {code: LESSON_LOCKED, message, refused_from}` the editor **drops** the refused local edits (reverts to the stored state at `refused_from`, never re-sending them) and shows a `danger`-toned notice naming what was lost ("Your last edits were not saved because Lesson 4 was submitted. They have been removed from your view."), then stays read-only. Unauthenticated sockets are refused and show the signed-out flow.
- Must not: write the document through any REST route, retry a refused update, apply remote text as HTML, or keep a second copy of the document outside the Yjs doc. New dependencies (`prosemirror-*`, `y-prosemirror`, `yjs`, `@hocuspocus/provider`) go to the batch merge agent (A0).
