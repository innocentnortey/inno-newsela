### Story
US-5 — As an outline author (P-2) I need each ELD code shown with the sheet's label beside the official strand, and a choice to keep or re-map it, so that the lesson cites the state's standard and not a mislabelled one. Platform work: the normalizer, the validation report and the checks all resolve codes against this one index of official text (GR-5).

### What to build
`packages/core/src/intake/standards-index.ts` and the seed data under `packages/core/data/standards/**` (A4a intake core; pure, no I/O at call time).
**Seed data** (derived once from `docs/source/05-standards-referenced.md`, which quotes the CDE tables; each file carries a header naming the source, the date and the rule "official text only, never the sheet's labels", GR-5): `ccss-ela-6.json` (every code in that document plus its parents and each parent's lettered leaves, with `[CA]` marks), `eld-6.json` (the 12 ELD codes by part, strand, sub-part and the `.Em/.Ex/.Br` tiers), `msls-6.json` (the five library-standard codes, written `MSLS 2.1a`), and `eld-verdicts.json` (the **verdict table**: per ELD code the official strand name, the sheet descriptions seen, and `fits`, `partial` or `mismatch` with a suggested re-map, e.g. `ELD.PII.6.5` "Use transitions to connect ideas" → mismatch, suggest `ELD.PII.6.2b`).
**`StandardsIndex`** (DO-4 §8; loaded by `load_standards_index(dir)`, plus `StandardsIndex.from_rows(rows)` for the database-backed `PgStandardRepo.index()`): `resolve(code, sheet_label?)`, `leaves_of(code)`, `text_of(code)`. `resolve` returns `StandardResolution{input_code, status, resolved, suggestion, eld_label_mismatch}`: `ok` (a leaf or a code with no sub-parts), `parent` (a code with leaves; `resolved` lists them, nothing is chosen), `malformed` (`6.2` with no strand prefix → suggestion `RL.6.2` only when unambiguous), `unknown` (`RL.6.9.a` does not exist → suggestion `RL.6.9`). The optional `sheet_label` is an additive parameter to DO-4's `resolve(code)`: with it, `eld_label_mismatch` is true when the verdict table lists that label for that code as `mismatch`. Ranges (`W.6.2.a–f`) are the normalizer's job (NL-16), not the index's. A code with an ELD tier suffix resolves to its base code.
Must not: invent text for a code, read the network or the database, carry a label from the sheet as standard text, or import `@ls/db`.
