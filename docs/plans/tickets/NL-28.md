### Story
US-8 — As an outline author (P-2), I need a run to survive a worker restart and failed lessons to be retried on their own, so that a killed worker costs at most the calls in flight and no lesson is stored or paid for twice. This ticket is the queue underneath that promise.

### What to build
**Module:** `packages/db/src/repos/job-queue.ts` — `PgJobQueue implements JobQueue` (DO-4 §3.4) from `PgRepo_ctor{db, ids, clock}`; table `lesson_job` (NL-08 `0004_runs.sql`; this ticket writes no DDL). It is the riskiest SQL in the product (HP-7), so every method is one statement or one short transaction and has an integration test. Runs are created in tests by a raw-SQL fixture helper (`packages/db/src/testing/seed-run.ts`, this ticket's), because `PgRunRepo` is NL-27's, same wave.
- `create_run_jobs(jobs, tx)` bulk-inserts `NewJob`s as `queued` (`queued_at = clock.now()`), `ON CONFLICT (idempotency_key) DO NOTHING`; returns the number inserted. `create_candidate_job(job, tx)` inserts one (with `NewJob.reviewer_note` into `lesson_job.reviewer_note`; DO-4 §3.4, DO-3 §6, §13 R-15) and returns its `JobRow`; `claim` copies `reviewer_note` onto `ClaimedJob`; the partial unique index (one queued or running candidate job per lesson, NL-08) turns a second into `DomainRefusal(INVALID_TRANSITION, details.reason "candidate_in_flight")`.
- `claim(worker_id, max_active_runs, lease_ms)`: in one statement with `FOR UPDATE SKIP LOCKED`, picks from the active runs (state `planning` or `running`, at most `max_active_runs` of them, oldest first) the run with the fewest running jobs, and inside it the oldest queued job (`queued_at`, then `job_id`). `lesson` jobs are claimable only when the run's `plan_stored_at` is set (R-8); `unit_plan` and `candidate` jobs are not gated. Sets `status running`, `attempt = attempt + 1`, `worker_id`, `lease_until = now + lease_ms`, `started_at` if null, `tile_state` to `planning` (unit_plan) or `drafting`; returns `ClaimedJob` (with `unit_id`, `prompt_version_id`, `schema_version`, `outline_version_id`, `started_by`, `idempotency_key` read from the run row, G-23) or null. Jobs of `paused`, `capped` or `cancelled` runs are never claimed.
- `renew_lease(job_id, lease_ms)`: extends only a job that is still `running` with a lease not yet lapsed; returns false otherwise (taken over or requeued).
- `set_tile_state(job_id, tile_state)`; `finish(outcome)`: only on a `running` job (a second finish is a no-op), sets `status`, `tile_state`, `failure_reasons_json`, `brakes_fired`, `repairs`, `truncation_retries`, `retries`, `cost_usd`, `finished_at`, and sets `calls_lost` to the count of this job's `model_call` rows with `status 'lost'` (read-only access to that table; nothing else writes `calls_lost`).
- `requeue_expired(now)`: `running` jobs with `lease_until < now` → `queued` (attempt kept, `worker_id` cleared); returns `RequeueReport{requeued, job_ids}`. It touches only `lesson_job`; marking lost calls and releasing reservations belong to `ClaimLoop.start` (NL-30).
- `requeue_failed(run_id, tx)`: only `generation_failed` jobs of the run → `queued`, failure fields cleared; ready jobs are untouched; returns the count. `cancel_run(run_id, reason, tx)`: queued jobs → `cancelled`, tile `failed`, `failure_reasons [{check: reason}]` (`cancelled`|`capped`); running jobs are left to finish (they stop at their next node through `is_cancelled`); returns the count. `jobs_for_run(run_id)` → `JobRow[]`. `is_cancelled(job_id)` → true when the job is `cancelled` or its run's state is `cancelled` (not for `capped`: in-flight calls finish).
Must not: write `model_call`, `spend_reservation`, `run` or `lesson` rows; call a model; add a migration.
