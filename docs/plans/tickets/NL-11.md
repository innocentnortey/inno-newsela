### Story
Platform work, no US of its own: every route (`with_route`, NL-13), service and screen speaks the OpenAPI shapes. Zod mirrors named exactly like the components let a route parse a request once and a test prove the code and the contract cannot drift apart.

### What to build
`packages/schema/src/api/*.ts` (owned by this ticket) and `packages/schema/tests/contract/**`. One exported Zod schema per component of `docs/contracts/interface.openapi.yaml` (102 of them, named exactly as the component, e.g. `Session`, `StartRunRequest`, `TransitionResult`, `Error`, `ErrorCode`), grouped by card in `common.ts` (`Sha256`, `StateVector`, `Timestamp`, `NullableText`, `Error`, `ErrorCode`, `ProseMirrorDoc`), `session.ts`, `outlines.ts`, `runs.ts`, `board.ts`, `lessons.ts`, `review.ts`, `transition.ts`, `metrics.ts`, `exports.ts`, `prompts.ts`, `collab.ts` (the `server_messages` of `x-collaboration-channel`: `StoredMessage`, `ModeMessage`, `RefusedMessage`). No barrel: callers import by subpath (`@ls/schema/api/runs`).
- `ApiErrorCode` is the `ErrorCode` enum (36 codes, equal to `x-error-catalog`) with a `const` tuple `API_ERROR_CODES`.
- Request mirrors are `.strict()` (an unknown key is `INVALID_REQUEST`); `ProseMirrorDoc` alone allows extra keys (OpenAPI `additionalProperties: true`).
- `TransitionRequestInput` (`api/transition.ts`, DO-4 §5, G-11): the lenient route mirror of `TransitionRequest` where `Approve.rating`, `RequestChanges.note` and `Reopen.reason` are optional and nullable, every other field strict, so a missing one reaches `decide_transition` and returns the card's `RATING_REQUIRED` / `NOTE_REQUIRED` / `REASON_REQUIRED` instead of `INVALID_REQUEST`.
- Contract tests read the YAML (`yaml` dev dependency) and compare; the generated types file `docs/contracts/generated/api-types.ts` is the type-level oracle.
Must not: restate a card, define a shape that is not an OpenAPI component (except `TransitionRequestInput` and the three channel messages), edit the YAML or generated types, or put model-output schemas here (NL-09).
