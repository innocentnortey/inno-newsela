### Story
US-13 — As a reviewer (P-1) I need the draft laid out in Newsela's sections, minutes and blocks, with each part's address, so that I review something I could hand straight to Newsela's system, not a wall of text. US-14 — the evidence stays beside the text. This ticket is the code that turns the model's role-tagged blocks into the stored lesson, so the model never writes a node, a time or a safety tip placement (DIR-3).

### What to build
`packages/core/src/compile/` (A5; pure). Depends on `@ls/schema` (incl. `content_hash`) and `@ls/editor-schema`.
**`templates.ts`: `SECTION_TEMPLATES`** (R-11): Reading, Writing, Academic Discussion, Research, Presentation = Launch 5 · Literacy Lab 10 · Learning in Action 30 · Look Back 5 · Homework; Spark = Launch 15 · Learning in Action 30 · Look Back 5 · Homework; Flex Day and assessments = Launch 5 · Learning in Action 40 · Look Back 5. Each `SectionSlot{name, minutes, required_roles}`; `required_roles` follow the "Typed blocks" tables in WP-1, WP-2 and WP-3 §B and `docs/source/04-lesson-structure-analysis.md` §3 (e.g. Literacy Lab and Learning in Action carry the Integrated ELD callouts; every lesson at least one `cfu_item`).
**`compile-draft.ts`: `compile_draft(draft: LessonDraft, ctx: CompileContext): CompiledLesson`.** Places each `DraftBlock` in its `section` (and `part`) and maps role to node: `routine_heading` → `routine_heading` (icon from a fixed name table: Quick Write → `writing`, Pulse Check / Check for Understanding → `cfu`, Think-Pair-Share / Turn and Talk → `academic_discussion`, Language Study → `notes_section`, else `notes_section`); `teacher_talk` → paragraph with the `teacher_talk` mark (a leading `Say:` / `Ask:` / `Say these Directions:` bold); `sample_response` → `sample_response` mark; consecutive `callout_purpose`, `callout_say`, `callout_watch` of one part → one `collapsible` "Integrated ELD Instructions" holding the three `callout`s in that order; `support_table` (lines `situation | try this`) → `collapsible` "Additional Student Support" with a header row "Situation | Try this"; `cfu_item` → `routine_heading` (icon `cfu`, "Pulse Check (<standard_code>)"), the stem, a lettered `ordered_list` (type `A`), then one rationale per option labelled Correct or Incorrect by `key_index`; `quick_write` → `routine_heading` (writing) + paragraph; `text_evidence_needed` → `quote_placeholder` (`slot_id`, reason); `excerpt_slot` → `excerpt_slot` (rights `unset`); `teacher_tip` → `teacher_tip`; `homework` → paragraphs in Homework; `paragraph`, `list` → `paragraph`, `bullet_list`. **Safety tips (HP-9):** every `safety_note` segment of `ctx.row` gets exactly one `teacher_tip` node carrying its `safety_note_id`, in Homework, teacher-only: the model's `teacher_tip` wording is used when the draft has one for it, otherwise code inserts a tip holding the note's original text (the note is never lost and never appears in a student-facing block); `safety_tips` lists those nodes' addresses. Section `minutes` = the sum of its blocks' `minutes` (no silent correction: the check flags a 3-minute Look Back); `front_matter.minutes_total` = their sum. Every section's content is normalised through `EDITOR_SCHEMA.nodeFromJSON(…).toJSON()` (all attributes explicit) so the hash survives the Y.Doc round trip (NL-19). `teacher_word_count` = words in all text nodes outside `teacher_tip`; `placeholders` = count of `quote_placeholder` + `excerpt_slot` nodes. `content_hash` = `content_hash(lesson)` from `@ls/schema`.
**`CompileError{lesson_id, reason, address}`** (`section_not_in_template`, `role_not_allowed`, `unknown_node`) for a schema-valid draft that cannot be placed: a block whose section the template lacks; `homework` outside Homework or `callout_*` / `support_table` in Launch, Look Back or Homework [A]; a node `assert_known_nodes` rejects. No partial lesson is returned.
**`addresses.ts`: `assign_addresses(lesson, unit_id)`** sets each `Section.address` to `<lesson_id>.<SectionName without spaces>` (R-21; `G6.U4.L4.LearningInAction`) and exports `part_address(section_address, part_label)` for the level-2 "Part A" headings (`…LearningInAction.PartA`); idempotent.
Must not: call a model or the network, import `@ls/ydoc` or a driver, invent text (a placeholder is a node, never a quote), or rewrite a model-supplied minute.
