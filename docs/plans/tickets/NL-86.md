### Story
US-36 — As the builder I trust the build's numbers before the demo: a full 47-day run of the issued unit, driven through the product's own HTTP API, with a report whose every number is read from stored rows (R-51), so the video never states a number the database cannot back.

### What to build
Build the machinery for the one real full run (NL-112 runs it; this ticket proves it on the stub and the Prism mock).

- `evals/src/driver/**` — an HTTP driver over the OpenAPI (`docs/contracts/interface.openapi.yaml`, generated types from NL-11): `signIn` (credentials from `DRIVER_EMAIL` / `DRIVER_PASSWORD`, never stored or logged), `uploadOutline`, `getValidationReport`, `recordIntakeChoice` (confirm each error with `confirm_fix`), `startRun` (with an `Idempotency-Key`), poll `getRunProgress` every 2 s until terminal, `getRunSummary`. It calls **only** the public API (no database writes, no service imports). In real provider mode it refuses to start unless `--cap-usd` is given and is at most `BUILD_SPEND_CEILING_USD`.
- `evals/src/full-run-report.ts` — `build_full_run_report(run_id) -> FullRunReport` (DO-4 §11): *n*, `first_pass_schema_valid`, `repairs`, `failures_by_reason`, `placeholders`, `grounding_flags_by_kind`, `confirmations` (median per lesson), `cost_usd`, `report_path`, built **only from stored rows** (`RunRepo.summary_rows`, `ModelCallLog.totals_for_run`, `IssueRepo`, `AlignmentRepo`, `lesson_version` hashes). Writes `evals/reports/full-run-<run_id>.md` and stores the path on the `eval_run` row.
- `evals/src/suites/s9.ts` (`npm run eval:full-run -- --unit G6-U4`) and `s13.ts` (draft quality: every approved lesson rated, rating split with *n* from the frozen `lesson_metrics` rows; ≥ 2 of 3 demo lessons `usable_with_edits` or better): fill the NL-49 shells; thresholds from DO-5 (S9: first-pass schema-valid ≥ 90%, 100% terminal with reasons, round-trip hash 47/47, spend ≤ run cap, ≤ $1 per lesson, p95 ≤ 5 min, wall ≤ 2 h, summary totals equal call sums).

**Must not:** spend real money in any test (stub provider; the Prism mock for the driver's contract test); write to the database outside the public API; embed a credential; invent a number not present in a stored row.
