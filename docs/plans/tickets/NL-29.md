### Story
US-7 — As an outline author (P-2), I need each lesson to be drafted, checked, repaired at most once and stored as a numbered draft with its full provenance, or to fail with a stated reason, so that the board shows ready lessons I can open and honest reasons for the rest.

### What to build
**Modules (DO-3 §2.4, DO-4 §6):** `apps/worker/src/generation/lesson-job-runner.ts` (`LessonJobRunner`) and `apps/worker/src/generation/nodes/{draft-node,compile-check-node,repair-node,store-node,fail-node}.ts`. TypeScript interfaces and constructors exactly as DO-4 §6 (`DraftNode`, `CompileCheckNode`, `RepairNode`, `StoreNode`, `FailNode`, `LessonJobRunner`, `LessonJobState`). All collaborators are DO-4 ports or earlier-wave real code; same-wave ones (`PaidCaller`/`ModelCallRecorder` NL-33, `LessonDocStore` NL-36, `CheckContextLoader` NL-38, `RunFinalizer` NL-30, `LessonVersionRepo`/`LessonStateRepo` NL-42, `SafetyFlagRepo` NL-43) are typed from DO-4 and tested with doubles. No node reserves or settles by itself: every call goes through `PaidCaller` (G-17, G-18), which reserves that call's own worst case right before sending it.
- **DraftNode.** `runs.pinned_choices(run_id)` → `outlines.row_context(outline_version_id, lesson_id, pinned)`; standards via `standards.texts(codes)`; plan entries (own and neighbours) from `runs.unit_plan(parent_run_id ?? run_id)` (a candidate run reuses its parent's plan, R-8); `renderer.render_lesson_draft(DraftPromptInput{prompt = prompts.get(job.prompt_version_id), …, template = SECTION_TEMPLATES[type], example_set_id null, reviewer_note null})`. First `recorder.checkpoint(job_id, "lesson_draft", 1)`: a stored completed output is used and **no call is sent**. Otherwise `PaidCaller.call` with alias `GENERATION`, `output_mode "prompt_embedded"`, `max_output_tokens DRAFT_OUTPUT_TOKEN_CAP` (32000), `timeout_ms MODEL_CALL_TIMEOUT_MS`, `effort MODEL_EFFORT`, `temperature null`, `ctx.attempt 1`, `purpose "lesson_draft"`, `user_id = job.started_by`. `stop_reason "max_tokens"` → one truncation retry (`purpose "truncation_retry"`, ordinal 1, `max_output_tokens TRUNCATION_RETRY_TOKEN_CAP` 48000, its own reservation; `truncation_retries 1`, not counted as the repair); truncated twice → brake `truncation_retry`, route to fail. `SpendRefused` → brake `spend_run_cap|spend_day_cap|spend_project_cap` and fail with no repair; a `ProviderError` that survived the recorder's retries → fail with its kind; `rate_limit_retries` is read from `RecordedCall.retries`.
- **CompileCheckNode.** Parse `raw_output` as JSON and validate with the Zod `LessonDraft` (issue paths only → `schema_issues`; no raw text in errors) → `compile_draft(draft, CompileContext{row, template, unit_id = job.unit_id, schema_version})` (`CompileError` → `compile_error`) → `loader.load(lesson_id, compiled.lesson, compiled.content_hash)` → `run_checks(ctx, CHECK_RULES, CHECK_POLICY)` → `check_result`; `check_passed` = no blocking finding.
- **Router.** `route_after_checks` (NL-22) decides `store` / `repair` / `fail` (`max_repair_rounds 1`; the repair gets the draft and only what failed).
- **RepairNode.** Alias `REPAIR` (`MODEL_REPAIR_ID`), `checkpoint(job, "repair", 1)` first, `render_repair(RepairPromptInput{draft_raw, failing findings, schema_issues, template})`, `PaidCaller.call` (`prompt_embedded`, `DRAFT_OUTPUT_TOKEN_CAP`), `repair_rounds + 1`; then CompileCheckNode runs again and the router decides once more.
- **StoreNode** (one `tx.with_tx`, G-25). Lesson job: `versions.write_generated_version(NewGeneratedVersion{kind "generated", idempotency_key = job.idempotency_key, provenance{outline_row_hash, prompt_version_id, model = served model of the draft call, parameters {effort, max_output_tokens, output_mode}, schema_version, example_set_id null, run_id, model_call_ids = every call of the job in order, cost_usd = sum of the job's settled call costs, ai_assisted_spans 0, derived_from_version_id null}})`. `created false` → the earlier run already stored v1: return its version and write nothing else. `created true` → `docs.seed_initial(lesson_id, lesson, system actor, tx)` (seq 1 plus the coalesced `check_job` in the same transaction) + `flags.create_for_lesson(lesson_id, source_rows, tx)` + `states.set_state(lesson_id, "draft", null, tx)`. **Safety flags are written here** (DO-4 §6 `StoreNode`; this settles the slice plan's open item 3): `source_rows` are the outline row numbers whose `safety_note` segments the run's pinned choices confirmed (`confirm_safety_note`); none → no flag rows. Candidate job: `write_generated_version(kind "candidate", adopted false)` only; if the lesson is `generation_failed` and has no generated version the candidate becomes v1 the same way as a lesson job (CON-16).
- **FailNode.** `outcome.failure_reasons = failure_reasons_for(FailureInput)` (NL-22). Lesson job → `set_state(generation_failed)`. Candidate job → if `versions.has_generated_version(lesson_id)` the lesson state is **not** touched (an `in_review` lesson stays `in_review`); with no version it becomes `generation_failed`. A job refused before its first call (capped, cancelled) writes no lesson row (CON-6).
- **LessonJobRunner.run(job).** `queue.set_tile_state` at each step (`drafting`, `checking`, `repairing`); draft → compile_check → route → (repair → compile_check → route) → store | fail → `queue.finish(outcome)` → `finalizer.after_job(run_id, outcome)`. `queue.is_cancelled(job_id)` is read between nodes (cancelled → no further call, status `cancelled`); `settings.job_wall_clock_ms` (600000) is checked before each node (brake `job_wall_clock`, no further call); `LeaseLost` stops the job and leaves it to `requeue_expired`; a `SpendRefused` or surviving `ProviderError` goes straight to fail.
Must not: write `model_call` or `spend_reservation` rows itself; import the Anthropic SDK; write `issue` or `alignment_link` (the check worker does, NL-81); edit `run-finalizer.ts`/`claim-loop.ts` (NL-30), `unit-plan-job.ts` (NL-31), `wiring/generation.ts` (NL-79).
