### Story
US-11 — As a reviewer (P-1) I need to see which lesson to review next, sorted by what blocks, so my time goes where it matters; the same board shows dependency flags (US-12) and the north-star tile (US-30), the reviewer minutes per approved lesson, with its *n* and no baseline claimed.

### What to build
- `app/(app)/units/[unitKey]/board/page.tsx` + `src/features/board/**`: breadcrumb *Units › Grade 6 › Unit 4*; `h1` "Unit 4 · *The Lightning Thief*" with a count chip; the roll-up sheet (five state cells as filter buttons, plus a track bar whose text equivalent reads "Draft 34, In review 6, Submitted 2, Approved 3, Failed 2"); the north-star `metric-tile` ("Reviewer minutes per approved lesson", median, *n*, two guard tiles, the caption "No baseline yet (AQ-14). Measured with us as reviewers."); the segmented filter as a radio group "Filter lessons by state" (*Changes requested* and *Reopened* only when any exist); the board table (Lesson link, Type, State pill, Blocking, Advisory, Reviewer, Note) with `aria-sort` on Blocking; the links row (Run summary, Unit plan, and the nav-flagged Coverage, Unit quality, Export entries hidden when their cut fires, via NL-24's `nav.ts` flags).
- Data: `getUnitBoard` (CON-9: rows, roll-up, filter) polled with `use-poll.ts` (2 s, stale banner after > 10 s, focus never moved, polite announce only "Lesson 7 is ready" or a run-state change); `getUnitMetrics` (CON-10) fetched separately so a tile failure leaves the table up. Sort is the server's order (UXQ-5: blocking, then advisory, then lesson order; failed first, approved last); the screen never re-sorts.
- Row action by role (UXQ-6): reviewer click → SCR-9; approver click on a `submitted` row → SCR-14, any other row → SCR-9 read-only; a failed row's "Retry" links to SCR-6 (author only). Notes render the dependency flags ("Waits on Lesson 5's excerpt", "…approval", "A lesson this depends on was reopened"), send-back tag pill, and the judge note when present, all as text (R-58).
- Must not: show minutes per named person or rank reviewers (GR-15); compute any figure client-side; edit a lesson; add bulk actions.
