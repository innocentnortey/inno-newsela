### Story
US-29 — As an approver (P-3) I need every version of a lesson with its hash and provenance, and the audit log, so the lesson can be defended to a state reviewer.

### What to build
- `app/(app)/units/[unitKey]/lessons/[lessonKey]/history/page.tsx` + `src/features/history/**`: two-pane. Page sheet: `h1` "History · Lesson 4"; an ordered list of versions (generated v1, candidate v2 not adopted, submit snapshot v3, approval, reopen v4) each with kind, who, when, from-state → to-state, short hash (full on hover and in a **Copy hash** button with a polite "Copied") and reason; `?version=` selects one. Rail: **Provenance** for the selected version as a stat list (outline-row hash, prompt version, model, schema version, example set, run, cost) and the **Audit log** rows ("Safety flag cleared by J. Rivera: <note> · 10:42").
- Data: `getLessonHistory` (CON-19). A provenance field the server lacks renders "Missing" in `danger` (a defect signal, never a blank); read-only for every role; loading skeleton list; can't-load shared message. No empty state (v1 always exists).
- Must not: edit anything, show reviewer time or minutes by person (GR-15), or hide a missing field.
