### What to build
**1. Adopt `apps/web` (DO-3 §1, §4 A0).** Add it to the root workspaces as `@ls/web`; `apps/web/package.json` becomes A0's: keep every FW-1 dependency at its pinned version (superset, no drift), add `@ls/*` workspace dependencies and the scripts `dev`, `build`, `typecheck`, `lint` that defer to the root config; `apps/web/tsconfig.json` extends `tsconfig.base.json`. Delete `apps/web/package-lock.json`; re-resolve the root lockfile (reaches everything: full suite once). FW files (`src/styles`, `src/components`, `app/(dev)`) are not edited.
**2. Composition root (DO-3 §8, DO-4 §5 `build_web_services`, §12).** `apps/web/src/server/container.ts` exports `build_web_services(settings: WebSettings): WebServices`: `Logger` → `WebDeps` (from `apps/web/src/server/deps.ts`) → `wire_sessions`, `wire_outlines`, `wire_runs`, `wire_review`, `wire_metrics`, `wire_assist`, `wire_prompts`, `wire_exports`, `wire_coverage` → merged record; cached on `globalThis` once per server process; `import "server-only"`. A `getServices()` helper reads `load_web_settings(process.env)` once.
**3. Wiring stubs.** One file per area under `apps/web/src/server/wiring/`: `sessions.ts` (filled by NL-25), `outlines.ts` (NL-26), `runs.ts` (NL-78), `review.ts` (NL-53), `metrics.ts` (NL-54), `assist.ts` (NL-116), `prompts.ts` (NL-34), `exports.ts` (NL-102), `coverage.ts` (NL-91). Each exports `wire_<area>(deps: WebDeps)` returning its DO-4 §12 record with every service **unset** (`undefined`), and a header comment naming its filler. Names follow DO-3/DO-4; the slice plan's wiring-owner table calls `sessions.ts` "auth", `outlines.ts` "intake" and `exports.ts` "export" (same files).
**4. `deps.ts` (local structural types).** `WebDeps` = `{settings, logger, db, ids, clock, model_client}` with `db`, `ids`, `clock`, `model_client` typed from `apps/web/src/server/deps-types.ts`: four minimal structural interfaces with the member names of `PgDatabase` (`with_tx`, `ping`, `close`), `IdGenerator` (`new_id`), `Clock` (`now`, `sleep`) and `ModelClient` (`complete`) from DO-4 §3.1, §3.6, §9. Reason: `PgDatabase` (NL-08, same wave), `Clock`/`IdGenerator`/`ModelClient` (NL-12, W2) merge after this ticket and NL-06 depends only on FW-1 and NL-01. **NL-12 replaces the four bodies with `export type { … } from` the real files** (a one-file edit recorded in the collision map). Until then the container builds `db`/`ids`/`clock` from throw-on-use placeholders and stub mode (`MODEL_PROVIDER_MODE=stub`) only; `real` mode throws `ConfigError`-style `NOT BUILT: NL-32`.
Must not: construct a repository, adapter or service (wiring fillers do), import another app, edit FW files or `docs/contracts/**`, or add a route.
