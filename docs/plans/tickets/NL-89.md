### Story
Platform ticket (cut #2, no user story of its own): a binary, advisory, provisional judge on a second provider (PD-12) reads one activity and one official standard and answers "does it teach this?". It adds a second provider key and sends lesson text off-box, so it is security work.

### What to build
Build the judge machinery; the trigger after store, the `judge_no` advisory issue and the claim loop are NL-110, and the calibration script is NL-111.

- `packages/llm/src/openrouter-judge.ts` — `OpenRouterJudgeAdapter implements JudgeClient` (DO-4 §2): the **only** module that calls OpenRouter. Constructor record `OpenRouterJudgeAdapter_ctor{api_key: SecretStr (OPENROUTER_API_KEY), model_id (MODEL_JUDGE_ID), timeout_ms}`. `verdict(JudgeRequest) -> JudgeVerdictResult{verdict "yes"|"no", rationale, served_model, usage, raw_text, provider_request_id}`: sends **only** `activity_text`, `standard_text`, the rubric and the question (no lesson id, user, email or other lesson text), parses a strict JSON verdict with Zod, raises `ProviderError` kinds on timeout / 429 / 5xx / unparsable output, never retries itself.
- `packages/llm/src/stub-judge.ts` — `StubJudgeClient implements JudgeClient` with scripted verdicts for tests and the stub mode (DO-4 names `stub.ts`; a separate file avoids editing NL-14's).
- `packages/db/src/repos/judge.ts` — `PgJudgeRepo.insert_verdict(NewJudgeVerdict) -> JudgeVerdictRow` into `judge_verdict` (`lesson_id`, `content_hash`, `address`, `code`, `question`, `verdict`, `model_call_id`, `served_model`); append-only.
- `apps/worker/src/judge/judge-job.ts` — `JudgeJob.run(lesson_id, content_hash) -> JudgeRunReport{pairs, verdicts_no, cost_usd}`: per (activity, standard) pair: `PromptRenderer.render_judge` → `SpendLedger.reserve` (`max_call_cost`; refusal skips the pair and counts it) → `ModelCallLog.insert_sent` **before** the call → `JudgeClient.verdict` → `ModelCallLog.complete` → `settle` (or `release` on failure) → `JudgeRepo.insert_verdict`. Every call is a `model_call` row (`purpose "judge"`, alias `JUDGE`). It writes **no** issue and never touches Approve (NL-110 adds the advisory issue).

**Must not:** send anything but the four inputs to OpenRouter; log or store the key; make a verdict block anything; skip the reservation; edit the generation path or `IssueRepo`.
