### Story
US-1 and US-2 — As an outline author (P-2), I need to upload the unit outline as CSV or XLSX, or paste a public Google Sheet link, and get a numbered, hashed version, so that every run can say exactly which outline it came from and re-uploading never touches a lesson.

### What to build
**1. Repositories (DO-3 §2.2 `packages/db/src/repos/outlines.ts`, DO-4 §3.5).** `PgOutlineRepo implements OutlineRepo` and `PgStandardRepo implements StandardRepo`, both from `PgRepo_ctor`. This ticket implements `list_units`, `insert_version`, `version`, `rows`, `choices` (read), `links` and `row_context`; the three choice-writing methods `upsert_choice`, `mark_confirmed`, `generate_gate_inputs` are left as stubs that throw `NotBuiltYet("NL-77")` (NL-77 fills them in the same file, slice plan W4 row). `insert_version(v, outline, links, tx)` takes `pg_advisory_xact_lock('outline:'||unit_id)`, numbers the version `max(number)+1`, stores `outline_version`, one `outline_row` per `NormalizedRow` (with `row_hash` = sha256 of its canonical JSON) and the `lesson_link` rows in the caller's transaction; two near-simultaneous uploads therefore get two distinct numbers. `PgStandardRepo.index()` builds NL-15's `StandardsIndex` from the `standard` table; `texts(codes)` returns `StandardRow`s.
**2. Fetcher (`apps/web/src/server/adapters/google-sheets.ts`, DO-4 §3.2).** `GoogleSheetsExportFetcher implements SheetFetcher` from `GoogleSheetsExportFetcher_ctor{timeout_ms = SHEETS_FETCH_TIMEOUT_MS, max_bytes = OUTLINE_MAX_BYTES}`. `fetch_export(sheet_url)` accepts only `https://docs.google.com/spreadsheets/d/<id>/…` (any other scheme, host, port or userinfo → `INVALID_REQUEST` with `details.fields = ["sheet_url"]`, so the server never fetches an address a user chose), builds the export URL itself (`https://docs.google.com/spreadsheets/d/<id>/export?format=xlsx`), makes **one** GET with redirects handled by hand: a redirect to any host other than `docs.google.com`/`doc-*.googleusercontent.com`, to an `accounts.google.com` sign-in page, or a 401/403 is `SHEET_NOT_PUBLIC`; a timeout or network error is `SHEET_UNREACHABLE`; the body is streamed and aborted past `max_bytes` (`UNSUPPORTED_FILE`, `details.reason "too_large"`). Returns `FetchedSheet{url, kind, data, sha256, fetched_at}`. No retry.
**3. Service (`apps/web/src/server/services/outline-service.ts`, DO-4 §5 `OutlineService`).** Create the file with the **full** DO-4 constructor `(outlines, standards, sheets, audit, tx, ids, clock, settings)` so NL-77 adds `report` and `record_choice` without changing it. `list_units(user)` → `UnitList` (each unit: `unit_id`, `unit_key` e.g. `g6-u4`, `title` "Grade 6 · Unit 4", `versions` newest first, `latest_run {run_id,state}|null` read through `RunRef` from the `run` table by a single read). `upload(user, file, unit_id)`: size over `OUTLINE_MAX_BYTES` or not CSV/XLSX (by content, not only by name) → `UNSUPPORTED_FILE` with `details.reason` `too_large`|`type`; `parse_workbook` → `normalize_outline(grid, await standards.index(), OUTLINE_MAX_ROWS)` (`HEADER_NOT_FOUND` with `details.columns_looked_for`, `TOO_MANY_ROWS`) → `compute_lesson_links` → one `tx.with_tx`: file under the unit the sheet writes (`unit_as_written` + grade, e.g. `G6.U4`; a conflicting filename unit is left for CON-4's `confirm_unit`, never moves the version), `insert_version` (`source_kind upload_csv|upload_xlsx|sheet_link`), `same_as_version` = the lowest earlier version number with the same sha256 (or null), `changed_lessons` = number of lesson rows whose `row_hash` differs from, or is absent in, version N-1 (0 for a first version or an identical re-upload), and one `audit_event` (`outline.upload` or `outline.import`, `target_kind "outline_version"`, `version_hash` = sha256, `details` ids and counts only). `import_link(user, req)` → `fetch_export` once, then the same path with `source_kind sheet_link`; the sheet is never fetched again for that version (the stored rows and sha256 are the record).
**4. Routes (thin, `with_route`):** `apps/web/app/api/units/route.ts` (`GET`, all roles), `apps/web/app/api/outline-versions/route.ts` (`POST` multipart, author only), `apps/web/app/api/outline-versions/import/route.ts` (`POST`, author only). Request parts parse with the Zod mirrors from NL-11 (`ImportLinkRequest`).
**5. Wiring (`apps/web/src/server/wiring/intake.ts`, A0's stub; DO-4 `wire_outlines`)** builds the repos, `GoogleSheetsExportFetcher`, `PgAuditLog` and `OutlineService`; returns `OutlineWiring{outlines}`.
Must not: store or echo cell text as HTML; follow a redirect off the allow-listed hosts; keep the uploaded bytes outside the version's rows and hash; call a model; edit `container.ts`, `package.json` or DDL; implement report or choice behaviour (NL-77).
