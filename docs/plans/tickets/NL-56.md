### Story
US-1 / US-2 — As an outline author (P-2), I need to upload the unit outline as CSV or XLSX, or paste a public Google Sheet link, and get a fixed, numbered version, so that every later step points at one known input.

### What to build
- `app/(app)/units/[unitKey]/outlines/new/page.tsx` + `src/features/upload-outline/**`: page sheet `dialog-md` wide, `h1` "Upload outline", segmented control *File · Sheet link*. File: a drop zone that is a labelled button with **Choose file** (dragging is never the only way), "CSV or XLSX, up to 200 rows". Link: a **Google Sheet link** URL field and the helper "The sheet must be shared so anyone with the link can view it." Primary **Upload** / **Import**.
- Calls `uploadOutline` (multipart) or `importOutlineLink` (CON-2). On success shows the summary line from the response ("Grade 6 · Unit 4 · version 1 · 41 lessons · 6 flex days · 7 arc headers · 1 total row") then navigates to SCR-4 for that version; a repeated hash shows "Version 2 is the same as version 1; 0 lessons changed." with a link to the report.
- Trim (a) (PRD §6.5): the link import is the first thing cut; the segmented control then disappears (one flag in `src/features/upload-outline/`).
- Must not: parse the file in the browser beyond the extension check, or store anything on an error.
