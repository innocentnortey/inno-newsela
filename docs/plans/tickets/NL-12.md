### What to build
**1. Ports, one file each (DO-3 §3, DO-4 §3; Metz S5).** `packages/core/src/ports/<port>.ts` for the 31 ports of DO-3 §3: `tx`, `model-client` (also `StructuredCallRequest`, `PromptBlock`, `ModelResponse`), `judge-client`, `sheet-fetcher`, `collab-commands` (also the command and edit records), `lesson-docs` (`LessonDocReader`, `LessonDocStore`), `job-queue`, `check-queue`, `spend`, `model-call-log`, `sessions`, `outlines`, `standards`, `runs`, `lesson-state`, `lesson-versions`, `lesson-graph`, `board-reads`, `issues`, `safety-flags`, `alignment`, `suggestions`, `audit`, `metrics`, `prompts`, `exports`, `judge`, `evidence`, `clock`, `ids`. Each file holds the port interface and the records DO-4 §3 attaches to it, names and fields as written there (money `Usd` is a `Decimal`). `ports/outlines.ts` **re-exports** `OutlineVersionRow`, `IntakeChoiceRow`, `LessonLinkRecord` from `@ls/schema/outline` (NL-09 owns them). No barrel; callers import `@ls/core/ports/spend`. After this ticket each file belongs to the area that implements its port (DO-3 §4); a change is a `CHG` through that owner.
**2. Time and ids (DO-4 §3.6).** `SystemClock`, `FakeClock` (`advance(ms)`, `sleep(ms)` resolves when advanced), `PrefixedIdGenerator` (`new_id(prefix)` → `<prefix>_<26-char ULID>`, monotonic within one millisecond).
**3. Errors (DO-4 §10.2).** `packages/core/src/errors.ts`: `DomainRefusal`, `ProviderError`, `ModelOutputInvalid`, `SpendRefused`, `LeaseLost`, `CollabUnavailable`, `ConfigError` (re-exported from `@ls/config`), `CompileError`, `InvariantViolation`, and `SchemaUnknownError` re-exported from `@ls/editor-schema`. `PoolExhausted` stays in `@ls/db/pool-exhausted` (NL-08; core may not import db).
**4. Shared fakes** (`packages/core/src/testing/`): `FakeTxRunner`, `FakeAuditLog`, `FakeJobQueue`, `FakeSpendLedger`, `FakeModelCallLog`, `FakeCollabCommands`, `FakeLessonStateRepo`; each records its calls in order and replays scripted results or errors; an unscripted call throws `UnscriptedCall`. Other fakes belong to the ticket that owns the port's first consumer.
**5. `PgAuditLog`** (`packages/db/src/repos/audit.ts`, DO-4 §3.5): `append(e, tx)` inserts one `audit_event` (`ae_…` id, `at` from the clock) in the caller's transaction; `history(lesson_id)` reads `audit_log_v` oldest first. A guard rejects `details` holding an email address or any string over 120 characters with `InvariantViolation` (ids and codes only: OBS-7).
**6. Re-point `deps-types.ts`** in `apps/web/src/server/`, `apps/worker/src/` and `apps/collab/src/` (created by NL-06/NL-07) to `export type { … } from` `PgDatabase`, `IdGenerator`, `Clock`, `ModelClient`; this is the one edit this ticket makes in another ticket's area (recorded in the collision map).
Must not: write a Pg repository other than `PgAuditLog`, add a method to a port that DO-4 does not list, or import a driver, `@ls/db`, `@ls/llm` or `@ls/ydoc` into `packages/core`.
