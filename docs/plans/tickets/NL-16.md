### Story
US-3 — As an outline author (P-2) I need every row marked OK, warning or error, with the original cell and a proposed fix, and Generate kept off until I have confirmed every error, so that a bad code never reaches 47 paid model calls. US-4 — I need each cell split into content, writer task, editor note, unit rule and safety note, with a default I can change, so that a reviewer's note or a warning to the teacher is never pasted into a lesson as if it were lesson text. This ticket is the plain-code (no model) engine behind both (HP-6, PD-27).

### What to build
All pure code in `packages/core/src/intake/` (A4a; SheetJS is the one allow-listed parser library). Tests and fixtures: `packages/core/src/intake/*.test.ts`, `packages/core/tests/fixtures/outline/**` (this ticket owns it; built by a tracked deterministic script `packages/core/scripts/build-outline-fixtures.ts` from `docs/data/samples/g6-u4-lesson-outline.json` and the `synthetic-*` files).
**`parse-grid.ts`: `parse_workbook(data: bytes, kind: SheetKind): CellGrid`.** CSV (RFC-4180 quoting, multi-line cells, NBSP preserved) and XLSX (first sheet, values only: `cellFormula false`, `bookVBA false`, no external links). Anything else, an empty file, or a sheet over 20,000 cells or 60 columns [A] raises `IntakeError{code: "UNSUPPORTED_FILE", details.reason}` (`not_csv_or_xlsx`, `empty`, `too_large`). `IntakeError` lives in `intake/errors.ts`: the pure functions cannot import `DomainRefusal` (NL-12 is a wave later), and `OutlineService` (NL-26) re-raises it as `DomainRefusal` with the same code and details.
**`normalize.ts`: `normalize_outline(grid, standards, max_rows): NormalizedOutline`.** Finds the header row by column names (case-insensitive, any position, any column order: SYN-2); `HEADER_NOT_FOUND` when none matches, `TOO_MANY_ROWS` over `max_rows` (200). Row kinds `lesson`, `flex_day`, `arc_header`, `total`; ids from `Lesson #` (`G6.U4.L4`; flex days `G6.U4.FLEX-1a`…, FE-2); the unit from the sheet header, the filename unit kept separately (`unit_from_filenames`). Ranges expand (`W.6.2.a–f`, en dash). Codes resolve through `StandardsIndex` (NL-15); a bare number takes the prefix of the nearest preceding code in the cell (`6.2` after `RL.6.1` → proposed fix `RL.6.2`). Cell text is split into `SegmentRecord`s of kind `content`, `writer_task`, `editor_note`, `unit_rule`, `safety_note` with the defaults CON-4 fixes: notes default to `apply`, writer tasks to excerpt slots (`writer_task` finding). **Finding kinds are exactly CON-3's list:** errors `malformed_code`, `nonexistent_code`, `unit_conflict`, `duplicate_id`, `missing_required_column`; warnings/info `parent_code`, `bad_filename`, `eld_mismatch`, `eld_not_checked`, `vocabulary_over_cap`, `vocabulary_word_missing`, `homework_links_later_row`, `non_breaking_space`, `duplicate_text`, `instruction_shaped`, `safety_note_proposed`, `writer_task`; each warning carries a `default_choice`, each finding the cell's `original_text` untouched. `instruction_shaped` is set by `INSTRUCTION_PATTERNS` (imperatives aimed at a model: "ignore the rules above", "disregard", "you must", "quote chapter", "system prompt"…): the segment stays `content`, flagged (SYN-1, R-6). `safety_note_proposed` comes from `SAFETY_PATTERNS` (`safety-patterns.ts`: sentences in homework or description cells addressed to the teacher that warn about triggering content, e.g. "warn students about potentially triggering…"), default `confirm_safety_note`, never auto-cleared (PD-26). Unit rules ("Across Investigation 1: Cap at 6 words per lesson") become `UnitRuleRecord{text, scope_lesson_ids}` scoped by the arc headers. Output is deterministic: rows by `row_number`, findings by `finding_id` (stable hash of row, kind, ordinal).
**`lesson-links.ts`: `compute_lesson_links(rows): LessonLinkRecord[]`** (HP-1): a homework item naming an excerpt or title another lesson's writer task or text set also names → `homework_text` (WP-1: row 8's "The Hare and the Lion" → row 9); a homework item that names a text with no title, matched to a later lesson's "select an excerpt" task → `excerpt_slot`; a page range that ends where the next lesson's focus pages begin → `page_continuation`. Stable `link_id`; deterministic.
Must not: call a model, the network or the database; sanitize or rewrite cell text (stored verbatim; rendering is text-only, R-58); drop a row silently; or add a finding kind (a `CHG-N`).
