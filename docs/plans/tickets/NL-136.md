**1. `docs/delivery/<YYYY-MM-DD>-demo-script.md`.** Table: `time · on screen · narration · source row (inventory id) · evidence path`. Add a shot list line per row for the `demo-video` skill, and a "cannot be shown" list (cut items) so the video never implies them.
