### Story
Delivery (R-23, cut #2) — the advisory judge may only be shown once it agrees with a person. Innocent's labels are the expected answer (DO-5 *Expected-answer authority*: a model is never its own authority). Why now: the labels need real activities from the full run, and the judge calibration (NL-132) cannot run without them.

### What to build
**What Innocent does (only he can label; `gate::human`).** About 45–60 minutes.
1. Claude prepares `evals/judge/labels.csv` (a tracked file, no lesson text beyond the one activity per row) with about 30 rows chosen from the NL-112 lessons: columns `pair_id, lesson_ref, activity_text, standard_code, standard_text, label, note`. `label` is empty. Claude draws the pairs so about 40% are clear yeses, about 40% clear noes and the rest borderline, and says so on the issue **without marking which row is which**. The split into 20 for calibration and 10 held back is fixed by Claude by a seeded draw and written in `evals/judge/split.json` (git-tracked, committed before labelling). Innocent does not need to see the split.
2. For each row he answers one question: **"Does this activity teach or check this standard?"** `1` = yes, `0` = no. A `note` is optional (one line on why, useful for the rubric). He fills the `label` column in the VS Code editor on `claude-vultr`, or tells Claude the labels in the chat and Claude enters them verbatim.
3. He says "labels done" on the issue. If he prefers not to build the judge, he says "no judge" instead: cut #2 then fires, Claude closes NL-110, NL-111, NL-132 and this ticket as unused, and the docs say "Alignment is checked by code and confirmed by a named reviewer; no model judge in this build" (PRD §6.4).

**What Claude records afterwards.** Counts only: rows labelled, yes/no split, the date; the 20/10 split file hash; one dev-log line; `.claude/state/resume.md` next action (NL-132). Claude never edits a label to match the judge, never shows the judge the 10 held-back labels while tuning (DO-5 *Development and held-out separation*), and never labels a pair itself.
