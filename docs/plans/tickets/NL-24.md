### What to build
**1. Generated client (DO-3 §2.3 `api-client.ts`, §10).** `npm run api:types` runs `openapi-typescript docs/contracts/interface.openapi.yaml -o apps/web/src/lib/api-types.ts` (must equal `docs/contracts/generated/api-types.ts`). `apps/web/src/lib/api-client.ts`: one typed client over `paths` (e.g. `openapi-fetch`), base URL from `NEXT_PUBLIC_API_BASE` (empty = same origin; Prism in mock mode), `credentials: "same-origin"`. Every non-2xx becomes `ApiError { status, code: ApiErrorCode, message, details, requestId }` read from the OpenAPI `Error` envelope; a non-envelope body or a network failure becomes the client-only code `NETWORK`. `UNAUTHENTICATED` on any `(app)` page redirects to `/sign-in?next=<path>`. No hand-built URLs anywhere. `src/lib/keys.ts` maps readable keys (`g6-u4` ↔ `G6.U4`, `L4` ↔ `G6.U4.L4`, IA §3).
**2. Prism mock harness.** Script `mock:api` = `npx @stoplight/prism-cli mock docs/contracts/interface.openapi.yaml -p 4010`; a Playwright `mock` project starts Prism and `next dev` with `NEXT_PUBLIC_API_BASE=http://127.0.0.1:4010`. `apps/web/src/test-utils/` gives every screen ticket: `signInAs(page, role)` (the `getSession` example per role), `mockOperation(page, operationId, { code, example })` (Prism `Prefer` header, non-production only), `respondWithError(page, operationId, code, details?)` (a `page.route` answer typed by `components['schemas']['Error']` where the OpenAPI has no example for that code), `renderWithSession(ui, role)` for Vitest.
**3. Mock collaboration server** (`apps/web/mocks/collab-mock.ts`, script `mock:collab`, port 4020): an in-memory Hocuspocus server, no Postgres, speaking `x-collaboration-channel`'s message shapes — Yjs sync and awareness; `stored {content_hash, state_vector, stored_at}` ≤ 2 s after the last update; test controls `POST /__mock/lock` (broadcast `mode {read_only, state: submitted}`, then answer each further update with `refused {code: LESSON_LOCKED, message, refused_from}`), `/__mock/unlock`, `/__mock/drop` (close sockets → client `DISCONNECTED`); an upgrade without the mock `ls_session` cookie is refused. Lets NL-63 prove SP-2's editor rule without NL-80.
**4. App frame.** `app/(app)/layout.tsx` on FW-3's AppShell: nav (Units, Unit board, Prompt guidance for authors; entries flagged by cut number in `src/features/frame/nav.ts` so a fired cut hides its entry), top bar with breadcrumb slot, name, role and **Sign out** (`signOut`). Session gate via `getSession` → `src/features/frame/session-context.tsx` (`useSession()` → `{ user, role }`); `src/lib/roles.ts` `can(role, action)` for presentation only (the server decides). Shared conventions (SCREEN_SPECS *Conventions*) in `src/features/frame/`: `CantLoad`, `NotFound`, `StaleBanner`, `ForbiddenBanner` (repeats the server's sentence, nothing changes), `RoleNote`, `DisabledReason`; `src/lib/use-poll.ts` (2 s cadence, stale after > 10 s of failures, data kept with its time, never moves focus); `src/lib/announce.tsx` (polite, debounced live region, design.md §5 rule 7); `src/lib/draft-memory.ts` (UXQ-1: typed dialog text survives a re-sign-in on the same page).
**5. Shells handed over** (each renders its frame and a placeholder; the named ticket owns the file afterwards): `src/features/start-run/start-run-dialog.tsx` `StartRunDialog({ outlineVersionId, open, onClose })` → NL-58 · `src/features/insert-quote/insert-quote-dialog.tsx` `InsertQuoteDialog({ lessonId, slotId, open, onClose })` → NL-65 · `src/features/resolve/resolve-dialog.tsx` `ResolveDialog({ lessonId, mode: "resolve" | "clear_flag", issueId?, flagId?, open, onClose })` → NL-66 · `src/features/send-back/send-back-dialog.tsx` `SendBackDialog({ lessonId, mode: "request_changes" | "reopen", pin, open, onClose })` → NL-69 · `src/features/assist/assist-panel.tsx` `AssistPanel({ lessonId, selection, onClose })` → NL-72 · `src/editor/lesson-editor.tsx` `LessonEditor({ lessonId, lesson, readOnly, onClientState })` → NL-63 · `src/features/workspace/actions/action-bar.tsx` `WorkspaceActionBar({ lesson, issues, clientState })` and `use-review-heartbeat.ts` `useReviewHeartbeat({ lessonId, versionId })` → NL-64.
**6. SCR-1 Sign in** (`app/sign-in/**`, `src/features/sign-in/**`): no app shell; the card per SCR-1 *Layout* with **Staff email** and a password field (CON-1 System choice: email + password on seeded accounts), **Sign in**, the staff note, and the demo-accounts `well` listing the three seeded roles (demo builds only). Landing: author → `/units`, reviewer and approver → `/units/g6-u4/board`, or a same-origin relative `next`.
Must not: call a route outside the OpenAPI, edit `docs/contracts/**`, render any string as HTML, or ship `mocks/**` / `test-utils/**` in a production bundle. New dependencies (`openapi-fetch`, `openapi-typescript`, `@stoplight/prism-cli`, `@hocuspocus/server`, `@hocuspocus/provider`, `yjs`, `@axe-core/playwright` if absent) go to the batch merge agent (A0 owns `apps/web/package.json`).
