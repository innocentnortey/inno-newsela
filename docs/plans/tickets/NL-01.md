### Story
Platform work, no US of its own: every other ticket builds inside this workspace, reads these settings and writes through this logger. Why it comes first: one A0 owner for every `package.json`, `tsconfig.json`, the root lockfile and the lint rules means no later ticket collides on them (Metz B2).

### What to build
**1. Workspace (DO-3 §1, Metz B2).** Root `package.json` (npm workspaces `apps/*`, `packages/*`, `evals`, `load`, `ops`; Node 24, npm 11), `tsconfig.base.json`, one root `package-lock.json`, root `eslint.config.js`, `vitest.workspace.ts`. Create `package.json` + `tsconfig.json` (extends base, `exports: {"./*": "./src/*.ts"}` subpaths, **no barrel `index.ts`**) for `apps/worker`, `apps/collab`, `packages/{schema,editor-schema,core,ydoc,db,llm,prompts,config,obs}`, `evals`, `load`, `ops`. Package names `@ls/<dir>`. Pinned dependencies per package from DO-3 §1: `zod`, `zod-to-json-schema`, `@noble/hashes` (schema); `prosemirror-model` (editor-schema); `xlsx` (SheetJS) and `compromise` (core, lint allow-list only); `yjs`, `y-prosemirror` (ydoc); `pg` (db); `@anthropic-ai/sdk` (llm); `@hocuspocus/server` (collab); dev: `typescript`, `vitest`, `eslint`, `eslint-plugin-boundaries`. `apps/web/package.json` and `tsconfig.json` are **not** touched here (NL-06 adopts them).
**2. Boundaries lint (DO-3 §1 arrows).** `packages/core` imports only `@ls/schema`, `@ls/editor-schema`, `xlsx`, `compromise` (never `pg`, `@anthropic-ai/sdk`, `yjs`, `@hocuspocus/*`, `next`, `node:http`); `packages/{db,llm,ydoc}` import `core` port types and their one library; no app imports another app; no package imports an app. A second rule bans `dangerouslySetInnerHTML` and `innerHTML =` in `apps/web` (R-58).
**3. Root scripts (DO-3 §9).** Every name there exists in root `package.json` (`lint`, `typecheck`, `test`, `test:e2e`, `db:migrate`, `db:seed`, `schemas:emit`, `eval:golden`, `eval:grounding`, `eval:faults`, `eval:full-run`, `eval:seed`, `eval:heldout`, `eval:judge-calibrate`, `load:spike`, `ops:backup`, `dev`). One whose target file does not exist yet exits 2 with `NOT BUILT: owned by NL-<n>` (never a silent 0).
**4. `packages/config` (DO-3 §7, DO-4 §9).** Zod over `process.env`: `SharedSettings`, `ModelSettings`, `SpendSettings`, `WebSettings`, `WorkerSettings`, `CollabSettings`, loaded by `load_web_settings(env)`, `load_worker_settings(env)`, `load_collab_settings(env)`. Defaults are the SP-1 values in the DO-3 §7 table (e.g. `MODEL_GENERATION_ID=claude-sonnet-5-5`, `MODEL_EFFORT=low`, `MODEL_CALL_TIMEOUT_MS=240000`, `DRAFT_OUTPUT_TOKEN_CAP=32000`, `TRUNCATION_RETRY_TOKEN_CAP=48000`, `GENERATION_CONCURRENCY=6`, `RUN_CAP_DEFAULT_USD=13.00`, `BUILD_SPEND_CEILING_USD=75`). A missing or malformed value throws `ConfigError{variable, problem}` naming the variable, never its value. Secrets are `SecretStr` (redacts in `toString`, `toJSON`, `util.inspect`). Collab loads with no model or spend settings and no provider key (Metz S4); `ANTHROPIC_API_KEY` is required only when `MODEL_PROVIDER_MODE=real`; `WORKER_ID` defaults to `<hostname>-<pid>`.
**5. `packages/obs`.** `Logger` (DO-4 §9): one JSON line per call with `ts`, `level`, `event`, `service`, `build_id` and any of `request_id`, `run_id`, `lesson_id`, `job_id`, `store_id`, `duration_ms`; `extra` takes ids, counts and codes (a string over 120 characters is replaced by `[omitted: too long]`); `SecretStr` prints `[redacted]`. `resolve_build_id(env, git)`: `RENDER_GIT_COMMIT`, else `git rev-parse --short HEAD`, else `dev`.
**6. Root files.** `docker-compose.yml` with the `postgres:16` service only (no `ports`, WF-38/OBS-10) and `docker-compose.test.yml` adding `127.0.0.1:55434:5432` for local tests (`TEST_DATABASE_URL` default `postgres://ls:ls_dev_only@127.0.0.1:55434/ls_test`); append to `.gitignore` (`.env`, `node_modules`, `.next`, `evals/local/`, keep every existing line).
Must not: add a barrel file, touch `apps/web/{package.json,tsconfig.json}` or FW files, write DDL (NL-08), store a key in any file, or add a setting not in DO-3 §7.
