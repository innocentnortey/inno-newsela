### Story
US-25 — As an approver (P-3) I need to approve one pinned version, so that "approved" means a named person approved exactly that text. Platform work: the live document is a Y.Doc, the stored copy is JSON with a hash, and Submit must prove the stored state covers what the submitter holds. This package is the only place that crosses between them (HP-4, SP-2).

### What to build
`packages/ydoc/src/` (A5; the one place that imports `yjs` and `y-prosemirror` besides the editor and collab).
**`convert.ts`.** `lesson_to_ydoc(lesson: StoredLesson): YDocBytes`: a Y.Doc with `front_matter` (a `Y.Map`: title, type, standards, vocabulary, `minutes_total`, `text_cards`, `schema_version`), an ordered `Y.Array` `section_order` of section addresses, a `Y.Map` `section_meta` (name, minutes per address) and one `Y.XmlFragment` per section named `section:<address>` filled by `y-prosemirror` from the section's ProseMirror JSON. A fixed client id makes two conversions of one lesson byte-identical. `ydoc_to_lesson(data: YDocBytes, schema_version: number): StoredLesson` reads it back, runs `assert_known_nodes` first (an unknown node or mark raises `SchemaUnknownError`; a `schema_version` other than 1 raises; nothing is dropped) and normalises each section through `EDITOR_SCHEMA.nodeFromJSON(…).toJSON()` so null and default attributes are explicit.
**`hash.ts`.** Re-exports `content_hash` from `@ls/schema/content-hash` (the same function object: G-29) and adds `state_vector_of(data): StateVector` (base64 of `Y.encodeStateVector`) and `covers(stored: StateVector, client: StateVector): boolean` (true when, for every client id in `client`, `stored`'s clock is at least `client`'s; a client id absent from `stored` with a clock above 0 is not covered). A malformed base64 vector throws `StateVectorError`.
Must not: reorder, rewrite or drop content, use a random client id when seeding, define its own hash, or import `@ls/core` or a driver.
