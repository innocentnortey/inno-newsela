### What to build
All in `packages/schema/src/` (Zod; A2 owns `packages/schema/**` except `api/**` (NL-11) and `package.json` (NL-01)).
**`ids.ts`.** One validated string type per DO-4 §2 identifier, one regex each, never built inline: `UnitId` `^G\d{1,2}\.U\d{1,2}$`; `LessonId` `^G\d{1,2}\.U\d{1,2}\.(L\d{1,3}|FLEX-\d{1,2}[a-z]?)$`; `OutlineVersionId` `^G\d{1,2}\.U\d{1,2}\.ov\d+$`; prefixed ids `<prefix>_<26-char ULID>` for `usr run job mc lv st iss sug sr ae ov exp ev pr ops` (`IdPrefix`); `RequestId` `req_…` or the client's `[A-Za-z0-9_.-]{1,64}`; `Sha256` 64 lowercase hex; `StateVector` base64.
**`outline.ts`.** `NormalizedOutline`, `NormalizedRow`, `SegmentRecord`, `UnitRuleRecord`, `IntakeFinding`, `OutlineCounts` (DO-4 §8 intake) and, because NL-15…17 depend only on this ticket, the three intake records `OutlineVersionRow`, `IntakeChoiceRow`, `LessonLinkRecord` (DO-4 §3.5); NL-12's `ports/outlines.ts` re-exports them, never redefines them.
**`unit-plan.ts`.** `UnitPlanDraft` / `UnitPlanEntryDraft`: ≥ 1 entry, unique `lesson_id`, `day ≥ 1`.
**`lesson-draft.ts`.** `LessonDraft`, `DraftBlock`, `CfuItemDraft`, `TextCardRecord`. `DraftBlock.role` is exactly the 15 roles of DO-4 §8 and **has no `quote`** (HP-2). A `cfu_item` block carries `cfu` with `key_index` inside `options` and one rationale per option; every other role has `cfu: null`. Also `zod_issue_paths(error): string[]` (paths only, e.g. `blocks[3].role`, never values: feeds `ModelOutputInvalid.issues` and `RepairPromptInput.schema_issues`).
**`lesson.ts`.** `StoredLesson`, `FrontMatterRecord`; `sections[].content` is a **structural ProseMirror JSON type** (object with string `type`, optional `attrs`, `content`, `marks`, `text`; root `type: "doc"`), so this package does not import `@ls/editor-schema` (DO-3 follow-up 1). `schema_version` int ≥ 1.
**`content-hash.ts`.** `content_hash(lesson: StoredLesson): Sha256`: SHA-256 (`@noble/hashes`) of canonical JSON (keys sorted recursively, no whitespace, array order kept, UTF-8); the one function the compiler (NL-18) and `@ls/ydoc` (NL-19) share (G-29).
**`export.ts`.** `ExportBundleFile`, `ExportedLessonRecord` (`export_version` literal `1`).
**`scripts/emit-json-schemas.ts`.** `emit_json_schemas(out_dir): EmittedSchema[]` writes `outline.schema.json`, `unit-plan.schema.json`, `lesson-draft.schema.json`, `lesson.schema.json` to `docs/contracts/schemas/` and the export schema to `docs/contracts/lesson-export.schema.json`; deterministic bytes; `npm run schemas:emit`.
Must not: define a `quote` role, import `@ls/editor-schema`, `@ls/core` or a driver, or edit `api/**`.
