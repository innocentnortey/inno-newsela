### Story

### What to build
`packages/editor-schema/src/schema.ts` (A2; depends on `prosemirror-model` only).
**Nodes (the allow-list, R-11, R-58).** From Newsela's own schema (`docs/source/04-lesson-structure-analysis.md` §2): `doc`, `paragraph` (attr `align` null or `center`), `text`, `heading` (attr `level` 1–5), `bullet_list`, `ordered_list` (attrs `order`, `type` `A` for lettered choices), `list_item`, `table`, `table_row`, `table_cell` (`colspan`, `rowspan`, `colwidth`), `table_header`, `routine_heading` (attr `icon` ∈ `cfu notes_section writing graphic_organizer academic_discussion personal_dictionary reading`), `callout` (attr `variant` ∈ `purpose say watch`), `collapsible` (attr `label`), `hard_break`. Lesson Studio additions: `teacher_tip` (teacher-only block, HP-9, attr `safety_note_id` nullable), `quote_placeholder` (attrs `slot_id`, `reason`) and `excerpt_slot` (attrs `slot_id`, `rights` ∈ `unset public-domain Newsela-owned licensed to-clear short-quote-commentary`, `source_ref` nullable). **Marks:** `strong`, `em`, `teacher_talk`, `sample_response` (roles, not colours; a render step maps role to colour).
**API.** `SCHEMA_VERSION = 1`; `EDITOR_SCHEMA` (the `prosemirror-model` `Schema`); `assert_known_nodes(doc: ProseMirrorDoc, schema_version: number): NodeCheck{ok, node_count, schema_version}` walks the JSON and raises `SchemaUnknownError{lesson_id: null, schema_version, unknown_nodes}` for any node or mark name outside the list, or any `schema_version` other than 1; it never drops or rewrites a node. Callers (NL-18 compile, `LessonReadService`) catch it and re-raise with the lesson id via `.with_lesson_id(id)`. The error class lives here (core imports editor-schema; NL-12's `errors.ts` re-exports it).
Must not: add a node for a role colour, import `@ls/core`, `@ls/schema` or Yjs, or relax the guard to "drop and continue". A new node is a `SCHEMA_VERSION` bump with a re-compile from stored drafts (no model call).
