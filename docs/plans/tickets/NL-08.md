### What to build
**1. All DDL (DO-3 §6; Metz A1 rule).** The column lists include the §7b additions `lesson_job.reviewer_note` (text, null) and `model_call.retries` (int, not null, default 0) (DO-4 §13 R-15, R-16). `packages/db/migrations/0000_migrations.sql` … `0012_evidence.sql`, one file per row of the DDL-file column: `0000` `schema_migrations`; `0001_identity` `app_user`, `app_session`; `0002_intake` `unit`, `outline_version`, `outline_row`, `intake_choice`, `standard`, `lesson_link`; `0003_prompts` `prompt_version`; `0004_runs` `run`, `unit_plan`, `lesson_job`, `spend_reservation`; `0005_traces` `model_call`; `0006_lessons` `lesson`, `lesson_version`, `lesson_doc`; `0007_checks` `check_job`, `issue`, `alignment_link`, `safety_flag`; `0008_review` `suggestion`, `review_event`, `audit_event` and the view `audit_log_v`; `0009_metrics` `heartbeat`, `review_session`, `lesson_metrics`; `0010_exports` `export_bundle`; `0011_judge` `judge_verdict`; `0012_evidence` `eval_run`, `eval_case_result`, `probe_run`, `experiment_run`, `ops_event`. That is 35 tables and one view. Columns: every key column in DO-3 §6 plus every field of the matching row record in DO-4 §3.4–§3.5 (snake_case, same names). Money columns (`*_usd`) are `numeric(12,6)`; times are `timestamptz`; ids are `text`. Credentials hold hashes only (`password_hash`, `token_hash`).
**2. Constraints.** `app_user.email` unique on `lower(email)`; `app_session.token_hash` unique; `outline_row (outline_version_id, row_number)` key; `lesson_doc (lesson_id, seq)` key; `lesson_metrics.lesson_id` key (one row per lesson); `lesson_version.idempotency_key` unique (HP-7 mechanic 3); `run (started_by, idempotency_key)` unique (the 24 h window is the service's, CON-5); partial unique index on `lesson_job (lesson_id)` where `kind='candidate'` and `status in ('queued','running')` (CON-16); partial unique index on `check_job (lesson_id)` where `status='queued'` (coalescing).
**3. Append-only triggers (R-35).** `review_event`, `audit_event` and `lesson_metrics` reject every `UPDATE` and `DELETE` (`raise exception 'append-only: <table>'`). `lesson_version` rejects `DELETE` and any `UPDATE` of its content columns (`content_hash`, `state_vector`, `lesson_json`, `draft_json`, `provenance_json`, `dependency_record_json`); `adopted` may change `false → true` once (CON-16). `audit_log_v` unions `review_event` and `audit_event` (`at`, `source`, `lesson_id`, `actor_id`, `actor_name` via `app_user`, `action` (`lesson.transition` for review events), `from_state`, `to_state`, `version_hash`, `reason`) ordered by `at`; CON-19 reads it (NL-44).
**4. Code.** `src/pool.ts` + `src/tx.ts`: `PgDatabase(settings, pool_max, acquire_timeout_ms)` with `with_tx(fn, advisory_lock)` (commit on return, rollback on throw, `pg_advisory_xact_lock(hashtext(key))` when a key is given), `ping()`, `close()`; no free connection within the acquire timeout throws `PoolExhausted{pool, waited_ms}` (class in `src/pool-exhausted.ts`; NL-13 maps it to `SERVICE_BUSY`). `src/migrate.ts` `run_migrations(db): MigrationReport{applied, already_applied}`: files in name order, each in its own transaction, a row in `schema_migrations{id, checksum (sha256 of the file), applied_at}` and one `ops_event` row via `src/ops-event.ts` `record_ops_event(db|tx, {kind, service, build_id, details})` (default id `ops_<uuid>`; NL-12's generator replaces it where repositories mint ids). `ops/migrate.ts` is the `npm run db:migrate` entry point. A changed checksum of an applied file throws `MigrationError{migration_id, problem}`.
Must not: seed rows (NL-82), write a repository (their tickets), add a column "for later", expose a SQL view that joins `review_session` or `heartbeat` to a person, or import `@ls/core` (arrows: db depends on core's port types only, and none exist until NL-12).
