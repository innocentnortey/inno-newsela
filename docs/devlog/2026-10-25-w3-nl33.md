# NL-33: ModelCallRecorder, PaidCaller, PgModelCallLog (2026-10-25)

**Changed.** Added `packages/llm/src/{recorder,paid-call}.ts`, `packages/db/src/repos/model-calls.ts` (own transaction per method, optional `record_retry`), `tests/platform/model-call-capture.test.ts`; `decimal.js` 10.6.0 in the llm and db manifests.

**Checked.** eslint, typecheck, llm + db repo + capture + boundaries-lint tests green (37). Unpriced served model: raw output saved at cost 0, then InvariantViolation.

**Remaining.** `job_ids_with_calls(run_id)` (NL-30) is not added: it would change the NL-12 port and break the frozen `MemoryModelCallLog`; request to the port owner.

## Security-review fixes
- **Changed:** `PaidCaller` no longer releases once the provider call has completed: settle is retried 3 times, then the reservation stays held, `spend.settle_failed` is logged (ids only) and the error rethrown. Release happens only when no call completed. Root eslint now forbids `@ls/llm/recorder` and `@ls/llm/anthropic` (and relative paths) outside `packages/llm/src`, wiring/container/main files and tests; `tests/platform/paid-call-bypass-lint.test.ts` plants the bypass.
- **Accepted:** one reservation covers up to 1+PROVIDER_MAX_RETRIES sends, bounded by the retry count and run cap; overshoot is logged.
- **Noted:** `model_call.cost_usd` is 0 for unpriced calls while the ledger settles at the reserved max.
