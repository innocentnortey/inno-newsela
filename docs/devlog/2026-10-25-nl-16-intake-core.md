# 2026-10-25 NL-16 intake core (W2)

- **Changed:** `packages/core/src/intake/` now parses CSV/XLSX (`parse_workbook`), normalizes the outline (`normalize_outline`), computes lesson links and holds the instruction and safety pattern sets. Fixtures are built by `packages/core/scripts/build-outline-fixtures.ts`. `xlsx` 0.18.5 is replaced by SheetJS 0.20.3 from the SheetJS CDN (tarball URL with integrity hash in the single root lockfile); `npm audit --omit=dev` reports 0 vulnerabilities; the import name is unchanged, so no lint allowlist edit was needed.
- **Why:** NL-16; NL-01's security review flagged xlsx 0.18.5 (CVE-2023-30533, CVE-2024-22363).
- **Untrusted-upload mitigations:** byte cap before any parse; magic-byte sniff; zip central directory checked by declared sizes before inflating; `cellFormula`, `cellHTML`, `bookVBA` off; `__proto__`/`constructor`/`prototype` sheet names refused and header lookup uses a `Map`; declared-range, row, column, cell-count and cell-length caps; errors carry a reason word and numbers, never cell text; nothing logs.
- **Approved open items:** (1) supporting-standards codes are checked (findings) but `NormalizedRow` has no field for them; (2) info-only kinds (`non_breaking_space`, `eld_not_checked`) use level `ok` and are not counted in `warnings`; (3) "7 ELD mismatches" means 7 distinct sheet ELD codes; (4) `to_slot_id` values (`<lesson_id>.excerpt-1`, `<lesson_id>.pages`) are placeholders; (5) editor-note detection is heuristic (`NOTE_LINE` plus the vocabulary-column rule), so no count is asserted.
- **Deviations:** the issued JSON holds only the total row's formula (`=SUM(E4:E56)`), and SYN-2's total row is blank, so no cell text could mark it. The fixture builder writes the formula's displayed value (47.0) into the Days cell of row 57, and the SYN-2 loader appends the same row (the parser drops trailing blank rows). Standards double: `SL.6.4` has the leaf `a` (California addition, `docs/source/05-standards-referenced.md`), which gives exactly 3 non-existent-code rows (30, 34, 39).
- **For NL-26:** re-raise `IntakeError` as `DomainRefusal` with the same `code` and `details`; re-assert the 3 and 7 counts against the real StandardsIndex.
- **Checked:** `npm run lint`, `npm run typecheck`, `npx vitest run packages/core/src/intake`, tamper check on the frozen files, `npm audit --omit=dev`, `npm ci --dry-run`.
- **Remaining:** `npm ci` fetches xlsx from cdn.sheetjs.com (integrity-pinned, not availability-pinned); vendor the tarball later if CI or the Render build must not depend on that host.
