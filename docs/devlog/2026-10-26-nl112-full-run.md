2. **Driver sends no `Origin` header**, so sign-in answers 401 `UNAUTHENTICATED` (the web app checks Origin against `APP_ORIGIN`). I ran the driver through a /tmp wrapper that adds the header; repo code is unchanged.
3. **Driver never confirms the unit-conflict finding** (`unit.finding`, kind `unit_conflict`), so `POST /runs` returned 422 `VALIDATION_INCOMPLETE`. The wrapper confirmed it with the stored default (`U4`) before the start. Each driver start also uploads a new outline version (ov1 to ov4 exist); only one run row exists.
