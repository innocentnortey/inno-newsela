## How to read this

**Example.** Row M-1 is the north star. Lesson 4 is open in reviewer A's focused tab for 14 active minutes, then in
approver B's for 9; at B's first approval the server writes 23 into that lesson's frozen metrics row. M-1 is the
median of those values over the unit's approved Reading lessons, shown with *n* and the p90. If the median is above
60 minutes, the decision column says what to read next (M-8 edit distance by section, M-6 and M-7 block types).

**What the registry holds.** Every number the product, the eval plan (DO-5) or the observability contract (DO-6)
reports, with one formula and one denominator each. The framing doc's tree is the **headline set** (M-1…M-20, same
order and meaning); M-21…M-29 are capacity and spend metrics added for PD-33, PD-14 and PD-29; M-30…M-44 are the
eval-plan metrics each HP card and suite reports against. Value (M-1…M-14) and health (M-15…M-29) are separate groups
(GP-132); the *Unit quality* page shows the value group, the health tab the rest.

**Fixed id mapping** (DO-6 already cites it): NS → M-1, G-1 → M-2, G-2 → M-3, G-3 → M-4, V-1 → M-5, V-2 → M-6,
V-3 → M-7, V-4 → M-8, V-5 → M-9, V-6 → M-10, O-1 → M-11, O-2 → M-12, O-3 → M-13, O-4 → M-14, H-1 → M-15,
H-2 → M-16, H-3 → M-17, H-4 → M-18, H-5 → M-19, H-6 → M-20. Every framing metric exists; none is missing.

**Sources** name Postgres tables by their working names, shared with DO-6: `run`, `lesson_job`, `model_call`,
`lesson_version`, `check_result`, `alignment_link`, `review_event` (the append-only transition log, R-35),
`heartbeat` and `review_session` (R-49), `lesson_metrics` (the frozen per-lesson row written once at first approval),
`seeded_error`, `ai_assist_event`, `judge_label`, `judge_verdict`, `safety_flag`, `outline_version`, `load_test_run`.
DO-3 (code design) owns the final schema; a rename there updates this column in the same change.

**Labels.** `[T]` target, adopted under PD-1 and PD-32 (framing §3); `[A] → SP-N` a number the named spike replaces
with a measurement; `[M]` measured; `[C]` calculated. *Baseline* for every metric is honest: no Newsela review-time
baseline exists (AQ-14), so most read "none yet" with the run that sets it. Segments with fewer than 3 reviewers are
labelled, and no metric is ever shown per named person (E-4, GR-15).
