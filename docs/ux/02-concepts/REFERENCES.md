# References — Newsela Lesson Studio (UX-2)

**Owner of:** the reference shots behind each design direction. **Captured:** 2026-10-25, live on dribbble.com in an
isolated Chrome DevTools context, from the [feel brief](FEEL_BRIEF.md)'s search terms (16 searches, 371 unique shots;
[full search record](references/dribbble-search-2026-10-25.json)). **Internal reference only:** these are other
designers' work; they are credited here and never copied into the product. Mobbin and Refero were not used: no account
of Innocent's is set up for this project (ux-pipeline `references/tooling.md` → *Reference sources*).

**What the sweep showed.** Searching by feel and pattern instead of by industry returned modern document-review,
approval, triage and import screens, with almost no dated ed-tech. The four families that stood out became the four
directions in [`DESIGN-DIRECTIONS.md`](../../design/DESIGN-DIRECTIONS.md).
